# 模型测试

专门归档**模型验证/物理效应测试**的产物：测试脚本、数据（CSV/log）、截图/趋势图。

## 归档约定

- 每次正式测试建一个 `<测试名>_<日期>/` 子文件夹，里面放：
  - 测试脚本（可重复跑的 `.py`，脚本内注明场景/方法/还原语义）
  - 原始数据（`.csv`）与运行日志（`.log`）
  - 结果截图 / 趋势图（`.png`）
- 这里是**归档区**：Temp/ 是工作区（可被清理），测试确认有效后把产物
  **复制**到此处归档；Temp 原件去留不限。
- 归档截图/数据以模型实际输出为准，不手工修饰；解读写进
  `backend/开发交接.md` 对应迭代条目。
