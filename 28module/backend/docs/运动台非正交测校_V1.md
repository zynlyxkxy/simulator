## 1. 测的是什么

**定义**：运动台 Y 导轨实际方向 ê_y 相对 X 导轨实际方向（基准轴，X 不做
注入、视为基准）的偏角 φ（rad，µrad 级）——一阶真值矩阵
`A=[[1+εx, sinφ],[0,(1+εy)·cosφ]]` 的 φ，与机器常数
`stage_geo.as/ws_y_rail_dir_urad`（FK 真值注入旋钮）同语义
（`machine_constants.json:144-150`、`error_kinematics.py:50-56`）。配套
输出四组同源量：

- **非正交角 φ**（X 基准；`ref_axis="y"` 时报告其负值，交叉核对用）；
- **比例误差 εx/εy**（actual=指令×(1+ε)，ppm 级——基准尺节距信任下的
  轴步进比例；含相机像元当量误差别名，见 §7.6）；
- **物理↔逻辑双向矩阵** `matrix_l2p`（逻辑指令→物理实际 ≡ 规范 A）/
  `matrix_p2l`（=inv，补偿前馈 ≡ 规范 C）——全 2×2 实测像，列模长=ε、
  列方向=线方向角；
- **规范标量** EXY（=−X 基准 φ，夹角>90° 为正）、β（=ρ̄ 栅格/上板安装
  旋转）、附录 D 标准/扩展不确定度 u/U(k=2)。

另有两个**诊断角**（µrad 小数值）：θ_x=轴-栅格角（X 轴实际方向 vs 栅格
X 方向）与 θ_y−90°=wrap(φ−ρ̂)（Y 轴对称的轴-栅格角偏差），锚定关系
wrap(θ_y−θ_x)=φ 与机器常数语义一致。线法向残差 RMS/MAX（nm）是导轨
直线度弓形/高阶场的诊断通道（设计文档 §1 的 LUT 触发判据原材料）。

**方法一句话**：以晶圆 die 阵列为正交基准尺，X/Y 两线**十字对称跳测**
（中心±(K−1)/2 步、走距=格点节距），逐节点视觉识别得"标记相对相机光轴
的世界偏移" o_i，对步号拟合斜率后按**横向/沿轨分量**分解出角与比例。

## 2. 算法推导（栅格跳测法·十字对称轨迹）

实现：`metrology/stage_nonortho.py`（模块 docstring :1-126 是设计备忘；
主流程 `run_stage_nonortho` :261-697；核心拟合 `fit_nonortho` :194-240，
**纯函数可独立调用**）。输入已由 `calibration.start` 校验规范化
（`_validate_stage_nonortho`，`runtime/calibration.py:755-894`，见 §8.1）。

### 2.1 基准尺与物理前提

- **基准尺** = 晶圆 die 阵列：处方 `wafer_sites` 格点（默认 auto：
  pitch=size+gap=10+0.005=**10.005mm**，`recipe.py:89-94`）+ 每 site 的
  `site_marks`（quad 150µm，ratio ±0.76×site 半宽 → 默认 ±3.8mm 四角，
  `recipe.py:79-82`），**假定严格正交**。标记只存在于格点 → **走距必须
  =格点节距**：start 校验 pitch_mm 与处方 pitch_x/pitch_y 一致（容差
  0.001mm，不一致 400 报实际值，`calibration.py:841-857`）。
- **相位复现**：相邻节点走距恒=节距 → 逐节点观测的是**相邻 site 的同一
  相对角**，标记以同一相对位置进出 1.8mm 画幅——因此**中心必须对准某
  quad 角**（先点动居中再 start；缺省 center_xy=两轴当前位）。
- **十字对称**：K 须奇数（3,5,…,21，默认 5；偶数→400，
  `calibration.py:823-828`），X/Y 两线共中心，节点=
  center+(i−(K−1)/2)·pitch，i=0..K−1 **单调升序**（单侧逼近，消反向
  间隙友好），跨距=(K−1)×pitch（默认 4×10.005≈40mm）。

### 2.2 现场记录与每循环时序

作业启动（`stage_nonortho.py:287-298`）：记录两走位轴位（finally 恢复
用）；运行期 `_check_marks` 兜底（:293，start 已拦）；视觉切 REAL、点灯
（:403-406）。每循环 i=1..repeat：

```
_check_cancel（:408，协作取消，循环边界生效）
Y→center_y、X→center_x → wait（:409-411）
X 线（_scan_line :360-383）：X 逐节点走 center_x+(i−half)·pitch
    → wait → _snap_node（:372，见 2.3）→ 进度逐节点推进（:374-377，
    total=repeat×2×K，:396）；走完 X 回 center_x（:381）
Y 线同（Y 走、X 恒 center_y）
fit_nonortho(ox_seq, oy_seq, pitch, σ)（:416，见 2.4/2.5）
逐循环落：phi_rep/θ_x/θ_y/ρ/ψ_y（:421-435）、法向残差 RMS/MAX
    （:436-440）、nodes CSV 行（:445-469）、末循环 series 散点/拟合
    （:470-484）、主 CSV 行（:485-490）
```

finally：两走位轴回作业前位、恢复光源与视觉模式（:498-512）——cancel/
error 同样执行。

### 2.3 节点测量：fpp 帧最近峰 + 世界偏移 o_i

`_snap_node`（:300-358）：每节点 `frames_per_point`（fpp，默认 3）帧
identify，**逐帧取距画幅中心最近的有效峰**（score≥`cam.score_threshold`；
同 site 4 角互距≥5.2mm、默认 1.8mm FOV 内唯一，小 site 多角入幅时最近峰
防串；全部低于阈值→CalibError 带相位/节点号，:320-330），fpp 帧均值得
(col,row)——**逐帧原始坐标同时保留**（info.frames，规范 5.3 单帧保存，
进 nodes CSV 末两列）。

像素→世界偏移走 `_context` 链（`metrology/repeatability.py:99-132`）：

```
cam_pos    = camera_pose（含运动台实际位姿）
mark_world = cam.solve_pixel(col, row, cam_pos)
    # solve_rel：先按 dir_x/dir_y/swap_xy 反映射、再按 +rot_mrad（控制器
    # 认知）反旋——迭代 38 真值/认知分离后的反算链
o = mark_world − cam_world        # stage_nonortho.py:343
```

o_i 是**标记相对相机光轴的世界偏移**（画幅中心即光轴）：WS 台动=标记动
（σ=+1）、AS 台动=相机反向动（σ=−1），相对运动同式，σ 并入斜率修正
（:277, :220-221）。**mark_world 记录口径（迭代 44 修，ws/as 分列，
:344-352）**：ws 例行记 **WS_LS 读数位+o**（台基准实测位置链——真机
"编码器读数+视觉残差"日志同口径，随台步进 ~pitch；旧 cam_world+o 口径在
相机固定+跳测换标记下逐节点恒为常数、无分析价值，迭代 44 前数据作废）；
as 例行记 **cam_world+o**（相机随对准台动，cam_world 即对准台坐标推出，
"对准台结合像素"语义，天然逐节点变化）。两口径的像素反算都含 rot_mrad
控制器认知+dir/swap。**拟合链只消费 o_i（相对光轴偏移），与 mark_world
绝对值无关**——迭代 44 前的测校结果仍有效，仅过程数据列口径变了。

### 2.4 斜率拟合与横向/沿轨分量分解（弦模型）

两线 o_i 序列各自对步号 i 最小二乘（`_fit_slope` :172-191）：
`o = ō + s·(i−ī)`，法向残差=各点到拟合线的距离（mm，×1e6=nm）。相邻
节点观测标记换为相邻 site 同角 → **斜率=台步进向量−栅格步向量**（弦差，
迭代 42b 钉死的 o 语义）。设 s'=σ·s，p=pitch，ρ=栅格安装旋转（上片旋转
的显现通道，实测口径 β=ρ̂≈−load_rz，见 §4.2/§7.4），φ_t=Y 导轨真值
方向角，εx/εy=轴比例误差（actual=指令×(1+ε)）：

```
X 线  s_x' = p·((1+εx) − cosρ,              −sinρ             )
Y 线  s_y' = p·((1+εy)·sinφ_t + sinρ,  (1+εy)·cosφ_t − cosρ  )
```

分解（`fit_nonortho` :218-240；**一律横向/沿轨分量**——不用斜率方向/
大小整体读出：沿轨比例项会混进方向读出，εx>100µrad 时旧方向读出把 ρ̂
误判 π/2 致 φ 崩；且旧方向读出对真实栅格旋转带弦模型 ρ/2 隐性偏差，
真机带旋转上片会报幻影 φ——两坑均迭代 42b 修）：

```
ρ̂   = −asin(clamp(s_x'·ŷ / p))    X 线横向分量（弦模型精确）；
      |s_x'·ŷ| < _RHO_MIN_SIN·p（1e-4，100µrad 等效噪声地板）判 0
      ——比例项在沿轨分量，不触发误判（:145-151, :223-226）
ψ_y =  asin(clamp(s_y'·x̂ / p))    Y 线横向分量 ≈ sin(φ_t+ρ)
      （εy·sinφ_t 二阶可忽略；符号自带，:228）
φ   = wrap(ψ_y − ρ̂)               X 基准非正交角——ρ̂ 在差中消去，
                                    栅格整体安装旋转不影响测量（:229）
θ_x = −ρ̂                          轴-栅格角
θ_y = wrap(φ − ρ̂)                 偏差口径（GUI 标签"θ_y−90°"）；
                                    锚定 wrap(θ_y−θ_x)=φ（:237）
```

### 2.5 比例误差分离与物理↔逻辑双向矩阵

**步进向量恢复**（加回栅格步，:231-232）：

```
v_line = s' + p·R(ρ̂)·e_line        e_x=x̂、e_y=ŷ
弦模型下精确：v_x = p(1+εx)x̂，v_y = p(1+εy)ê_y
ε_line = |v_line|/p − 1            沿轨分量给比例（:238-239）
```

**作业级双向矩阵**（:551-578；恒 X 基准，不随 ref_axis 变；9 位有效数字
`_sig9` :162-164）：

```
v̄_line = σ 修正斜率的 repeat 均值 + p·R(ρ̄)e_line
M_l2p = [col_x | col_y]，col_line = v̄_line/pitch    逻辑基向量的实测像
        列模长=ε（scale_x/scale_y 同源，:558-559）、列方向=线方向角
M_p2l = inv(M_l2p)                                  补偿前馈
ac_check_norm = ‖M_l2p·M_p2l − I‖ 最大元（规范 6.4 数值核验，用未舍入
        原值，双精度应 <1e-12，:566-575；实测 8.5e-22）
det 退化（|det|≤1e-12）兜底 M_p2l=I、ac=None（:576-578，防御——物理上
        det≈1）
```

X 线方向**不再强制贴逻辑 X**——旧 [[1,sinφ],[0,cosφ]] 是本全矩阵 ε=1 且
col_x 横向置零的退化特例（迭代 39 口径，迭代 42b 升级）。与参考脚本
`grating_and_interferometer_parallel_NO_error_PCA.py` 的正向/逆向矩阵
同族（其 matrix[0][0]=a/[1][1]=d ≡ 本矩阵列模长口径）。

### 2.6 报告口径、统计与规范标量

- **ref_axis**：x（默认）报告 φ；y 报告 wrap(θ_x−θ_y)=**−φ**（交叉核对；
  :428-429）。`<pfx>nonortho_urad`（apply 写回键）**恒为 X 基准值**，不随
  ref_axis 变（:604-608）。φ 符号锚定：FK 注入 `*_y_rail_dir_urad=φ_t`
  时 X 基准实测 φ≈+φ_t、Y 基准≈−φ_t（:59-61）。
- **统计**：repeat 轮 φ 序列 → mean/std（`_mean_std`，总体 ddof=0，
  `repeatability.py:186-191`）/3σ；逐轮 θ_x/θ_y/ρ/ψ_y 同取均值
  （:537-542）。measured.phi_urad/phi_std_urad/phi_3sigma_urad 用报告
  口径（ref_axis）序列；std/3σ 对符号翻转不变。
- **规范标量（迭代 45）**：exy_urad=−X 基准 φ（规范式 4：EXY=γ−90°，
  夹角>90° 为正——矩阵层面 M_l2p≡规范 A、M_p2l≡C 完全一致，仅标量角
  符号口径相反，:631）；beta_urad=ρ̄（规范上板倾斜 β 同义，9.1 报告
  要素，:632）。
- **附录 D 不确定度**（:581-591）：

  ```
  u_meas = 线法向残差 RMS（两线合并全循环，mm——含直线度系统项，偏保守）
  Sxx    = p²·K(K²−1)/12                    （式 D.2，步号离差平方和×p²）
  u(E_XY)= √2·u_meas/√Sxx                   （式 D.4，两线独立斜率差）
  U      = 2u                               （式 D.6，k=2）
  rms=0 或 K<3 → exy_u/exy_U = None
  ```

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 晶圆已上片（`POST /api/workpiece/wafer`；本 routine 无显式上片校验
   ——由**视野标记检查**兜底：start 即 `_check_marks`，无标记→400
   "先上片/取 die"，`calibration.py:891-893`、`repeatability.py:55-66`）。
   **测校基线建议 0 偏置上片**（面板"0 偏置上片"钮，迭代 46 起）——
   上片旋转 <100µrad 会混叠进 φ（§7.4）。
2. 视觉链路 cv2 可用（REAL 必需；start 统一拦，`calibration.py:289-291`）。
3. **无工艺流程在跑**：工艺流程 running/paused、全片键合、一键串联 →
   400（`calibration.py:808-822`）。
4. 处方已挂（pitch 事实源；未挂→400，`calibration.py:830-831`）。
5. 模板已在视觉页注册（下相机 REAL 模板；site quad 150µm 小标记，
   中心对某 quad 角居中建模板）。

### 3.2 示教与参数选取

1. **选中心**：点动走位台（ws：WS_LS_X/Y；as：AS_X/Y）把某 site 的一个
   quad 角居到下相机视场中心（可用 `GET /api/vision/guide?cam=down`
   引导）——该中心即十字原点；相位复现保证各节点同一相对角入画幅
   （§2.1）。center_xy 缺省=当前两轴位，**推荐先对准再 start、不显式
   传 center_xy**（start 与运行期两道 _check_marks 都在作业启动位
   检查）。
2. **K 与跨距**：K=5（默认）跨距 40mm@10.005；规范 5.3 建议每线 ≥11
   点（不确定度 ∝1/(p·K^1.5)，§7.3）——K=11 跨距 100mm，注意行程
   守卫（center±(K−1)/2·pitch 两端须在走位轴软限位内，
   `calibration.py:879-889`）。

5. **ref_axis**：默认 x（与机器常数/写回键同语义）；y 输出负值，交叉

### 4.1 注入 φ_t=+200µrad：单循环分解逐步

真值：`ws_y_rail_dir_urad=200`（ê_y=(sinφ_t, cosφ_t)），0 偏置上片
（ρ=0），εx=εy=0。

```
X 线  s_x' = p·(1−cos0, −sin0) = (0, 0)
      |s_x'·ŷ|=0 < 1e-4×10.005mm≈1.0µm/步 → ρ̂=0（噪声地板判 0）
Y 线  s_y' = p·(sinφ_t, cosφ_t−1)
           = (10.005×1.99999999e-4, 10.005×(−2.0e-8))
           ≈ (2.0010e-3, −2.0e-7) mm/步
ψ_y  = asin(2.0010e-3/10.005) = asin(sinφ_t) = φ_t = 200.000 µrad
φ    = wrap(ψ_y − ρ̂) = +200 µrad ✓（X 基准实测=注入真值）
θ_x  = 0；θ_y = wrap(φ−ρ̂) = +200 µrad
v_x  = s_x' + p·x̂ = (10.005, 0)        → εx = |v_x|/p−1 = 0
v_y  = s_y' + p·ŷ = (2.0010e-3, 10.0049998)
      |v_y| = hypot(...) = 10.00500000 → εy = 0（弦模型精确）
col_x = (1.0, 0.0)；col_y = (2.0e-4, 0.99999998)
M_l2p = [[1.0, 0.000199999999], [0.0, 0.99999998]]   （9 位有效数字）
det   = 0.99999998
M_p2l = [[1.0, −0.000200000003], [0.0, 1.00000002]]
A·C−I 的 (0,1) 元 = 1×(−2.00000003e-4) + 1.99999999e-4×1.00000002 ≈ 0
      → ac_check_norm 双精度 <1e-12（回归实录 8.5e-22）
col_y 方向角 atan2(2.0e-4, 0.99999998) ≈ +200µrad = φ；列模长 1 = scale_y
```

读法：矩阵 (0,1) 元≈sinφ、(1,0) 元=X 线横向（此处 0）；col_y 的方向角
即非正交角、列模长即比例——"角在横向、比例在模长"的矩阵表达。

### 4.2 上片旋转工况：ρ̂ 读出与消去

真值同 §4.1，另加上片旋转 load_rz=+250µrad（面板"处方注入"上片；栅格
旋转 ρ=−load_rz=−250µrad，迭代 46 口径）：

```
X 线横向 s_x'·ŷ = −p·sin(−2.5e-4) = +2.50125e-3 mm/步（≈2.5µm/步）
      2.5µm/步 > 噪声地板 1.0µm/步 → 读出有效
ρ̂   = −asin(2.50125e-3/10.005) = −250.000 µrad → beta_urad=−250
Y 线横向 s_y'·x̂ = p·(sin2e-4 + sin(−2.5e-4)) = 10.005×(−5.0e-5)
ψ_y = asin(−5.0e-5) = −50.000 µrad
φ   = wrap(ψ_y − ρ̂) = −50 − (−250) = +200 µrad ✓（栅格旋转差中消去）
θ_x = −ρ̂ = +250 µrad；θ_y = wrap(φ−ρ̂) = +450 µrad；
      wrap(θ_y−θ_x) = +200 ✓（锚定关系）
v_x = s_x' + p·R(ρ̂)x̂ = (p(1−cosρ)+p·cosρ̂, −p·sinρ+p·sinρ̂)
      = (10.005, 0)（ρ̂=ρ 精确相消）→ εx=0 不被上片旋转污染
```

读法：β 是上片旋转的**显现通道**（0 偏置上片 β≈0 属正常，与处方
load_rz 默认 250µrad 不矛盾——处方值只经"处方注入"通道生效，迭代 46
答疑）；ρ̂ 被读出后在 φ 差中消去。但若旋转小于 100µrad 噪声地板，ρ̂
判 0、不再消去而**全量混叠进 φ**（§7.4）。

### 4.3 比例误差注入：εx=+200ppm

## 7. 误差来源与注意事项

1. **相机识别噪声**：REAL 链质心噪声（recipe `sim_sensors.
   fast_noise_px`，按相机分路，down=0.1px 默认档（up=0.1、coarse=0.15，
   `recipe.json:91-95`）；down 相机 1px=600nm，
   `machine_constants.json:30-41`）是 o_i 噪声主项。fpp 帧均值把单
   节点噪声压为 σ_node=RSS(相机σ, 到位重复性σ)/**√fpp**（设计文档
   §2 口径）——fpp 收益按 √ 律递减。
2. **轴到位重复性**：每次重走节点的到位 repeat 进 o_i（WS/AS 到位
   3σ≈0.03~0.05µm 级，迭代 48 实测 WS_LS_X 0.031 / WS_LS_Y 0.045µm）；
   升序单侧逼近已消反向间隙的一阶影响（§2.1）。
3. **杠杆量级式**：斜率噪声 σ_slope=σ_node/√Sxx，
   Sxx=p²K(K²−1)/12；φ 由两线横向斜率差出 →
   **σ_φ≈√2·σ_node/(p·√(K(K²−1)/12))**（附录 D 同式）。默认
   K=5@10.005mm 杠杆 40mm → σ_φ ~1µrad 级（迭代 37 时 pitch=20mm、
   杠杆 80mm 曾达 ~0.5µrad 级）；**加大 K/pitch（∝p·K^1.5）比加 fpp
   （∝√fpp）收益大**——规范 5.3 建议每线 ≥11 点。
4. **ρ̂ 噪声地板与上片旋转混叠**：_RHO_MIN_SIN=1e-4（100µrad 等效；
   `stage_nonortho.py:145-151`）。上片旋转 **>100µrad**：ρ̂ 读出有效、
   在 φ=ψ_y−ρ̂ 中消去（§4.2）；**<100µrad**：判 0、不再消去而**全量
   混叠进 φ**——迭代 38 教训（回归 prep 上片 jitter_rz=±30µrad 随机
   旋转全量混叠致段 FAIL，关 jitter 后 14/14 绿）。**测校基线一律
   0 偏置上片**；β 读数即上片旋转显现通道（迭代 46 答疑：0 偏置
   β≈0 属正常）。
5. **基准尺假定**：die 阵列严格正交是仿真合成真值，**待真机标定**
   （真机对应标准标记硅片/玻璃片，正交性由计量溯源保证）；pitch 被
   处方锁死（标记只在格点上）——噪声受限时加密网格反而更差，可调
   的是 K 与 fpp（设计文档 §2 密度权衡）。
6. **ε 的别名与边界**：ε 含**相机像元当量误差**别名（基准尺信任像元
   当量 k=0.6µm/px；真机需干涉仪/激光尺解耦）；阿贝/直线度等**位置
   相关项不进比例**，落残差/LUT（§2.5，`stage_nonortho.py:613-615`）。
7. **误差地图别名地板**：主套件（六分量误差地图开）存在 ~±10µrad 级
   系统地板（确定性地图别名+测量噪声；迭代 37/39 交接记录）；truth
   级 ±5µrad 只有地图归零可达（test_metrology 真值段承担，§4.5）——
   属设备真值固有系统差，真机同此口径。
8. **模板与选峰**：site quad 150µm 小模板、中心对某 quad 角居中注册；
   同 site 4 角互距≥5.2mm、默认 1.8mm FOV 内唯一；小 site 多角入幅
   时**最近峰防串**（§2.3）。全帧低于 score 阈值→CalibError 带相位/
   节点号（:328-330）。
9. **cancel/恢复语义**：cancel 只置标志，下一循环首抛 CalibCanceled
   （:408，`repeatability.py:169-177`）；finally 一定恢复两走位轴
   作业前位/光源/视觉模式（:498-512），用户模板绝不删除。
10. **物理约束对照（历史）**：旧一阶 M 法（迭代 36，已删）受 FOV
    1.8mm 限制、标记须全程在画幅内 → 扫描跨距 ≤0.9×FOV≈1.6mm →
    σ_φ≈7µrad 级（3σ≈20µrad，真值段 ±25µrad 容差；开发交接 §6 物理
    杠杆口径）——这是迭代 37 重写为栅格跳测法的物理动机：现行法
    标记不漂移出画幅（走距=节距相位复现），跨距=(K−1)×pitch 只受
    行程限位约束。
