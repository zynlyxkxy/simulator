## 1. 全片键合（POST /api/process/full_wafer）

### 1.1 路径规划（启动时刻一次性，显式配对表）

纯函数（`full_wafer_runner.plan_sites / order_dies`，可单测）：

- **site 侧**：`recipe.wafer_sites_cells()` 全量格点 → `skip_bonded`
  （默认 true）按 `workpieces.site_bonded`（1µm 容差）过滤已键合位 →
  `path_mode` 排序：
  - `center_out`（默认）：按 |x|+|y| 升序（曼哈顿距离中心向外，同列
    按行列号定序）；
  - `serpentine`：按行号升序分行，奇数行（0 起第 2/4…行）列反向，
    形成蛇形走刀；
  - `nearest`：最近邻链——从离中心最近位出发，每步取离上一位欧氏
    距离最近的未访问位；
  → `count>0` 截断（0=全部可用位）。
- **die 侧**：film 上 die 按 `die_order` 排序：
  - `nearest_pick`（默认）：离取片位距离升序，口径同
    `build_flip_pick_flow` 缺省选片（die 世界 ≈ film_stage 工具点 +
    film_pos，取片位=机械常数 flip_pick.pick_point_xy_mm）；
  - `serpentine`：按 die id 行列蛇形（行升序、奇行反向）。
- 两侧等长截断（die 耗尽优雅截短）后一一配对成**配对表**
  `[{die, site:{row,col}}...]`，随启动响应返回并落进状态，供面板
  选片选位图高亮"当前/下一对"。
- **规划三值（2026-09-05 迭代 15）**：启动响应与流程首条日志给出
  「可用 site 数（count 截断前）/ 膜上 die 数（含处方派生对照）/
  配对数」——`pairs=min(可用site, 膜上die)`，膜上 die 按**上膜时刻**
  处方铺（处方后改不重铺），「全片只键合 N 颗」类问题一眼定位；
  膜布局陈旧时响应 `dies_expected≠dies_on_film` 并在首条日志/面板
  给"请重新上膜"提示（另见 `GET /api/workpiece/layout` 的
  `film_layout_mismatch`，面板工艺页常驻提示）。

### 1.2 执行

晶圆在位守卫（不在位 400）；EGA 未完成则先跑一次 `wafer_ega`（只做
一次）；然后逐对跑 `flip_pick(die) → flip_handoff → focus_level(
per_site, site) → fine_align(site) → bond(site)`——复用 process_flows
现有 builder 与 `FlowEngine.run_steps`，每对独立等完成。已键合守卫
（builder 侧）天然防重；`skip_bonded=false` 时规划不去重，但 bond
守卫仍拒重复键合（记 fail）。

- 每 die 用 `bond_results.collect_stage / finalize_record` 落记录
  （buf 每 die 新起，与单片 chain 同一收集器，采集异常不阻断）。
- 任一 site 失败：记 `{die, site, ok:false, error}` 进 results，按
  处方 `stop_on_fail`（默认 false）继续下一颗或中止。
- 结束后按处方 `post_inspect.auto_after_full` 自动触发键合后检测
  （`process_flows.maybe_auto_post_inspect(eng, "full")`）；单片 chain
  结束对应 `auto_after_single`（chain_runner 收尾同款调用）。流程忙
  （running/paused）时跳过不排队。
- 与单片 chain 互斥（任一方 active 时另一方启动 409）；运行中重复
  启动 409。

## 2. 键合后精度检测（POST /api/process/post_inspect）

> **2026-09-05 迭代 15 重构：红外套刻**（替代迭代 11 的
> 逐标记单独寻址拍照方案——旧方案把 EGA 拟合残差、下相机绝对位姿系统
> 差、逐标记 AS 重复定位、离焦噪声放大全部混进 measured，是"检测值比
> truth 大得多"的根因）；**2026-09-07 迭代 20 修订：两次独立触发**
> （用户实测工艺：同一机位先 quad 模板后 cross 模板各下一次识别，
> 中间不动轴；迭代 15 的一次 identify 双模板列表契约保留但流程不再用）
> + 单对模式两处修正（投影角差 × 相机方向行列式符号换算回世界系——
> 下相机 dir_y=−1 镜像，旧代码直接拿像角差当世界角差，符号反、此前被
> 小角度掩盖；位置差扣 drz×J(d0) 旋转项）。真实工艺（用户描述）：下
> 相机红外通道穿透一个芯片厚度，焦面=晶圆面（下芯片表面），同一画幅
> 同时看到 site 的 quad 标记（下芯片侧）与 die 的 cross 标记（上芯片
> 侧），形成套刻图；同一画幅两个模板分别识别，再用精对准同一算法族
> 算上下芯片相对偏差。

body 可选 `{"sites": [[row,col],...]}` 子集（空=全部已键合位；子集中
未键合/未知位 400）。生成动态流程 `build_post_inspect_flow`：

1. **降温**：`wafer_keep_warm=true` 时先显式 `heater off`
   （StopTargetTempWithPlan——保温计划不停会把温度拉回
   wafer_temp_C），再 `heater set` Heat_Dw →
   `post_inspect.cool_target_C`（默认 25℃）等温（±2℃，timeout 900s）。
   降温方向走 tuning `bond_hw.wafer_cool_rate_cps`（默认 5℃/s）主动
   冷却（迭代 11 第一棒 engine 模型）。
2. **安全检查**：键合头 BS_Arm_Z → head_z_safe_mm、翻转 FA_Z 安全位
   + FA_X 撤离（同 wafer_ega 安全位模式）。
3. **AS_Z 对焦＝晶圆面**（下芯片表面）：`AS_Z = as_z_chuck_focus +
   t_w`（不加 die 厚——红外通道穿透一个芯片厚度，焦面=晶圆面时 site
   quad 与 die cross 同画幅都合焦，IR 假设；旧方案对焦 die 顶面
   =晶圆面+die厚，用户实测离焦）。
4. **逐已键合 site 复测**（`pi_measure` op，**每 site 一次走位、两次
   独立触发**）：
   - AS 把首个套刻标记对（quad#0/cross#0，同一角落）送到下相机光轴
     ——寻址 = EGA map + WS 平移补偿（与 fa_measure 晶圆侧严格同式：
     `AS = anchor + map(p) + (WS−ws_ega)`；目标超 AS 行程时联动
     WS(X/Y) 把标记对带进 AS 可达域，迭代 11c 逻辑保留）。下相机
     FOV 1.8×1.8mm（真机值）装不下 ±3.8mm 的全组四角标，一画幅拍
     的是同一角落的 quad⊕cross 套刻对；
   - **两次独立 `identify`**（`_vision_identify`，MQTT 通道；迭代 20
     起：先 `vision_marks.tpl_wafer_site`=quad 后 `tpl_post_inspect`
     =cross，各带 `ir_overlay=true`，同机位中间不动轴；迭代 15 的
     一次双模板列表契约保留但流程不再用）+ **`ir_overlay` 红外通道**
     （vision_model.collect_marks 的 ir_overlay 分支：被键合 die 覆盖
     的 site quad 标记恢复可见——可见光下物理遮挡；die 角标 z 按晶圆
     面计——IR 假设下两层同焦。可见光通道 EGA/调平/精对准行为不变）；
   - 按标记名分双组（FAST=场景名 `site_R{r}C{c}#k` / `die_id#k`；
     REAL=模板名；FAST 解析不按模板过滤，两次触发结果各含全部在视
     标记，须按名各取本组再合并），全部点用**同一 cam_pos**
     `solve_pixel` 到世界系；
   - measured 解算两模式：**FOV 内 ≥2 对**（大 FOV/小标记距布局）→
     quad/cross 点集各自相对各自设计点集拟合（精对准算法族
     `fine_align.ALGORITHMS`，算法取处方 `fine_align.algorithm`）后
     `compose_rigid` 取组间刚体偏差；**单对**（本机默认）→ dx/dy =
     世界系位置差经 EGA map 线性部逆变换回设计系再减设计差（差分
     向量，平移/相机位姿/EGA 系统差全对消；位置差另扣 drz×J(d0)
     旋转项——角标在半径 ~3.8mm 处，die 相对 quad 的旋转会在单对
     位置差里混入 drz×r 项，迭代 20 修正）、drz = 两条目投影角差 ×
     相机方向行列式符号 sign(dir_x·dir_y·(swap?−1:1)) 换算回世界系
     （下相机 dir_y=−1 镜像须翻号，迭代 20 修正——旧代码符号反，
     被小角度掩盖）；
   - 结果 **measured dx/dy/drz（mm/rad 全线约定）** →
     `BondResults.update_measured(die_id, ...)` 回填并落盘。
5. 对准台 AS_X/AS_Y 回 as_safe_xy_mm、AS_Z 回焦面零位。

### 2.1 红外套刻注明（物理依据）

键合后 die 标记面朝下埋在硅片背面之下，可见光不可见。本仿真按真实
D2W 设备做法建模：**下相机红外通道穿透一个芯片厚度成像**（用户已确认
"下相机有各种波长光源"假设），焦面=晶圆面（下芯片表面），同一画幅内
site 的 quad 标记（下芯片侧，z=晶圆面）与 die 的 cross 标记（上芯片
侧，物理 z=晶圆面+die厚）都合焦（IR 假设——`vision_model.collect_marks`
ir_overlay 分支把 die 角标 z 按晶圆面计；远心投影 z 不影响 (x,y)，
clamp 只改离焦量）。视觉层 wafer_die 标记（命名 `die_id#k`，随 die
真实落位——site 设计坐标过上片旋转 wrz + 键合物理残差
die["resid"]——+WS_Rz+模块姿态+真值枢轴）即 cross 组真值来源；site
quad 标记（`site_R{r}C{c}#k`）为下芯片组真值来源。

### 2.2 对消性与精度预算（迭代 15 新口径）

- **measured 语义 = 套刻相对测量**：两组标记同帧、同相机位姿、同一
  cam_pos 反投影，归算只做组间相对刚体/差分变换——**EGA map 拟合残差
  （~1µm）、下相机绝对位姿系统差（~2.5-3µm，align_stage 6DOF 未标定
  项）、逐标记 AS 重复定位、离焦噪声放大全部组内相消**，不进
  measured；EGA map 仅用于走位寻址（粗定位，其误差对两组相同）。旧
  口径（迭代 11~14：逐标记 EGA map 归算）把上述系统差全部混入
  measured——这就是"检测值比 truth 大得多"的根因。
- 残余误差源：FAST 质心噪声 0.15px × 0.6µm/px ≈ 0.09µm/标记（差分
  σ≈0.13µm）、WS/AS 到位重采样（40nm 3σ，迭代 13 起）、map 线性部
  对差分向量的残差（µm×1e-4 量级，可忽略）。drz 通道（单对模式）=
  FAST 投影角差（FAST 角无显式噪声，drz 残差≈真值噪声层）。
- truth（2026-09-07 迭代 20 起）= 键合接触时刻真值（bond_truth op 在
  触力停轴后用 6DOF 真值走 fa 同一 fit 管线采样，键合头下降链进入）
  + 压合微滑移（默认 0）；fa 时刻 phys_resid 保留为 align_resid 分量
  ——完整模型/分量预算见《键合误差模型_V1.md》；**新 measured 与
  truth 同量级可比**（回归判据 |measured−truth| < 1µm / 100µrad，
  i15.pi_overlay_measured；实测样例见《开发交接.md》迭代 15/20 条目）。
- 历史档案（迭代 11b 修复链）：wafer_die 标记真值漏乘上片旋转 wrz
  与键合物理残差 → pi 侧误加 R(θ) 寻址旋转项 → 修复为"标记真值随
  晶圆物理位 + 寻址/归算纯走 map"。该配对在迭代 15 重构中保留。

  measured 新口径（"套刻相对测量，EGA/相机位姿系统差已对消"）。

## 4. 误差传递链定义（bond_results.chain）

| 段 | 来源 | 内容 |
|---|---|---|
| wafer_load | workpieces.wafer.offset/rz | 上片注入偏移/旋转真值 |
| ega_fit | eng.ega_result | EGA 拟合修正 tx/ty/θ + 3σ 残差 |
| pick_coarse | eng.coarse_offset | 取片粗对准实测偏差（die 世界位−标定中心） |
| handoff_tilt | die.rx/ry | 交接后 die 在头倾斜真值（处方注入） |
| focus_level | eng.fl_fit | 调平残余/焦面残差 + verify 判定 |
| fine_align | eng.fine_align_result | Δ 解算/补偿次数/确认逐轮 rounds/物理残差 phys_resid（µm/µrad） |
| bond_params | recipe.bond + eng.heaters + eng.bond_touch_pos | 处方力/保压/温度 + 键合时刻加热器实温 + 寻力实际接触位 |

truth = fine_align phys_resid 末轮（键合动作本身不引入新 XY/Rz 误差；
无则 null+truth_note）。measured = post_inspect 红外套刻复测回填
（§2；迭代 15 起=套刻相对测量，系统差已对消）。记录另带 `timing`
（迭代 15：t_start/t_end/五阶段耗时，sim_t，产率分析数据源，见
《产率分析与产率模式_V1.md》）。
