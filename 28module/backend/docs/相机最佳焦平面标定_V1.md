测校项：`best_focus` 相机最佳焦平面标定（迭代 42 新增），cam=`up`/`down`
两模式（coarse 不支持）。思想取自参考测校框架
`测校/HoriMetrologyScirptsFramework/OptimalFocalCal.py` 的**区间收缩法**
（上下精对准最佳焦平面标定），实现 `metrology/best_focus.py` 的

`_validate_best_focus`（`runtime/calibration.py:956-1081`）。

本文面向设备工程师逐行核对算法：所有公式、字段名、默认值均对准代码实际
实现（引用格式 `文件:行号`）。焦面常数的语义、高度链消费与几何推导见
`docs/调焦调平与高度链_V1.md`（§3 focus_level 组表 / §4 焦面零位推导），

## 1. 测的是什么

**定义**：沿"相机↔标记"相对 Z 自由度扫描 Z，逐点用模板匹配 **score 作
清晰度代理**，找 score-Z 曲线峰值对应的 Z——即该相机在当前标记面上的
**最佳焦平面轴位**，作为机器常数 `focus_level` 组对应焦面键的标定值
（measured 单键）写回。

| 模式 | 扫描轴 | 谁在动 | measured 写回键 | 焦面语义 |
|---|---|---|---|---|
| cam=`down` | AS_Z | 下相机挂对准台，动镜头 | `as_z_chuck_focus_mm` | 下相机焦面=**裸吸盘面**（884.9）时的 AS_Z（默认 −1.0） |
| cam=`up` | BS_Arm_Z | 键合臂带吸盘动=标记动 | `head_z_upfocus_mm` | AS_Z=`as_z_chuck_focus_mm` 时上相机焦面=**裸键合头吸盘面**（1053.83+BS_Arm_Z）的 BS_Arm_Z（默认 −119.83） |

轴/键映射在校验期定死（`calibration.py:992-994`），结果 `measured`
只有对应一键（`best_focus.py:232`）。

**与调焦调平链的关系**（互引 `调焦调平与高度链_V1.md`）：这两个焦面键
是高度链的基准"认知"——晶圆侧进场 `AS_Z_entry = as_z_chuck_focus_mm +
t_w`、键合头侧进场 `BS_Arm_Z_entry = head_z_upfocus_mm + (AS_Z_entry −
as_z_chuck_focus_mm) + t_d`（该文 §4）；写回后高度链自动跟随，无需重启。
该文 §3 记载的"测校回填路径"即由本 routine 生产（两键经
APPLY_GROUP_ROUTE 路由 `focus_level` 组，`calibration.py:212-213`）。

**工况注记（重要，真机/仿真差异）**：

- **down 仿真口径**：下相机标记源 = wafer_marks（晶圆在片才有 FAST 解析
  标记），裸吸盘无可用标记，故仿真里 down 只能**晶圆在位**做，测得的是
  **晶圆面**焦面（与裸吸盘面常数差一个片厚 t_w）。真机测校应在
  **裸吸盘+吸盘标记**工况做（真机吸盘有实体标记可识别），本 routine
  的算法与写回链不变。此为本仿真的已知口径差距（i42 缺口注记）。
- **up 口径**：须键合头**无 die**（裸吸盘）。仿真侧吸盘心标记实体为
  `head_chuck_cross`（吸盘尖端面真空十字气道交叉中心处补的 150µm
  cross，`vision_model.py:895-906`）——无 die 恒在、有 die 被物理
  覆盖不出（与 wafer site 标记被已键合 die 覆盖同口径）；有 die 时
  up 前置走位后的视野预检报"视野内无标记"。

## 2. 算法推导（区间收缩法 + 末轮抛物线亚步距拟合）

输入已由 `calibration.start` 校验规范化（见第 6 节）：`template_name`、
`axis`（down=AS_Z / up=BS_Arm_Z）、`const_key`、`z_start/z_end`、
`step_mm`、`rounds`、`frames_per_point`(fpp)、`wait_ms`、`preset`
（up 前置走位 dict）。

### 2.1 清晰度评价：score 代理

参考框架 `OptimalFocalCal.GetMTFScores` 用 Sobel 原图清晰度
（`OptimalFocalCal.py:239-243`，需相机回图）；本链 VSS_Com 契约不回图，
改用**识别结果 score 作清晰度代理**（`best_focus.py:155-157`：每次
`_identify` 取 `max(lstScore)`）——两模式下 score 均随离焦单调退化，
且真机同样可得：

- **FAST**：解析投影直接合成
  `score = FAST_BASE_SCORE − 0.15·min(blur, 3) + U(−0.01, 0.01)`，截断
  [0,1]（`vision_model.py:1820-1822`；基准 `FAST_BASE_SCORE=0.96`，
  `vision_model.py:334`）。其中
  `blur = |focus_err_um| / dof_um`（`vision_model.py:1256-1263`），
  上/下精对准相机 `dof_um=20`（`machine_constants.json` cameras 组，
  2026-08-24 用户真实光学数据）。即 score 是以真焦面为中心的**三角
  峰**：斜率 0.0075/µm，|focus_err| ≥ 3×DOF（60µm）后饱和于 0.51；
  blur>3 时该条 `judge=false`（`vision_model.py:1828`），但 FAST 的
  `lstScore` 仍返回饱和值（build_result 只滤 in_fov，
  `vision_model.py:1849-1857`）。score→blur 的映射斜率（0.15）与判废
  阈值为**仿真合成值，待真机标定**。
- **REAL**：模板匹配 NCC 随离焦模糊天然退化（渲染链按 blur 加高斯，
  `vision_model.py:327-329`）；离焦过深匹配不上时 `_identify` 抛错
  （lstCol 空，`calibration.py:1769-1777`），作业**该点记 score=0
  不阻塞**（`best_focus.py:162-165`，与 `_focus_scan` 同惯例，
  `calibration.py:1835-1839`）。

**逐点降噪**：每个 Z 点拍 `frames_per_point` 帧，score 取均值
（`best_focus.py:153-168`）；entry 携带的 `blur_ratio`/`focus_err_um`
（`vision_service.py:1517-1518`）同取均值留档（全帧失败则为 None）。

### 2.2 z 网格与每轮时序

`_z_grid`（`best_focus.py:69-79`）：z_start→z_end 按 step 步进（含
端点；末段不足一步时补 z_end 端点，与参考框架
`OptimalFocalCal.py:150-156` 同式）。

作业时序（`best_focus.py:129-207`；启动时记录轴位/灯态，
finally 恢复，:111-118/:208-217）：

```
开灯（_set_light + _await_light，:130-131）
up 前置走位（仅 cam=up，:132-137）：
    按 preset 逐轴 AS_Z→AS_X→AS_Y→BS_Arm_Z 走位 → wait_ms
    → _check_marks 视野预检（走位到位后兜底；无标记→作业失败）
轮 r = 0..rounds−1（轮首 _check_cancel，:141）：
    zs = _z_grid(lo, hi, h)                    （首轮 lo/hi/h =
                                                  z_start/z_end/step_mm）
    逐点 k（点首 _check_cancel，:146；进度 :147-149）：
        走 axis→z（:150）→ wait_ms（:151）
        fpp 帧 identify → score 均值（:153-168，识别失败帧记 0）
        记 CSV 行 + 日志（:169-175）
    整轮 max(scores) ≤ 0 → CalibError（全范围没识别到标记，
        检查物料/光照/模板/焦面常数先决，:177-180）
    argmax → 峰 z_pk（:181-187，peaks 历史 + 本轮入 scan_rounds）
    末轮 → 三点抛物线拟合 z*（:188-201，2.4）后 break
    否则区间收缩（:202-207，2.3）
```

cancel 检查点在**每轮首+每点首**（`best_focus.py:141,146`）；轴位恢复
顺序 up 先抬 BS_Arm_Z 再回 AS（防撞，:113-114），光源恢复原灯态。

### 2.3 区间收缩

每轮 argmax 峰点 `i_pk` 后（`best_focus.py:202-207`）：

```
lo = zs[i_pk−1]（i_pk>0 时；峰在左边界则 lo 保持）
hi = zs[i_pk+1]（i_pk<末点 时；峰在右边界则 hi 保持）
h  = h / 2
```

即区间缩到**峰点左右各一采样点**、步长减半——与参考框架
`OptimalFocalCal.py:185-196` 同策略（边界侧保持一项也相同）。点数账
（缺省窗口 ±0.3mm、step 0.02、rounds=2）：首轮 31 点（含端点），次轮
5 点（峰点 ±0.02、步 0.01）。收缩的前提是**峰在本轮窗口内**——故初始
窗口必须含真焦面（见 5.1）。

### 2.4 末轮三点抛物线拟合（亚步距 z*）

末轮峰处取三点做抛物线拟合（`_parabola_peak`，`best_focus.py:82-89`；
调用 :191-200）。设峰点 i（须 0<i<len−1）三点 (z₁,z₂,z₃)、
score (s₁,s₂,s₃)：

```
denom = s₁ − 2·s₂ + s₃
z* = z₂ + (s₁ − s₃)·(z₃ − z₁) / (4·denom)
```

即过三点抛物线的顶点闭式解（等距网格下 z₃−z₁=2·step，退化为
`z₂ + (s₁−s₃)·step/(2·denom)`，与 `_focus_scan` 的
`q_peak += 0.5·step·(y1−y3)/denom` 同款，`calibration.py:1846-1851`）。

退化防护（`best_focus.py:188-200`，`detail.fit` 三态）：

| fit | 条件 | z* 取法 |
|---|---|---|
| `parabola` | 峰不在边界且 \|denom\| ≥ 1e−9（`_EPS_DENOM`，:66） | 上式亚步距顶点 |
| `argmax（平顶曲线抛物线分母退化）` | 峰不在边界但 \|denom\| < 1e−9 | argmax 点 z₂ |
| `peak_at_edge（峰值在扫描边界，建议扩 z_start/z_end）` | i_pk=0 或末点 | 边界 argmax 点 |

### 2.5 CSV 列定义

`runtime/metrology_data/best_focus_<cam>_MMDD_HH_MM_SS.csv`（命名与落盘
`_csv_write`，`extra_routines.py:92-100`，撞名自动 `_N` 后缀；表头
`best_focus.py:218-221`，行格式 :169-171）：

```
round, point, z_mm, score, blur_ratio, focus_err_um
```

每行一个采样点：`round` 轮次（**自 0 起**，注意与结果
`series.rounds[].round` 自 1 起相差 1）、`point` 轮内点序（自 0 起）、
`z_mm` 轴位（%.6f）、`score` 该点 fpp 帧均值（%.4f）、`blur_ratio` /
`focus_err_um` 诊断列（均值，%.4f / %.2f；该点全帧无诊断时留空）。
结果回执带 `csv` / `csv_name` 键（`best_focus.py:248`）。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. **模板已注册**：缺省模板 down=`vision_marks.tpl_wafer_site`（现值
   `cv_quad`）/ up=`vision_marks.tpl_head_chuck`（现值 `tpl_head_chuck`，
   `machine_constants.json:128-134`；常数缺键时兜底名
   `tpl_head_chuck`/`cv_quad`，`calibration.py:1004-1014`）。给了
   `template_name` 须非空且已在视觉页注册，否则 start 400 列可用名
   （`calibration.py:1015-1020`）。作业不自建不删模板。
2. **物料/工况**：
   - down：**晶圆已上片**且当前位视野内有标记——down 不走位（当前位即
     扫描位），start 即做 `_check_marks` 视野预检，无标记 → 400
     （`calibration.py:1073-1077`，`_check_marks` 定义
     `metrology/repeatability.py:55-61`：REAL 在陶瓷面/吸盘纹理上 NCC
     可能误判过阈值，必须几何前置拦）。语义注意：仿真里测得的是
     **晶圆面**焦面（见 §1 工况注记）。
   - up：键合头**无 die**（裸吸盘）；`wafer_ega.as_anchor_xy_mm` 与
     `focus_level` 两焦面键现值须大致正确——前置走位按现值走
     （AS_Z→`as_z_chuck_focus_mm`、AS_X/Y→锚点、BS_Arm_Z→
     `head_z_upfocus_mm`，`calibration.py:1040-1048`），常数错得离谱
     会在走位后视野预检报"视野内无标记"（`best_focus.py:137`）。
3. **视觉链路**：FAST/REAL 均可，作业**不切视觉模式**（REAL 需 cv2）；
   光源自管（作业开灯、finally 恢复原灯态）。
4. **无工艺在跑**：工艺流程 running/paused、全片键合、一键串联 → 400
   （`calibration.py:1059-1072`）。
5. **扫描窗口在轴软限位内**：AS_Z [−2.0, 6.0] mm / BS_Arm_Z
   [−190.0, 0.0] mm（`axes_config.py:20,28`；两端越限 → 400，
   `calibration.py:1031-1038`；up 前置走位四轴逐轴另有守卫，
   :1049-1058）。

### 3.2 参数选取

- **z_start/z_end**：留空 = 当前焦面常数 ±0.3mm（缺省窗口以现值为中心，
  故现值偏离真值超过 ±0.3mm 时须显式给窗口把真值包进去——FAST 的
  score 在 ±3×DOF=60µm 外饱和、REAL 直接识别失败记 0，峰不在窗口内
  时 argmax 落在饱和/零分平台，拟合无意义）。面板侧 z_start/z_end 须
  成对填写（`panel/index.html:6274-6278`）。
- **step_mm**：默认 0.02（=1×DOF）；减小步长提高首轮分辨率但线性加点。
- **rounds**：默认 2。每多一轮区间缩 4 倍（两点间距减半两次）、step
  减半，末轮抛物线已给亚步距，一般 2~3 轮足够。
- **frames_per_point**：默认 3，FAST score 抖动 ±0.01（U(−0.01,0.01)）
  经 3 帧均值降到 ~±0.006；REAL 噪声大时可加到 5~10。
- **wait_ms**：默认 10，走轴后稳定等待。

### 3.3 启动 / 中断 / 判读

```
POST /api/calibration/start
  {"routine": "best_focus", "cam": "down",
   "params": {"rounds": 2, "frames_per_point": 3, "wait_ms": 10}}
→ job_id；GET /api/calibration/status?job_id=N 轮询（progress 逐点：
  "第 r/R 轮 z=….（k/n）"，:147-149；总数为逐轮重估的近似值 :144）；
done 后 GET /api/calibration/result?job_id=N。
POST /api/calibration/cancel {"job_id": N}（协作式取消：下一轮首/点首
  生效 → canceled；finally 恢复轴位/灯态照跑）
```

cam=`up` 仅需把 `"cam"` 改为 `"up"`（前置走位由作业自动完成）。

判读要点：

- `measured.<const_key>` vs `current.<const_key>`：实测焦面 vs 现标定值
  （差值即本次要修正的认知偏移，µm 量级读 GUI 大数字行）。
- `series.best_z_mm`（= measured 值）与 `series.peaks_mm`：各轮 argmax
  峰轨迹应逐轮收敛；跳变提示窗口/模板问题。
- `detail.fit`：应为 `parabola`；`peak_at_edge` → 按提示扩窗口重测；
  `argmax（平顶…）` → 曲线太平（模板/光照差或已在焦面平台上）。
- `confidence`：末轮峰 score（FAST 理想 ≈0.96；明显偏低提示离焦残余
  或模板质量差）。
- `series.rounds[]`：各轮 z-score 曲线（GUI 画图数据，含 `step_mm`、
  `z_mm[]`、`score[]`、`blur_ratio[]`、`peak_z_mm`）。

### 3.4 写回

```
POST /api/calibration/apply
  {"job_id": N, "fields": ["as_z_chuck_focus_mm"]}   # down
  {"job_id": N, "fields": ["head_z_upfocus_mm"]}     # up
```

fields 须为 measured 实际携带的那一键；经 APPLY_GROUP_ROUTE 路由
`focus_level` 组（`calibration.py:212-213`），机器常数校验（范围见
§6.3）→ 原子落盘 → 热生效。写回后高度链自动跟随；**建议写回后同工况
复测一次**：down（晶圆面口径）/up 的复测 best_z 应落在同真值附近
（up 因前置走位含 AS_Z 现值，复测还交叉验证了两键自洽）。

## 4. 计算示例（一组自洽数字手算复核）

以 cam=down、FAST 模式为例，**示例数据为示意**（仿真合成：FAST score
模型见 2.1；真机数字待真机标定）。工况与回归 `i42.best_focus_down`
同口径：晶圆在位、误差链 OFF（确定性真值：晶圆面标记 z=885.9=下相机
焦面@AS_Z=0 ⇒ 真值 best_z=0.0）、注入焦面认知偏移
`as_z_chuck_focus_mm=0.2` ⇒ 缺省窗口 [−0.1, 0.5]、step=0.02、rounds=2、
fpp=3。

### 4.1 第 1 轮：31 点扫描与 argmax

网格 z = −0.10, −0.08, …, 0.50（(0.5−(−0.1))/0.02+1=31 点，含真值 0）。
score 期望（blur=50·|z|，score=0.96−0.15·min(blur,3)）：

| z (mm) | −0.10 | −0.06 | −0.04 | −0.02 | 0.00 | +0.02 | +0.04 | +0.06 | +0.10 |
|---|---|---|---|---|---|---|---|---|---|
| blur | 5→3 | 3 | 2 | 1 | 0 | 1 | 2 | 3 | 5→3 |
| score | 0.51 | 0.51 | 0.66 | 0.81 | **0.96** | 0.81 | 0.66 | 0.51 | 0.51 |

argmax → z_pk=0.00（峰相对次峰余量 0.15 ≫ 3 帧均值噪声 ~±0.006，峰位
稳定）。注意 ±0.06 之外全部饱和于 0.51 平台——平台内部靠噪声分不出
高低，这就是"窗口必须含峰"的数值直观。

### 4.2 第 2 轮：区间收缩 + 抛物线拟合

收缩：lo=z[−1 点]=−0.02、hi=z[+1 点]=+0.02、h=0.01 → 5 点
{−0.02, −0.01, 0, +0.01, +0.02}。设各点 3 帧均值（含残余噪声，示意）：

```
z:      −0.02    −0.01    0.00    +0.01    +0.02
score:  0.8093   0.8846   0.9607   0.8861   0.8088
```

argmax i=2（z=0.00），0<i<4 且不在边界 → 抛物线：

```
denom = s₁ − 2·s₂ + s₃ = 0.8846 − 2×0.9607 + 0.8861 = −0.1507
z* = 0.00 + (0.8846 − 0.8861) × (0.02 − (−0.02)) / (4 × (−0.1507))
   = (−0.0015) × 0.04 / (−0.6028)
   ≈ +0.0001 mm  （+0.1 µm）
```

结果（对照 §6.2 字段）：`measured.as_z_chuck_focus_mm = 0.0001`、
`current = 0.2`、`series.best_z_mm = 0.0001`、`series.peaks_mm =
[0.0, 0.0]`、`detail.fit = "parabola"`、`confidence = 0.9607`。
|z* − 真值 0.0| = 0.0001 ≤ 0.01，满足回归断言口径（|best_z − 真值| ≤
step_mm/2 = 0.02/2，`test_metrology.py:4914`）。

CSV 行示例（round 自 0 起；第二轮第 3 点）：
`1,2,0.000000,0.9607,0.0300,-0.60`。

### 4.3 up 模式对照（回归真值口径）

cam=up、注入 `head_z_upfocus_mm=−119.7` ⇒ 缺省窗口 [−120.0, −119.4]；

## 5. 误差来源与注意事项

1. **score 平台区（最大误差源）**：FAST 在 |focus_err| ≥ 3×DOF=60µm 外
   score 饱和 0.51、REAL 直接识别失败记 0。初始窗口不含真焦面时，
   argmax 落在平台噪声上，区间收缩会"收敛"到垃圾值。REAL 有兜底
   （整轮 max(scores)≤0 → 作业失败报错，`best_focus.py:177-180`），
   **FAST 平台无此守卫**——窗口选取（±0.3mm 缺省以现值为中心）是
   本 routine 最重要的使用前提；现值可信度差时先扩窗口。
2. **step 粒度与拟合残差**：抛物线顶点精度 ~末轮 step 的 1/2 量级
   （缺省两轮后 step=0.01，回归按 |best_z−真值| ≤ step_mm/2=0.01mm
   验收）；相对 ±20µm 景深的消费口径足够。更细须加 rounds 或减小
   step_mm。
3. **模板/标记质量**：score 代理依赖模板匹配对离焦的单调退化；模板
   含大背景、多标记同视野（lstScore 取 max，:157）或标记不对称都会
   压平/拉偏峰形。宜用小而特征强的注册模板（缺省 cv_quad /
   tpl_head_chuck 均为 150µm 级）。
4. **down 工况语义**：晶圆在位测得=晶圆面焦面=裸吸盘常数+片厚
   （仿真口径，见 §1）；真机须改裸吸盘+吸盘标记工况。把晶圆面值直接
   写回 `as_z_chuck_focus_mm` 会让高度链偏低一个片厚——真机 SOP 必须
   先下片。
5. **up 前置走位依赖常数现值**：锚点/下焦面现值错 → 视野无标记（作业
   失败）或标记偏心（score 峰值仍在，但识别稳定性变差）。换吸盘/
   调机后应先标 as_head_center 再做 up best_focus。
6. **识别噪声**：FAST score U(±0.01) 经 fpp 均值衰减 1/√fpp；REAL NCC
   噪声更大，fpp 宜 5+。噪声直接进抛物线三点，是 z* 残差的主项。
7. **走轴稳定与到位重复性**：每点 wait_ms 后拍照；AS_Z/BS_Arm_Z 到位
   重复性（µm 级）逐点独立进入 z*。扫描全程单调方向走位（z_start→
   z_end 升序），回程差不进相邻点差分。
8. **cancel/恢复语义**：cancel 只置标志，下一轮首/点首生效
   （`best_focus.py:141,146`），终态 canceled；finally 一定恢复
   BS_Arm_Z/AS_Z/AS_X/AS_Y 作业前轴位（up 先抬臂再回台，防撞顺序，
   :113-114）与原灯态（:208-217）。
9. **网格末段补端点的轻近似**：z_end 不足一步时补端点使末间隔
   < step（:77-78）；峰恰落在倒数第二点时，抛物线公式按三点实际
   横坐标 (z₃−z₁) 计算但仍假设峰点居中，非等距情形为近似（与参考
   框架同款处理；实际拟合点多在半宽内，影响可忽略）。
