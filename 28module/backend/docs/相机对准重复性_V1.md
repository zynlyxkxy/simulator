# 相机对准重复性_V1

测校族：相机对准重复性（静态连拍 + 动态往复两 routine），**两条执行
链**（GUI MQTT 自跑链 / 后端作业链）跑同一物理动作：

| routine / 程序 | 测什么 | 后端实现 | GUI 程序（MQTT 自跑链） |
|---|---|---|---|
| `align_repeat_static` 静态对准重复性 | 设备静止连拍标记，row/col 像素 3σ（nm）+ 角度 3σ（µrad） | `metrology/repeatability.py:308-349`（`run_static`） | `metrology_gui/SingleCameraAlignStability.py`（上/下/粗对准相机通用） |

## 1. 测的是什么

**定义**：同一标记在同一机位下被同一相机反复识别的质心稳定度。

- **静态**：所有轴不动，连拍 repeat 次——指标只反映相机读数稳定
  性（REAL 图像噪声 → NCC 匹配 → 判真点云质心的波动链）；
- **动态**：每拍前载体轴做完整 起始位→拍照位 往复——指标 =
  相机读数稳定性 + 运动机构重复定位精度的综合（3σ 显著大于静态
  为正常现象）。

**两个口径的输出**（组装 `_assemble`，`repeatability.py:229-305`）：

| 口径 | 字段 | 说明 |
|---|---|---|
| 像素 | stats.row/col.{mean_px, std_px, s3_px, s3_nm} | 质心散布；nm = px×k_nm |
| 角度 | stats.angle.{mean_deg, std_deg, s3_urad} | 判真点 lstAngle 均值序列（有角度信息才带） |
| 运动轴（仅动态） | stats.axes.{axis}.{mean_mm, std_mm, s3_um} | 动轴**到位 actual** 散布（迭代 48 起；旧口径记名义 pos 恒=target、3σ 恒 0，见 §2.3） |
| 世界坐标 | stats.mark_world.{x,y}.{mean_mm, s3_um} | 质心反投影世界系等效散布 |

### 2.4 统计口径（两链同一公式）

像素当量（后端 `nm_per_px`，`repeatability.py:42-45`）：

```
k_nm = cam.pixel_um / cam.mag × 1000
     up/down = 6.0/10.0×1000 = 600 nm/px
     coarse  = 2.74/0.3×1000 ≈ 9133 nm/px   （machine_constants cameras）
```

GUI 侧初值同口径（`metrology_gui/metrology_config.py:33-37`），
启动时 `refresh_nm_per_px` 从 `GET /api/machine_constants` 刷新
（`:53-67`）；GUI 绘图 `np.std(...,ddof=0)×3×k_nm`
（`SingleCameraAlignStability.py:161-175`、
`AlignStabilityDynamic.py:342-356`）。后端 `_mean_std` 总体 ddof=0
（`repeatability.py:186-191`）：

```
s3_px = 3·sqrt( (1/n)·Σ(x_i−mean)² )
s3_nm = s3_px × k_nm                     （round 2，:240-244）
s3_urad(angle) = 3·σ_deg·π/180·1e6       （:251-257）
s3_um(axis)    = 3·σ_mm×1000             （动态，:260-267——
                  迭代 48 起 σ 作用在 actual 序列上）
s3_um(mark_world) = 3·σ_mm×1000          （:268-280）
```

### 2.5 CSV 列定义（两链）

- 后端链静态：`single_camera_stability_*.csv`
  （`repeatability.py:336-345`）：
  `index,col,row[,angle_deg],mark_world_x/y/z_mm,cam_world_x/y/z_mm`
- 后端链动态：`align_stability_dynamic_*.csv`（`:410-419`）：
  `index,col,row[,angle_deg],<动轴 actual…>,mark_world×3,cam_world×3`
  ——动轴列迭代 48 起为 **actual 读数**（7 位小数）。
- GUI 链静态：`single_camera_stability_*.csv`（同目录同前缀），
  **仍只有 `index,col,row` 三列**（`SingleCameraAlignStability.py:
  139-148`，pandas 落盘 index 为浮点 `0.0` 样式；富化留待需求，
  属已知边界）。
- GUI 链动态：`align_stability_dynamic_*.csv`（同目录同前缀），
  **迭代 49 起 20 列行基准**（`AlignStabilityDynamic.py:278-321`）：

  ```
  index, col, row,
  d_col_px, d_row_px,              # 相对第 0 帧像素差（round 4）
  t_s,                             # 相对开始时刻秒（round 3）
  AS_X_mm, AS_Y_mm, WS_LS_X_mm, WS_LS_Y_mm,            # 四轴名义 pos
  AS_X_act_mm, AS_Y_act_mm, WS_LS_X_act_mm, WS_LS_Y_act_mm,  # 四轴 actual
  mark_world_x_mm, mark_world_y_mm,
  mark_world_dx_nm, mark_world_dy_nm,   # 相对第 0 帧标记世界差×1e6
  cam_world_x_mm, cam_world_y_mm
  ```

  注意三点：① 轴列是**固定 AS/WS 四轴**（与 jog_group 无关，便于
  跨档对比；coarse 档动轴 FA_X 不在四轴内，轴列仅是参考读数）；
  ② actual 取数（/api/axes）与世界反算（/api/vision/solve_pixel）
  失败时**降级写空列**并只落一次告警日志，不阻塞测校
  （`AlignStabilityDynamic.py:253-263`）；③ 日志末尾追加
  "mark_world 与台读数之差为固定装配偏置（工具点+标记设计位置），
  逐行应恒定"提示行（`:328-329`——世界坐标原点≠台读数原点，
  判据=同行恒定 nm 级）。迭代 48 曾为其短暂扩到 11 列
  （index,col,row,AS_X,AS_Y,WS_LS_X,WS_LS_Y,mark_world_x/y,
  cam_world_x/y），迭代 49 富化为现行 20 列。

同目录同前缀，靠**列数**区分是哪条链落的（后端静态 9~10 列/
动态 11~12 列 vs GUI 静态 3 列/动态 20 列）。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件（两链共用）

1. 标记载体在位且进视野：down→晶圆上片（下相机看晶圆标记）；
   up→键合头有芯片；coarse→翻转模块有 die（`_check_marks` 前置，
   `repeatability.py:55-78`——视野无标记直接 CalibError，防无特征
   面 NCC 误判产垃圾散布）。
2. 视觉链可用 cv2（REAL 模式必需，`calibration.py:289-291`）。
3. GUI 链另需：后端在线且 MQTT broker 可达（GUI 启动即连
   `127.0.0.1:1883`，断连时界面可开、运行才报错，
   `SingleCameraAlignStability.py:51-59`）。
4. 动态：无工艺流程在跑（start 400，`calibration.py:363-376`）。

### 3.2 静态步骤（两链）

- 后端链：
  ```
  POST /api/calibration/start {"routine":"align_repeat_static",
    "cam":"down","params":{"repeat":50,"wait_ms":10,
    "template_name":"必填-已注册模板"}}
  → status 轮询 → result
  ```
  模板名**必填**（迭代 34 起）：空/None → start 400 并列可用模板
  名；给了须已注册（存在性同 400）。作业不自建模板、结束不删用户
  模板（`calibration.py:344-360`、`:1635-1639`）。
- GUI 链：SingleCameraAlignStability 页选相机（上/下/粗对准）+
  模板名（**必填**，须在视觉页已注册）+ repeat/wait → 运行。
  **首拍即测量拍**（迭代 42 起无 warm-up）；拍照 15s 不出结果即
  报错（重拍 1 次仍败抛 TakePhotoError 中止，异常文本含后端
  error 原文）。运行开始时接收线程先清空闲置积压 MQTT 帧
  （日志"已清空闲置积压 MQTT 帧 N 条"）。
  参数输入框为 `MetrologyDoubleSpinBox`：小数位超过 decimals 的
  输入**不会弹回**——逐键放行、提交（失焦/回车）时四舍五入到
  设定小数位（`metrology_gui/qt_custom_ui.py`，迭代 34）。

### 3.3 动态步骤（两链）

- 运动组映射（两链同名契约）：down→晶圆台 WS_LS_X/Y（jog_group=
  wafer，默认）或对准台 AS_X/Y（jog_group=align，2026-09-08 需求②）；
  up→对准台 AS_X/Y；coarse→翻转模块 FA_X（仅 X，Y 输入禁用）。
  后端映射 `JOG_GROUPS`（`calibration.py:151-156`）/
  `jog_axes_override`（`repeatability.py:382`）；GUI 映射
  `camera_stage_map`（`metrology_config.py:43-48`）+ down 相机
  下拉（`AlignStabilityDynamic.py:115-144`）。
- 位置参数：start_xy/photo_xy 绝对坐标成对给出（X→第 1 轴、Y→第 2
  轴；分量在软限位内，`calibration.py:402-421`）；或 travel_mm 兼容
  别名（photo=当前位、start=photo−travel，[0.1,20]mm，
  `:422-439`）。GUI 起始位/拍照位各配"取当前位"按钮
  （`job_base.fetch_axes_pos` 纯 HTTP GET /api/axes，按相机+
  运动组映射轴组回填，`AlignStabilityDynamic.py:146-173`）。
- 时序（后端 `run_dynamic`，`:391-409`；GUI 同款
  `AlignStabilityDynamic.py:233-266`）：
  ```
  循环 i：各轴 → start_xy → wait_ms → 各轴 → photo_xy → wait_ms
          → 拍照（15s 超时直给，失败重拍 1 次）→ 记 col/row
          →（GUI 链：记四轴 pos/actual + 世界坐标 + t_s）
          →（后端链：记 context + 动轴 actual）
  ```
  注意两链均**首拍即测量拍**（迭代 42 起 GUI 链拍照位 warm-up
  已删）。GUI 链走位等待 `wait_stage_stop` 30s 超时抛错（CTL 帧
  断流直给不永久挂）；同一 take_photo 内上一 attempt 的迟到帧
  有效收下（also_accept——后端单拍最坏 ≈12s 贴 15s 窗时避免
  "迟到帧丢弃+重拍再超时"双杀放大，同机位物理等价）。

### 3.4 中断与判读

- 后端链：`POST /api/calibration/cancel`（循环边界生效，
  `repeatability.py:169-177`）；finally 恢复轴位/光源/模式（用户
  模板不删；自建临时模板仅三旧标定项有，`calibration.py:1700-1722`）。
- GUI 链：interrupt 停轮询 + 发 cancel（静态自跑则直接停循环，
  `SingleCameraAlignStability.py:155-158`；动态
  `AlignStabilityDynamic.py:336-339`）。
- 判读：静态看 `stats.row/col.s3_nm`（相机读数稳定性）；动态另看
  `stats.axes.*.s3_um`（**到位 actual 3σ**——迭代 48 起非零为正常，
  量级=配置 repeat_3σ（WS/AS≈0.04µm、FA_X≈0.5µm 级；恒 0 反而
  说明 actual 读取失败回退名义）与 `stats.mark_world.*.s3_um`；
  角度看 `stats.angle.s3_urad`。像素 3σ 的经验 sane 上界 =
  5×k_nm（回归断言，`tests/test_metrology.py:797-826`）。

## 4. 计算示例（真实数据手算复核）

数据来自本后端 2026-09-10/15 实测（默认机器常数、k_nm=600）。
§4.1/§4.2 为后端链 CSV，§4.3 为 GUI 链 CSV（**迭代 48 前三列窄表
的历史样本**——现行 20 列里 col/row 两列定义不变，见 §2.5）。

### 4.1 静态（后端链，`single_camera_stability_0910_21_04_41.csv`，down，n=10）

col 列 10 行：1498.6270, 1498.7010, 1498.6260, 1498.7470, 1498.7820,
1498.5890, 1498.6630, 1498.7440, 1498.6630, 1498.7030

```
Σcol = 14986.8450   mean = 1498.6845 px
偏差 = [−0.0575, +0.0165, −0.0585, +0.0625, +0.0975, −0.0955,
        −0.0215, +0.0595, −0.0215, +0.0185]
Σ(col−mean)² = 0.034341
σ  = sqrt(0.034341/10) = 0.058601 px
3σ = 0.1758 px = 0.1758×600 = 105.48 nm
```

row 列 10 行：1498.6260, 1498.6260, 1498.5950, 1498.5970, 1498.5970,
1498.6650, 1498.6670, 1498.5900, 1498.5930, 1498.6250

```
Σrow = 14986.1810   mean = 1498.6181 px
Σ(row−mean)² = 0.007607
```

## 5. 误差来源与注意事项

1. **REAL 图像噪声 → 质心噪声**：recipe `sim_sensors.fast_noise_px`
   （默认 0.15px 档，迭代 28 起按模板响应度折算灰度噪声、物理
   封顶）是静态 3σ 的主项；`real_noise_scale` 倍率可热调
   （`tests/test_metrology.py:970-1025` 的去相关噪声与单调性核验）。
2. **动态附加项 = 台重复定位**：repeat/map 误差在到位时刻经 6DOF
   进图像（i29 注入点核验，`tests/test_metrology.py:1246-1327`）：
   动态 3σ² ≈ 静态 3σ² + 注入 3σ²；名义 pos 恒等于指令目标，
   真实到位散布在 **axis_log（actual，迭代 48 起）**与
   context.axes_actual（pos/actual 分离口径）。
3. **两链口径差异**（比对数据前必读 §2.2/§2.3/§2.5）：warm-up
   （迭代 42 前两链差异项，现两链均无）、单拍超时（GUI 15s 直给
   +重拍 1 次 vs 后端内部帧上限）、CSV 列（GUI 静态 3 列/动态
   20 列 vs 后端静态 9~10 列/动态 11~12 列）、失败语义
   （GUI 重拍 1 次仍败即中止；后端失败即 error 态，
   均绝不以 0 值混入统计）、GUI 链接收积压/断线重连行为
   （迭代 42/48 加固，Operation Log 可观测）。
4. **模板策略**（迭代 34 起）：align_repeat_static/dynamic 的
   `template_name` **必填**——空/None → start 400 并列可用模板名，
   给了须已注册；作业不自建临时模板、结束绝不删用户模板
   （`calibration.py:344-360`、`:1635-1639`）。用户模板须在点亮光源
   状态下创建。低对比模板的经验噪声上限可把散布压到结果量化分
   辨率之下——迭代 28 起 s3=0 视为合法（物理封顶如实兜底，非链
   断裂，`tests/test_metrology.py:814-817`）。
   （全库仍自建 `_cal_<job_id>` 临时模板的只剩 focus_scan/
   pixel_equivalent/rotation_direction 三个旧标定项——无模板参数、
   不在测校软件 9 项内，属已知边界，`calibration.py:1640-1642`。）
5. **cancel/恢复语义**：协作式取消循环边界生效；done 的语义包含
   finally 现场恢复完成（`calibration.py:1723-1727`）。
6. **coarse 相机**：仅 FA_X 单轴（CH_Rz 是旋转轴，对居中 die 不
   产生像素位移，不能当点动轴，`calibration.py:143-147`）；k_nm≈9133，
   同像素散布下 nm 值大一个数量级，判读注意单位。GUI 链 20 列
   CSV 的固定四轴（AS/WS）对 coarse 档只是参考读数，动轴 FA_X
   不在其内。
