# 工艺流程：翻转取片（flip_pick）V1

2026-08-26（第 2 版）。翻转模块从蓝膜拾取芯片并翻转到粗对准姿态的参数化工艺流程——
**机械常数（machine_constants.json `flip_pick` 组）× 处方（recipe.json）
驱动的动态流程生成**，为后续上位机工艺开发打样。

- 生成器：`runtime/process_flows.py` → `build_flip_pick_flow(engine,
  die_id=None)`，生成时刻实时读常数+处方（PUT 改参后下一次运行自动跟随，
  天然热生效）。
- 执行：`FlowEngine.run_steps(steps, name)`（flow_engine.py 新增）——与
  flows.json 具名流程**共用同一状态机**（idle/running/paused/done/aborted）
  与 pause/stop/step/日志，面板"工艺流程"tab 经 `GET /api/flow/state`
  直接可见；运行冲突 409 沿用具名流程语义。生成结果（`steps_def` 含全部
  计算出的轴目标值）随 API 响应返回，供上位机核对/展示。
- API：`POST /api/process/flip_pick {die_id?, paused?}` → 生成并运行；
  die_id 缺省=离取片位最近的 film die；未知/不在 film 的 die_id → 400；
  **flip 载体已有 die 时 400，需先执行 `/api/process/flip_place_back`**。

## FA_Rx 姿态语义（2026-08-26 修正，全局统一）

- `FA_Rx = 0`：吸盘面朝上（芯片背面/无图案面朝粗对准相机，粗对准可见）。
- `FA_Rx = −π`：吸盘面朝下（取片位，面朝蓝膜 die）。
- 因此 `fa_rx_pick_rad = −π`，`fa_rx_flip_rad = 0`。

## 工艺时序（用户给定 6 步 + 碰撞安全/粗对准共 7 步）

| # | 步骤 | 轴/IO | 目标值来源 |
|---|------|-------|-----------|
| 0 | 抬 Z 到安全位（旋转前防碰撞） | FA_Z | `fa_z_safe_mm` |
| 1 | 翻转模块到取片姿态（拾取头朝下） | FA_X、FA_Rx | 常数 `fa_x_pick_mm`、`fa_rx_pick_rad`（−π） |
| 2 | 蓝膜台送目标 die 到取片位 | ES_X、ES_Y | `pick_point_xy_mm − film_stage 工具点 xy − die.film_pos`（工具点读 error_kinematics.json，不新造事实源） |
| 3 | 翻转 Z 下降到接触位 | FA_Z | `fa_z_pick = film_surface_z_mm + die_thk_mm − chuck_face_z0_mm`（吸盘面贴 die 顶面，含 die 厚防过压磨损） |
| 4 | 蓝膜顶针顶起 die + 过压 | ES_PunchZ | `es_punch = film_surface_z_mm + die_thk_mm + pin_overtravel_um/1000 − pin_top_z0_mm` |
| 5 | 开负压拾取 + 拾取判定 | ChuckVac `OpenNegtive` → `wait_grip`（超时 `pick_vac_timeout_s`）→ `wait_die carrier=flip` | 判定失败 → abort + 报警文本（见下） |
| 6 | 收尾 | 顶针降 0 → FA_Z 升 `fa_z_safe_mm` → FA_Rx 翻转到 `fa_rx_flip_rad`（0，芯片背面/素板面朝上）→ FA_Z 调 `fa_z_view_mm` 进粗对准景深 | 全部机械常数 |
| 7 | 粗对准中心微调 | FA_X | `coarse_die_center_mm`，使 flip die 进入 coarse FOV 中心 |

拾取判定两级报警文本（上位机报警语义对照）：
- `取片失败：ChuckVac 负压未建立（未拾取到芯片）`——wait_grip 超时；
- `取片失败：真空已建立但 die 未交接（carrier 未变 flip，transfers.json
  film_to_flip 条件未触发）`——wait_die 超时。

交接本身由 transfers.json `film_to_flip` 规则在条件满足上升沿自动完成
（FA_X∈[0±3]、FA_Z∈[−5±3] + ChuckVac 负压）。**选片物理保真**：规则无
die_site 时，from=film 的交接选"拾取头（flip 工具点 xy）正下方最近的
film die"（workpieces._select_die，2026-08-24 修正——旧行为 cand[0]
会抓错片）。

## 逆向流程：把芯片放回蓝膜（flip_place_back）

- API：`POST /api/process/flip_place_back`。
- 约束：flip 载体必须有 die，否则 400。
- 时序：
  1. FA_Z 抬到 `fa_z_safe_mm`；
  2. FA_Rx 转到 `fa_rx_pick_rad`（朝下）；
  3. FA_Z 下降到 `fa_z_pick`（贴蓝膜）；
  4. ChuckVac `OpenPositive` 吹气破真空；
  5. `wait_die carrier=film`（确认 die 已回到 film）；
  6. FA_Z 抬到 `fa_z_safe_mm`，流程结束。

## 常数 × 处方联动（改参即变，回归 19.3 锁定）

- die 厚 t 变 → `fa_z_pick` 与顶针目标同步变（t 0.5→0.8：FA_Z_pick
  −4.2→−3.9、顶针 1.65→1.95）；
- `chuck_face_z0_mm` 变 → FA_Z_pick 变（891.6→891.0：−3.9→−3.3）；
- `pin_overtravel_um` 变 → 顶针目标变；
- `fa_z_view_mm` 变 → 收尾 FA_Z 变（粗对准对焦补偿）；
- `fa_z_safe_mm` 变 → 所有旋转前的抬升高度同步变。

## 上位机开发对照（变量名映射）

流程生成器内变量名即常数/处方式样名：`pick_x/pick_y`←`pick_point_xy_mm`；
`film_surface_z_mm`、`chuck_face_z0_mm`、`pin_top_z0_mm`、`fa_x_pick_mm`、
`fa_rx_pick_rad`、`fa_z_safe_mm`、`fa_rx_flip_rad`、`fa_z_view_mm`、
