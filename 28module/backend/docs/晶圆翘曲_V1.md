# 晶圆翘曲_V1 —— bow+saddle 二维静态场 × 逐片物料真值 × 共焦/视觉/接触位贯通（2026-10-14 迭代 73）

晶圆翘曲（wafer warpage）仿真层：把"晶圆面是平的"这一历史假设升级为可开关的
二维翘曲场，贯通高度测量链（共焦/调焦调平/寻力几何支路）、视觉离焦链
（FAST blur_ratio / REAL 模糊核）与键合接触位（真值力）。默认 OFF 热切换，
与模态（迭代 22）/热仿真（迭代 23）同规格。

> 迭代 77：顶栏「误差全关」开启时，已有或显式注入的翘曲均不进入共焦、视觉
> 离焦或接触位；新上片抽取零翘曲。参数与本模块独立 `enabled` 状态保留。

## 1. 模型与方程

### 1.1 翘曲几何（晶圆局部系）

晶圆局部坐标系 (u,v)：原点=晶圆心（上片 offset 后的世界位置），随片旋转
（局部系 yaw = wafer_stage 模块姿态 rz + WS_Rz 轴值 + 上片 rz 真值——翘曲是
物料属性，随片随台一起转）。R = 晶圆半径（recipe.wafer.diameter_mm/2）。

面内高度场（V1 二阶双分量）：

```
z(u,v) = bow·(1 − r²/R²) + saddle·(r²/R²)·cos(2·(φ−θ))
         r² = u²+v²，φ = atan2(v,u)，θ = saddle_ang_deg（周期 180°）
```

- **bow（穹顶）**：球面拱起，z(心)=bow、z(边缘)=0；bow>0 = 心高边缘低
  （dome）。物理来源：薄膜应力均匀分量（背面镀层/氧化层应力）、研磨
  损伤层。300mm 裸 Si（775µm 厚）典型 <50µm；薄片/键合片可达数百 µm。
- **saddle（马鞍/薯片）**：bimetal 型二阶项，边缘幅值 ±saddle（两峰两谷）。
  物理来源：应力各向异性、吸盘夹持不均。
- **线性坡度项不重复建模**：上片 rx/ry 倾斜注入（recipe wafer_load）已覆盖，
  翘曲场只含曲率分量（bow/saddle 在面内均无净线性项/净平移）。

局部坡度（小角=梯度，观测/文档用）：bow 径向 ∂z/∂r = −2·bow·r/R²（边缘
|坡度|最大）；saddle 梯度在旋转系解析求导后回转（warpage.warp_tilt_rad）。

### 1.2 解算：读时合成（无 tick）

翘曲场是**静态解析场**——无积分态、无主循环开销。消费侧在读取时刻把
dz(x,y) 热查叠加进各自的真值面高/接触位（口径同 thermal 的 deform_map
"读取时合成"注入，error_kinematics.py 的 thermal_on 热查先例）。OFF/未挂
载/无片/无实抽真值 → 恒 0，读数逐位不变（i73.warpage_off_zero_impact
钉死）。

### 1.3 与物理主循环的关系

不挂 1kHz tick。唯一的周期性消费在 engine._refresh_loop_consts_locked
（1Hz 机器常数热读窗）：键合接触位 warp_dz 随窗刷新（迭代 56 热修正
dz_c−dz_h 同槽位）。共焦/视觉侧全部按需（读数/拍照时）计算。

## 2. 参数与默认值（warpage.json）

| 键 | 默认 | 域 | 语义 |
|---|---|---|---|
| bow_um | 30.0 | [-500,500] µm | 穹顶幅值（心高为正）；300mm 裸 Si 典型 <50µm |
| saddle_um | 12.0 | [-500,500] µm | 马鞍边缘幅值 |
| saddle_ang_deg | 0.0 | [-360,360]° | 马鞍方位角（晶圆局部系，随片旋转） |
| jitter_pct | 20.0 | [0,100] % | 逐片抽取抖动（名义幅值高斯 σ 百分比；0=每片=名义值） |

**全部为工程估值，待真机翘曲实测（平顶仪/干涉仪/共焦面扫描）标定**——与
modal fn/ζ"待 FRF 辨识"、thermal CTE/kc"待热态实测"同口径。

**物料真值语义**（与设备本体参数的本质区别）：warpage.json 存的是**分布
参数**（名义值+抖动），不是某片晶圆的真值。上片时 WarpageSystem.draw()
按 jitter 从**私有 RNG** 抽取本片 {bow_um, saddle_um, ang_deg} 挂 wafer
实例（workpieces.wafer_warp，下片/复位/处方应用清空）——私有 RNG 不污染
全局随机序列（thermal 环境游走同口径，防既有测试基线漂移）。PUT 改参数
不动已在位晶圆的实抽真值（下一片起按新分布抽取）。显式真值注入通道：
POST /api/workpiece/wafer 带 warp={bow_um,saddle_um,ang_deg}（确定性测试/
SOP 复现用，校验域同参数表）。

## 4. 与其他层的耦合

- **热仿真**：单向独立。热变形是设备结构 6DOF 位姿漂移（deform_map），
  翘曲是晶圆物料面形；两者在共焦面高/接触位**叠加**（热 chuck_z_growth
  抬整个吸盘面，翘曲在其上面内起伏）。热仿真 docstring 的"热斑→晶圆
  局部翘曲属下一代"指**热致翘曲**（温度梯度引起的时变翘曲），V1 不建
  （静态场），见 §11。
- **模态**：无耦合（振动叠加在面高读数噪声层，不与静态场互调）。
- **EGA/精对准**：XY 测量链不受影响（远心投影 z 不进 (x,y)）；翘曲经
  离焦影响 REAL 链图像质量，间接考验识别鲁棒性。

## 5. 调研依据（方案选型）

- 翘曲二阶分解（bow 球面 + saddle cos2θ）是 SEMI 标准与晶圆几何计量
  （GB/T、SEMI MF534 bow 定义、光刻机 wafer shape 建模）的通行最低阶
  展开；更高阶（三瓣/W 形）待真机数据驱动再加。
- "读时合成"注入选型同 thermal deform_map：真值单源（场方程）+ 消费侧
  热查，避免在每个消费点维护副本（防漂移）。
- 逐片抽取挂 wafer 实例：与 wafer_load z/rx/ry 上片注入同语义（物料真值
  随片走），而非 machine_constants（设备本体可标定量）——参数归位经
  2026-10-14 误差链评审确认。

## 6. 与参考项目对比

模态/热仿真是"设备本体"层（结构动力学/热学），翘曲是**首个股物（物料）
层仿真**：首次把物料形状真值纳入误差链。至此评审指出的三大缺口（晶圆
翘曲/光学畸变/伺服环动态）补齐其一；翘曲→接触位/离焦的贯通路径与
真机"翘曲→逐 die 焦面/键合压力波动"问题链一致。

## 10. 实机标定路线

1. 平顶仪/干涉仪面扫描实测若干片晶圆 → 最小二乘分解 bow/saddle（r² 与
   r²cos2θ 基）+ 残差评估是否需更高阶项；
2. 统计多片幅值分布 → 标定 jitter_pct；
3. 与本模型对照：共焦多点面扫描（现有 fl_measure 栅格即可采集）重放
   实测片，校核场方程符号/方位约定；
4. 翘曲→键合良率关系（薄 die 压合 void 率）属工艺层，V1 不建（§11）。

## 11. 已知边界

- **无热致翘曲**（温度梯度→时变面形）：热仿真节点均温，热斑→局部翘曲
  属下一代（热仿真_V1 §11 同记）；
- **XY 真值不贯通**：翘曲坡度经杠杆的 XY 效应量级 |∇z|×杠杆 ≈
  0.3µrad×数十 mm ≈ nm 级，低于轴重复性 3σ=40nm 噪声地板，V1 不建；
  die 在翘曲面上的落位倾斜（压合平行度）同理未建（~µrad 级，工艺层
  课题）；
- **r>R 不截断**（多项式延拓）：与面高公式的无限平面假设同口径——超出
  晶圆边缘的测量本无物理目标；
- **die 层按 die 心整体平移**：翘曲坡度跨 die（~10mm）的面内变化 ≪DOF，
  不逐角标分级；
- **场景盘渲染不变形**：REAL 渲染的晶圆 disc 仍画平面（翘曲经标记 z
  进入离焦链；盘体变形渲染属可视化增强，非误差链）；
- **蓝膜/die 自身翘曲不建**（die 膜面形态另属蓝膜张紧问题）。
