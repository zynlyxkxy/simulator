## 1. 产率口径（UPH）

- **UPH = 成功键合颗数 / 生产时间**；生产时间 = **首颗取片开始 → 末颗
  键合结束的净流水时间**（sim_t 口径；回零 / EGA / 上片 / 闲置**不计
  入**——run 级 t_first=第一颗 die flip_pick 阶段起点 sim_t、
  t_last=最后一颗成功 die bond 阶段终点 sim_t，net = t_last − t_first）。
- 分阶段耗时五段：`flip_pick`（取片，含粗对准）/ `flip_handoff`（交接）
  / `focus_level`（调焦调平）/ `fine_align`（精对准）/ `bond`（键合）
  ——参照参考项目 prep（不占硅片台段）/ bond（占硅片台段）拆分思路，
  每阶段在 runner 侧以 sim_t 计时，存进 bond_results 记录 `timing.
  stages`；`wafer_ega` 阶段不计入（对应"回零/EGA/上片/闲置不计入"）。
- 记录 `timing`：`{t_start, t_end, stages:{...}}`（每 die；pipelined 且
  预取命中时 flip_pick 段=预取时长，t_start=预取启动 sim_t）。
- run 级记账 `BondResults.throughput_add(ok, fail, net_s, stage_durs,
  overlap_s)`：单片链每次运行记一笔（ok=1/fail=1），全片批次结束记一
  笔（ok/fail=批次计数，net=首颗取片→末颗键合，stage_durs=成功颗阶段
  耗时汇总，overlap=预取重叠总和）。随 `bond_results.json` 持久化
  （`throughput` 键），`POST /api/workpiece/reset`（clear）一并复位。
- `GET /api/bond/throughput` 输出：
  `{ok, runs, ok_count, fail_count, net_time_s, uph_total, uph_recent,
  recent_n, stage_avg_s, overlap_s, _note}`
  - `uph_total` = 3600 × ok_count / net_time_s（net>0 且 ok>0，否则
    null）；
  - `uph_recent` = 3600 × (N−1) / (最近 N 条记录末次−首次 t_end)
    （N≤10，按 timing.t_end 排序；流水线友好——按完成节拍而非单颗
    墙钟）；
  - `stage_avg_s` = 五阶段各自均耗时（s/颗，无数据为 null）；
  - `overlap_s` = 产率模式预取重叠时间累计（串行恒 0；单列，参照
    backend overlap_ms）。
  - **`live` 进行中实时块**（2026-09-06 迭代 17 WP-C 产率实时化；
    `throughput_public(eng)` 从 ChainRunner/FullWaferRunner status +
    eng.sim_time 组装，duck-typing 不 import runner）：
    - 无运行 → `live=null`；
    - 全片运行中 → `{active:true, kind:"full"|"pipelined"（按处方
      full_wafer.pipelined）, current:{die,site:[r,c],stage},
      progress:[i,n], run_ok, run_fail（本轮已完成/失败颗数，
      来自 results 计数）, cur_elapsed_s（当前颗已耗时=sim_t−当前颗
      t_start；runner 把每颗 t_start 挂进 status.current、首颗起点挂
      run_t_first）, est_uph（本轮已完成实测 UPH=3600×run_ok/
      (sim_t−run_t_first)，run_ok=0 为 null）}`；
    - 单片链运行中 → `{active:true, kind:"single", current:{die:null,
      site,stage}, progress:null, run_ok:0, run_fail:0, cur_elapsed_s
      （=sim_t−链首个实跑阶段起点，ChainRunner._state.t_start），
      est_uph:null}`（单片=1 颗，完成前 done=0）。

## 2. 产率模式（pipelined，流水线预取）

- 开关：处方 `full_wafer.pipelined`（默认 **false=串行**，现有行为不
  变；处方面板"全片键合"组有开关）。机械常数 `flip_handoff` 组新增
  **`fa_x_standby_mm`（默认 −1050.0，翻转模块携片待机位；待真机标定）**。
- **触发窗口**（类比 backend 安全相位）：当前 die 完成 `flip_handoff`
  （芯片已上键合头）即为安全点——取片交接链（FA/ES 轴系 + 翻转真空）
  不碰键合头/硅片台/对准台资源，窗口 = flip_handoff 完成后即可（本机
  没有"热/力保持才安全"的更严约束，因预取链与键合链轴系天然不相交）。
- **流水线时序**：die i 的 flip_handoff 完成 → 立即为 die i+1 在**第
  二 FlowEngine 实例**（runner 懒创建，主 eng.flow 跑当前颗的
  focus_level/fine_align/bond，两链互斥由引擎层碰撞检查兜底）执行
  `flip_pick(die i+1)`（含粗对准）→ FA_Z 回安全位 → 携片到待机位
  `fa_x_standby_mm` 等待；die i bond 完成 → 立即 `flip_handoff(i+1)`
  （从待机位到交接位）。预取与当前颗后段并行的时间记 **overlap_s**
  （= min(预取结束, 当前颗 bond 结束) − 预取启动，逐颗累计）。
- **异常语义**（backend 对齐）：
  - 预取失败/未完成 → 记 `window_missed`（状态计数）回退串行，**不影
    响当前颗**（当前颗键合早已完成）；该 die 的 results 条目带
    `prefetch_error` 明细（含 flow2 失败步骤信息）。
  - 预取半成品（die 已拾到 flip 才 abort）→ 回退前先跑
    `flip_place_back` 放回蓝膜恢复干净起点，再串行 `flip_pick`；
    回退失败则该 pair 记 fail（错误含回退原因）。
  - full_reset / 人工 stop：主流程 FlowEngine.stop 之外，预取线程的
    flow2 同步 stop；runner 收尾等预取线程退出（join ≤5s）。
- **沙盒干涉**：待机位与预取动作序列全部走现有引擎层碰撞检查（起步
  409/运动中 soft-stop）。初值 −1050 的实测依据（迭代 15 冒烟）：曾取
  −1100——待机吸盘盒 min x≈54.4，与对准相机承载台盒（fl_measure
  die/up #4 走位 AS_X≈+3.8 时 max x≈56.8）相交 2.4mm > ε（2mm），
  fl_measure 起步 409、两流程同时 abort；外移 50mm 到 −1050 后待机吸
  盘盒 min x≈104.4，与承载台全程净空 ~47mm（回归 i15.pipelined_done
  预取全成功验证）。
