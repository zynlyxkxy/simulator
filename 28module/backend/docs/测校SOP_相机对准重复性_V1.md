# 测校SOP_相机对准重复性_V1 —— align_repeat_static / align_repeat_dynamic 静态·动态合订（2026-09-07 初版；2026-09-08 迭代 25 修订：测校工作台 UI、template_name、动态 start_xy/photo_xy 绝对坐标）

> **本文档已被 `相机对准重复性_V1.md` 取代（时序/计算/示例以新文档为准），保留供历史参考。**

相机对准重复性测校作业的操作规程。两个测校程序（routine）合订一份：

- `align_repeat_static`：静态——设备静止下连续拍照识别对准标记，统计
  row/col 像素坐标 3σ（换算 nm），评估相机自身的测量稳定性。
- `align_repeat_dynamic`：动态——运动机构在 **起始位置→拍照位置**
  （绝对坐标，每循环 起始位→等待→拍照位→等待→拍照）间往复，
  统计 row/col 3σ（nm）+ 往复轴到位 3σ(µm)，
  评估相机读数与机构重复定位的综合稳定性。

两程序全部走 REAL 视觉链路（需 cv2）。模板两种用法（2026-09-08 迭代 25
起）：**默认**由作业在当前位自动示教、结束自删；也可在"视觉模板名称"
里填**已在视觉页注册**的模板名（模板须在当前机位用点亮光源的状态创建，
作业结束不删除用户模板）。作业期间占用机器（有作业运行时 409 拒并发），
结束自动恢复轴位/光源/视觉模式。纯测量程序，无"应用写回"。

参考真机 SOP：`测校/重构后SOP/相机对准重复性测试/相机对准重复性测试_SOP_V2.docx`、
`测校/重构后SOP/相机动态对准重复性测试/相机动态对准重复性测试_SOP_V2_最新.docx`。

## 1. 范围

- 工具对象：测校页（panel）**测校工作台**（2026-09-08 迭代 25 起，
  嵌入式单测校项工作台，对齐参考框架 HoriMetrologyScirptsFramework 的
  独立 GUI 形态）——左侧测校项列表选择 上/下/粗对准相机 × 静态/动态
  共 6 项，对应 `align_repeat_static` / `align_repeat_dynamic` 程序。
- 使用人员：设备精度测试工程师、视觉系统维护工程师。
- 应用阶段：设备安装调试、相机更换或维护后、定期视觉模板精度校验。
- 静态与动态的区别：
  - 静态：测试期间各运动轴保持静止，结果只反映相机读数稳定性
    （图像噪声 → 质心/模板匹配波动）。
  - 动态：每次拍照前都含一次完整 起始位→拍照位 往复运动，结果 =
    相机读数稳定性 + 运动机构重复定位精度，3σ 显著大于静态为正常现象。

## 2. 输入

| 参数 | 键名 | 说明 |
| --- | --- | --- |
| 相机 | cam | 由工作台测校项决定：`up`（上精对准）/ `down`（下精对准）/ `coarse`（粗对准） |
| 视觉模板名称 | template_name | 可选。空 = 作业启动时在当前位自动示教临时模板、结束自删；填名 = 使用该**已注册**模板（不存在 → 400 并列出可用模板），结束不删除 |
| 重复次数 | repeat | 连续拍照识别的循环次数，[10,1000]，默认 50；**建议 ≥50** 保证 3σ 统计有效性 |
| 等待时间 | wait_ms | 每次拍照前的等待时间（ms），默认 10，≥0；等相机/运动与视觉稳定 |
| 起始位置 (x,y) | start_xy | **仅动态**，绝对坐标 mm；X 分量→第 1 根载体轴、Y→第 2 根（coarse 仅 FA_X，只用 x）。每循环先走到起始位 |
| 拍照位置 (x,y) | photo_xy | **仅动态**，绝对坐标 mm；起始位等待后走到拍照位、再等待、再拍照。两点都不得超轴软限位 |
| （兼容）往复行程 | travel_mm | 旧参数别名：未给 start_xy/photo_xy 时按旧语义 拍照位=当前位、起始位=拍照位−travel（[0.1,20]，默认 5） |

运动类型（只读提示）与载体轴映射：`down`→晶圆台 WS_LS_X/Y、
`up`→对准台 AS_X/Y、`coarse`→翻转模块 FA_X（仅 X 向单轴）。

参数在工作台 Input Parameters 卡片内设置，启动时经
`POST /api/calibration/start` 提交。

## 3. 输出

- 趋势图（Result Display）：row、col 两幅子图上下排（X=循环序号，
  Y=nm——后端随结果下发 `series_nm` = px 序列 × nm_per_px；标题行内嵌
  各自的 **3σ nm**，黄虚线=均值）；有角度系列时第三幅为角度波动
  （Y=µrad 偏移）。
- 统计摘要行：repeat / wait_ms / template_name / nm_per_px /
  csv_name / 耗时；动态附各往复轴到位 3σ(µm)。
- 操作日志（Operation Log）：逐行滚动——每循环 `cycle time: i / n`、
  每次检测 `detect result: row: …, col: …`、结尾
  `data saved: <csv文件名>`（后端 status 的 `log` 字段，环形 200 行）。
- CSV 数据文件：落盘于 `runtime/metrology_data/`，时间戳命名；
  列定义 = index（循环序号）、col、row（像素坐标 px）、（有角度时）
  angle_deg、（动态）各往复轴到位列（mm，列名=轴名，如 WS_LS_X）。

## 4. 前提准备

1. **标记载体在位**：所测相机视野内必须有可识别的对准标记——
   - `down`：晶圆已上片（wafer 在位）；
   - `up`：键合头已取 die（die 在头）；
   - `coarse`：翻转模块上有 die。
   无标记则识别必然失败。
2. **轴已回零**：相关运动轴完成回零，坐标系可信。
3. **视觉 REAL 链路可用**：需 cv2（REAL 链路依赖；链路不可用时作业
   启动即报错）。
4. **模板两种用法**：默认无需预建（作业启动时在**当前位**自动示教、
   结束自动删除）；若使用"视觉模板名称"指定的已注册模板，该模板必须
   是在标记清晰位于视野内、**光源点亮**状态下创建的（暗图模板必然
   匹配失败）。无论哪种，启动前都须把轴点动到"标记清晰位于视野中心"
   的拍照位（动态程序即 photo_xy）。
5. **工艺流程未在运行**：作业期间占用机器（409 拒并发），动态程序
   会实际动轴，务必确认无工艺流/其他作业在跑。
6. **行程安全（动态）**：start_xy 与 photo_xy 两点都必须在对应轴
   软限位内（启动时后端校验，越界 400 报轴名与限位）；往复路径上
   无障碍。
7. **作业期间不要操作轴控面板**：任何手动点动都会污染测量
   （静态直接报废本次数据，动态叠加额外误差）。

## 5. 操作步骤

1. 打开控制面板 → 测校页 → 左侧**测校项列表**点击要测的项（如
   "下精对准·静态对准重复性"）；右侧出现该测校项的工作台。
2. 在 Input Parameters 卡片设置参数：视觉模板名称（可空）、repeat
   （默认 50）、wait_ms（默认 10）；动态项另设 起始位置/拍照位置
   (x,y)（coarse 项只有 x 可填）。
3. 点"开始测量"。有作业在跑时后端返回 409，启动被拒；作业运行中
   参数区与按钮自动禁用。
4. 作业运行中：标题条右侧显示进度（i/N），Operation Log 逐行滚动
   `cycle time` / `detect result`。
5. 完成后 Result Display 显示 row/col 趋势图（标题含 3σ nm），日志
   以 `data saved:` 落尾；历史作业列表（近 20 条）可点行回看。

## 6. 结果分析

- **核心指标**：row/col 的 3σ(nm)，越小越好——表示静态下相机对
  标记读数的稳定性 / 动态下读数+机构重复定位的综合稳定性。
- **换算公式**：`3σ(nm) = 3 × std(px) × nm_per_px`。
  各相机 nm_per_px：up/down = 600（k≈0.6 µm/px）、
  coarse ≈ 9133（k≈9.133 µm/px）。
- **验收参考（静态，源自测校需求文档）**：up 约 ≤84 nm、
  down 约 ≤91 nm。
- **与噪声配置联动**：实测 3σ 直接取决于 sim_sensors 页各相机的
  噪声设置——FAST 链看 `FAST_NOISE_PX`，REAL 链（默认）看
  `real_noise_scale`（迭代 27 起，渲染底版逐帧去相关 + 倍率旋钮）。
  判读结果前先核对配置。量级参考：real_noise_scale=1 时 down 静态
  3σ≈2~3nm（纯传感器噪声地板）；scale=4≈9nm、10≈28nm。真机验收量级
  （up≈84nm/down≈91nm）还包含振动/热漂移等——仿真里对应模态仿真
  地板激励（默认 OFF），要复现真机量级可同时开模态仿真或调大
  real_noise_scale。
- **曲线形态**：理想曲线在均值附近平稳随机波动；趋势性漂移、周期
  性波动、异常跳变均为异常（见 §7）。
- **动态判读**：动态 3σ 含机构重复定位误差，显著宽于静态为正常；
  异常偏大时先跑一次静态对比，区分问题来自相机读数还是运动机构
  （轴到位 3σ(µm) 行可直接看机构重复定位分量）。

## 7. 异常排查

| 异常现象 | 可能原因 | 排查方向 |
| --- | --- | --- |
| 识别失败 / 返回无效坐标 | 标记载体不在位（down 无晶圆 / up 无 die / coarse 翻转模块无 die）；标记不在视野内；REAL 链路 cv2 缺失 | 先上片或取 die；点动使标记居中；确认视觉 REAL 链路可用 |
| 启动报错 409 | 有测校作业在跑 / 工艺流程运行中 | 等当前作业结束；确认工艺流已停 |
| 3σ 异常偏大且曲线随机跳动 | FAST_NOISE_PX 设置过大；标记对比度差 | 核对 sim_sensors 页该相机噪声配置；检查标记与照明 |
| row/col 曲线趋势性漂移 | 仿真侧：热仿真开启引入热漂移；真机侧：环境温度变化、未预热 | 查热仿真开关状态（默认 OFF）；真机预热 30 min 以上再测 |
| 曲线周期性波动 | 模态仿真激励未关；外部振动；照明频闪 | 查模态仿真开关（默认 OFF）；远离振源；检查光源 |
| 运动报错 / 运动不到位（动态） | start_xy/photo_xy 超轴软限位（400 会报轴名与限位）；轴未回零 | 复核两点坐标；先回零再测 |
