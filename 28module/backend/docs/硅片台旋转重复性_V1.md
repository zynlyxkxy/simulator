## 1. 测的是什么

**定义**：硅片台绕 Z 轴（WS_Rz）从基准角 rz0 转到 rz0+rot 后，晶圆上
标记相对"绕枢轴理想旋转"的偏差。分两个互补口径：

- **角度口径**：每循环跨点最小二乘拟合实际旋转角 θ_i，角度误差
  `e_i = θ_i − rot_rad`——mean = 系统角偏差（增益/零偏类系统误差），
  **3σ = 旋转角重复性**（主指标，对应 SSPS「计算 3σ 值」）。
- **位置口径**：各点拟合残余（旋转分量已被 θ_i 吸收后的平移
  残差）的 3σ（nm）——WS_LS 平移轴到位重复性、相机识别噪声、示教点
  处杠杆残差。

对应 SSPS 误差合成 `σ_硅片台总 = √(σX² + σY² + (R·σRz)²)`：逐点拟合
残余即 σX/σY，angle_err 3σ 即 σRz。

**唯一模式：taught 示教多点（直接测角法·双示教位）**。迭代 34 起
**auto 全自动路径已移除**（start 无 taught_points → 400；`detail.mode`
恒 `"taught"`）；迭代 35 起**双示教位改造**：旋转后走访不再由后端按
认知枢轴预测走位（Δ=(I−R)(P−c) 段与 start 预估 400 已删），改为逐点
走**用户直接示教的旋后可见位 `pose_after`**（缺省=`pose` 同位复测）：

| 模式 | 触发 | 测法 | 什么时候用 |
|---|---|---|---|
| `taught` 示教多点（**直接测角法·双示教位**，唯一模式） | 给 `taught_points`（2~10 点，每点 `{tpl, pose, pose_after 可选}`）或旧四键（映射为 2 点，`runtime/calibration.py:640-646`）；**缺示教参数 → start 400**（迭代 34 起；`calibration.py:567-572`） | 基线逐点走 `pose` 测世界坐标 P_k → WS_Rz 走 rz0+rot_rad → 逐点走 **`pose_after`**（用户示教旋后可见位）实测 Q_k → 跨点 `_fit_rot` 闭式拟合实际旋转角 θ_i → e_i=θ_i−rot_rad | 生产口径：按工艺关心的具体点位评估；点位/模板/旋后可见位受控可复现；旋转中心/增益两个标定 routine 共用同一示教几何 |

直接测角法与旧"回零重测差分"的差别：旧法 Rz 转完**回零**再重测
（测的是"回零后相对基线的残余"）；直接测角法在**旋转态**下按旋后
示教位跟拍（测的是"实际转了多少角"），系统角偏差与随机重复性分离。
（auto 全自动路径曾是附件 4.2 基线向量法的直接实现，2026-09-15
迭代 34 删除——历史对照见 §9。）

### 2.3 双示教位 pose_after（迭代 35；预测走位 Δ 段已删）

旋转态下标记随晶圆绕枢轴转 θ，双示教位由**用户直接示教旋后可见位**
`pose_after`（四分量 {AS_X,AS_Y,WS_LS_X,WS_LS_Y}，与 pose 同结构）：

- **示教口径**：把 WS_Rz 转到 rz0+rot_rad，按旋后实际可见位重新居中/
  走位示教该点（GUI 示教表旋前/旋后双取位按钮分别回填，
  `metrology_gui/WsRotateRepeat.py` 模块 docstring:14-24）；
  `pose_after` 缺省=`pose`（同位复测）——小角度（杠杆×rot ≪ FOV 半宽
  0.9mm）时可不示教旋后位。
- **几何参考**（示教 pose_after 的估算式，非后端职责）：旋后保持标记
  在视场内所需 WS 平移 ≈ `Δ = (I−R(rot))·(P−c)`（c=认知枢轴）——这正是
  迭代 35 前后端预测走位的公式，现在只作为用户示教时的参考；回归测试
  侧的 `_rot_pose_after`（`tests/test_metrology.py:2327-2361`）即按
  该式为用户生成等价 pose_after。后端本体不消费任何枢轴认知
  （`_rz_pivot_belief` 仅在 center/gain 的 detail 参照位出现，见 §5）。
- **软限位两道防（现行）**：start 逐轴校验——pose_after 与 pose 同走
  `_check_taught_pose` 逐轴软限位 400（`calibration.py:669-697`，
  未知轴/非数值同 400）；运行期守卫 `_walk_limit_guard`
  （`extra_routines.py:634-646`——每点下发前复核 WS_LS_X/Y 目标，
  越限抛清晰 CalibError，提示检查该点 pose_after 旋后示教位）。
  **迭代 32 的 start 预估 400（`_check_rotate_pred_limits`，按示教位
  估计标记世界 P、预演 Δ）已随预测走位段一并删除**。

与预测走位的本质差别：旧法后端按认知枢轴 c 算 Δ 并叠加在 WS 目标上，
枢轴认知误差×旋转角决定标记是否留在视场内；双示教位把"旋后标记在哪
可见"完全交给用户示教（实测 Q_k 仍是真实拍照反算），算法不再依赖
枢轴认知，大角度/大杠杆场景的可见性由示教者保证。

### 2.4 跨点 _fit_rot 闭式拟合实际旋转角 θ_i → 角度误差 e_i

代码 `extra_routines.py:769-770`，拟合助手 `_fit_rot`
（`extra_routines.py:560-597`，旋转三件套共用）。设基线世界坐标集
`P={P_k}`、当次旋转态实测集 `Q={Q_k}`（k=1..N，均为 2.2 的
world_ref）：

```
重心        P̄ = (1/N)·Σ P_k         Q̄ = (1/N)·Σ Q_k
向量集      u_k = P_k − P̄           v_k = Q_k − Q̄
Σcross = Σ_k (u_k.x·v_k.y − u_k.y·v_k.x)
Σdot   = Σ_k (u_k.x·v_k.x + u_k.y·v_k.y)
θ_i    = atan2(Σcross, Σdot)         (rad；Σdot ≤ 1e-12 取 0——
                                       点全重合退化守卫，:583)
C      = (I−R(θ))⁻¹·(Q̄−R(θ)·P̄)     （旋转中心 2×2 直接解，
                                       det=2(1−cosθ)；本 routine 弃用，
                                       center/gain 用，见 §5/§6；
                                       det<1e-18 → CalibError
                                       "角度档退化"，:584-592）
e_i    = wrap(θ_i − rot_rad, ±π)     (:770)
```

即 2D Kabsch/正交 Procrustes 闭式解：只允许刚体旋转（重心消平移、
不许缩放）下使 `Σ|R(θ)·u_k − v_k|²` 最小的转角。atan2 拟合**平移
自由**：旋转台跑出（平移误差）不进 θ_i，只有星座的**纯旋转**进入——
这是直接测角法把"系统角偏差"从平移误差中分离出来的关键。

**为什么在世界坐标系拟合而不在像素系**：示教点各自居中拍摄，N 个
点的像素全部 ≈ (1500,1500)，像素向量集 u_k≈0 → Σdot≈0，atan2 退化
为纯噪声（迭代 31 冒烟实测散布 ±2 rad）。补偿后的世界坐标按晶圆
几何散布（百 mm 杠杆），旋转信息完整保留。

### 2.5 每点位置残余：拟合残余

代码 `extra_routines.py:775-790`。旋转分量已被 θ_i 吸收后，逐点残差：

```
r_k = v_k − R(θ_i)·u_k      (世界系 mm)
d_col_nm[k].append(r_k.x × 1e6)     # mm→nm
d_row_nm[k].append(r_k.y × 1e6)
d_col_px[k].append(r_k.x × 1e6 / k_nm)   # 兼容 px 键
d_row_px[k].append(r_k.y × 1e6 / k_nm)
```

`k_nm = nm_per_px(svc, "down")`（`extra_routines.py:710`），定义
`metrology/repeatability.py:42-45`：`k_nm = cam.pixel_um / cam.mag ×
1000`——即 machine_constants.json `cameras.down.pixel_um / .mag`
= 6.0/10.0 = 0.6 µm/px = **600 nm/px**（与 `vision_model.py:505-508`
派生 k_mm 同一事实源）。

统计（`extra_routines.py:825-841`）：每点每轴 3σ 同时给 px 与 nm
（ddof=0，见 2.6）。物理含义：θ_i 已把当次旋转（含 Rz 回零残余的
旋转分量）吸收，残余 = 平移轴到位误差 + 识别噪声 + 逐点杠杆残差。

### 2.6 统计口径

`_mean_std`（`metrology/repeatability.py:186-191`），**总体 ddof=0**：
`σ = sqrt( (1/n)·Σ(x_i − mean)² )`，`3σ = 3σ`。

- 各点位置残余：n=repeat → `stats.points[k]`
  （`extra_routines.py:833-837`）与 `series.points[k]`
  （`:828-832`，nm 与 px 同出）。
- 角度误差：n=repeat 个 e_i → `stats.angle_err.{mean_urad, std_urad,
  s3_urad}`（`:838-841`），**mean=系统角偏差、s3=旋转角重复性**；
  序列 `series.angle_err_urad`（e_i）与 `series.theta_fit_urad`
  （θ_i 本体，µrad，`:847-848`）。
- **兼容字段**（迭代 32 保留，防旧客户端渲染崩，
  `extra_routines.py:846-860`）：`stats.dtheta` 填 angle_err 同一统计
  （不是旧"回零差分角"）、`stats.residual`/`series.d_col_px/d_row_px`
  填点 0 拟合残余、`series.dtheta_urad` 填 e_i 序列。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 晶圆已上片（`POST /api/workpiece/wafer`；start 校验
   `runtime/calibration.py:560-562`）。
2. 视觉链路可用 cv2（REAL 模式必需；start 统一拦
   `runtime/calibration.py:289-291`）。
3. 无工艺流程在跑（建议；本 routine 的 start 校验不做流程忙拦截）。
4. WS_Rz 置于测量基准角（通常 0；该位置即 rz0）。
5. 各示教点模板**已在视觉页注册**（下相机 REAL 模板；作业不自建不删，
   校验 `runtime/calibration.py:656-667`）。**宜选小标记**（site
   quad 150µm）——大 cross（2mm 晶圆全局十字）在渐晕下跨旋转态
   NCC 质心有 θ 相关系统差（详见 5.5 模板策略实测）。

### 3.2 示教流程（2~10 点，双示教位）

1. **选点**：推荐跨片远点（wafer_mark_1/2/3/4 或键合区周边 site
   quad）——点间杠杆越长 θ_i 越准（量级式见 7.3）。**每个点须使
   标记在 rz0 可见**（基线在 rz0 拍摄）。
2. **逐点示教旋前位 pose**：WS_LS 走位把标记居到下相机视场中心（可用
   `GET /api/vision/guide?cam=down` 引导）；注册/确认模板；记录四轴
   示教位 {AS_X, AS_Y, WS_LS_X, WS_LS_Y}（panel 测校页 / PyQt5 测校
   GUI 均有「取当前位」按钮；GUI 示教表旋前/旋后双取位分别回填，
   `metrology_gui/WsRotateRepeat.py` docstring:14-24）。pose 分量允许
   留空，后端按当前位补齐（`runtime/calibration.py:687-688`）。
3. **按需示教旋后位 pose_after**：把 WS_Rz 转到 rz0+rot_rad 后，若
   标记会转出视场（杠杆×rot 接近/超过 FOV 半宽 0.9mm），按旋后实际
   可见位重新走位示教该点四轴位；小角度（杠杆×rot ≪ 0.9mm）可省略，
   缺省=pose 同位复测（`calibration.py:650-653`）。旋后位估算可参考
   Δ=(I−R(rot))(P−c)（见 2.3）；start 对 pose_after 逐轴软限位 400。
4. **rot_rad 选取**：范围 (0, 0.6] rad 且 ≤ WS_Rz 行程（±1°，行程差
   0.0349 rad；校验 `runtime/calibration.py:580-604`）。双示教位下
   旋转角只受 Rz 行程与各点 pose/pose_after 软限位约束——示教点离
   旋转中心越远、角越大，旋后可见位与旋前位差越大（`Δ≈θ·|P−c|`），
   越需要显式示教 pose_after。
5. 兼容旧四点键：`tpl_before/tpl_after + pose_before/pose_after`
   等价于 2 点 taught_points（`runtime/calibration.py:640-646`；
   互斥 400，`:620-624`；旧四键的 pose_after 语义是"第二点示教位"，
   映射后两点 pose_after 缺省=各自 pose）。

### 3.3 启动 / 中断 / 判读

```
POST /api/calibration/start
  {"routine": "ws_rotate_repeat", "cam": "down",
   "params": {"taught_points": [{"tpl":…, "pose":{…}, "pose_after":{…}}, …],
              "rot_rad": 0.01, "repeat": 10, "wait_ms": 20}}
→ job_id；GET status 轮询；done 后 GET result。
POST /api/calibration/cancel {"job_id": N}（协作式取消：下一循环边界
  生效 → canceled；finally 恢复轴位/光源/视觉模式照跑，
  extra_routines.py:802-816、metrology/repeatability.py:169-177）
```

判读要点：

## 5. 硅片台旋转中心标定（ws_rotate_center）

实现：`metrology/rotate_center.py`（`run_ws_rotate_center`，
`rotate_center.py:81-292`）；参数校验 `_validate_rotate_sweep`
（`runtime/calibration.py:700-752`）。

### 5.1 测的是什么

WS_Rz 的**实际旋转中心**在晶圆面内的位置，输出相对 **WS_Rz 机械
旋转轴心**（运动链名义正解的不动点）的偏移
`measured.rz_center_offset_mm = [cx, cy]`（mm），以及**标定时机台位**
`measured.rz_center_ref_xy_mm = [作业起点 WS_LS_X, WS_LS_Y]`（迭代 35
起双键；写回机器常数 `fine_align` 组两键后，消费侧认知枢轴按
`pivot = 吸盘心信念 + offset + (当前 WS_LS_XY − ref_xy)` 平移复用，
`_rz_pivot_belief`，`extra_routines.py:482-510`；ref=[0,0]（旧数据
缺省）时平移项关闭=历史行为）。**换吸盘/维修后须重标本 routine**
（GUI 结果区有"标定机位 ref_xy"只读行提示同口径，
`metrology_gui/WsRotateCenterCalib.py:236-258`）。

基准点口径（易混，务必区分，`rotate_center.py:19-28` 与
`extra_routines.py:513-550`）：

- **WS_Rz 机械轴心**（`_rz_axis_center`，`extra_routines.py:525-550`）：
  运动链名义几何的不动点——用两个 Rz 位置的名义工具点反解
  `(I−R(δ))c = o(δ)−R(δ)o(0)`（仅用 nominal_mm，与误差链无关）；
  真值注入 `recipe.sim_align.rz_center_true_offset_um` 即叠加在**本
  点**上（vision_model.collect_marks 的 pivot 语义），故 measured
  与注入键同口径可比。
- **吸盘心**（`_chuck_center`，`extra_routines.py:513-522`）：
  wafer_stage 工具点（多孔陶瓷面中心）。与机械轴心存在**名义几何差
  ~0.106mm**（链配置 Rz center 是 sandboxes 占位值——**合成值，待真机
  标定**，见 error_kinematics.json wafer_stage._note；精对准确认环
  对该差不敏感）。
- 参照（名义值）：机械轴心=(58.216200, 111.610147)mm、
  吸盘心=(58.110200, 111.610200)mm（Δx≈0.106mm ✓）。

### 5.2 算法推导：每 (循环,角度档) _fit_rot 闭式 (θ_ij, C_ij)

时序（`rotate_center.py:123-166`）：基线（rz0）逐点走 pose 测世界
坐标 P_k（与第 2 节同口径）→ 每 repeat 循环逐**角度档**
`θ_j = ±step_rad×1..n_angles`（对称档，正档升序后负档升序，
`rotate_center.py:110-111`），WS_Rz 走 rz0+θ_j 后每档逐点走
**pose_after**（双示教位旋后可见位，下发前 `_walk_limit_guard`
软限位守卫）实测 Q_kj → 全部档走完回 rz0。

每 (循环 i, 档 j) 对 (P_k, Q_kj) 过 `_fit_rot` 闭式
（`extra_routines.py:560-597`；rotate_center.py:170-173）：

```
θ_ij = atan2(Σcross, Σdot)          （与 2.4 同式，角度本体）
C_ij = (I−R(θ_ij))⁻¹·(Q̄−R(θ_ij)·P̄)  （2×2 直接解）
     物理约束 Q̄−C = R(θ)·(P̄−C) 整理得 (I−R(θ))·C = Q̄−R(θ)·P̄
     det = 2(1−cosθ)——小 θ 病态 = 既有 1/θ 放大；det<1e-18 →
     CalibError"角度档退化（step_rad 过小）"（_fit_rot 内防护）
```

中心 = 全部 (i,j) 拟合中心 C_ij 的**分量均值**（`rotate_center.py:213-217`），
measured 偏移 = 中心均值 − WS_Rz 机械轴心；3σ=hypot(分量散布)（µm）。
拟合残差 `r = (Q−R(θ)P) − (I−R(θ))·C_ij` 逐点逐 (循环,档) 收集
（`rotate_center.py:177-184`）。

与迭代 32"已知指令角堆叠 2×2 最小二乘"（(ΣMᵀM)c=ΣMᵀr，θ_j 当已知量）
的根本差别：现行口径 θ_ij 是**每 (循环,档) 实测拟合角**而非指令角——
指令角的增益误差不再直接进 C 的方程右端（它只随 θ_ij 的实测噪声/系统
差间接进入）；旋转中心拟合的敏感项变为**视觉链旋转态系统差**（逐 mark
NCC 位置系统差经 1/θ 放大别名进 C，见 5.5）与**角度档摆幅下的逐档
散布**（各档摆幅不同→NCC 系统差各异，center.s3 口径=逐 (循环,档)
拟合散布）。

**双示教位可见性约束**（`rotate_center.py:43-46`）：pose_after 为每点
单一示教位——角度档扫 ±n×step 时各档的标记可见性由**示教点杠杆×角度
摆幅 < FOV 半宽（0.9mm）**保证（宜近旋转中心小杠杆示教，回归用例统一
半径 ≤15mm；或按最大档示教 pose_after）；缺省 pose_after=pose 时须
杠杆×n_angles×step_rad ≪ 0.9mm。

2. **模板策略（实测驱动，`rotate_center.py:35-46`）**：全程**示教

   示教点宜选**小标记**（site quad 150µm——小模板走连续几何角，
   质心 θ 相关偏差实测 ~10µm/rad 级，经 1/θ 放大后仍在 µm 级
   预算内）。
3. **隔离误差链做验收**：旋转台跑出（dx/dy 误差地图）按
   `(ΣMᵀM)⁻¹ΣMᵀρ` 结构别名进拟合 ~20µm——设备真值固有系统差，

## 6. 旋转角度校准（ws_rotate_gain）

实现：`metrology/rotate_gain.py`（`run_ws_rotate_gain`，
`rotate_gain.py:57-223`）；参数校验同 `_validate_rotate_sweep`
（`runtime/calibration.py:700-752`）。

### 6.1 测的是什么

WS_Rz **实际旋转角/指令旋转角的增益系数**
（`measured.rz_gain`，无量纲 ~1.0）。写回 `fine_align.rz_gain` 后，
flow_engine 精对准补偿按 `物理角 = 轴位增量 × rz_gain × rz_sign`
换算。增益误差会使"按指令角补偿"的工艺旋转错位——本 routine 直接
测真：每个角度档用 `_fit_rot` 测出实际角，再对指令角做线性回归。

### 6.2 算法推导

时序（`rotate_gain.py:95-140`）：基线逐点走 pose 测 P_k（同第 2 节）
→ 每 repeat 循环逐角度档 θ_j（±step×1..n 对称，`rotate_gain.py:84-85`）
WS_Rz 走 rz0+θ_j → 每档逐点走 **pose_after**（双示教位，下发前
`_walk_limit_guard` 软限位守卫）实测 Q_kj → 跨点 `_fit_rot` 闭式拟合
**实际旋转角** `θ_a = atan2(Σcross, Σdot)`（`rotate_gain.py:129-131`，
与 2.4 同式；atan2 拟合平移自由，旋转台跑出不进增益）→ 回 rz0。

拟合 `θ_a = gain×θ_c (+offset)`（`rotate_gain.py:141-153`）：

```
过原点 LS（主输出）：  gain = Σθ_a·θ_c / Σθ_c²
带截距 2 参数 LS（诊断）：g1 = Σ(θc−θ̄c)(θa−θ̄a)/Σ(θc−θ̄c)²，
                        offset = θ̄a − g1·θ̄c
对称角度档（Σθc=0）下二者恒等：g1 ≡ gain；
截距 offset = θ̄a = 固定角偏差（基线一次性定位偏置只进截距不进增益）
```

每 repeat 得 gain_i（与诊断 g1_i、offset_i）→ mean + 3σ。

### 6.3 参数 / 结果字段 / 写回

参数与 ws_rotate_center 完全相同（`_validate_rotate_sweep` 共用：
taught_points 必填 ≥2、step_rad (0,0.3] 默认 0.01、n_angles [2,8]

## 7. 误差来源与注意事项

1. **相机识别噪声**：REAL 链质心噪声（recipe `sim_sensors.
   fast_noise_px`，默认 0.15px 档）是逐点拟合残余与 θ_i 噪声的主项
   之一；典型各点位置残余 3σ ≈ 20~360 nm、θ_i 逐循环散布 ~1µrad。
2. **轴到位重复性**：WS_LS/AS 每次重走示教位（pose / pose_after）的
   repeat 误差进入逐点残余；atan2 拟合重心消去整体平移，逐点非共同
   位移才进 θ_i。
3. **θ_i 灵敏度（杠杆量级式）**：设单点世界坐标噪声 σ_w（mm）、
   示教点星座 RMS 半径 `L̄ = sqrt( (1/N)·Σ|u_k|² )`，则

   ```
   σ_θ ≈ σ_w / L̄        (rad)
   ```

   3 点 161/228mm 跨距 → L̄≈107.5mm，σ_w~0.1µm → σ_θ~1µrad。**示教点
   越散 θ_i 越准**；两点全同（星座退化）时 Σdot→0，拟合失效（守卫取
   0，`extra_routines.py:583`）。
4. **为什么基准是 rz0 而不是硬件 home**：测量是"相对基线"的差分
   ——基线在作业启动时的 WS_Rz 位置取得（`extra_routines.py:719`），
   旋转态实测后 Rz 回 rz0 进下一循环（:764）；基准角只锚定世界坐标
   集 P_k，与硬件零点无关。
5. **双示教位的示教质量**：旋后示教位的居中残余直接进 Q_k 的逐点
   坐标（经 world_ref 补偿后等价）；atan2 拟合平移自由，共同的居中
   偏置不进 θ_i，但逐点不一致的示教残余会进逐点拟合残余 3σ。旋后位
   偏离过大触发运行期 `_walk_limit_guard`（`extra_routines.py:634-646`）。
6. **恒定系统分量相消**：相机常数（k/dir/swap 与反算链认知 rot_mrad）
   与运动链姿态误差的恒定分量同时进入基线与实测的反投影，做差后相消
   （但进入逐点世界坐标绝对值）。
7. **cancel/恢复语义**：`POST /api/calibration/cancel` 只置标志，
   下一循环首（rotate_center/gain 另有每角度档首）检查点抛
   `CalibCanceled`（`metrology/repeatability.py:169-177`），终态
   canceled；`finally` 一定恢复 AS/WS/WS_Rz 作业前轴位、下相机
   光源、视觉模式（`extra_routines.py:802-816`），用户模板绝不删除。
8. **三个 routine 的误差结构差异**（选型注意）：repeat/gain 的
   atan2 拟合**平移自由**（旋转台跑出不进角度）；center 的 C 求解对
   **视觉链旋转态系统差**敏感（1/θ 放大，见 5.5；迭代 35 起角度来源
   为实测 θ_ij 而非指令角，指令角增益误差不再直接进入），对模板策略
   最挑剔（宜 site quad 小标记示教模板 + 小杠杆）。

## 9. 与附件 4.2 基线向量法的对照（auto 路径已移除）

taught 直接测角法是附件 4.2 基线向量法的多点推广：N 点星座替代
两点基线，`_fit_rot` 的 atan2(Σcross, Σdot) 拟合替代向量夹角（N=2
时二者等价），并把"回零差分"升级为"旋转态实测实际角"（系统角偏差
与随机重复性分离）。

原 auto 全自动路径（**迭代 34 已删除**）曾是附件 4.2 的直接实现，
历史口径备查：自动选晶圆全局标记（`wafer_mark*`）中相距最远的一对
A/B（基线 L≈228mm），FOV 1.8mm 装不下远点对故分段走位各拍一点、
质心反算世界坐标并按 WS 走位量补偿，两点各就地建临时模板（结束
删）；每循环 WS_Rz 转 rot_rad→回 rz0→重测 A/B，`Δθ = wrap(
atan2(u.y,u.x) − θ0, ±π)`（u=B−A，即附件 4.2 的
`θ = atan2(cross(u,v), ⟨u,v⟩)` 相邻循环夹角形式）；统计 Δθ 3σ
（µrad）与 mean−指令角。该路径无示教参数即跑的便利性由"基线最长、
灵敏度最高"补偿，但远点对跨状态匹配可靠性差（两点需就地临时模板）、
且回零差分把系统角偏差与重复性混在一起——迭代 32 的直接测角法
taught 路径全面优于它，迭代 34 按"示教参数化唯一模式"收敛契约
（无 taught_points → start 400，回归 `i34.ws_rotate_auto_gone`）。

迭代 32~34 的 taught 路径曾由后端按认知枢轴做**预测走位**
（Δ=(I−R)(P−c) 叠加 WS 目标、start 预估 400），迭代 35 起删除并改
**双示教位**（旋后走用户示教 pose_after）——算法不再依赖枢轴认知，
大角度/大杠杆场景的可见性责任移交示教者（§2.3）。
