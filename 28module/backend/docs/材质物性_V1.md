# 材质物性_V1 —— 组件材质工程物性库（2026-09-06 迭代 21）

为后续热仿真打底的**材料物性单一事实源**：本迭代只做落盘 + 面板展示 +
API，热漂移注入（ΔL=CTE·ΔT·L）后续迭代再接（用户明确"后面再考虑"）。

- 后端模块：`runtime/materials.py`（照 machine_constants.py 模板：白名单 +
  validate + 注册表类 + tmp/os.replace 原子落盘）。
- 落盘文件：`runtime/materials.json`（材料库）+ `runtime/material_map.json`
  （组件映射），首次启动自动播种。
- 面板：控制面板「组件材质」tab（卡 1 工程材料库行内编辑/新增/删除，
  卡 2 组件材质映射下拉指派）。

## 1. 材料库字段定义

每种材料 = 键（`^[a-z][a-z0-9_]{0,39}$`）→ 对象：

| 字段 | 单位 | 校验区间 | 说明 |
|---|---|---|---|
| `name_cn` | — | 非空字符串 | 中文名（面板显示） |
| `cte_ppm_K` | ppm/K | [−5, 60] | 热膨胀系数（热仿真主消费字段） |
| `youngs_GPa` | GPa | [1, 1000] | 杨氏模量 |
| `poisson` | — | [0, 0.5] | 泊松比 |
| `density_kg_m3` | kg/m³ | [500, 23000] | 密度 |
| `thermal_cond_W_mK` | W/(m·K) | [0.01, 500] | 热导率 |
| `spec_heat_J_kgK` | J/(kg·K) | [100, 5000] | 比热容 |
| `note` | — | 字符串（可缺省） | 备注（数值口径） |

## 2. 组件材质映射与 presetId 默认种子

- 组件事实源：`html_model/d2w_front.json`（TwinDOM 工程原文件，
  **只读消费**，启动时 `ComponentCatalog` 解析一次；文件缺失/损坏时组件
  列表为空但服务照常拉起，材料库/映射仍可用）。当前 168 个扁平节点，
  每节点 `id`（唯一）/`name`（唯一）/`parentId`/`material.presetId`。
- 映射 = `component_id → material_key`（`null`=未指定）。落盘
  `material_map.json`；首次启动与前端后增组件按下表种子：

## 3. API（9010 网关）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/materials` | 材料库全量 + `ref_counts`（各材料被组件引用数） |
| PUT | `/api/materials` | `{"set":{键:物性对象},"delete":[键]}`：存量键部分字段合并、新键须全字段；删除被引用材料 400；物性越界 400（errors 逐条定位）→ 原子落盘 |
| GET | `/api/material_map` | 组件映射全量（component_id→材料键/null） |
| PUT | `/api/material_map` | patch 式 `{component_id:材料键|null}`（只动给出的组件）；材料键不存在/组件 id 不存在 400 → 原子落盘 |
| GET | `/api/components` | 组件目录（id/name/parentId/preset_id）+ 当前 `material_key` |

## 4. 与后续热仿真的衔接预留

热仿真（后续迭代，本迭代不做）按组件查 CTE 计算热漂移：
`ΔL = CTE × ΔT × L`（组件特征尺寸 L 与温度场 ΔT 由热模型给出）。
本表已备齐 CTE/热导率/比热/密度四维热相关物性（杨氏模量/泊松比为
热应力扩展预留）；消费侧届时从 `engine.materials.get_map()` +
`get_materials()` 取数，无需改本模块 schema。
