## 1. 工艺定位与设备结构

- 流程链位置：晶圆上片+EGA → 翻转取片 → 粗对准 → 芯片交接 → 调焦调平
  → **精对准（本文）** → 键合（下一迭代）。
- 上芯片（die）吸附在**键合头**上（XY 不可动），标记面朝下，**上相机**
  （随对准台）朝上看 die 角标（`film.marks`）。
- 下芯片=晶圆上的 site，随**硅片台** WS_LS_X/WS_LS_Y/WS_Rz 运动；**下相机**
  朝小看 site 对准标记（`wafer.site_marks`）。
- 所有 XY/θ 补偿都落在**硅片台**（键合头无 XY 轴）；**测量期间 WS/BS 全
  冻结，只动对准台 AS**（锁轴快照校验：测量前后比对 WS_LS_X/Y、WS_Rz、
  BS_Arm_Z、BS_CAL_Rx/Ry，动则抛错）。
- 1.8mm FOV 一次只看一个标记 → **逐标记寻址**，FOV 内无配对歧义（天然
  免疫参考项目的 FD 镜像配对坑，不引配对表）。

## 2. 帧定义

- **对准系 m**（EGA 沿用）：`m = (AS − as_anchor) − (WS − ws_ega)`。
  物理含义：m = 晶圆点世界坐标 W − 当前吸盘心世界 K（纯平移关系，
  m 帧随吸盘平移）。EGA map `apply_map(fit, 设计点)` 给设计点的对准系
  坐标。
- **公共叠合帧**（精对准拟合帧）：原点 = 键合头吸盘心世界 H，轴向与世界
  对齐。两侧实测点都换算进该帧再拟合：
  - 晶圆侧：`W − H = m_meas + (WS − ws_ega) − (as_head − anchor)`。
    其中 `m_meas = m_target + (w − cam)`（w=identify→solve_pixel 真值世界，
    cam=相机光轴世界；该恒等式与 EGA map 无关，map 只影响寻址落点）。
    **注意**：只减 m_site 是错的——补偿后 WS 变了，(WS−ws_ega)−
    (as_head−anchor) 项不再为零，平移补偿会"测不见"（迭代 6 调试实证：
    初测时 fl_ready 关系使两者等价，首轮补偿后发散）。
  - die 侧：`od_meas = od + (w − cam)`（寻址 = 机械常数
    `as_head_center_xy_mm` + 角标设计偏移，同 fl_measure die 空间认知链；
    AS=as_head 时相机认头心，天然头心相对帧）。
- **设计点集**：晶圆侧 `ow[k] = site_marks.ratio[k] × site 半宽`；die 侧
  `od[k] = film.marks.ratio[k] × die 半宽`（各取前 N 个，N=处方
  `fine_align.measure_points`）。

## 3. 测量与拟合

- `fa_measure`：AS-only 逐标记寻址（晶圆侧 `AS = anchor + m + (WS −
  ws_ega)`，WS 冻结）→ identify → solve_pixel → 双侧各 N 点落存
  `eng.fa_meas`；丢标/未进焦 → 抛错 abort（同 ega_measure 语义）。
- `fa_solve`：双侧各自 fit：`T_w = fit(ow → 晶圆实测)`、`T_d = fit(od →
  die 实测)`；所需晶圆运动 **Δ = T_d ∘ T_w⁻¹**，取刚体参数 (tx, ty, θ)
  （`fine_align.compose_rigid`）。
  - **真值通道例外（2026-09-07 迭代 20）**：`_fa_truth_resid`（phys_resid
    /bond_commit 接触时刻真值）与 pi_measure 多点对组间解算的点云在
    **世界系**（质心距帧原点 ~43mm），compose_rigid 的 t_d−R_Δ·t_w 形
    会引入 θ_Δ×J(F) 参考原点耦合假平移（θ 残余 × 43mm ≈ 0.4µm 假散布，
    即旧 phys_resid dy 系统散布的根因）；这两处改用
    `fine_align.relative_delta`（t_d−t_w = 两侧设计原点像之差，参考点
    无关）。测量闭环点云在头心相对近原帧（|F|~0.1mm，耦合项 ~20nm），
    fa_solve/确认环维持 compose_rigid 不动。详见
    《键合误差模型_V1.md》§2.1。

### 3.1 五种算法（`runtime/fine_align.py`，纯标准库）

| 算法 | 参数 | 点数 | 说明 |
|---|---|---|---|
| rigid（默认） | 3（tx,ty,θ） | ≥2 | Kabsch 2D：θ=atan2(M10−M01, M00+M11)，M=互协方差 |
| similarity | 4（+scale） | ≥2 | Umeyama：先 Kabsch 再求等比缩放 |
| affine | 6 | ≥3 | 六参数仿射（ega 同式）；**n=2 欠定强制拒绝**（参考项目教训：n=2 时旋转劈给正交项） |
| ransac | 3 | ≥2 | 两点最小集全枚举（n≤8 → C(n,2)≤28）+ 内点阈值 2µm，最大内点集重拟合 rigid；标记被污染时用 |
| midpoint_2mark | 3（tx,ty,θ） | ≥2（只用前 2） | 双标记中点角度法（TORAY 式）：中点定平移、连线角定旋转；n>2 只用前 2 点并日志注明，余者仅计入残差统计。**精度注意**：无多点平均，θ 噪声 σ≈√2·σxy/基线（7.6mm 基线、FAST σxy≈0.09µm 实测逐轮 ±60~80µrad）——用该算法时确认阈值需按 2 点口径放宽（如 tol_rz≈200µrad），否则确认环物理上收敛不了 |

统一返回 `{tx, ty, theta, scale, rms, max_resid, residuals, n}`
（midpoint_2mark 的 n 恒 2，n>2 时附 `note`/`n_total`）。
选型建议：默认 rigid（无缩放自由度最稳健）；视觉系统有比例标定误差时
similarity；确知存在非正交畸变且 N≥3 才 affine；标记可能被污染（胶点/
划伤）时 ransac；与 TORAY 上位机算法对拍/复现其工艺口径时用
midpoint_2mark。

### 3.2 公式与数值示例（同一组点逐一手算）

公共示例点集（设计 4 点，单位 mm）：
`P1(−3.8,−3.8)  P2(3.8,−3.8)  P3(−3.8,3.8)  P4(3.8,3.8)`
真实变换：θ=+300µrad、t=(+12,−8)µm（R=[[c,−s],[s,c]]，c=0.999999955，
s=0.0003）。无噪实测点（µm 级尾数全保留）：

| 点 | 实测 x | 实测 y |
|---|---|---|
| P1 | −3.78685983 | −3.80913983 |
| P2 | +3.81313983 | −3.80685983 |
| P3 | −3.78913983 | +3.79085983 |
| P4 | +3.81085983 | +3.79313983 |

**rigid（Kabsch 3 参）**：设计质心 d̄=(0,0)，实测质心 q̄=(+0.012,−0.008)。
互协方差 M=Σ(q−q̄)(p−p̄)ᵀ 得 M00+M11=57.76、M10−M01=0.017328，
θ=atan2(0.017328, 57.76)=+300.0µrad；tx=qx̄−(c·dx̄−s·dȳ)=+12.0µm、
ty=−8.0µm。rms=0（无噪精确解）。

**similarity（Umeyama 4 参）**：先同上得 (t,θ)，再 scale=Σq·R p/Σ|Rp|²
=57.76/57.76=1.000000→ 结果与 rigid 全同。

**affine（6 参）**：正规方程解出 a11=c、a12=−s、a21=s、a22=c、
tx=+12µm、ty=−8µm；θ=atan2(a21−a12, a11+a22)=atan2(0.0006, 2.0)
=+300.0µrad，scale=(a11+a22)/2=1.0。

**ransac**：C(4,2)=6 个两点最小集，每组拟合后 4 点全在 2µm 内点阈内
（无噪），任取最大内点集=全集 → 重拟合 rigid，结果同上。

**midpoint_2mark（TORAY 双标记中点角度法）**——只取前 2 点 P1、P2：

- 中点（设计）：Cm_d=((−3.8+3.8)/2, (−3.8−3.8)/2)=(0, −3.8)；
- 连线角（设计）：CA_d=atan2(−3.8−(−3.8), 3.8−(−3.8))=atan2(0, 7.6)=0；
- 中点（实测）：Cm_m=((−3.78685983+3.81313983)/2,
  (−3.80913983−3.80685983)/2)=(+0.01314, −3.80799983)；
- 连线角（实测）：CA_m=atan2(−3.80685983−(−3.80913983),
  3.81313983−(−3.78685983))=atan2(0.00228, 7.6)=+300.0µrad；
- θ=CA_m−CA_d=+300.0µrad；t=Cm_m−R(θ)·Cm_d=(0.01314,−3.80799983)
  −(0.00114,−3.79999983)=(**+12.0µm, −8.0µm**)。

TORAY 图原式（双侧差分形式）：die 侧两点 C1、C2，晶圆侧两点 P1、P2；
设计差 di=Pm_d−Cm_d、diA=PA_d−CA_d；实测差 dm=Pm_m−Cm_m、
dmA=PA_m−CA_m；**键合偏差 dX=dmx−dix、dY=dmy−diy、dθ=dmA−diA**。
沿上例（die 侧实测=设计无偏差，晶圆侧实测带上述变换，两侧设计点相同
→ di=(0,0)、diA=0）：dm=(0.01314−0, −3.80799983−(−3.8))=
(+13.14µm, −8.0µm)，dmA=+300µrad → dX=+13.14µm、dY=−8.0µm、
dθ=+300µrad。注意 dX(+13.14)≠Kabsch tx(+12.0)：原式的中点差**未做
R(θ) 回折**，含 θ×(基线/2)=300µrad×3.8mm≈1.14µm 的一阶耦合项；且
原式 dX 是"实测偏差"口径（纠偏量=−dX），与本注册表"晶圆应动量"
（compose_rigid 的 Δ=T_d∘T_w⁻¹）符号相反。本实现按注册表统一语义输出
（每侧 t=Cm_m−R(θ)·Cm_d，n=2 时与 rigid 精确解严格同值），保证
fa_solve/compose_rigid/补偿环可直接替换调用；与 TORAY 上位机对拍时按
上式换算口径差异（符号 + R(θ) 回折项）。

## 4. 补偿数学（先旋后移，旋转耦合进平移）

对 Δ=(tx, ty, θ)（公共帧=头心相对世界帧）：

1. **旋转**：δθ=θ，`WS_Rz 目标 = 当前 + δθ·rz_sign/rz_gain`（机械常数
   `fine_align.rz_gain/rz_sign`，轴位→物理角换算，默认 1/1）。
   **行程守卫**：WS_Rz ±1°（axes_config 硬限位），超限清晰报错。
2. **枢轴与阿贝耦合**：旋转中心（信念）`c = 吸盘心世界 XY +
   rz_center_offset_mm`（机械常数标定值，默认 [0,0]）。绕 c 旋转 δθ 使
   参考点 p（site 心世界信念 = K + apply_map(site)）产生耦合位移
   `coup = R(δθ)(p−c) − (p−c)`。
3. **平移**：`WS_XY += t − coup`（先旋后移：旋转到位后再补 XY）。
   正确性：t 定义在头心相对帧，fl_ready 后 p≈H，绕 p 旋转+t 与"绕 H
   旋转+t"差 (I−R)(p−H) ~ θ×|p−H|（二阶小量，µm 以下 nm 级）。
4. **EGA map 同步更新**（比参考项目多做的一步）：对准系 m=W−K 随吸盘
   刚体运动，旋转 δθ 后 `m' = R(δθ)·m`（平移/枢轴在 m 帧相消——推导：
   W'=c+R(W−c)+u，K'=c+R(K−c)+u ⇒ W'−K'=R(W−K)）。把 `fit["a"]` 与
   `(tx,ty)` 同旋 R(δθ) 复合进 `eng.ega_result`，后续 site 寻址（fl_ready
   /fl_measure/fa_measure 复测）不失效；补偿历史落存
   `fit["fine_align_comp"]`（dtheta/t/coup/u/pivot/ws_rz）。

## 5. 真值枢轴偏移（阿贝效应仿真）

真机 Rz 轴心与吸盘心不重合 → 阿贝误差。仿真注入：

- **真值侧**：`vision_model.collect_marks` wafer_marks 与
  `confocal.wafer_surface_z` 的 WS_Rz 旋转绕"吸盘心 + 真值偏移"
  （`_rotvec_apply_pivot`，真值偏移=recipe
  `sim_align.rz_center_true_offset_um`，默认 [0,0]=绕吸盘心，与历史行为
  一致）。两处共用 `vision_model.wafer_rz_pivot(recipe)`。
- **认知侧**：补偿按"吸盘心 + 标定偏移"（机械常数
  `fine_align.rz_center_offset_mm`）计算耦合。
- 两者不等 → 补偿后残余 ≈ δθ×(真值−标定) 被**确认环实测抓到**（真实
  测校行为：标定错枢轴，多补一轮才收敛）。

## 6. 确认环与双通道残差

`fa_compensate_confirm`：执行一次补偿后进入确认环（`confirm_enable`）：

- 每轮：全标记复测（AS-only + 锁轴快照）→ 重 fit → 残余判定
  （`|(tx,ty)| ≤ confirm_tol_xy_um` 且 `|θ| ≤ confirm_tol_rz_urad`）；
- 未过且未超 `confirm_max_iter` → 以本轮残差再补一轮；
- 超次按 `on_unconfirmed`：`abort`=抛错流程中止报警（judge=fail）；
  `continue_warn`=警告放行（judge=warn）。
- 每轮写日志（Δ、补偿量、耦合量 coup、残余、判定），轮次历史与最终结果
  （含 judge）落存 `eng.fine_align_result`，经 `flow.state.fine_align_result`
  暴露给面板。

**物理残差双通道**：补偿收敛后另算**真值残差**（不混含噪测量）——对
真值标记世界坐标（kinematics 6DOF + workpieces 真值，与 collect_marks
同一套数学，绕真值枢轴）走同一条 fit 管线，结果存
`fine_align_result.phys_resid`。用途：揭示"测量链↔真值链"的偏差来源
构成（迭代 7 对照实验分解见 §11：主项是 WS 到位 repeat 重采样随机误差，
非恒定框偏）。

### 6.1 阈值推导

FAST 解析投影质心噪声 σpx=0.15px × 0.6µm/px ≈ 0.09µm/轴。N=4 点、基线
（图案半宽）b≈3.8mm 时 θ 拟合噪声：
`σθ ≈ √2·σxy / (b·√N) ≈ 1.41×0.09 / 7.6 ≈ 17µrad`。
实测（2026-08-28 迭代 6 调试）：逐次 Δθ 散布 ±12µrad 与纯视觉噪声一致，
但确认轮残余的有效 σ 约 25~40µrad——除视觉噪声外还含**每会话一次的
测量链框偏分量**（EGA/初测同一噪声链的系统性实现，会话内各轮正相关），
残余序列表现为围绕偏置的振荡而非逐轮单调收敛。工程含义：①阈值
30µrad ≈ 1~1.8σ 有效值，单轮通过率有限属正常，**确认环多轮兜底是设计
行为而非异常**（实测典型 1~2 轮收敛，尾巴场景 4~5 轮）；②追求单轮高
通过率可把 measure_points 提到 6~8（σθ 按 √N 下降）或放宽
confirm_tol_rz_urad；③XY 阈值 0.15µm（2026-09-04 迭代 13 起，原 0.5µm
收紧）≈ 3σ_xy 量级，平移通道在 AS_X/Y repeat 3σ=40nm（迭代 13 用户
指定）下仍有充分裕度。
（迭代 7 §11 诊断进一步定位：该"框偏分量"主项=WS 到位 repeat 重采样，
会话内各轮正相关的原因是同一到位偏置被复测链沿用。）

## 7. 流程生成器（build_fine_align_flow）

2026-08-28 迭代 7 起**走位精简**（信任链：前置状态由流程链保证，精对准
不再重复进场——旧的 fl_ready 复用与两个进场对焦 move 会 undo 调平补偿
后的实测焦面，已删除）：

1. 守卫（均 400）：晶圆在位、head 有 die、EGA 完成、**本机已完成调焦
   调平补偿**（`eng.fl_fit["compensate"]` 或 `level_memory`）；且
   **`eng.fl_ws_frozen` 存在且 site 匹配**（focus_level per_site 的
   fl_ready 已把该 site 送到头下并冻结 WS，fa_measure 的 freeze_ws 寻址
   以此为基准），否则报错提示先执行 focus_level per_site；
2. `fa_measure` → `fa_solve` → `fa_compensate_confirm`；
3. 对准台回安全位：AS_X/AS_Y → `flip_handoff.as_safe_xy_mm`（精对准
   完成后退出键合头下方）。

路由：`POST /api/process/fine_align {site?: [row,col], paused?}`。
一键串联（五阶段自动链）见 `POST /api/process/chain`（迭代 7，

## 9. 已知限制

- die 在键合头上的 rz 目前不进视觉真值（head_die_marks die_rz=0），
  die 侧旋转误差只能靠 bond_head 6DOF 误差体现；
- 物理残差由 WS 到位 repeat 重采样主导（迭代 7 诊断，§11）；repeat
  全置 0 且误差地图/6DOF 全关时仍残余 ~0.7µm/15µrad 的地图耦合测校
  框偏（认知链常数 as_anchor/as_head_center/相机安装偏移的推导值与
  "地图开启"状态自洽，地图全关时暴露）——正常使用（地图开）下被抵消，
  属已知测校偏差行为，非 bug；
- 确认环复测不重新对焦（假定调焦调平已做好，补偿只动 WS XY/Rz 不动 Z）；
- 键合动作本身属下一迭代。

## 10. 技术要点汇总

- **帧链**：对准系 m=W−K（随吸盘平移）→ 公共叠合帧（头心相对世界）；
  晶圆侧实测换算必须带 `(WS−ws_ega)−(as_head−anchor)` 项（只减 m_site
  会把平移补偿"测不见"，迭代 6 实证）。
- **测量链**：fa_measure 锁轴快照（WS_XY/Rz、BS_Arm_Z、BS_CAL_Rx/Ry，
  动则抛错）+ AS-only 逐标记（1.8mm FOV 天然无配对歧义）→ identify
  → solve_pixel → 双侧各 N 点。
- **补偿/阿贝**：先旋后移；枢轴=吸盘心+rz_center_offset_mm（标定值），
  真值枢轴=sim_align.rz_center_true_offset_um（可注入不等→阿贝残余
  被确认环抓到）；旋转耦合 coup=R(δθ)(p−c)−(p−c) 从平移中扣除。
- **EGA map 同步**：补偿旋转复合进 eng.ega_result（m'=R(δθ)·m），
  后续 site 寻址不失效；历史落存 fit["fine_align_comp"]。
- **确认环**：复测-重fit-残余判定，tol_xy/tol_rz/max_iter/on_unconfirmed
  四处方参数；多轮兜底是设计行为（§6.1）。
- **双通道残差**：测量通道（确认环残余）+ 真值通道（phys_resid），
  分解见 §11。
- **锁轴**：_FA_LOCK_AXES 六轴快照比对，容差 1e-6。
- **阈值推导**：σθ≈√2·σxy/(b·√N)，FAST σxy≈0.09µm、b≈3.8mm、N=4
  → ≈17µrad；tol_rz=30µrad≈1~1.8σ 有效值（§6.1）。
- **信任链走位**（迭代 7）：精对准不再 fl_ready/进场对焦（会 undo
  调平后实测焦面），守卫 fl_ws_frozen site 匹配；完成后 AS 回安全位。

## 11. 物理残差诊断（迭代 7 需求 3：计算错误还是重复性？）

**问题**：精对准 judge=pass 后物理残差（真值通道）仍有亚 µm 级平移/
十几 µrad 旋转——是解算/常数计算错误，还是轴重复性？

**方法**（FA_DEBUG=1 对照日志 + 三组对照实验，同一确定性注入
load_x=0.2/load_y=−0.15/rz=200µrad、jitter 关、共焦 σ=0，全链
chain 跑通后读 fine_align_result.phys_resid）：

| 实验 | 条件 | phys tx | phys ty | phys θ |
|---|---|---|---|---|
| 基线 | 地图开、repeat 默认（WS 500nm 3σ） | +0.053µm | +0.697µm | +15.4µrad |
| 基线复跑 | 同上（另一会话） | +0.022µm | +0.443µm | +9.4µrad |
| expA | 地图开、**repeat 全置 0** | −0.041µm | −0.193µm | −0.5µrad |
| expB | **repeat=0 + 误差地图/6DOF 全关** | −0.074µm | −0.712µm | −14.5µrad |

**结论**：

1. **主因是 repeat（到位重采样随机误差），不是计算错误**：repeat 全
   置 0（expA）后残余塌缩到 |t|≤0.2µm、|θ|≤0.5µrad；基线残余逐会话
   涨落（0.44~0.70µm、9~15µrad，随到位重采样种子变），非恒定框偏。
   量级自洽：WS 500nm 3σ 到位重采样 → σ_xy≈170nm/轴，经确认环"按
   含偏测量收敛到测量零"后物理残余≈末轮 WS 到位 repeat 残余，
   σθ≈√2·σxy/基线≈17µrad 与 §6.1 推导一致。迭代 6 遗留的"恒定
   ~1µm 框偏"预判**被实验推翻**（当时是 repeat 500nm 下的单次观测，
   且本迭代走位精简后进场不再 undo 焦面）。
2. **次级项：地图耦合的测校常数框偏（~0.7µm/15µrad）**：expB 残余不
   消失且与基线近反号——认知链常数（as_anchor/as_head_center/相机
   安装偏移）的推导值与"误差地图开启"状态自洽，地图全关改变了真值链
   与认知链的相对关系，把该项暴露出来。正常使用（地图开）下被抵消，
   属**已知测校偏差行为**（真机对应：标定只在整机误差状态下自洽）。
3. **处置**：按用户指示 WS_LS_X/WS_LS_Y repeat 改 3σ=40nm
   （`axes_config._repeat_3sigma`，其余轴不变）。改后全量回归复测
   （fa.main_phys_resid，同确定性注入，两轮）：**物理残差从 500nm 基线的
   0.44~0.70µm/9~15µrad 降到 (−0.11,−0.27)µm/−4.2µrad 与
   (0.00,−0.52)µm/−7.3µrad**（主项随 repeat 缩放，
   与诊断一致）；诊断固化为回归用例 `i7.repeat0_residual`（repeat=0
   时 |t|≤2.0µm、|θ|≤40µrad 阈值断言——残余剩余项=FAST 视觉噪声
   σxy≈0.09µm/σθ≈17µrad 的末轮含噪收敛代价，阈值留 ~10σ 余量，仍
   远低于 500nm 基线量级，可区分塌缩/不塌缩）。
