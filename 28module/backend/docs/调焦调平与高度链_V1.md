## 1. 光谱共焦读数模型

真实光谱共焦位移计：白光聚焦在被测面上，按反射光谱峰值波长反推面到探头的
距离，量程数百 µm、重复精度 nm 级。仿真读数模型（`confocal.py`）：

- **量程**：读数 ∈ `[0, confocal_range_um]`（默认 0~700 µm）。读数加上噪声后
  落在量程之外 → **无读数**（`valid=false`，`reading_um=None`）。量程外无
  读数是流程内"AS_Z 搜索找有效窗"的触发条件。
- **近大远小**：读数 = 被测面相对共焦焦面的偏差映射。下探头（朝下看晶圆，
  面越高读数越大）：
  `reading = mid_down + (z_surface − z_focusplane) × 1000 + noise`；
  上探头（朝上看芯片下表面，面越低读数越大）：
  `reading = mid_up + (z_focusplane − z_surface) × 1000 + noise`。
- **中点共面约定（调焦原理核心）**：共焦读数 = 量程中点
  （`confocal_mid_*_um`，默认 350 µm）↔ 被测面正好落在对应相机的最佳焦面上
  （装配约定，机械常数可调）。因此"共焦读数调到中点"与"相机在焦"等价——
  共焦 700 µm 量程 ≫ 相机 ±20 µm 景深，共焦负责**快速定位焦面**，相机只
  在焦面附近做精细识别。
- **噪声**：`noise ~ N(0, σ)`，σ = **recipe `sim_sensors.confocal_sigma_um`**
  （默认 0.05 µm，真实共焦 nm 级取保守值；回归/冒烟注入 σ=0 得确定性）。
  归属说明（迭代 2）：σ 是传感模型的**物理噪声真值**，不是"可标定的设备
  认知"，因此不属于机械常数——仿真注入类参数统一归测校页（"传感器仿真"
  卡，`data-p` 绑定 recipe，落盘 recipe.json，每次读实时取=热生效）。
- **焦面世界 z**：直接取相机焦面公式（`vision_model.camera_pose` 同一来源：
  相机位姿 + look_dir×wd_mm，含模块 6DOF 误差与 AS_Rx/Ry 姿态并入），不另
  建一套——中点共面约定下两者天然一致。
- 调试 API：`GET 9010 /api/confocal/read?probe=up|down` →
  `{reading_um, valid, z_surface, z_focus}`（同步直读，不走 MQTT）。

## 2. 探头安装几何（前端模型确定值，不可改）

来源：`html_model/d2w_front.json`（TwinDOM 工程，2026-08-27 测定）：

- 上/下光谱共焦与上/下精对准相机**同挂对准相机承载台**（align_stage 模块，
  随 AS_X/Y/Z 平移 + AS_Rx/Ry 微转）。
- 探头局部 offset（`confocal.py PROBE_MOUNT`，CAD 真值）：
  up = `[0, -47.5, +15.0]`（零位世界 z=925.0，朝上量键合头芯片下表面）；
  down = `[0, -47.5, -15.0]`（零位世界 z=895.0，朝下量晶圆面/裸吸盘面）。
- 共焦相对相机 **ΔX = 0、ΔY = -25.0 mm**（共焦局部 [0,-47.5] vs 相机
  [0,-22.5]；Z 同高）。后端口径 `focus_level.confocal_cam_dx_mm=0.0` /
  `confocal_cam_dy_mm=-25.0`（上/下共用，测校可改）。
  含义：共焦探头对准点 P 时，相机光轴对准的是 P−(dx,dy) = P+(0,25)——
  fl_measure 走位按此补偿（流程生成器 `to_aim` 预算进 aim 坐标）。
- **AS_Y 行程 −30~120（迭代 4 回退）**：上相机真实零位世界 y=1.0，加上
  AS_Y∈[−30,120]，相机光轴可覆盖 y∈[−29,121]；键合头吸盘中心世界 y=7.0
  落在该区间（AS_Y=+6.0 时对准），因此 die 侧 align_first 与直接走位均可达。
  该行程与前端模型原行程一致，待真机确认。
- **as_head_center_xy_mm（迭代 4 修正）**：上相机光轴正对键合头吸盘中心
  (−42.5,7.0) 时对准台 AS_X/AS_Y 的轴位。真实零位下相机世界=(−42.5,1.0)，
  故 AS_X=0.0、AS_Y=+6.0。**仿真假定，待真机测校**。
  die 空间测高以此点为基准，`point` 为相对该中心的设计偏移；探头最终
  认知位置 = `as_head_center_world + point + (cam_dx, cam_dy)`。
- **走位认知链（迭代 2/3）**：fl_measure 的所有走位都不用探头真值位置
  （`confocal.probe_pose`），而是用"相机光轴世界 XY + (cam_dx, cam_dy)"
  作为探头的**认知位置**——相机位姿由 vision_model 合成（名义+6DOF
  误差+轴姿态），偏移取机械常数。改错常数 → 测点偏移 → 拟合面歪，
  与真机"测校参数错了工艺就跑偏"的行为一致；`probe_pose` 真值只用于
  读数模型自身（物理读数永远基于真值面高）与测量记录 world 字段。
  **迭代 3 修正**：die/stage 分支原先把"探头目标"误当"相机目标"参与
  世界坐标减法（AS 坐标与世界坐标混用），导致 die 测点 Y 向整体偏移约
  25mm、拟合面斜率错误；现统一先把"探头目标"换算成"相机目标 AS 坐标"
  （die：相机 AS 目标 = as_head_center + point − confocal_offset；stage：
  相机世界目标 = point − confocal_offset，再转 AS 坐标）再移动。
- 位姿合成复用相机路径（`_ProbeSpec` 伪相机 + `vision_model.camera_pose`），
  模块名义位姿、6DOF 误差、AS_Rx/Ry 轴姿态全部自动并入。

## 4. 高度测量链（公式推导）

世界 z 基准（仿真口径，与前端模型一致）：

- 吸盘陶瓷面顶：**884.9**（`vision_cameras.json` down._note）；
- 键合头吸盘面零位（BS_Arm_Z=0）：**1053.83**；
- 上相机零位 z=925.0、wd=10 → 焦面 `925 + AS_Z + 10`；
- 下相机零位 z=895.9（凑 wd 的微调值）、wd=10 → 焦面 `895.9 + AS_Z − 10`。

**焦面零位常数推导**：

- `as_z_chuck_focus_mm = -1.0`：`895.9 + AS_Z − 10 = 884.9`（下相机焦面 =
  无晶圆吸盘面）→ AS_Z = −1.0。
- `head_z_upfocus_mm = -119.83`：AS_Z=−1 时上相机焦面 `925 − 1 + 10 = 934`
  = `1053.83 + BS_Arm_Z`（= 无芯片键合头吸盘面）→ BS_Arm_Z = −119.83。

**进场高度（流程步骤 3）**：

- 晶圆侧：`AS_Z_entry = as_z_chuck_focus_mm + t_w`（t_w=处方晶圆厚；默认
  −1+1 = 0，与 EGA 现状一致）。物理含义：下相机焦面 = 晶圆面
  （884.9 + t_w）。
- 键合头侧：`BS_Arm_Z_entry = head_z_upfocus_mm + (AS_Z_entry −
  as_z_chuck_focus_mm) + t_d`（t_d=处方芯片厚；默认 −119.83+1+0.5 =
  −118.33）。物理含义：上相机焦面（随 AS_Z 1:1 平移）= 芯片下表面
  （1053.83 + BS_Arm_Z − t_d，芯片挂在吸盘下，越厚头越高）。

**真值面高函数（共焦读数消费方）**：

- 晶圆面：`z = 884.9 + t_w + z_err + rx_w·(x−cx) − ry_w·(y−cy)`
  （cx,cy=晶圆中心世界坐标；z_err/rx_w/ry_w=上片注入，默认 0，§7）；
- 芯片下表面：`z = 1053.83 + BS_Arm_Z − t_d + rx_eff·(x−xd) − ry_eff·(y−yd)`
  （xd,yd=die 中心世界坐标；rx_d/ry_d=芯片在头倾斜注入）；
- 裸吸盘面：884.9（测校用）；head 无 die 时上探头打在键合头吸盘面
  （1053.83+BS_Arm_Z，2026-09-08 修正：光打吸盘面同样反射——与下探头
  无晶圆读裸吸盘同口径的测校基准；BS_Arm_Z≈-118.8mm 时读数≈中点 350µm）。

**BS_CAL 坡度耦合（调平闭环关键）**：BS_CAL_Rx/Ry 是物理调平轴，转动改变
芯片面世界坡度。面高公式约定 `rx=∂z/∂x`、`ry=−∂z/∂y`，而旋转轴 Rx 产生
的是 y 向坡度（rotvec 约定），两者交叉对应：

```
rx_eff = rx_d − BS_CAL_Ry        （∂z/∂x 方向）
ry_eff = ry_d − BS_CAL_Rx        （∂z/∂y 方向）
```

compensate 的补偿量按同一约定解算（`Δcal_ry = a_d − a_w`、
`Δcal_rx = b_w − b_d`，a/b=世界系拟合坡度），保证"补偿→面真值变化→复测
找回"闭环方向正确。

**焦面基准 = 芯片中心 XY**：compensate 定焦时，AS_Z 使下相机焦面 = 晶圆
**测点中心**面高、BS_Arm_Z 使上相机焦面 = 芯片**测点中心**面高（拟合平面
在 centroid 处取值）。键合位中心即芯片落点，中心对焦即工作点对焦。

**"进场调一次 + 调平后调一次"策略**：AS_Z/BS_Arm_Z 只在进场（步骤 3）与
compensate（步骤 5）各调一次，不随每个测点反复动。理由：频繁动 AS_Z 会
把轴定位误差/回程差反复引入测量链（每次动轴都是一次误差注入）；共焦读数
自带面高换算（`z_surface = z_focus ± (reading−mid)/1000`，见 §6），同一
AS_Z 基准下测完所有点再一次性定焦，误差只进一次。

## 5. 流程：build_focus_level_flow（三种模式 × 可选先对准）

路由 `POST 9010 /api/process/focus_level`，body `{mode, site?, align_first?,
paused?}`；mode = `per_site`（默认）/ `global` / `off`（POST 参数，不动
recipe 结构）。守卫（生成时刻 ValueError → 400）：晶圆不在位 / 键合头无
die / EGA 未完成（ega_result 不在）/ mode 非法。

流程启动时 `flow_engine._start` 按内容重置测量态：只有含 fl_measure/fl_solve
的步骤才清 `eng.fl_measurements`/`eng.fl_fit`，避免交接/取片等流程误清
上下文。

### 5.1 per_site 模式（默认）

适合单键合位精调。WS 在测高阶段冻结，只动 AS，保证晶圆面与芯片面的测点
相对关系不受硅片台定位误差反复扰动。

1. **log** 开始（进场高度、目标 site、align_first/verify 入日志）；
2. **`fl_ready`**：键合头退 `head_z_safe_mm`、翻转退 `fa_z_safe_mm` /
   `fa_x_retreat_mm`；WS 把目标 site 送到键合头吸盘中心正下方（EGA 映射
   反解 WS 目标）；AS_X/Y 到 `as_head_center_xy_mm`（上相机认吸盘中心位）；
   记录当前 WS 位置到 `eng.fl_ws_frozen`。
   - `site` 参数可指定键合位，默认取离晶圆中心最近的键合位；
   - 若已在位（容差 0.05 mm）则跳过移动，只记录冻结位置。
3. **进场**：AS_Z → `as_z_chuck_focus + t_w`；BS_Arm_Z → 进场公式（§4）；
4. **晶圆面测高**：per_site 取当前 site 中心周围 N 点（站点半宽 × 内缩比例；
   `align_first=true` 时改用该 site 的 `wafer.site_marks` 比例点，默认 4 个
   @±0.76）。逐点 `fl_measure{probe:down, space:wafer, freeze_ws:true}`，
   `aim` 在生成时刻用 EGA 映射 + cam_dx/dy 补偿预算好；
5. **`fl_solve{wafer}`**；
6. **芯片面测高**：die 空间 N 点（`align_first=true` 时用 `film.marks` 角标
   比例 × die 半宽，否则均布图案），逐点
   `fl_measure{probe:up, space:die}`（头/WS 均不动，仅 AS 走位）；
7. **`fl_solve{die}`** → **`fl_solve{compensate}`**（BS_CAL_Rx/Ry 调平 +
   AS_Z/BS_Arm_Z 定焦，各调一次，§4 策略）；
8. **复测确认**（`verify=true` 时，迭代 5 重写）：晶圆面同点位 N 点复测
   `fl_measure{probe:down, space:wafer_v, freeze_ws:true}`（`align_first`
   原样继承——选了先对准则复测也先对准，即"二次对准"）→ 芯片面 N 点
   复测 `space:die_v` → **`fl_verify`** 拟合两面复测点并判定残余（§6）。

### 5.2 global 模式

适合全晶圆首片调平，WS 可全程运动。

1. log 开始 + log 晶圆面 3 个选中站点坐标；
2. 安全确认走位（同旧版：AS_X/Y 退 `as_safe_xy_mm`、BS_Arm_Z 退安全高度、
   FA_Z/FA_X 退安全位）；
3. 进场（同 per_site）；
4. 若已有 `eng.level_memory`（上一次 compensate 落存
   `{cal_rx, cal_ry, as_z, bs_arm_z, residual_urad, t}`），直接施加记忆补偿
   并跳到复测（同批晶圆复用调平结果）；
5. 否则测晶圆面 **固定 3 点**（迭代 5"切蛋糕"：整片晶圆视作大芯片，
   与 wafer_ega 同参数复算 EGA 站点
   `ega.select_measure_points(cells, n_pts=ega_n_points)`，再取**最大面积
   三角形** 3 点——`_fl_pick_triangle`，O(k³) 全组合，近似 120° 均布、
   覆盖最大半径；`measure_points` 不再影响 global 晶圆侧），
   `fl_measure{probe:down, space:wafer, freeze_ws:false}`；
   `align_first=true` 时每选中 site 取第 1 个 site_mark；
6. `fl_solve{wafer}` → die 面测高（仍 N=measure_points 点，不变）→
   `fl_solve{die}` → `fl_solve{compensate}` → 复测确认（同 per_site
   §5.1 第 8 步：wafer_v/die_v 各复测 + `fl_verify`）。

### 5.3 off 模式

只对焦不调平：安全确认 → 进场 → 复测（晶圆中心 down + 芯片中心 up 各
一次，保持单点行为，不做拟合判定）。

### 5.4 先对准（align_first）

`align_first=true` 时测点全部改为有标记的点：晶圆侧认 `wafer.site_marks`，
芯片侧认 `film.marks` 角标。`fl_measure` 先让相机到设计点 → 进程内
`vision.identify`（FAST/REAL 由视觉服务现状决定）→ 像素→世界换算得实测 XY
→ 按认知链把探头送到实测点。identify 失败 → 步骤失败 → 流程 abort（与
ega_measure 一致）。

**迭代 4 变更**：零位纠错后上相机真实零位 y=1.0、吸盘中心 y=7.0，
AS_Y=+6.0 即可覆盖键合头位 die；AS_Y 行程保持 −30~120，die 侧 align_first
不再降级。

## 6. fl_measure / fl_solve 语义

**fl_measure** `{probe, point:[x,y], space:"wafer"|"die"|"stage"|"wafer_v"|"die_v", aim?,
freeze_ws?, align_first?}`（wafer_v/die_v 为调平复测记录空间，走位语义
分别同 wafer/die，仅落存键不同）：

所有走位都走"相机光轴 + 标定偏移"**认知链**（§2）：探头被认为位于
相机光轴世界 XY + `(confocal_cam_dx_mm, confocal_cam_dy_mm)`。令
`offset = (cam_dx, cam_dy)`，则探头对准目标点 P 时，相机光轴须对准
`P − offset`。

1. **走位**：
   - **wafer 空间**：
     - `align_first=false`：生成器已把设计点用 EGA 映射成对准系坐标，
       再减去 `offset` 得到 `aim`（探头对准 P 时相机应处的对准系坐标）。
       若 `freeze_ws=true`（per_site 模式），WS 固定在 `fl_ready` 记录的
       位置，仅 AS 走位：
       ```
       AS_X = as_anchor_x + aim_x + (WS_LS_X − ws_ega_x)
       AS_Y = as_anchor_y + aim_y + (WS_LS_Y − ws_ega_y)
       ```
       其中 `as_anchor_xy_mm` / `ws_ega_xyz_mm` 来自 `wafer_ega` 机械常数。
       若 `freeze_ws=false`（global 模式），走 WS 先动、AS 后动的
       `_ega_split_targets`。
     - `align_first=true`：相机先到设计点（不带共焦偏移）→ 进程内
       `vision.identify`（模板源：down 认 `site_marks`，up 认
       `head_die_marks`；FAST/REAL 由视觉服务现状决定）→ 像素→世界换算
       得实测 XY → 探头按认知链送到实测点（仅 AS 微调）。identify 失败
       → 步骤失败 → 流程 abort。wafer 空间支持 `freeze_ws`。
   - **die 空间**：点 `point` 是相对键合头吸盘中心的设计偏移。相机目标
     AS 坐标 = `as_head_center_xy_mm + point − offset`，直接移动 AS_X/Y。
     这是迭代 3 修正后的框架：不再把"探头目标"误当"相机目标世界"去减
     当前相机世界位姿，因此拟合面斜率正确。
   - **stage 空间**：点 `point` 是世界 XY 直给。相机目标世界 =
     `point − offset`，再减去当前相机光轴世界位姿，得到 AS 增量：
     ```
     AS_X = 当前 AS_X + (point_x − offset_x − cam_pos_x)
     AS_Y = 当前 AS_Y + (point_y − offset_y − cam_pos_y)
     ```
   - **行程守卫**：die/stage 的 AS 目标在移动前校验行程，超限直接
     `RuntimeError`（不再降级）。
2. **读共焦**（**走 MQTT 往返**，§8）；无读数 → AS_Z 以测量前位置为中心按
   `focus_search_step_um` 螺旋外扩扫描（±`focus_search_span_um`/2 内），
   每次读数都走 MQTT；命中后**恢复 AS_Z 到测量前位置**再记录（面高换算
   与搜索位无关，见下），扫描穷尽仍无读数 → 步骤失败（报警文本含测点与
   搜索步数）；
3. **面高换算记录**：down 探头 `z_surface = z_focus + (reading−mid)/1000`，
   up 探头 `z_surface = z_focus − (reading−mid)/1000`；`world` = 探头实际
   世界 XY（`confocal.probe_pose` 真值；搜索只动 Z，XY 不变）。**wafer 系
   空间（wafer/wafer_v）另记 `plane_xy`**（迭代 5 修正）：晶圆刚性固定在
   吸盘上随 WS 平移，global 允许测点间 WS 运动，世界系下晶圆面不是固定
   平面（同一晶圆点在不同 WS 轴位世界坐标不同，直接世界系拟合会得出
   荒谬坡度——global 补偿曾因此 silently 错误）；`plane_xy = world −
   (当前 WS 轴位 − ws_ega 轴位)`，拟合统一在该晶圆台基准系进行（平移
   不改平面坡度，中心面高=点均值亦不变；per_site WS 冻结时与世界系
   完全等价）。die/stage 空间仍用 world。记录落存
   `eng.fl_measurements[space]`。

**fl_solve** `{mode:"wafer"|"die"|"compensate"}`：

- wafer/die：对 `fl_measurements[space]` 最小二乘拟合平面
  `z = a·x + b·y + c`（≥3 点，纯标准库 3 参法方程，复用 `ega._solve3`；
  共线/奇异 → 步骤失败；wafer 系空间用 `plane_xy`、其余用 `world`）；a=∂z/∂x、b=∂z/∂y 即面坡度（小角=倾斜 rad），
  rms/中心面高写日志，落存 `eng.fl_fit[space]`；
- compensate（原子补偿，各调一次）：
  ① BS_CAL_Rx/Ry 使芯片面 ∥ 晶圆面——`Δcal_ry = a_d − a_w`、
  `Δcal_rx = b_w − b_d`（交叉约定见 §4），钳到 ±0.1° 行程；
  ② AS_Z 定下相机焦面 = 晶圆测点中心面高（焦面随 AS_Z 1:1，取共焦模型
  焦面公式值，对模块 z 误差免疫）；
  ③ BS_Arm_Z 定上相机焦面（随新 AS_Z）= 芯片测点中心面高（芯片面随
  BS_Arm_Z 1:1 平移，增量式计算对常数误差不敏感）。
  残余坡度（钳位截断才非零）与焦面残差写日志；补偿结果同时落存
  `eng.level_memory`（global 复用）与 `eng.fl_fit["compensate"]`
  （`flow.state.fl_result` 暴露：cal_delta_urad / residual_urad / as_z /
  bs_arm_z / focus_resid_um）。

**fl_verify**（无参数，迭代 5 新增，op 白名单含之）：调平后**实测**复测
确认——补偿已真实施加在 BS_CAL_Rx/Ry 上（die 面物理随动），对复测空间
`wafer_v`/`die_v`（复测段以与正式测量相同的点位二次采高落存；
`fl_measure` 对这两个 space 的走位语义分别同 wafer/die，仅落存键不同；
流程启动重置 `fl_measurements` 含 wafer_v/die_v）各做平面拟合：

- 实测残余坡度 = die_v 拟合坡度 − wafer_v 拟合坡度（rad→µrad ×1e6）；
- 判定：`|res_rx|, |res_ry| ≤ level_tol_urad`（focus_level 机械常数，
  30µrad）。PASS/FAIL 都落存 `eng.fl_fit["verify"]`
  （`{residual_urad, wafer_grad_urad, die_grad_urad, judge}`，
  `flow.state.fl_verify` 暴露）；PASS 日志"调平复测 PASS：残余 …"；
  FAIL 同样落存后 `raise RuntimeError` → 流程 abort 报警（与真实设备
  一致；自动迭代补偿属后续迭代，本期只做确认）；
- 焦面复核（参考值，不判定）：复测点中心面高 vs 当前上下焦面偏差写日志。

## 7. 倾斜真值注入（测校页 wafer_load 卡）

| 字段 | 单位 | 消费方 |
|---|---|---|
| `z_um` | µm | 晶圆面高偏移 z_err（§4 晶圆面公式） |
| `rx_urad` / `ry_urad` | µrad | 晶圆面倾斜 rx_w/ry_w（上片时写入 wafer 真值） |
| `die_head_rx_urad` / `die_head_ry_urad` | µrad | 芯片在头倾斜 rx_d/ry_d（交接 flip↔head 完成时写入 die 载体真值） |

默认全 0；recipe.py 校验沿用 wafer_load 组。注入值是"真值"，调焦调平流程
的全部意义就是测量并补偿它们（回归用例注入 wafer rx=+300µrad + die
ry=−200µrad，补偿后应找回 BS_CAL_Rx≈−200µrad、Ry≈−300µrad）。

共焦读数噪声 σ 同在测校页（"传感器仿真"卡，recipe `sim_sensors` 组）：
`confocal_sigma_um` 默认 0.05 µm、校验 0~10（区间惯例 (lo,hi]，0 合法——
回归/冒烟要确定性）。`confocal.py read()` 每次读实时取，PUT 即热生效。

## 8. MQTT 通讯契约要点

全文见 `前后端数据协议_V1.md` §12，要点：

- 触发 `confocal/trigger/{probe}`（payload 带 `req_id`，流程侧格式
  `fl-NNNNNN` 递增）→ 共焦服务（`ConfocalModel.start_mqtt()` 订阅
  `confocal/trigger/+`）收到即 `read()` → 发布
  `confocal/result/{probe}`（QoS0，req_id 原样回带，字段 reading_um /
  valid / z_surface / z_focus）；
- 主控侧 `ConfocalClient`（`engine.confocal_client`）：发布触发 → 等结果
  主题上同 req_id 消息（5s 超时判失败）；常驻收线线程只解析 JSON 填字典
  + Condition，不碰引擎状态（与流程线程解耦）；
- 客户端未挂载（单测/裸引擎场景）flow_engine 回退进程内直读
  `confocal.read()`；调试 API `GET /api/confocal/read` 恒为同步直读。

## 9. 与真实设备的对应关系及已知差距

对应关系：共焦"量程外无读数 + 读数调中点 = 相机在焦"即真机用共焦快速
定位焦面的工艺；调平 = n 点测高 → 最小二乘平面 → 单侧执行机构原子补偿
（真机硅片台 WS 无 Z/Rx/Ry，垂向调整全在键合头 BS_CAL_Rx/Ry ±0.1° 与
BS_Arm_Z，晶圆侧对焦靠 AS_Z 抬相机——与真机轴系一致）；global 调平记忆
对应真机"同批次首片调平、后续片复用"。

已知差距（有意不做，控制范围）：

- 无温漂、无多峰（多层透明材质多反射峰）、无斜面入射角效应（倾斜面上
  共焦光斑偏移/信号衰减）——读数模型只有线性映射 + 高斯噪声；
- 视觉链路（相机识别）仍是进程内直读，只有共焦走了 MQTT 服务化；
- AS_Y 行程 −30~120 与 `as_head_center_xy_mm=[0.0,6.0]` 均为迭代 4 零位
  纠错后的**仿真假定**，待真机测校确认；若真机几何不同，调整机械常数/轴行程
  后 die 侧 align_first 行为会同步变化，当前实现已按可达处理，不再降级；
- 相机寻峰式调焦（cal_focus 扫描）未做——中点共面约定已覆盖快速对焦，
  相机扫描留作后续测校流程；
- 共焦光斑尺寸/横向分辨率未建模（测点即数学点）；
- 调平执行轴回程差/重复定位误差未单独注入（走通用轴误差体系）。

**2026-08-27 顺带修复（align_first 暴露的视觉模型 bug）**：
`vision_model.head_die_marks` 原把 die 标记放在吸盘尖端面
（surface_z_offset=0）——那是 die 顶面；物理标记在 die 下表面（贴晶圆
侧）= 吸盘尖端面 − die 厚。原实现下 up 相机对 die 底面进焦时标记恒
离焦 t_d（默认 500µm）判废（此前没有任何用例对 up 相机做过有 die 的
identify，gap 未暴露）。已修：collect_marks/collect_layers 的
head_die_marks 均按 −t_d 取标记面。
