## 1. 测的是什么

**定义**：上相机识别键合头吸盘（collet）中心、且吸盘心十字标记正好
落在视场中心（相机光轴）时的**对准台轴位 [AS_X, AS_Y]**（mm）。该量
在机器常数里有两个名字——它们是**同一物理量**：

| 常数键 | 组 | 消费方 |
|---|---|---|
| `as_head_center_xy_mm` | `focus_level`（`machine_constants.json:95-98`） | fl die 空间寻址基准：align_first die 空间 AS 目标 = 本键 + die 角标设计偏移（`flow_engine.py:1860-1867`）；fl_ready 第 3 步 AS 就位（`flow_engine.py:1925-1948`）；fl_measure die 侧测点基准（`process_flows.py:856`、`:1039`） |
| `as_anchor_xy_mm` | `wafer_ega`（`machine_constants.json:71-74`） | 对准台锚点：WS 处于 EGA 位时 AS 移到本值，相机光轴正对吸盘心——EGA 分流 `_ega_split_targets`（`flow_engine.py:1661-1670`）与 fl_ready 的 WS 反解（`flow_engine.py:1946-1948`）依赖不变量 `anchor − ws_ega = 吸盘心零位 − 相机零位`（`machine_constants.json:65` wafer_ega._note） |

**为什么同值**：上/下相机同挂对准相机承载台（align_stage 模块，工具
点 (−42.5, 23.5, 910)），mount offset 仅 z 不同——up `[0, −22.5,
+15.0]`、down `[0, −22.5, −14.1]`（`vision_cameras.json:25`、`:35`），
XY 零位世界同为 (−42.5, 1.0)。故"相机光轴对准吸盘心时的 AS 轴位"对
两台相机是同一个数，measured 双键同值给出（`as_head_center.py:
194-196`），apply 双键联动写回（见 §6.3）。

**真值口径**（`as_head_center.py:33-36`）：误差链 OFF 时 bond_head
吸盘心世界 = (−42.5, 7.0)、上相机零位世界 = (−42.5, 1.0)，故真值锚点
恒 = (0, 6) mm，与两键默认值一致；误差链 ON 时真值含 align_stage /
bond_head 两模块 6DOF 装配偏差（µm~10µm 级，仿真实测 (~+0.006,
5.984)），测得的是"含装配真值的实际锚点"——真机测校同此口径（真机
的装配偏差就是物理存在）。两键现值均为**仿真假定，待真机标定**
（focus_level._note `machine_constants.json:93`）。

**算法一句话**：动态再逼近直接测量法——前置走位到"现锚点 + 两焦面
基准"后，每轮把 AS 先 +1mm 再回锚点（单侧逼近消反向间隙），拍照识别
吸盘心十字，像素经像元当量 + 相机安装映射（含 rot_mrad 认知）反算
世界偏移 δ，新锚点 = 当前 AS 位 + δ；repeat 轮取均值。

## 2. 算法推导（动态再逼近直接测量法）

实现：`metrology/as_head_center.py` 的 `run_as_head_center`
（`as_head_center.py:84-224`）。输入已由 `calibration.start` 校验规范
化（见 §6.1）：`template_name`、`repeat`、`wait_ms`。

### 2.1 作业时序

启动时读三个机器常数（`_const` 异常回退默认，`as_head_center.py:
75-81`）：

```
anchor0      = wafer_ega.as_anchor_xy_mm      （缺省回退 [0.0, 6.0]，:93-94）
as_z_focus   = focus_level.as_z_chuck_focus_mm（缺省 −1.0，:95-96）
head_z_focus = focus_level.head_z_upfocus_mm  （缺省 −119.83，:97-98）
```

记录现场（`as_head_center.py:99-105`）：上相机原灯态 + 作业前轴位
（`restore_axes = ("BS_Arm_Z", "AS_Z", "AS_X", "AS_Y")`——恢复顺序即
先抬键合臂再回对准台，防撞）。开灯（`:116-117`）后：

```
前置走位（:118-123，先 AS 后 BS：头下降时对准台已在锚点，与 fl_ready 同序）：
    AS_Z → as_z_focus          （下相机焦面基准位，同时是上相机焦面链基准）
    AS_X → anchor0.x，AS_Y → anchor0.y
    BS_Arm_Z → head_z_focus    （裸吸盘面进上相机焦面）
sleep(wait_ms) → _check_marks(up) 视野预检（:124-125，见 5.4）
循环 i = 0..repeat−1（每循环首 _check_cancel，:127）：
    动态再逼近（:131-134）：AS_X/Y → anchor0+1mm → 回 anchor0
    sleep(wait_ms)（:135）
    identify(up, template_name)（:136）→ 判真点云质心 (col,row)（:137）
    _context 反算 mark_world / cam_world（:139-142，见 2.2）
    δ = mark_world − cam_world（:143）
    anchor_i = (AS_X.pos, AS_Y.pos) + δ（:144-146）
finally：恢复四轴作业前位 + 原灯态（:166-175）
```

### 2.2 像素 → 世界坐标反算链

质心取**判真点**（score ≥ 相机阈值，默认 0.6）均值
（`calibration.py:1780-1791`——只采纳判真点可滤掉 NCC 亚阈值幽灵
峰）；score 记 `max(lstScore)`（`as_head_center.py:138`）。`_context`
（`metrology/repeatability.py:99-132`）一次取齐：

1. **相机世界位姿**：`camera_pose(eng, cam, poses, positions)`
   （`runtime/vision_model.py:693-708`）= align_stage 模块 6DOF 位姿
   （名义+误差链）+ 随姿态旋转的 mount offset → `cam_world_mm`。
2. **质心反投影**：`cam.solve_pixel(col, row, cam_pos)`
   （`vision_model.py:563-574`）：

   ```
   (u, v) = (col − W/2, row − H/2)            # 相对画幅中心 px
   solve_rel（vision_model.py:543-561）：
       swap_xy 逆映射（up 为 false）
       dx0 = u·k·dir_x，dy0 = v·k·dir_y        # 方向性反映射
       (dx, dy) = R(+rot)·(dx0, dy0)           # 控制器认知安装微旋
   mark_world = cam_pos + (dx, dy)             # 焦面平面世界坐标
   ```

   其中像素当量 `k = pixel_um / mag / 1000`（`vision_model.py:505-508`
   的 k_mm 属性），上相机 = 6.0 / 10.0 / 1000 = **0.6 µm/px**
   （`machine_constants.json:18-19`）；dir_x = 1.0、dir_y = −1.0、
   swap_xy = false、rot_mrad = −0.599（控制器认知，只进反算链；
   `machine_constants.json:20-23`、`:28` cameras.up._note）。

### 2.3 δ 符号约定与新锚点合成

δ = mark_world − cam_world（画幅中心即相机光轴）。**上相机挂对准台
随台动**：AS 走 +δ，视场中心也走 +δ，故"把相机光轴送到标记上"的新
锚点为

```
anchor_i = (AS_X.pos, AS_Y.pos) + δ        （as_head_center.py:144-146）
```

注意与 JOG_AXES up 组 rel = −1（`calibration.py:146`）的口径互逆：
那边是"动相机等效标记反向移动"（点动符号），这里求"相机要走多远才
盖住标记"，直接 +δ（`as_head_center.py:24-28`）。**写回自证**：apply
写回后复测，AS 已在新锚点，δ ≈ 0 → 复测 measured ≈ 已写回值；若符号
写反，偏差会被放大而不是吸收——回归 `i42.as_head_center_recheck` 即
验此闭环（残差 < 0.005mm、mean|δ| < 2µm，
`tests/test_metrology.py:4840-4854`）。

### 2.4 动态再逼近（消反向间隙）

每轮拍照前 AS_X/AS_Y 先同偏 +1mm 再回 anchor0（`_JOG_MM = 1.0`，
`as_head_center.py:72`、`:131-134`）——两轮反向后从**同一方向**
（+侧）逼近锚点，丝杠/联轴器反向间隙在每轮终态一致，不进逐轮散布；
与 stage_nonortho 升序跳测同哲学。1mm 行程远大于 AS 间隙量级，足以
充分换向。

### 2.5 统计口径

`_mean_std`（`metrology/repeatability.py:186-191`），**总体 ddof=0**：
`σ = sqrt((1/n)·Σ(x_i − mean)²)`。逐轮锚点序列 `series.anchor_x/y_mm`
（mm）与世界偏移 `series.delta_x/y_um`（µm = mm×1000，
`as_head_center.py:202-205`）；统计 `stats.anchor`
（`as_head_center.py:183-185`、`:206-210`）：

```
x/y 分量：{mean_mm, s3_nm}（s3 = 3σ × 1e6，mm→nm）
整体    ：s3_nm = hypot(s3x_nm, s3y_nm)（客户端首选口径）
```

measured 取逐轮锚点均值（round 6 位）：`measured.as_anchor_xy_mm =
as_head_center_xy_mm = [mean_x, mean_y]`（双键同值，
`as_head_center.py:194-196`）；`current` 同两键现值（`:197-200`）。

### 2.6 CSV 列定义

`runtime/metrology_data/as_head_center_MMDD_HH_MM_SS.csv`（命名
`_csv_write`，`metrology/extra_routines.py:92-105`；表头
`as_head_center.py:176-181`），**14 列**，每行一轮：

```
index, AS_X_mm, AS_Y_mm,           # 本轮拍照时 AS 轴位（名义 pos）
mark_col_px, mark_row_px, score,   # 质心像素与最高分
cam_world_x_mm, cam_world_y_mm,    # 相机光轴世界位（_context）
mark_world_x_mm, mark_world_y_mm,  # 质心反投影世界位
delta_x_mm, delta_y_mm,            # δ = mark − cam
anchor_x_mm, anchor_y_mm           # anchor_i = AS + δ
```

结果回执带 `csv`（相对路径）/ `csv_name` 键（`as_head_center.py:211`）。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. **键合头无 die**：有 die 时吸盘心被 die 物理覆盖，不出
   `head_chuck_cross` 标记（`vision_model.py:894-906`——该 150µm
   cross 为无 die 时恒在的吸盘心真空十字气道交叉中心，仿真合成实体，
   按 tpl_head_chuck 同尺度补出），走位后视野预检失败 → 作业 error。
2. 视觉链路可用 cv2（start 全局门槛 `runtime/calibration.py:289-291`）。
   **视觉模式 FAST/REAL 均可**（作业不切模式——score 两模式单调可测
   且真机可得，`as_head_center.py:42-44`）。
3. 无工艺流程在跑（flow running/paused、全片键合、一键串联 → start
   400，`calibration.py:938-952`；本 routine 动四轴）。
4. 模板已注册（视觉模板库；作业不自建不删）。缺省 = 机器常数
   `vision_marks.tpl_head_chuck`，现值 `"tpl_head_chuck"`
   （`machine_constants.json:133`；合成模板 cross 150µm 已在模板库，
   `vision_templates.json:152-167`——本测校预留）。
5. 两焦面常数可信：`focus_level.as_z_chuck_focus_mm`（现 −1.0）与
   `head_z_upfocus_mm`（现 −119.83）决定前置走位的焦面——这两个键
   由 `best_focus` 标定（同迭代 42），值不对会离焦 → score 低于阈值
   → 无判真点 error。
6. 无需上片（本测量与晶圆无关）。

### 3.2 启动 / 中断 / 判读


## 4. 计算示例（一组自洽数字手算复核）

**示例数据为示意**（自洽合成，非某次实测落盘）：场景同回归
`i42.as_head_center`——误差链 OFF（真值锚点恒 (0, 6)），先 PUT 把
两键认知改为 [0.05, 6.05]（+0.05mm 认知偏移），repeat=5、wait_ms=10。
上相机内参：k = 0.6 µm/px、dir_x = 1.0、dir_y = −1.0、swap_xy = false、
rot_mrad = −0.599 → θ_b = −5.99e−4 rad（cos ≈ 0.99999982，
sin ≈ −5.99e−4）；画幅 3000×3000，中心 (1500, 1500)。

### 4.1 一轮：像素 → 世界 → δ → 锚点

误差链 OFF 下标记真值世界偏移 δ_true = (0, 6) − (0.05, 6.05) =
(−0.05, −0.05) mm。其像素落点（正演反推，仅作示意的输入构造）≈
**(col, row) = (1416.72, 1583.38)**。作业测量链手算复核：

```
u = 1416.72 − 1500 = −83.28 px     v = 1583.38 − 1500 = +83.38 px
dx0 = u·k·dir_x  = −83.28 × 0.0006 × 1.0  = −0.049968 mm
dy0 = v·k·dir_y  =  83.38 × 0.0006 × (−1) = −0.050028 mm
R(+θ_b) 反旋安装微旋：
dx = 0.99999982×(−0.049968) − (−5.99e−4)×(−0.050028) ≈ −0.0499980 mm
dy = (−5.99e−4)×(−0.049968) + 0.99999982×(−0.050028) ≈ −0.0499981 mm
δ = (−0.0499980, −0.0499981) mm ≈ (−49.998, −49.998) µm
anchor_1 = (0.05, 6.05) + δ = (0.0000020, 6.0000019) mm ≈ 真值 (0, 6) ✓
```

（0.6µm/px 下 83.3px ≈ 50µm；微旋认知 −0.599mrad 在 50µm 偏移上只引
入 ~0.03µm 级旋转修正，量级相符。）

### 4.2 五轮统计（repeat=5）

逐轮锚点（mm；示意，含百 nm 级识别/到位噪声）：

| i | anchor_x | anchor_y |
|---|---|---|
| 0 | 0.0000020 | 6.0000019 |
| 1 | −0.0000015 | 5.9999986 |
| 2 | 0.0000028 | 6.0000024 |
| 3 | −0.0000022 | 5.9999991 |
| 4 | 0.0000009 | 6.0000012 |

```
mean = (0.0000004, 6.0000006) mm → measured 双键 = [0.0, 6.000001]
σ_x = sqrt(18.94e−12 / 5) = 1.946e−6 mm  → 3σ_x = 5.84 nm
σ_y = sqrt(11.532e−12 / 5) = 1.519e−6 mm → 3σ_y = 4.56 nm
stats.anchor.s3_nm = hypot(5.84, 4.56) = 7.41 nm
```

读法：measured 与真值 (0, 6) 的偏差 ~1e−6 mm 量级（回归验收 < 0.01
mm）；与认知现值 [0.05, 6.05] 的差 = 本次要写回修正的 +50µm 认知偏移。

### 4.3 写回后复测（符号自证）

apply 双键写回 [0.0, 6.000001] 后：anchor0' = 新值，δ_true' =
(0,6) − (0.0, 6.000001) ≈ (0, −0.000001) mm → 复测逐轮 |δ| 只剩噪声
（mean|δ| < 2µm 验收），measured₂ ≈ measured₁（残差 < 0.005mm 验收）。
若 δ 符号取反，写回后偏差翻倍（0.05→0.10），复测 δ 均值 ~ −100µm
立刻暴露——这是本 routine 内置的符号正确性检查。

## 5. 误差来源与注意事项

1. **相机识别噪声**：REAL 链质心噪声（recipe `sim_sensors.
   fast_noise_px`，按相机分路，up=0.1px 默认档，`recipe.json:91-95`）
   × k=0.6µm/px ≈ 60nm 级单轮散布，是逐轮 anchor 散布与 3σ 的
   主项之一；repeat 取均值压 measured 不确定度（σ/√n）。
2. **AS 到位重复性**：每轮回 anchor0 的到位误差直接进入 δ 与
   anchor_i；动态再逼近把反向间隙换成单向到位重复性（残余见 2.4）。
3. **rot_mrad 认知不准的影响有界**：认知 −0.599mrad 与真值 view_rot
   （−0.0286479° ≈ −0.500mrad，`vision_cameras.json:30`）不完全相等
   时，solve 链世界解带旋转误差 (θ_b − θ_t)，对 anchor 的影响 ≈
   |δ|×|θ_b−θ_t|（50µm × 0.1mrad ≈ 5nm）；且写回自证闭环按
   |θ_b−θ_t| 几何收敛，一次写回即收敛到 nm 级（微旋本身由
   camera_microrot 标定，见 `docs/相机微旋转角标定_V1.md`）。
4. **视野预检在走位后做**（`as_head_center.py:125`）：start 时机台
   未必在测量位，当前位预检会误拒，故 start 校验器只查模板/repeat/
   wait_ms/工艺忙（`calibration.py:897-953`）；前置走位到位后
   `_check_marks`（`metrology/repeatability.py:55-78`）兜底，无标记
   → 作业 error 态带"最近的标记距视野中心 X.XXmm"文案。
5. **焦面常数联动**：as_z_chuck_focus_mm / head_z_upfocus_mm 错了会
   离焦（上相机景深 ±20µm）→ score 低于阈值（0.6）→ "无判真匹配点"
   error；先用 best_focus 标好两焦面键再跑本项。
6. **cancel/恢复语义**：cancel 只置标志，下一循环首检查点抛
   `CalibCanceled` → 终态 canceled；`finally` 一定按
   BS_Arm_Z → AS_Z → AS_X → AS_Y 顺序恢复作业前轴位（先抬臂防撞，
   `as_head_center.py:101`、`:166-171`）并恢复原灯态，用户模板绝不
   删除。
7. **双键同值联动的纪律**：apply 漏写一个键会使 EGA 链（wafer_ega
   锚点）与 fl 链（focus_level die 基准）分裂——fl_ready 的 WS 反解
   同时用两个键（`flow_engine.py:1936-1948`），分裂直接变成 die 落点
   系统偏差。盘上两键若不一致（如手工 PUT 过其中一个），跑一次本项
   并双键写回即收敛。
8. **FAST/REAL 均可、不切模式**：FAST 下 repeat 扫描快两个量级，适合
   回归；REAL 接近真机链。真值口径差异只在误差链 ON/OFF（见 §1），
   与模式无关。
