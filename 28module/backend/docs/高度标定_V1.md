# 高度标定_V1

测校族：键合头 Z 向两个"慢速寻力"高度标定 routine（迭代 49 新增）。
两者都不用相机做测量（cam 恒 `"up"` 仅为注册契约占位），共用同一套
"低速下降 + 力阈值判接触"范式（与 bond 流程 force_search op 同源，
`runtime/flow_engine.py:955`）：

| routine | 测什么 | 实现 |
|---|---|---|
| `flip_handoff_height` Flip与键合头承接高度标定 | 键合头压到 flip 吸盘上 die 背面的实际接触位 Z* → measured.head_z_touch_mm（写回 flip_handoff 组同名键，正逆向交接共用）+ flip_surface_mm | `metrology/handoff_height_calib.py`（`run_flip_handoff_height`，:62） |
| `bond_height_calib` 键合头键合高度标定 | 键合头压到晶圆上 die 的实际接触位 Z* → measured.head_z_contact_mm（**裸值**=Z*−芯片厚−晶圆厚，写回 bond 组同名键）+ z_contact_mm | `metrology/bond_height_calib.py`（`run_bond_height_calib`，:57） |

本文面向设备工程师逐行核对算法：所有公式、字段名、阈值均对准代码
实际实现（引用格式 `文件:行号`）。单位约定：直线 mm（显示层 µm
注明换算）。

## 1. 测的是什么（flip_handoff_height）

**定义**：正向交接（flip→head）与逆向吸回（head→flip）共用的承接
高度——机器常数 `flip_handoff.head_z_touch_mm`
（`runtime/machine_constants.json:78-91` 组，键 :85）。交接动作里
键合头（BS_Arm_Z）下降到该位后，头吸盘底面应正好轻贴 flip 吸盘上
die 的背面（两吸盘间隙恒=die 厚）：偏高 → die 悬空、交接失败；
偏低 → 压伤 die。本 routine 用真实力链把该位**实测**出来：键合头
以 search_speed_mm_s（默认 0.2mm/s）慢降，力读数 ≥ force_threshold_n
（默认 2.0N）即停，停稳位即 Z*。

语义链（仿真真值侧，`runtime/engine.py:2209-2239`
`_tick_force_locked` 的 flip 交接接触支路，迭代 49）：

- flip 吸盘裸面在 BS_Arm_Z 坐标系的 z = tuning
  `bond_hw.flip_contact_z_mm`（**真值旋钮**，默认 −51.43，
  `runtime/tuning.json:28`；裸引擎兜底 `engine.py:113-114`）——
  仿真合成值，**待真机标定**。
- die 背面有效接触位 flip_eff = flip_contact_z_mm + 处方芯片厚
  （recipe `film.dies.thickness_mm`，默认 0.5，`runtime/recipe.json:169`；
  缓存 `engine.py:1365-1367`）= −51.43+0.5 = **−50.93**，恰等于
  机器常数缺省值（认知=真值，出厂理想）。
- 支路门控（`engine.py:2229-2237`）：flip 上有 die 且
  |FA_X−fa_x_handoff_mm|≤1.0 且 BS_Arm_Z 进入邻域
  （pos<flip_eff+2）时，压入量 press=flip_eff−pos，真值力
  F=k·press（k=tuning bond_hw.force_spring_k_n_per_mm=500N/mm，
  `tuning.json:21`），与键合支路压入取 max（`engine.py:2238`）。

measured 四键口径（`handoff_height_calib.py:169-173`）：

- `head_z_touch_mm` = Z*（停稳后 BS_Arm_Z 实际位）——**写回键**；
- `flip_surface_mm` = Z* − chip_thickness_mm——flip 吸盘裸面高，
  与真值旋钮 flip_contact_z_mm 同口径（差=阈值压入量，见 §4/§7.1）；
- `contact_force_n` / `chip_thickness_mm` 只读回显，不写回。

与常数 _note 的几何推导（`machine_constants.json:79`）互证：Rx=0
呈现位 die 背面世界 z=982.9+FA_Z，交接时 FA_Z=fa_z_safe=20 →
1002.9；头吸盘底零位 z=1053.83 → 1002.9−1053.83 = **−50.93**。
**fa_z_safe_mm 改了 head_z_touch_mm 要同步重标**。

## 2. 算法推导（慢速寻力法）

实现：`metrology/handoff_height_calib.py`（:62-190）。参数已由
`calibration.start` 校验规范化（§8.1）。

### 2.1 时序

```
读常数（:69-74）：
    head_z_safe  = flip_handoff.head_z_safe_mm      （0.0）
    as_safe      = flip_handoff.as_safe_xy_mm       （[0.0, 120.0]）
    fa_x_handoff = flip_handoff.fa_x_handoff_mm     （−1242.35）
    touch0       = flip_handoff.head_z_touch_mm     （−50.93，现认知值）
z_start = touch0 + 2.0    （:75，名义接触位上方 2mm——安全侧，见注）
z_floor = touch0 − 2.0    （:76，超程下限）
保存 FA_X/AS_X/AS_Y 当前位（:77-80，finally 恢复用）

前置走位（:93-98，防撞顺序：先抬头 → 退对准台 → FA_X 到交接位 →
                          下到 z_start）：
    BS_Arm_Z → head_z_safe
    AS_X/AS_Y → as_safe          （对准台退避让开交接区）
    FA_X → fa_x_handoff          （flip 支路门控前提）
    BS_Arm_Z → z_start
慢降寻力（:101-135）：
    eng.move(BS_Arm_Z, z_floor, search_speed_mm_s)   （默认 0.2mm/s）
    每 20ms 采样循环：
        _check_cancel（:104）→ 取消抛 CalibCanceled
        读 z/moving（:105-108）、oActualForce（:109）、
            ChuckVac/ChipVac 压力（:110-111）
        落 series + CSV 行（:113-119）；progress 上报（:121）
        rd ≥ force_threshold_n → 原地停轴（:122-129：
            eng.move 重规划到当前位，同 force_search 停法）→ break
        已停且 z ≤ z_floor → CalibError "寻力未接触"（:130-134）
停稳确认（:137-143，in_position 且 not moving，10s 超时）
Z* = 停稳后 BS_Arm_Z 实际位（:144-145，覆盖触发瞬间值——重规划
    目标=当前位，减速段不产生额外压入）
finally 恢复（:146-156）：BS_Arm_Z→head_z_safe → FA_X/AS_X/AS_Y 回
    作业前位
```

注（`handoff_height_calib.py:13-15`）：起点取名义接触位**上方** 2mm
（+2 安全侧）——若按任务书字面 "−2"，起点已在接触面下方 2mm、触力
立即击穿阈值，物理不成立。

### 2.2 接触判据与力读数链

判据只一个：**发布力读数 rd ≥ force_threshold_n**。读数点位
`SystemMachine.SS_Bonding.M_BS.oActualForce`
（`handoff_height_calib.py:48`），与面板显示、flow_engine
force_search 同源的含噪读数。读数链（`engine.py:2248-2260`，迭代
49）：

```
raw = F_true × (1 + force_gain_err) + force_offset_N ± force_noise_N
发布 rd = (raw − sensor_calib.force_offset_n) / sensor_calib.force_gain
```

注入真值在 recipe sim_sensors 组（默认 force_gain_err=0.003、
force_offset_N=0.05N、force_noise_N=1.0N，`recipe.json:90,109-110`）；
标定补偿在机器常数 sensor_calib 组（默认 gain=1.0/offset=0.0 即不
补偿，`machine_constants.json:174-181`——bond_force_calib 的写回
目标）。默认状态下 rd ≈ F_true×1.003+0.05±1.0。

阈值语义两道约束：

- **防误触**：未接触时 rd ∈ 0.05±1.0 ⊂ [−0.95, 1.05]，阈值 2.0N
  有约 2× 裕量，噪声峰不会假触发；
- **触发压入量**（系统性偏差，§7.1）：接触后力斜率
  dF/dz = k·(1+gain_err) ≈ 501.5 N/mm，触发时真值压入
  press* = (2.0−0.05)/(1.003×500) ≈ 3.9µm——Z* 是"压入 ~4µm 处"
  而非几何接触面。

**负压两列只记录不判据**：ChuckVac/ChipVac（PressureSwitch.oValue，
`handoff_height_calib.py:49-50`）随采样落 series/CSV（:110-111,
:116-119），供判读时确认 flip 持片真空在位、且作业**全程不动真空**
（不触发真实交接）；接触判定不消费负压。

### 2.3 Z* 与派生量

```
Z*               = 停稳后 BS_Arm_Z 实际位           （:144-145）
head_z_touch_mm  = round(Z*, 6)                     （:169，写回候选）
flip_surface_mm  = round(Z* − chip_thickness_mm, 6) （:170-171）
contact_force_n  = round(触发瞬间发布读数, 4)         （:172）
```

几何含义：头吸盘底面贴 die 背面时 BS_Arm_Z = Z*；die 背面 =
flip 裸面 + die 厚，故 flip 裸面 = Z* − t_chip。默认链
Z*≈−50.934 → flip_surface≈−51.434 ≈ 真值旋钮 −51.43（差=press*）。

### 2.4 采样 / 抽稀 / CSV

- 采样节拍 20ms（`time.sleep(0.02)`，:135），默认速度下
  0.2mm/s×0.02s = **4µm/点**（触发量化粒度）。
- series 抽稀到 ≤400 点（:161-166，step=ceil(n/400)）；**CSV 全量**
  不抽稀。
- CSV（`_csv_write`，`metrology/extra_routines.py:92`）：落盘
  `runtime/metrology_data/flip_handoff_height_MMDD_HH_MM_SS.csv`，
  表头（:157-159）：

```
t_s, z_mm, force_n, chuck_vac_kpa, chip_vac_kpa
```

  每行一个采样点：相对下降启动的秒、BS_Arm_Z 位、发布力、两路
  负压（kPa）。结果回执带 `csv`/`csv_name` 键（:176）。

## 4. 计算示例（示意数据手算复核）

示例数据为示意（默认常数/处方/注入下的模型手算，与回归实测同口径；
回归实测值见末段）。默认链：touch0=−50.93 → z_start=−48.93、
z_floor=−52.93；真值 flip_eff=−51.43+0.5=−50.93；k=500N/mm；
采样 4µm/点。

**下降段**：z_start −48.93 → 接触面 −50.93，行程 2.0mm → 500 采样
≈10s；期间 F_true=0，发布 rd=0.05±1.0（噪声带内波动，不触发）。

**触发点**：pos 一过 −50.93 真值力按 500N/mm 爬升，每采样
ΔF_true=500×0.004=2.0N。发布 rd=F_true×1.003+0.05±1.0：

```
第 501 点 pos=−50.934：F_true=2.0，rd=2.056±1.0 ∈ [1.056, 3.056]
    → 约半数实现本点即 rd≥2.0 触发
第 502 点 pos=−50.938：F_true=4.0，rd=4.062±1.0 ≥ 3.062 > 2.0
    → 最迟本点必触发
Z* ≈ −50.934 ~ −50.938（噪声决定落在哪点；标称压入
    press*=(2.0−0.05)/(1.003×500)=3.89µm → Z*≈−50.9339）
```

**measured**（取 Z*=−50.9339、t_chip=0.5）：

```
head_z_touch_mm = −50.9339        （写回候选）
flip_surface_mm = −50.9339−0.5 = −51.4339
    vs 真值旋钮 flip_contact_z_mm=−51.43 → 差 3.9µm = 阈值压入量（§7.1）
contact_force_n ≈ 2.0（触发瞬间发布读数）
```

**落盘**：全程 ~500 行 CSV 全量；series 抽稀 step=ceil(500/400)=2
→ ~250 点（≤400 ✓）。

**回归实测**（`tests/test_metrology.py:5144-5174`，i49 段冒烟）：
Z*≈−50.936（断言 |Z*+50.93|≤0.05）、flip_surface=Z*−0.5 恒等、
series 点数 ≤400、CSV 落盘——与上手算同口径（差异=噪声实现）。

## 5. 键合头键合高度标定（bond_height_calib）

实现：`metrology/bond_height_calib.py`（`run_bond_height_calib`，
:57-161）；参数校验 `_validate_bond_height_calib`
（`runtime/calibration.py:1193-1210`）。

### 5.1 测的是什么

键合头压到**晶圆上 die** 的实际接触位 Z*，反推机器常数
`bond.head_z_contact_mm`——**裸接触位**口径：无晶圆无芯片、头吸盘
表面贴硅片台陶瓷面时的 BS_Arm_Z（`machine_constants.json:136-143`
组，键 :138；几何真值=陶瓷面顶 884.9−头吸盘底零位
1053.83=**−168.93**）。有效接触位=裸值+晶圆厚+芯片厚
（`engine.effective_bond_contact_mm`，`runtime/engine.py:129-133`，
flow 侧与 engine 真值力模型共用同一函数）。该值是键合 z 向一切
动作的基准：偏低 → die 压入过深伤片；偏高 → 键合力建立不起、
接触确认 FAIL。

measured 五键（`bond_height_calib.py:137-144`）：

```
z_contact_mm      = Z*（实测有效接触位，含晶圆+芯片厚度）
head_z_contact_mm = Z* − chip_thickness_mm − wafer_thickness_mm
                    （裸值，**写回键**）
contact_force_n / chip_thickness_mm / wafer_thickness_mm（只读回显）
```

### 5.2 算法推导（与 flip 项的差异）

同一慢速寻力范式（20ms 采样、rd≥阈值原地停轴、停稳取 Z*、
"寻力未接触"超程分支），差异：

| 环节 | flip_handoff_height | bond_height_calib |
|---|---|---|
| 走位 | 抬头→退对准台→FA_X 交接位→z_start（:94-98） | **只动 BS_Arm_Z**（:86-87）——AS/WS 靠测前手动就位（§5.4） |
| z_start | touch0+2.0（:75） | **bond.head_z_search_mm**（:64,:70，默认 −166.9，§5.3） |
| z_floor | touch0−2.0（:76） | 裸值+晶圆厚+芯片厚−1.0（:70-72，照 force_search 的 search_overtravel 语义；源码注释：再深撞 RxRy调整球座×多孔陶瓷面沙盒对，实测碰撞阈 ≈−171.6，:66-69） |
| 真值接触位 | flip_eff=flip_contact_z_mm+芯片厚 | eff_contact=裸值+晶圆厚+芯片厚（`engine.py:1378-1379` 缓存） |
| 收尾恢复 | 抬 head_z_safe + FA_X/AS 回原位（:146-156） | BS_Arm_Z 抬 0（:124-128） |
| CSV | 5 列带两路负压 | 3 列 `t_s,z_mm,force_n`（:129-130） |
| measured | Z* 直接是写回键 | 写回键=裸值=Z*−两厚度（:137,:140） |

时序主体（:86-123）：BS_Arm_Z→z_start → move(z_floor,
search_speed_mm_s) → 20ms 循环读 oActualForce（:95）→ rd≥阈值停轴
（:103-108）→ 停稳 10s（:115-121）→ Z*=停稳位（:122-123）→
finally 抬 0（:124-128）。

### 5.3 与 head_z_search_mm / contact_verify / 处方厚度的关系

- **bond.head_z_search_mm**（`machine_constants.json:139`）：bond
  流程两段速下压的**快慢切换高度**（慢速寻力段起点，裸值，默认=
  裸接触位+2.0mm 安全余量；流程按处方厚度同样换算后使用，
  `runtime/process_flows.py:1360-1362, 1291-1295`）。本 routine
  直接以它为慢降起点（z_start）——同源同口径。**注意：apply 只
  写回 head_z_contact_mm，不联动 head_z_search_mm**——裸值改动
  较大时须手工复核该键（保持 ≈新裸值+2.0mm），否则流程快速段
  终点偏深/偏浅。
- **contact_verify（接触确认）**：bond 流程 force_search 停轴后
  双源判定（`runtime/flow_engine.py:1023-1063`）——源一（轴链）：
  实际接触位 vs 期望有效接触位（裸值+两厚度），
  |dev|≤`bond.contact_verify_tol_um`（默认 50µm，
  `machine_constants.json:140`）；源二（几何真值）：confocal 独立
  核算 geom_gap_um 兜底。证据落 eng.bond_contact_evidence → 结果
  分析留证（`runtime/bond_results.py:171-182`）。**本 routine 是
  源一的上游标定**：写回正确裸值后"期望=真值"，dev≈0；流程若
  FAIL "接触位异常（厚度/机械常数不符）"，先重跑本 routine 再查
  处方厚度。
- **处方厚度**：engine 真值与流程换算都吃 recipe
  （wafer.thickness_mm=1.0 `recipe.json:5`、

## 6. 力-位移曲线判读（两个 GUI 页共用）

两个 PyQt5 页的结果区都是 matplotlib 力-位移曲线（x=z_mm，
y=force_n）+ 接触点红点标注 + 统计表 + 写回按钮

   [−0.95, 1.05]）→ 接触后近似线性上升（斜率≈k·(1+gain_err)
   ≈501.5N/mm；采样密度 4µm/点 → 图上力每点跳 ~2N）→ 阈值 2.0N

2. **全程零力到 z_floor**：报"寻力未接触"——查工件是否在位

3. **起点即超阈 / 曲线从高点起步**：z_start 已在接触面下方——
   常数（head_z_touch_mm / head_z_search_mm）或厚度参数错误。
4. **上升段斜率异常**：偏离 ~500N/mm 量级 → 力传感链问题——跑

5. **噪声带顶到阈值线**：误触发风险——默认 2.0N 对 [−0.95,1.05]

6. **flip 页真空列**（chuck_vac_kpa/chip_vac_kpa，CSV 第 4/5 列）：

## 7. 误差来源与注意事项

1. **阈值压入量（系统性）**：Z* 是"发布力首次 ≥阈值"的轴位，不是
   几何接触面——标称偏差 press*=(F_thr−offset)/((1+gain_err)·k)
   ≈3.9µm（默认链）。阈值越小越接近几何面，但受 §6.5 误触约束。
   该偏差对交接/键合是**同一口径**的（流程 force_search 同样以力
   阈值判接触），故写回后系统内自洽。
2. **采样量化与噪声散布**：4µm/点 × 力斜率 2N/点，±1N 噪声 →
   触发点逐次在相邻 1~2 采样间摆动，Z* 散布 µm 级。routine 无
   repeat 统计（单次测量）——要重复性数字就连跑几次看 measured
   散布。
3. **读数链补偿状态**：sensor_calib 默认不补偿（gain=1/offset=0），
   Z* 含 gain_err/offset 影响；bond_force_calib 写回后读数链被
   修正（噪声不可补偿），重跑本两项 Z* 会更贴近真值几何面。
4. **厚度参数与处方一致性**：routine 厚度参数只进 measured 换算
   与 z_floor（bond）；engine 真值侧用处方厚度。两者不一致 →
   裸值换算错位 + 超程窗余量错误，且不报任何错——默认值即处方
   默认（0.5/1.0），改处方厚度后测校参数要同步。
5. **flip 支路门控**：真值力要求 |FA_X−fa_x_handoff_mm|≤1.0 且
   flip 有 die 且 pos<flip_eff+2（`engine.py:2229-2237`）——
   routine 走位保证前两条（engine 读同一常数，1s 缓存重读）；若
   交接位常数 fa_x_handoff_mm 改了，门控同步跟随，无需额外处理。
6. **超程窗语义**：flip z_floor=名义接触位−2mm、bond=期望有效
   接触位−1mm（照 search_overtravel；再深撞沙盒对，实测碰撞阈
   ≈−171.6，`bond_height_calib.py:66-69`）。窗随**现认知常数**
   走——常数漂得太多时窗也错，触不到力报"寻力未接触"是保护性
   结果。
7. **cancel/恢复语义**：cancel 只置标志，下一 20ms 采样检查点抛
   CalibCanceled，终态 canceled；finally 一定恢复（flip：抬
   head_z_safe + FA_X/AS_X/AS_Y 回作业前位；bond：抬 0）。
8. **待真机标定**：tuning flip_contact_z_mm=−51.43、flip_handoff
   组与 bond 组各几何推导值均为仿真合成/前端模型几何——真机上
   以本两 routine 实测写回为准。
9. **热/模态**：接触沿触发模态接触脉冲（`engine.py:2240-2247`，
   模态 ON 时）；低速寻力（0.2mm/s）下对 Z* 的影响未建模，真机
   如有热漂需求应在工艺温度稳定后测。
