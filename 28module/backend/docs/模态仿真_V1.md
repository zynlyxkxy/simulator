## 1. 模型与公式

### 1.1 模态本体（两层）

- **每轴 SISO 模态**（21 轴 × `{fn_hz, zeta, enable, input_gain
  [,thermal, contact]}`）：该轴执行器/传动链的二阶共振模态
  `ẍ + 2ζωẋ + ω²x = −a(t)`（ω=2πfn），位移分量 q 加进该轴读数
  （`error_system.actual`，error_system.py:151）→ 到位判据/整定尾巴自然
  变长、读数抖动真实化（UPH 影响真实化）。
- **全机 MIMO 模态**（默认 9 个 `{fn_hz, zeta, enable,
  inputs{轴:增益}, outputs{模块:6DOF 投影}[,thermal, contact]}`）：多轴
  加速度共同激励同一结构模态（"硅片台快跑摇门架、键合臂下压激头/台
  共振"），模态位移 q 按观测矩阵 C 投影到模块 6DOF 位姿
  （`error_kinematics.compute` 读取时叠加，error_kinematics.py:382-390，
  零 tick 开销）→ 相机拍照标记位置抖动（FAST/REAL 同吃）、toolpoints
  抖动、键合 truth 自动带振动分量（走迭代 20 管线，零改动）。
  outputs 模块名与 `error_kinematics.json` 对齐（wafer_stage /
  align_stage / bond_head / flip / film_stage），6 分量 =
  [dx,dy,dz (mm/mm), drx,dry,drz (rad/mm)]。

### 1.2 解算：解析传播（精确离散二阶更新）

每 tick（1kHz）对每模态按"激励 f 在 dt 内常值保持"求精确离散解
（任意步长稳定，与参考项目同公式；modal.py `_step`）：

```
xss = −f/ω²                          （静平衡位）
x0 = q − xss,  v0 = qd
q1  = e·(x0·c + (v0+ζω·x0)/wd·s)
qd1 = e·(v0·c − (ζω·v0+ω²·x0)/wd·s)
其中 wd=ω√(1−ζ²)，e=exp(−ζω·dt)，c=cos(wd·dt)，s=sin(wd·dt)
```

三角/指数因子按 (fn 量化 0.01Hz, ζ) 缓存（热软化漂移下防缓存无限增长），
稳态每模态每 tick 仅数次乘加；空闲（无激励且 |q|,|qd| 低于阈值）自动
归零省算力。

### 1.3 激励三件套

| # | 激励 | 公式/口径 | 说明 |
|---|---|---|---|
| ① | 轴加速度基础激励 | 每 tick 由 `ax.vel` 差分，限幅 ±2×amax（执行器限幅，同参考项目）；SISO 经 `input_gain`、MIMO 经 inputs 矩阵叠加 | 运动激发模态的主通道 |
| ② | 连续地板振动随机力 | 每使能 MIMO 模态白噪声力：`σ_F=√(4ζω³·Var_t/dt)`，反解自输出 RMS 口径 `Var_t=(RMS_level×1e−3)²/N_modes_on`（mm²）——各使能模态 q 的 RSS≈等级值 | **工程近似，非真 1/3 倍频程 VC 谱**；等级：off / clean 0.1µm / typical 0.3µm（默认）/ poor 1.0µm / custom ∈(0,100]µm |
| ③ | 键合接触脉冲 | engine 力模型接触沿 → 带 `contact:true` 的模态/轴注入速度冲量 `qd += impulse_mm_s`（∈[0,50]mm/s，默认 0.2） | 默认目标：BS_Arm_Z 轴、head_z_bounce、wafer_stage_rock |

### 1.4 热软化耦合（小）

带 `thermal:"head"/"wafer"` 标记的模态：

```
fn_eff = clamp(fn·(1 − coeff·ΔT), 0.55·fn, 1.15·fn)
ΔT = 对应加热器当前温度 − 22℃（head→PulseHeat_Up，wafer→Heat_Dw）
coeff 默认 0.0012/℃（∈(0,0.01]）
```

用已有两路加热器温度做耦合，本层不做热解算。fn_eff 进 `_trig_factors`
（量化缓存）与 `/api/modal/state` 的 fn_hz 显示。
**2026-09-09 迭代 23 起 ΔT 源可切换**：热仿真（thermal.py，见
《热仿真_V1.md》）ON 时改读热网络节点温度（head→bond_head、
wafer→wafer_chuck，同 REF 22℃ 口径；未映射回退 None→heater.cur 口径），
OFF 时回退 heater.cur——i23b.modal_fn_eff_source 进程内断言三态。

### 1.5 曝光积分（视觉，超越参考项目点）

拍照时按曝光窗内**标记模块相对相机安装模块**的横向（X/Y）模态位移
（`modal.exposure_vib`，vision_service.py:1084）：同一模态对标记/相机
两模块的投影是相干项（相对位移 = q×(out_mark−out_cam)），模态间按
RSS 合成 → (σ_mm, 主导方向 rad)。

- **FAST**：等效质心噪声按平方和并入（vision_service.py:1135-1140）：
  `σ_eff = √(σ_noise² + (vib_pp/(2√2·k_px))²)`，其中
  `vib_pp = 2√2·σ_vib`（正弦峰峰值↔RMS），`k_px` = 相机像元当量
  （machine_constants 派生）。
- **REAL**：按 vib_pp 生成线型运动模糊核 cv2 滤波（`_motion_blur`，
  vision_service.py:111）：核长 = round(vib_pp_px) 取整（<2px 无感不
  处理，限幅 21px 防极端参数拖垮渲染线程），方向 = 主导模态投影方向。

## 7. 实测数字（迭代 22 回归/验证，2026-09-08）

- 地板 typical：9 使能 MIMO 模态 RSS **0.277µm**（目标 0.3µm 工程近似
  口径，i22.modal_floor_rms 区间断言 0.1~0.9）；toolpoints wafer_stage
  误差相对 OFF 基线实测偏移 Δmax=127.8nm（断言 >30nm）。
- 运动激发：WS_LS_X 5mm@600mm/s 行程 → scope 峰值 **1.407µm** vs 缓冲
  尾段底噪 **0.0175µm**（≈80×）；整定尾巴 **0.144s**（|q|>0.2µm 持续，
  OFF 对照零记录）。
- 接触脉冲：BS_Arm_Z 跨越接触沿 → head_z_bounce 峰值 **0.531µm** vs
  等幅非接触行程对照 **0.154µm**（3.4×）。
- 曝光积分（FAST 同机位连拍散布）：OFF **0.148px** → ON+地板较差
  **1.096px**（7.4×，i22.modal_exposure_fast 宽松断言 >2×）。
- 性能红线：modal ON 干净窗 tick=1000.0Hz / push=499.9Hz（≥999 不破）；
  quick 348/348 全绿（墙钟 182.9s）。

## 8. 实机化路线

1. **FRF 辨识替换 B/C 与 fn/ζ**：锤击法/执行器脉冲激励实测频响 → 峰值
   拟合 fn/ζ、相干分析定耦合方向 → 替换 modal.json 默认值（当前全部
   工程估值）。
2. **真 VC 谱实测**：加速度计测安装地基 1/3 倍频程谱 → 按 VC 曲线
   （VC-A~VC-G）替换"输出 RMS 等级"工程近似（滤波器形状化激励谱）。
3. **伺服环 FRF/陷波器/输入整形**：当前伺服环是一阶滞后近似（迭代 3
   口径），模态层与环解耦；真机环模型到位后可研究环-结构耦合（参考
   项目同样未做）。
4. **热仿真本体**：✅ 已落地（2026-09-09 迭代 23，`runtime/thermal.py`
   LPTN 21 节点真网络+热变形 6DOF 贯通，见《热仿真_V1.md》）；热软化
   ΔT 源已切换为热模型输出（thermal ON 时，见 §1.4）。本层 coeff 真机
   标定仍可研究改由热模型标定链统一驱动。
