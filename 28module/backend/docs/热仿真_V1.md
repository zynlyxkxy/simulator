## 1. 模型与方程

### 1.1 LPTN 网络方程

168 个前端模型组件归并为 **21 个集总热节点**（20 个 groups 登记根 +
1 个 electronics 虚拟节点），节点间三类耦合构成真热网络——不是每节点
独立手拍 τ（与参考项目的关键区别，见 §6）：

```
C_i·dT_i/dt = P_i                            （注入功率：加热器/电机/电子件）
            + Σ_j G_ij·(T_j − T_i)           （邻接导热：20 条 links）
            + Σ_k G_rad,k·(T_k − T_i)        （辐射链：rad_links，迭代 55）
            + h·A_i·(T_env − T_i)            （自然对流边界）
            + G_a·(T_h − T_i)                （加热器大电导锚定，仅锚定节点）
G_ij = kc·λ_eff·A/L，λ_eff = 2λ_aλ_b/(λ_a+λ_b)（调和平均，串联热阻语义）
G_rad = ε_eff·σ·A·F(t)·(T_a²+T_b²)(T_a+T_b)（线性化辐射电导，见 §3A）
```

- **邻接导热**：kc=接触系数（(0,1]，工程估值：花岗岩链接 0.5、其余 0.3）；
  λ_eff 为两节点质量加权导热率的调和平均；A/L 由节点包围尺寸派生
  （links 可带 `l_mm`/`a_mm2` 覆盖）。
- **对流**：全节点统一 h（(0,100] W/m²K，默认 5=室内自然对流量级），
  节点表面积 A=包围盒六面×`area_factor`（默认 0.7 折算），electronics
  虚拟节点面积直给。
- **锚定**：加热器节点以 `anchor_w_per_k` 大电导挂到 heater.cur（温控环
  零改动——热网络只是"看"温控结果，不与功率注入双重计算：冷却方向由
  锚定回流实现，功率注入只算加热方向）。

### 1.2 解算：半隐式 Euler（无条件稳定）

每热 tick 对每节点：**自耦合（对流+锚定+邻出）后向、邻接/边界温度前向**：

```
T_i ← (C_i/dt·T_i + P_i + ΣG·T_neighbor + h·A·T_env + G_a·T_h)
      / (C_i/dt + ΣG + h·A + G_a)
```

对角项全在分母 → 任意步长稳定（无条件），无需小步长；dt 自适应
`min(0.5s, max(0.05s, 0.25×dt_stable_explicit))`，当前参数下
dt_stable_explicit=3.246s（最紧节点=wafer_chuck 锚定 2000W/K），
取 **dt=0.5s（div=500，2Hz）**。邻居温度用上一拍值（前向），网络
 hopping 一个 tick 一节点——0.5s 步对 τ≥3s 的网络无感。

### 1.3 与物理主循环的关系

- 分频调用：1kHz 主循环 `_tick_i % div == 0` 时解算一次；OFF 时 engine
  侧早退零开销（同 modal 先例）。
- 温度历史环形缓冲：每节点 3600 样本×0.5s = **30min 窗**
  （`/api/thermal/curve`）。
- 变形注入**读取时合成**（`error_kinematics.compute`/`axis_scale_ppm`），
  不进 tick 路径——热变形贯通零 tick 开销（modal MIMO 投影同先例）。

## 3A. 辐射链（rad_links，位置相关视角系数，2026-09-21 迭代 55）

**动机**：固定邻接链只表达结构传导——迭代 54c 严格双分支实验证明
（`Temp/_thermal_head_camera.py`），300℃ 键合头压到对准相机上方 vs 抬起，
全部 21 节点 ΔT 逐位相等（影响精确为 0）。真机同场景辐射换热
~0.7~2.7W（Stefan-Boltzmann 估算），相机支架温升数 ℃、光轴漂移
µm~十 µm 级——必须建第三类耦合。

**模型**（每热 tick 线性化，显式滞后一拍，2Hz 下非线性温和）：

```
P_a→b = ε_eff·σ·A·F(t)·(T_a⁴ − T_b⁴) = G_rad(t)·(T_a − T_b)    [T 用 K]
G_rad(t) = ε_eff·σ·A·F(t)·(T_a² + T_b²)·(T_a + T_b)
ε_eff = 1/(1/ε_a + 1/ε_b − 1)                    （两表面换热有效发射率）
```

**视角系数**（工程近似，圆盘对圆盘推广，单调有界）：

```
gap(t)   = max(gap_min, gap0 + dir·(pos − pos_ref))    [gap_axis 可空=恒定 gap0]
lateral² = Σ (pos_i − ref_i)²                          [lat_axes 0~4 轴]
F(t)     = f_max · r_eff² / (gap² + lateral² + r_eff²)   ∈ [0, f_max]
```

**默认 4 链**（`thermal.py DEFAULT_RAD_LINKS`；热源只有 bond_head/
wafer_chuck 两个，近环境节点互辐射 T⁴ 太小不入表，可自行添加）：

| a → b | 场景 | gap 来源 | lateral 来源 | A_eff | r_eff | f_max |
|---|---|---|---|---|---|---|
| bond_head → align_optics | 头→上（对准）相机 | BS_Arm_Z @−119.83（上焦面）dir=+1 gap0=10mm | AS_X@0 / AS_Y@6 | 2000mm² | 25mm | 0.4 |
| wafer_chuck → align_optics | 热吸盘→下（对准）相机 | 恒定 13mm | WS_LS_X@−42.394 / WS_LS_Y@7 | 2000mm² | 60mm | 0.4 |
| bond_head → wafer_chuck | 键合接近/接触→晶圆与 die | BS_Arm_Z @−168.93（接触）dir=+1 gap0=0.5mm | WS_LS_X/Y 同上 | 2000mm² | 25mm | 0.5 |
| bond_head → die_chuck | 交接位→flip 芯片吸盘 | BS_Arm_Z @−51.43 dir=+1 gap0=1mm | FA_X@−1242.35 | 800mm² | 15mm | 0.4 |

ε 默认 ε_a=0.8（加热金属面）/ε_b=0.9（陶瓷涂层支架）。间隙/横向参考位
按整机零位几何实测（迭代 55 探针：头在上焦面位距上相机 10mm、下相机
距吸盘 13mm、EGA 位轴坐标）。**实测量级**（迭代 55 实验，头 300℃
上焦面位）：辐射流 ≈2~3W → align_optics 2h 内 +2.0℃（仍在爬升）、
对准台光轴 X 漂移 +4.6µm（抬起位仅 +0.9µm）；头 → 晶圆/die 键合期
辐射同量级（工艺热预算相关）。

**实现要点**：rad 电导上限（T=400℃、F=f_max）计入 g_tot 稳定 dt 余量
（实测 ≈0.04W/K ≪ 现有电导，dt/div 不变）；流量计入节点能量收支与
守恒残差；deform 消费链零改动（align_optics_drift 等现有映射自动
获得辐射温升）。校验：a/b 节点存在且不等、eps/f_max ∈(0,1]、
area/r_eff/gap 区间、gap_axis.dir=±1、轴名存在，逐条 400。

## 4. 热变形映射（deform_map，5 条）

节点温度 → 模块 6DOF 位姿叠加 / 轴读数 scale，**读取时合成零 tick 开销**；
注入 `error_kinematics.compute`（模块）与 `axis_scale_ppm`（轴 scale 项）
→ 工具点误差/视觉真值/键合 truth 全线贯通，走迭代 20 管线零改动。

```
膨胀：ΔL = CTE·ΔT_mean·L·expand_dir            （nodes 均值 ΔT×有效 CTE）
弯曲：θ  = CTE·ΔT_pair·bend_len/bend_h         （pair 两节点温差→梯度弯曲，
      绕 bend_axis 旋转 + θ×bend_lever 沿 bend_trans_dir 平移）
scale：axis 读数 scale_ppm += Σ g_axis·CTE_eff·ΔT_mean（节点热源致轴行程膨胀）
```

|---|---|---|---|
| granite_pair | granite_low+granite_up 均值 / pair 温差 | wafer_stage 模块：膨胀 (0.5,0.5,0)×300mm + 绕 x 弯曲（L=1000/h=285mm，杠杆 300mm→z）+ WS_LS_X/Y scale | 双层花岗岩上热下冷→门架弯腰 |

### 4.1 面高/接触位热联动（迭代 56）

deform_map 的 Z 分量经三条链路到达测量/工艺真值（**热 OFF 逐位零变化**）：

- **共焦面高**（`confocal.py::_thermal_dz`）：`wafer_surface_z`/
  `die_surface_z`/`collet_surface_z` 叠加对应模块热变形 Z 分量
  （wafer_stage/bond_head）——吸盘热态下共焦测高随温度爬升
  （110℃ ≈+50µm，真机"键合高度须在工艺温度标定"的物理来源）；
  300℃ 头使上共焦对裸吸盘面下移 ~1mm 失焦（超量程=None，物理正确）。
- **键合/交接接触位**（`engine._refresh_loop_consts_locked`）：
  `eff_contact_mm = base + dz_chuck − dz_head`（接触条件
  head_tool_z+dz_h = chuck_top+t_w+t_d+dz_c 的解析解）；flip 交接支路
  同加 `−dz_head`。真机"键合接触点随温度漂移"的复现：头 300℃+吸盘
  110℃ 时接触提前 ~1.07mm（头伸长主导）。
- **视觉离焦**（既有模块位姿链零改动）：晶圆标记 z 本就走
  wafer_stage 模块位姿（vision_model.py:794）——chuck_z_growth 入网后
  下相机对晶圆面随温度热离焦（blur≈Δz/DOF，110℃ ≈2.5）；上相机侧
  头热失焦自迭代 23 起已在（drift watch 实测需重聚焦）。

## 5. 调研依据（方案选型）

- **LPTN vs FEA 取舍**：集总参数热网络（LPTN）与 FEA/CFD 是热分析三
  路线（[ETS 综述](https://espace.etsmtl.ca/id/eprint/2232/1/DANG_Dinh_Dong.pdf)）；
  FEA 看似更准，但**对流系数/接触热阻的不确定性两家相同**
  （[The Industrial Electronics Handbook](https://lib.zu.edu.pk/ebookdata/Engineering/Electrical%20Engineering/Power%20Electronics%20and%20Motor%20Drives%20..Richard%20C.%20Dorf.pdf)），
  而 LPTN 参数可直接由阶跃实验辨识、实时性零成本——仿真侧选型 LPTN
  （21 节点），FEA 留给设计侧离线校核（调研结论 ATE 2025 口径）。
- **热误差权重**：机床总误差中热误差占 **40–70%**
  （[Sci. Rep. 2025](https://www.nature.com/articles/s41598-025-98143-4)、
  [SPIE 2026](https://www.spiedigitallibrary.org/conference-proceedings-of-spie/13732/1373202/The-prospective-prediction-of-thermal-error-of-NC-machine-tools/10.1117/12.3072322.full)）——
  精密设备仿真的头号缺失项，本迭代补齐。
- **环境温控带**：ASHRAE 光刻区 ±0.06~0.3K（调研结论）；公开佐证：
  光刻 bay 典型 22±0.1℃、一般 fab 23±0.5℃
  （[TROX 微电子 HVAC](https://cdn.trox.de/5b8abaeb6f86ad66/0d8f613d50a1/TROX-HVAC-Systems-for-Microelectronics-Industry.pdf)）——
  波动档 fine/typical/coarse=±0.05/0.1/0.5℃ 按此标定。
- **mK 级灵敏度**：300mm 硅片每 0.001℃ 胀 ~2.6nm
  （[Praecis Lithography](https://www.praecis.com/lithography)：5nm
  节点 overlay 预算 2~3nm）——热链路 nm 级贯通是本仿真的核心价值；
  曝光周期内 wafer/table 温变可达 1℃ 量级需主动控制
  （[PMC 2025 光刻热控综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC12388758/)）。

## 10. 实机标定路线

1. **温度测量**：SensArray 类测温晶圆（wafer 面多点）+ 关键点热电偶
  （臂梁/门架/对准台），采集冷态→工艺热态全程曲线。
2. **阶跃辨识**：单加热器阶跃（PulseHeat_Up/Heat_Dw 分别），各节点
  t63/稳态 ΔT → 逐节点辨识 C（斜率）与 R 链路（稳态比）；环境波动档
  按实测 HVAC 功率谱归到 fine/typical/coarse。
3. **变形标定**：热态下复测 EGA map/精对准残差漂移 → 标定 deform_map
  的 expand_len/bend_len/bend_h/杠杆（当前=几何工程估值）。
4. **电机损耗**：各轴组电流/功率计实测典型占空比 → P_fl 与活动度
  权重（0.65/0.35）标定。
5. **辐射链（迭代 55）**：热像仪/热电偶测热源邻近节点的温升-位置曲线
  （如头 300℃ 扫 BS_Arm_Z 记录相机支架 ΔT(gap)）→ 逐链标定 ε_eff、
  area、f_max、r_eff 与 gap/lateral 参考位；真机表面发射率差异大
  （抛光金属 0.05~0.2 vs 氧化/涂层 0.8+），ε 优先实测。
6. 标定后参数走 PUT /api/thermal 落盘即生效（接口已备）。

## 11. 已知边界

- 全部 CTE/kc/额定 W/h/P_fl 为**工程估值**（手册典型+几何估算），
  未标定；数值只做趋势/量级真实，不做 °C 级精度承诺。
- 组件材料兜底 ss_304（未指派材质时）；节点τ 跨 4 数量级，慢结构
  （花岗岩/铸铁/蓝膜台 τ≈5~18h）在任何可演示时长内不达稳态——能量
  守恒残差读数的长尾即此（物理正确，非缺陷）。
- 辐射链（迭代 55 起）：视角系数为**工程近似**（圆盘推广式，非精确角
  系数），ε/A/f_max/r_eff 全为估值，数值只保证量级与位置单调性正确；
  热 shimmer（热气流扰动成像）与热目标红外辉光进图像=视觉层效应，
  未建模（需要时单独立项）。强迫对流（气浮/风扇）未分速建模。
- deform_map 的膨胀/弯曲特征长度是几何估值，待 §10.3 标定替换。
- 面高/接触位热联动（迭代 56 §4.1）只叠加**热变形增量**——共焦面高的
  静态误差链差异仍由既有测校链覆盖（历史口径保持）；节点内温度梯度/
  局部热斑（辐射打到吸盘表面是局部加热）与 RX/RY 热倾斜不建模（LPTN
  节点均温固有边界，热斑→晶圆局部翘曲属下一代特性）；die_chuck 温升
  仍无下游 deform 消费（flip 交接高度热漂移未建模，需要时照搬
  chuck_z_growth 模式）。
