# 轴号对照表 V1（21 轴）

> 用途：上位机同事轴号未整理完，先借下位机点位表 + 仿真权威配置出一版对照表，供双方对账。
> 编制日期：2026-08-20。同内容 CSV 见 `轴号对照表_V1.csv`（UTF-8 带 BOM，Excel 直开）。

## 表头说明

- **模块**：点位表分系统划分（WS 硅片台 / BS 键合 / AS 对准 / CH 芯片传输·翻转 FA / ES 蓝膜台）。
- **轴名**：仿真轴名（`axes_config.py` 权威）；点位表 ACS 侧名称不一致的在"点位表路径"列注明。
- **ACS轴号**：ACS 控制器物理轴号。WS_LS 三轴 0/2/4 为同事确认真值（双驱龙门占偶数轴号对 0+1/2+3/4+5）；AS/FA_X/ES_PunchZ 的 6/7/8/9/10 由点位表"轴名定义"表与 motion config3/config4 双重佐证，上位机侧待对账；PLC 轴不过 ACS 标"—"；AS_Rx/AS_Ry 点位表未列轴号，标"待整理"。
- **类型/单位**：全线统一 直线 mm、旋转 rad（速度 mm/s、rad/s）；TwinDOM 前端内部为 deg，rad↔deg 换算只发生在 `html_model/联机注入.js` 边界。
- **行程/默认速度**：以 `axes_config.py` 现行值为准（其口径对齐前端 JSON 2026-08 版）；与其他资料冲突的数值写入"依据来源"列备注，状态标"待确认"。
- **回零类型**：CiA402 方式号（17=负向找负限位、18=正向找正限位），括号内为仿真回零类型分派（`axes_config.py home_type()`）：gantry_dual 双驱龙门 / plc_sync_trio 顶针三轴同步 / zero_sensor 零位传感器 / vendor_es 外包模块。
- **回零buffer**：真机回零 = 控制器 buffer 程序号。18 为同事确认（WS_LS）+ config 实证（AS/FA_X），17 为 config3 实证（ES_PunchZ）；PLC 轴无 ACS buffer 标"—"。注意：仿真内 `engine.BUFFERS` 1~3 是自定义动作序列，与真机 buffer 号无对应。
- **前端轴id**：TwinDOM 工程稳定标识，WS 二进制帧按此顺序（《前后端数据协议_V1.md》§3 idx 0~20）。
- **点位表路径**：点位表 Cordis 路径（PLC 轴）或 ACS 侧轴名（ACS 轴，ACS 走轴号不走路径）；无对应者标"—"。
