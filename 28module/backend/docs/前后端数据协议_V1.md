# 前后端数据协议 V1（实时轴位置流）

> 配合《接口规范_V1.md》§6。本文档只定义**仿真运行时 ↔ 3D前端**的实时通道。
> 实时性目标：物理 1kHz tick；WS 推送 ≥500Hz；本机单向延迟 p50 < 1ms。

## 1. 通道

- WebSocket：`ws://127.0.0.1:9010/ws`，服务端→客户端二进制帧推送轴位置；客户端→服务端文本 JSON 下发指令。
- HTTP 调试口（同一端口）：`GET /api/axes`（JSON 快照，含轴 id 字典；顶层 `t` 与 `sim_time` 同值，均为仿真时钟秒）、`GET /api/io`（PLC 点位快照，读输出映像，写入最长晚一个扫描周期可见，默认 4ms）、`GET /api/health`（含 `plc_scan_ms`）。
- `/api/axes` 每轴在原有字段外新增（2026-08-19，伺服环动态）：`pe`（跟随误差 = value − x_actual，原生单位）、`x_actual`（伺服实际位置，一阶滞后跟随 value）、`state`（`idle/moving/settling`；`settled` 字段语义随之收紧为 `state=="idle"`，settling 整定期不算到位）；`actual` 改为基于 `x_actual` 叠加误差（errormap 仍按 value 查表）。`POST /api/axis/config` 新增可写字段 `tau / settle_window / settle_time`（正数，秒/原生单位，持久化）。
- PLC 扫描周期配置：`POST /api/plc/scan {"ms": 1~50}`（整数校验，非法 400），持久化于 config_overrides.json 顶层 `plc_scan_ms`。
- **注意：WS 108B 二进制帧格式不变**（values 仍为名义值 value；pe/x_actual 只走 `/api/axes` HTTP 快照，不进帧）。
- 可视化聚合口：`GET /api/viz`（轴位 + 工件 + 气路一帧聚合）。其中 `vacuum` 保持 **bool 字典**（联机注入.js 按 `!!值` 消费，勿改结构）；真空密封细节走新增的 `vacuum_detail` 字典：`{回路名: {on, pressure, flow, sealed, grip_ok}}`，仅真空吸附类回路有条目。密封物理：有工件盖住吸盘=密封（目标 -80kPa / 0.5 L/min），无片=泄漏（目标 -30kPa / 10 L/min）；`grip_ok = 负压开 && sealed && pressure < -60kPa`，交接规则/面板"有无片判断"以此为据。工件区另带 `film:{present}`（蓝膜是否在位，2026-08-21 蓝膜工件层）。
- **独立搜力 IO（迭代 78 模型扩展点）**：`POST /api/io/command {"path":"SystemMachine.SS_Bonding.M_BS","cmd":"ForceSearch","args":{...}}` 启动 PLC 组合动作，返回 `accepted`、实际参数与初始 Busy；与 9102 同名命令一致。参数默认 `Force=2N / Speed=0.2mm/s / Steady_Time=0.5s / Tolerance_N=1N / Max_Distance=5mm / Timeout=120s`。从当前 BS_Arm_Z 下行，到力立即停轴，以 50ms 滑动平均力稳定确认后锁存 `oForceSearchDone=true`；`oForceSearchBusy/Done/Fail/Pos` 经 `/api/io` 或 PLC `/io/observe` 读取，点位输出映像最多晚一个 PLC 扫描周期。StopForceSearch、全部停止或外部 BS_Arm_Z 运动可中止；未接触、超时、急停和轴故障不置 Done。full_reset 同时停止并清空状态。独立搜力不启动力 PID、不转移动料、不生成键合结果；与完整 bond 的 `force_search` op 不同。
- 工件物料：`POST /api/workpiece/wafer`（晶圆上/下片）、`POST /api/workpiece/film` `{"action":"load"|"unload"}`（2026-08-21 起蓝膜为正式工件：load 幂等按当前处方重铺 film die 阵列；unload 级联移除 film 上 die，响应带 removed_dies；蓝膜不在位时 unload 400；reset/recipe apply 复位在位；film 不在位 → 含 film 侧的交接规则不触发、coarse 相机无膜面无标记）。
- 相机拍照记录：`GET /api/camera/captures?limit=N`（默认 50，环形缓冲上限 100 条）。PLC 侧 `M_AS.{AlignCameraTigger_1/2, AS_CameraOn}` 收到 SetBool true / Pulse 即产生一条 `{id, t, source, axes:{21轴快照}}`。
- **故障注入（W2，2026-08-19）**：`POST /api/fault` 两种形态——
  - 轴使能：`{"action":"disable"|"enable"|"reset_error","axis":"WS_LS_X"}`（axis 支持别名如 E_EPIN_Z 整组）。`disable`：静止仅去使能；运动中自由减速（3×amax 合成减速度）到静止后进 `fault`。`enable`：复使能并清 fault。`reset_error`：仅清 fault（真机语义：复位后再 Enable）。
  - 目标级：`{"action":"silent"|"drop","target":"acs"|"plc"|"mcs","on":true|false}`；`{"action":"restore","target":...}` = 解除该目标沉默+断线。`silent`：目标"收到不回不执行"（9102/9190 请求挂起、9101 不回帧、引擎吞动作指令）；`drop`：关 listen socket 拒连（ECONNREFUSED）+ 断已有连接。
  - 参数非法一律 400。`GET /api/fault` 返回 `{ok, silent[], dropped[], fault_axes[], axes:{名:{enabled,fault}}}` 全量快照；`/api/health` 新增 `faults` 字段（`{silent[], dropped[], fault_axes[]}`）；`/api/axes` 每轴新增 `fault`（bool）。enabled/fault 为运行时状态，不持久化，重启复位。

- **一键复位（彻底）：`POST /api/full_reset`（2026-09-04 迭代 13）**——区别于 `/api/reset`（只清 estop/fault）。依次：单片链/全片链 request_stop → 流程在跑（running/paused/stopping）先 stop 等停 → flow/chain/full_wafer 状态清零（ChainRunner/FullWaferRunner 新增 `reset()`）→ `eng.reset()`（原语义）+ `workpieces.reset()` → `eng.ega_result/fl_fit/fine_align_result/coarse_offset/level_memory/bond_touch_pos/bond_contact_evidence` 等测量结果清零 → 视觉识别结果环形缓冲清空（vision_service `clear_results()`）→ 倍速回 ×1 → 温控压控回环境态（`eng.reset_thermal_force()`：三回路 PID 复位、加热器全关、温度回 25℃、力输出 0）→ **键合结果历史清空**（bond_results `clear()`，2026-09-09 迭代 23 起，与 `/api/workpiece/reset` 对齐——此前刻意保留，"测量结果已清但结果分析页还在"自相矛盾）。**不动**：recipe/machine_constants/tuning 持久化文件。面板工具栏"一键重置"按钮（btnFullReset）改调本接口后刷新页面。另：`POST /api/bond/clear`（迭代 23）单独清空键合结果历史（记录+产率统计），物料/流程不动——结果分析页"清空记录"按钮用。
- **机械常数 bond 组新增 `contact_verify_tol_um`**（默认 50.0，迭代 13）：force_search 触力停轴后核对 |实际接触位 − 期望有效接触位| ≤ 本值，超差 FAIL"接触位异常（轴链：厚度/机械常数不符）"；迭代 17 起双源判定——另用 confocal 几何真值在键合 site 处核算 `geom_gap_um`（die 底面−晶圆面），超同一容差 FAIL"接触面间隙异常（几何真值）"；证据（actual_contact_z/eff_contact/偏差µm/geom_gap_um/触力N）写流程日志并进 bond_results `chain.bond` 段 `contact_verify`（详见《热压键合与温控压控_V1.md》§1）。

- **工艺流程编排（W4，2026-08-19）**：`GET /api/flows`（流程定义全量 + 当前
  state/current）、`GET /api/flow/state`（运行态：`{ok, state, flow,
  current_step, steps:[{i,op,desc,status,dur_ms,info}], log:[{t,level,msg}],
  elapsed_s}`，state ∈ idle/running/paused/done/aborted）、
  `POST /api/flow/run {"name","paused"?}` / `pause` / `resume` / `step` /
  `stop` / `reset`、`POST /api/flows/restore_example`、
  `PUT /api/flows {"flows":[...]}`（schema 校验，非法 400 且 `errors[]` 逐条
  定位）。状态冲突（运行中再 run、未暂停 step、运行中 PUT）→ 409。
  步骤 op 全集与字段见《仿真实现原理.md》"工艺流程编排"一节（2026-08-21 起含 `film` op：`{"op":"film","action":"load"|"unload"}` 蓝膜上下机，示例流程首步已带 load）。

## 2. 二进制帧格式（小端）

| 字段 | 类型 | 说明 |
|---|---|---|
| magic | u8 | 固定 0xA1 |
| version | u8 | 1 |
| axis_count | u16 | 21 |
| sim_time | f64 | 仿真时钟（秒，单调） |
| wall_time | f64 | 发送时刻 epoch 秒（`time.time()`），前端用它算单向延迟 |
| seq | u32 | 帧序号，检测丢帧 |
| values | f32 × 21 | 轴当前值，单位：**直线 mm、旋转 rad（全线统一 rad）**，顺序固定见 §3。注：TwinDOM 前端模型内部旋转轴单位为 deg，由前端注入脚本在边界做 rad↔deg 换算，模型文件不改 |

帧总长 108 字节。推送频率 500Hz（每 2 个物理 tick 一帧）。

## 4. 客户端→服务端指令（WS 文本 JSON）

```json
{"cmd":"move","axis":"WS_LS_X 或前端轴id","target":100.0,"speed":200.0}
{"cmd":"home","axis":"... 或 ALL"}
{"cmd":"estop"}          // 全部轴急停
{"cmd":"reset"}          // 急停复位
{"cmd":"setSpeed","scale":1.0}   // 全局倍速 0.1~8
{"cmd":"runBuffer","buffer":1}   // ACS buffer 程序
{"cmd":"io","path":"SystemMachine.SS_ME.M_AIR.WT_WaferVac","op":"OpenNegtive"}  // PLC 气路/IO 命令
{"cmd":"ping","t":123.456}  // 服务端原样回 {"pong","t"} 测往返
```

`move` 按轴归属自动路由 ACS / PLC 模拟器。指令不逐条回执（状态经推送帧反映），出错回文本帧 `{"ok":false,"error":"..."}`；`move` 被拒（干涉/限位/掉使能等）时回执额外带 `"axis"` 与 `"target"` 字段（2026-08-20 起），前端据此弹回滑块并在 HUD 提示。

## 5. 前端处理要求

- 收到帧立即写入 `axis.current`（数据延迟 ≈ 传输延迟）；渲染仍在 rAF。
- 保留最近 2 帧算速度，帧间做线性外推（上限 20ms），消除 2ms 推送间隔造成的抖动。
- HUD 悬浮层：连接状态、推送频率实测、单向延迟（wall_time vs Date.now，本机同时钟）、丢帧计数、渲染 fps。
- 轴滑块在联机时改为发 `move` 指令给后端（不再只本地驱动）。
- 断线自动重连（1s 间隔）；未连接时页面保持单机滑块模式可用。

## 6. 沙盒干涉检查（/api/collision，2026-08-20 W5）

后端按 TwinDOM 模型沙盒（AABB）做干涉检查（原理见 docs/仿真实现原理.md
"沙盒干涉检查"节）。对前后端的契约面：

- `GET 9010 /api/collision` →
  `{ok, loaded, enabled, boxes, moving, fixed, pairs, exempt, depth_eps, active, events}`：
  - `loaded=false` 表示 runtime/sandboxes.json 未加载（检查整体停用）；
  - `depth_eps` = 当前穿模深度阈值（mm，默认 2.0，见 POST）；
  - `active` = 当前重叠对列表 `[[盒labelA, 盒labelB], ...]`；
  - `events` = 近期拦截事件环形记录 `[{t(仿真秒), pairs, stopped(被停轴)}]`。
- `POST 9010 /api/collision` 体 `{enabled: bool, depth_eps?: float}` →
  总开关（默认开）+ 穿模深度阈值在线改（合法区间 [0, 50]mm，非法 400）；
  响应 `{ok, collision_enabled, depth_eps?}`。重开后关闭期间形成的静止重叠只进
  `active` 报告，不追溯停；运动中的重叠立即 soft-stop。
- 干涉拒绝语义复用联锁：move/jog/buffer 起步即撞 → **HTTP 409**
  （`{"ok":false,"error":"沙盒干涉：<盒A> × <盒B>；...（共 N 对）"}`，
  至多列前 3 对零件级盒名）；
  运动中撞入 → 全轴 soft-stop + 事件记录，无推送帧级通知（轮询
  /api/collision 或 /api/health 的 `collision` 字段获取）。
- `/api/health` 新增 `collision: {enabled, loaded, boxes, pairs, active}`
  （active 为当前重叠对数）。

## 7. 六自由度误差注入（/api/toolpoints、/api/kinematics，2026-08-20）

误差系统分两层，开关相互独立：单轴读数层（`enabled`，行为不变，作用于
`/api/axes` 的 actual 通道）与工具点 6DOF 层（`six_dof_enabled`，默认开，
作用于各模块工具点位姿误差）。两开关都经 `POST /api/errormaps` 设置
（`{"enabled":bool}` / `{"six_dof_enabled":bool}`，缺省键不动现状），
`GET /api/errormaps` 响应同时带 `enabled` 与 `six_dof_enabled`。

**统一误差全关（迭代 77）**：`GET /api/error_injection` 返回 `{disabled,
configured, effective}`；`POST /api/error_injection {"disabled":true}` 后，
所有仿真误差（含轴控 `3σ repeat`、固定偏移、比例/地图、6DOF、模态、热变形、
翘曲、视觉/共焦/温力传感器、处方上片、工艺微滑移与计量帧注入）不再进入模型
计算。默认 `disabled=false`，运行时内存态不持久化。`configured` 保留各独立
开关原值，`effective` 才表示实际注入状态；恢复 `disabled=false` 后按原配置
继续。正常运动/温控/流程/联锁与主动工艺补偿不关闭，已有工件不被移动；重新
上片得到理想上片。`/api/errormaps` 同步带 `all_errors_off` 和
`effective_enabled`，旧 `enabled` 字段语义不变。

- `GET 9010 /api/toolpoints` →
  `{ok, six_dof_enabled, modules:{模块名:{label, nominal_mm[3], error_mm[3],
  error_rad[3], error_nm[3], error_urad[3], axes:[...]}}}`：五模块（wafer_stage 硅片台 /
  align_stage 对准台 / bond_head 键合头 / flip 翻转模块 / film_stage 蓝膜台）
  工具点按串行运动链做 6DOF 误差合成（链定义与原理见 runtime/README.md
  "误差系统"节与 runtime/error_kinematics.py docstring）。`nominal_mm` 为
  名义正解工具点位置（机架坐标 mm，随轴动）；`error_*` 为工具点位姿误差，
  六自由度开关关闭时全零。`axes[]` 为**每轴分解**（2026-08-20 新增）：
  `{axis, kind, sample_mm[3], sample_rad[3], trans_mm[3], rot_trans_mm[3],
  attitude_rad[3], trans_nm[3], rot_trans_nm[3], attitude_urad[3]}`——
  `sample_*` 为该轴 6 分量采样原值（含沿轴 repeat+fixed+scale 并入）；
  `trans_mm` 为平移直接贡献；`rot_trans_mm` 为**旋转致平移（阿贝项，
  旋转单独绕生效枢轴作用于当前工具点的位移）**——T/R 链元行为统一
  （2026-08-20 枢轴语义澄清）：直线轴的 drx/dry/drz 角度误差同样是台面
  绕枢轴的微小转动，在工具点产生平移偏移（阿贝误差 = θ × 杠杆臂）；
  `attitude_rad` 为姿态贡献。
  各轴之和≈模块总计：Σ(trans_mm+rot_trans_mm)=error_mm、
  Σattitude_rad=error_rad（精确伸缩和）。只进测量/显示通道：不进轨迹积分、
  不进 WS 帧、不推 3D 前端（µm 级不可见）。
- `GET 9010 /api/kinematics` → 当前运动链配置（每模块
  `{label, tool_point[3], chain:[{axis, kind, dir, center, custom_center,
  effective_center}], _note}`；**每根链元（T/R 一致）都有旋转枢轴**：
  `center` 为默认枢轴（轴角度误差的物理支点、轴承中心等效点，**只读**）、
  `custom_center` 为自定义枢轴（默认 null）、
  `effective_center = custom_center ?? center` 为误差合成实际生效枢轴；
  `_note` 记几何默认值来源——挖自 sandboxes.json 零件 AABB（T 轴取随本轴动
  但不随下游轴动的滑台组件聚合盒中心），占位待真机标定）。
- `PUT 9010 /api/kinematics` 体
  `{"modules":{模块名:{"tool_point"?:[x,y,z],"chain"?:[{"axis","custom_center"?}]}}}`：
  部分字段合并（只提交改过的）；**链元只接受 `custom_center`**（三维有限向量
  或 null——null 恢复默认枢轴），默认 `center` 只读、传入即 400
  "默认旋转枢轴不可修改"，`dir` 等其他字段同样 400；模块级 `tool_point`
  仍可改。schema 校验（轴名存在 / 向量三维有限）失败 →
  **400** 且 `errors[]` 逐条明细、整体不应用；成功 200 立即生效
  （下次 /api/toolpoints 用新值）。默认**不持久化**；体带 "persist":true 时
  把当前生效配置原子写回 error_kinematics.json（响应带 persisted:true），
  不带则重启回 error_kinematics.json 盘面值；坏配置文件启动即报错拒绝拉起。

## 8. 处方系统（/api/recipe*，2026-08-20；film.dies 圆形规则 2026-08-24）

处方 = 一次键合作业的物料与布局定义（晶圆/键合位阵列/蓝膜 die 阵列），
全部参数在线可改并落盘 `runtime/recipe.json`；**改处方不动当前物料状态**，
布局生效需显式 apply。字段与默认值见 `runtime/recipe.py` 顶部 DEFAULT_RECIPE
与模块 docstring（标记 ratio 思路参考 d2w_sim_semiconductor_refactor）。

- `GET 9010 /api/recipe` → `{ok, recipe}`（全量）。recipe 结构：
  - `wafer`：`{diameter_mm, thickness_mm, marks:[{name, shape, x_mm, y_mm,
    size_um}]}`；`shape ∈ cross/box/circle`，`size_um` 标记尺寸（µm，旧键 size_mm 自动迁移 ×1000）；`thickness_mm` 参与键合有效接触位
    换算（2026-08-31 迭代 9 起自动联动：有效接触位 = 机械常数裸接触位
    bond.head_z_contact_mm(−168.93) + 晶圆厚 + 芯片厚(film.dies.thickness_mm)，
    engine.effective_bond_contact_mm 统一换算，flow 与真值力模型共用）。
  - `wafer_sites`：晶圆上键合位阵列，`mode ∈ auto/manual`。auto（默认）：
    `{size_x_mm, size_y_mm}`（null=**跟随 film.dies 芯片大小**）、
    `{gap_x_mm, gap_y_mm}`（默认 1）、`edge_margin_mm`（默认 3）——以晶圆心
    为原点铺满网格，**只保留四顶点都在 (R-edge_margin) 圆内的 site**；
    manual：`{rows, cols, pitch_x_mm, pitch_y_mm, origin_x_mm, origin_y_mm}`
    显式行列（旧版键兼容，无 mode 的旧 recipe.json 按 manual 迁移）。
  - `film.dies`：蓝膜 die 阵列几何，**是 workpieces die 阵列的唯一事实源**，
    `mode ∈ auto/manual`。auto（默认）：`{size_x_mm, size_y_mm}`（芯片大小，
    默认 4×4）、`{gap_x_mm, gap_y_mm}`（间隔=街宽，默认 1×1）、
    `edge_margin_mm`（膜面边距，默认 3）——膜面可用区为 `film.diameter_mm`
    的圆（默认 49，圆心=film 局部原点=模块中心），以圆心为原点铺满
    pitch=size+gap 网格，**只保留四顶点都在 (diameter/2-edge_margin)
    圆内的 die**（与 wafer_sites 同判定。2026-08-24 由矩形规则改圆形：
    旧键 `film_width_mm/film_height_mm/center` 两模式废除、PUT 进来 400
    指路 `film.diameter_mm`，auto 模式 `origin_x_mm/origin_y_mm` 亦废除
    ——需显式原点请切 manual）；manual：`{rows, cols, pitch_x_mm,
    pitch_y_mm, origin_x_mm, origin_y_mm}` 显式行列（不裁圆）；两模式都带
    `size_*`（描述+跟随源）与 `thickness_mm`。`film.marks`：每 die 标记定义（film/head 上的 die 共用）——
    `{shape(cross/box/circle), size_um, ratio:[[x,y]…], per_die}`；位置 =
    ratio（相对 die 半宽的比例，元素∈[-1,1]）× (size_x/2, size_y/2)，
    die 尺寸变则标记布局等比缩放；per_die 启用 ratio 前几个（默认
    4×box@±0.76 → 4mm die 时 ±1.52mm）。旧块 `film.die_mark`
    `{shape,size_mm,corner_ratio}` 加载自动迁移（ratio=四角×corner_ratio、
    size_um=size_mm×1000、shape box、per_die 4）。
  - **派生块（只读，运行时算出，不写盘）**：响应里注入
    `film.dies_derived {mode, rows, cols, pitch_x_mm, pitch_y_mm, count,
    effective_origin, positions_preview(前 8 个坐标)}` 与
    `wafer_sites_derived {mode, rows, cols, pitch_x_mm,
    pitch_y_mm, total_sites, positions_preview(前 8 个坐标)}`。dies 派生公式：
    pitch=size+gap；以膜面圆心为原点铺满网格（imax=floor((diameter/2
    -edge_margin-size_x/2)/pitch_x)，jmax 同理），只保留四顶点都在
    (diameter/2-edge_margin) 圆内的格点；rows/cols=铺满跨度（含被圆裁掉的
    空位），count=实留颗数，effective_origin 恒 [0,0]。默认 auto 派生 =
    7×7 跨度裁 4 角 = 45 颗@pitch5。
  - `GET 9010 /api/recipe/wafer_sites?limit=N` → `{ok, total_sites, limit,
    returned, derived, positions}`（全量坐标列表，默认 limit=200、上限 100000，
    避免几千点进 /api/recipe 响应撑爆面板轮询）。
  - `GET 9010 /api/workpiece/map`（迭代 10，die map 可视化选片选位）→
    `{ok, film_dies:[{row,col,x,y,id,carrier}], wafer_sites:[{row,col,x,y,
    bonded}], geometry:{film:{diameter_mm,die_size_x_mm,die_size_y_mm},
    wafer:{diameter_mm,site_size_x_mm,site_size_y_mm,edge_margin_mm}}}`。

    前端不自行推算。

## 11. 测校系统（/api/calibration/*，2026-08-21）

三个标定程序，全部走 **REAL 视觉链路**（渲染→TCP 9200→cv2 NCC 匹配），
测量结果经机器常数校验写回。calibration.py 实现，`calibration=None` 时
端点 503；cv2 缺失时 start 400。作业模式（无现成异步框架）：

- `POST 9010 /api/calibration/start` 体 `{"routine":"focus_scan"|
  "pixel_equivalent"|"rotation_direction", "cam":"down", "params"?{...}}`
  → 200 `{ok, job_id, state:"running"}`（工作线程异步执行）。同一时刻只跑
  一个作业，运行中再 start → **409**；未知 routine/相机 → 400；
  **coarse 的 focus_scan → 400**（镜头固连机架、蓝膜台无 Z 轴，无相对 Z
  自由度，wd 需机械标定）。
- `GET 9010 /api/calibration/jobs` → `{ok, active, jobs:[{job_id, routine,
  camera, state, t_start}...]}`（近 20 条）。
- `GET 9010 /api/calibration/status?job_id=N` → `{ok, job_id, routine,
  camera, state(running|done|error), progress{i,n,note}, t_start, t_end,
  error}`。终态 `done` 在**现场恢复完成后**才置位（轮询到 done 即安全）。
- `GET 9010 /api/calibration/result?job_id=N` → `{ok, result:{routine,
  camera, measured{...}, current{...}, points[...], confidence, detail,
  ts}}`；运行中/失败/未知作业 400。
- `POST 9010 /api/calibration/apply` 体 `{"job_id":N, "fields"?["wd_mm"]}`：
  把已完成作业的 measured（可只选部分字段）经机器常数校验写回+落盘+热生效
  → 200 `{ok, applied, persisted, derived}`；fields 不在测量结果里/未知
  作业/作业未完成 400，常数校验失败 400。

程序语义（选轴按各相机 marks.source 的载体模块）：

| routine | 做法 | measured | 默认 params |
|---|---|---|---|
| focus_scan | 扫"相机↔标记"相对 Z（up→BS_Arm_Z 动键合头携带的 die；down→AS_Z 动对准台携带的镜头），逐点 REAL identify 记 score（**判废点也记录**，画曲线用），抛物线拟合峰位 → 实测焦面距离 | wd_mm | range_mm=±3×DOF，step_mm=DOF/2 |
| pixel_equivalent | 点动已知 Δmm（默认 WS_LS_X 向），测质心像素位移 → k_um_px=Δ/Δpx → mag=pixel_um/k_um_px | mag | delta_mm=1.5（[0.1,10]，可用 axis 选 Y 向） |
| rotation_direction | X/Y 各点动一次测像素位移向量，枚举 (dir_x,dir_y,swap)×连续 rot 拟合（map_ang 角度对 θ 线性、斜率 dx·dy；Y 向量算角残差取最优；(D,θ)≡(−D,θ+π) 简并统一规范化到 \|θ\|≤π/2） | rot_mrad, dir_x, dir_y | delta_mm=1.0 |

- 点动轴（轴正方向运动产生的"标记相对相机"位移符号）：down=WS_LS_X/Y(+)；
  up=AS_X/Y(−，动的是相机)；coarse=ES_X/Y(+)。
- **安全**：所有轴运动走 engine.move 正常路径（联锁/estop/软限位/沙盒
  干涉检查全过，异常即作业 error）；作业前自建临时模板 `_cal_<job_id>`
  （亮灯后当前帧取 ROI），finally 恢复轴原位/光源/视觉模式并删模板。
- 精度基线（本仿真 REAL 链路，亚像素定位 ~0.1-0.2px 系统偏置）：
  focus_scan wd 误差 <±0.05mm；pixel_equivalent mag 误差 <±0.1%；
  rotation_direction 在 1mm 杠杆下 rot 误差 ~±0.2mrad（dir 符号精确）。
  测量用质心只采纳 score ≥ 阈值的判真点——NCC 接受下限附近会在大标记臂
  上产生 0.48 级幽灵实例（±~212px），见《视觉系统_V1.md》§9。

## 12. 光谱共焦（MQTT confocal/*、/api/confocal/read，2026-08-27）

调焦调平的高度测量传感层（runtime/confocal.py）。读数链路对齐视觉风格：
**触发与结果都走本机 MQTT broker(1883)，主控真订阅消费**（视觉链路主控
目前仍进程内直读，共焦是第一条全 MQTT 化链路）；同步 `read()` 保留给
调试 API。离线约束不变：broker 是本进程内迷你实现，无任何外部依赖。

- **触发主题** `confocal/trigger/{probe}`（probe = `up`/`down`），主控
  （flow_engine `fl_measure`）发布，QoS0，payload JSON：
  `{"req_id": "fl-000001", "probe": "down"}`（req_id 主控侧单调递增，
  用于结果关联）。
- **结果主题** `confocal/result/{probe}`，共焦服务（ConfocalModel 的
  MQTT 服务线程）订阅触发、执行测量后发布，QoS0，payload JSON：
  `{"ok": true, "probe": "down", "reading_um": 350.28, "valid": true,
  "z_surface": 885.9, "z_focus": 885.9, "req_id": "fl-000001"}`。
  字段语义：`reading_um`=共焦读数 µm（**null=无读数**：量程
  [0, confocal_range_um] 外或无有效目标）；`valid`=读数有效；
  `z_surface`/`z_focus`=被测面/焦面世界 z（mm，仿真真值出口，调试与
  换算用）；`req_id` 原样回带（触发的 req_id 为 null 时结果也是 null，
  主控只认领非空且匹配的 req_id）。
- **服务端**：`ConfocalModel.start_mqtt()` 常驻线程订阅
  `confocal/trigger/+`，收到触发即 `read()` 并 `mqtt_publish` 结果
  （与视觉服务同一 broker、同一一次性发布模式）；断线退避重连。
- **主控端**：`ConfocalClient`（engine.confocal_client）常驻收线线程
  订阅 `confocal/result/+`，只解析 JSON 按 req_id 填字典 + Condition
  通知（回调不碰引擎状态）；`request(probe, timeout)` 发布触发后等
  对应 req_id，超时（默认 5s）抛 RuntimeError → 流程步骤失败 abort。
- **调试 API（不走 MQTT，同步直读）**：
  `GET 9010 /api/confocal/read?probe=up|down` → 同上字段（无 req_id）；
  坏 probe → 400。
- 读数噪声 σ 不在机械常数（2026-08-27 迭代 2 迁出）：
  `recipe sim_sensors.confocal_sigma_um`（测校页"传感器仿真"卡，
  每次读实时取=热生效）。
