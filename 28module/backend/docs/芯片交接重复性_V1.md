# 芯片交接重复性_V1

测校族：交接链测校（`die_transfer_repeat`）。同一颗 die 在
「蓝膜台→顶针→Flip→键合臂」交接链上往复，分段测量 die 标记世界坐标
散布（3σ）：

| routine | 测什么 | 实现 |
|---|---|---|
| `die_transfer_repeat` 芯片交接重复性 | flip/head/back 三段各自的位置重复性（col 3σ(px) + world X/Y 3σ(µm)）；段间均值差 = 交接链各段位置偏差叠加 | `extra_routines.run_die_transfer_repeat`（`extra_routines.py:231-471`）；校验 `runtime/calibration.py:525-558`；GUI 页 `metrology_gui/DieTransferRepeat.py` |

本文面向设备工程师逐行核对算法：所有公式、字段名、阈值均对准代码实际
实现（引用格式 `文件:行号`）。设计口径见
`测校/测校文档/设计草稿/测量与校准策略草稿.docx`「芯片交接重复性」行
（蓝膜台→顶针→Flip→键合臂 分段偏差叠加）。

## 1. 测的是什么

**定义**：取一颗 die 后，让它在 **翻转台（flip）↔ 键合头（head）** 之间
往复交接 repeat 次，在三个链段节点各拍一次照、质心反算世界坐标：

| 段 | 拍摄时机 | 相机 / 模板 | 样本数 |
|---|---|---|---|
| `flip` 翻转段 | 作业首 `flip_pick` 取片后（**整个作业仅此一拍**，粗对准拍 = flip 段；迭代 43 起 flip 有余片则沿用、跳过取片，首段拍照照常） | coarse + 机器常数 `vision_marks.tpl_coarse_die`（默认 `cv_chipback`） | 1（无重复性统计意义） |
| `head` 键合头段 | 每循环 `flip_handoff` 交到键合头后，走位（AS_Y=6 / AS_Z=0 / BS_Arm_Z=-118.33 + guide 居中）→ 上相机拍 | up + `tpl_die_head` | repeat |
| `back` 回翻段 | 每循环 `head_to_flip` 回翻后，走位（**FA_Z 回粗对准调焦位 fa_z_view_mm**（迭代 34——back 段固定 back_tpl 可识别前提）+ FA_X=−5 + guide 居中）→ 粗对准拍 | coarse + `back_tpl`（**缺省=coarse_tpl**，迭代 34 起不自建临时模板） | repeat |

- **段内 3σ** = 该链段的到位重复性（交接机构 + 走位轴 + 相机识别噪声
  的集总）。head 段吸盘真空持片、guide 细相机居中，典型最好；back 段
  die 回翻后靠承靠面重新落座，典型最差（实测见 §4）。
- **段间均值差** = 交接链偏差叠加的物理位移：die 从 pick 位被搬到
  键合头（flip→head 均值差）、再从键合头回翻到翻转台（head→back）。
  注意跨段均值差里还含**两台相机链各自的恒定标定差**（相机位姿/
  k/rot 常数误差进世界坐标绝对值），段内 3σ 是差分量、不受其影响。
- **物料口径（迭代 43，用户明确要求"结束留片在拾取头"）**：全程只用
  **一颗** die，循环内**不放回蓝膜**；作业结束/异常/取消 die 均**留
  在拾取头（flip）不再归位**（中断场景可能在 head），`finally` 只按
  实际 carrier 打一行留片日志。正常路径蓝膜 die 数 N→N−1（取走 1）
  全程不回升、结束保持 N−1；下次作业沿用该片（见下）。**起始兼容
  三态**（`extra_routines.py:360-376`）：① flip+head 双残留 →
  CalibError 请先在工艺流程页清片；② head 单残留 →
  `_reclaim_head` 回收 head→flip（不再回放蓝膜，回收后沿用该片）；
  ③ flip 有余片（含回收所得/上一作业留片）→ 沿用、跳过首次
  flip_pick 取片（首段 flip 拍照照常）。回归即用 `/api/viz` 蓝膜
  计数轨迹与留片断言钉死本口径（`tests/test_metrology.py:1955`）。

### 2.2 三段时序（行号级伪代码）

视觉切 REAL、两相机点灯（`extra_routines.py:354-359`）后：

```

    flip+head 双残留 → CalibError 请先清片

        head→flip（不再回放蓝膜，回收片留 flip 沿用）；正常路径
        head 空 = 空操作，:294-307）
    flip 有余片（含回收所得/上一作业留片）→ 日志"沿用该片测校"
        + _pose_after_head_back() 回粗对准合焦观测位（:369-373，
        跳过取片）；否则 _run_flow(build_flip_pick_flow) 取一颗
        die（仅此一次，:374-376）
wait（:377）
_snap("flip", coarse, coarse_tpl)（:378，flip 段唯一一拍）

for i = 1..repeat（:379）：
    _check_cancel(job, i)（:380，协作式取消：下一循环边界生效）
    _reclaim_head()（:382，循环首幂等复位；正常路径空操作，保留兼容
        历史中断残留）
    _run_flow(build_flip_handoff_flow)（:383-384，die 翻到键合头）
    wait（:385）
    _pose_for_head_shot()（:386，:317-331）
    wait（:387）
    _snap("head", up, up_tpl)（:388，head 段）
    _run_flow(build_head_to_flip_flow)（:389-390，die 回翻转台）
    wait（:391）
    _pose_after_head_back()（:392，:333-352）
    wait（:393）
    # 循环内不放回蓝膜：die 留在 flip 上进下一循环（物料口径）；
    # back 段用固定 back_tpl（缺省=coarse_tpl，迭代 34 起不自建
    # 临时模板，:394-396）
    _snap("back", coarse, back_tpl)（:396，back 段）
```

走位细节：

- **head 段观测位** `_pose_for_head_shot`（`extra_routines.py:317-331`）：
  `AS_Y→6.0`、`AS_Z→0.0`、`BS_Arm_Z→-118.33`（把 die 底面送进上相机
  焦面），再 `vision.guide("up")` 取最近标记的建议移动量逐轴走位——
  guide 居中后质心 ≈ 上相机光轴落点。
- **back 段观测位** `_pose_after_head_back`（`extra_routines.py:333-352`）：
  **`FA_Z→fa_z_view_mm`（机器常数 flip_pick 组，迭代 34 新增——
  head_to_flip 结束停在 Z 安全位 20mm，die 离焦糊成均匀亮雾，固定
  back_tpl 识别前必须先回粗对准调焦合焦位，与 coarse_tpl 示教时的
  景深口径一致）** + `FA_X→−5.0` 观测位 + `vision.guide("coarse")`
  引导居中（die 回翻后位置与 pick 后略有差异，guide 精修）。
  （迭代 43 沿用余片路径同调本函数回合焦观测位再首段拍照。）

`finally`（`extra_routines.py:398-431`，作业结束/异常/取消都走）：

```
留片日志（迭代 43；:401-415）：die 不归位——按实际 carrier 打一行
    "die 留在拾取头（carrier=flip），未归位蓝膜"（中断在 head 如实
    打 head；双载体同见如实并记；异常吞掉不掩盖原始异常）
逐轴恢复 saved_axes 7 根轴位（:416-421）
恢复两相机灯态（:422-426）

```

（迭代 34 起 finally **不再删临时模板**——全作业无任何自建模板；
迭代 43 起 finally **不再归位 die**——原 `_reclaim_final` 物料归位

### 2.3 采集：拍照 → (col,row) + 质心反算世界坐标

统一入口 `_shot_world`（`extra_routines.py:221-228`）：

```
entry = svc._identify(cam_id, tpl)            # REAL 模板识别
col, row = svc._centroid(res, score_threshold)  # 判真点质心（px）
c = _context(svc, cam_id, cam, col, row)      # repeatability.py:99-132
return col, row, c
```

`_context` 内部调 `cam.solve_pixel(col, row, cam_pos)`
（`runtime/vision_model.py:563-574`）：

```
(dx, dy) = solve_rel(col − W/2, row − H/2)    # vision_model.py:543-561
    # u,v 先按 swap_xy 反映射、乘 k 与 dir_x/dir_y，再按 +rot
    # （控制器认知 rot_mrad）反旋——迭代 38/39 真值/认知分离后
    # 反算链只含认知
world = (cam_pos.x + dx, cam_pos.y + dy, cam_pos.z + look_dir·wd)
```

`_snap`（`extra_routines.py:309-315`）把 `(col, row, mark_world_mm)`
追加进对应段序列并记日志 `detect[tag]: ... world=(x,y)`。

物理含义：guide 把标记居中后，质心反算世界坐标 ≈ **该观测位下相机光轴
落点**；各循环的散布 = 光轴落点的重复性 + guide 居中残余×k + 识别噪声。

### 2.4 指标公式与统计口径

代码 `extra_routines.py:450-459`，对每段 tag ∈ {flip, head, back}：

```
cols_  = 该段全部 col 样本
st     = {col_s3_px: 3σ(cols_)}                        # 像素口径
wx, wy = 该段全部 world_x / world_y（mark_world_mm 非 None 者）
if len(wx) == len(segs[tag]) and wx:                   # 无缺失样本守卫
    st[world_x_s3_um] = 3σ(wx) × 1000                  # mm → µm
    st[world_y_s3_um] = 3σ(wy) × 1000
```

- `_s3`（`extra_routines.py:108-110`）= 3×`_mean_std`；
  `_mean_std`（`metrology/repeatability.py:186-191`）为**总体口径
  ddof=0**：`σ = sqrt((1/n)·Σ(x_i−mean)²)`。
- flip 段只有 1 个样本 → `col_s3_px=0.0`、`world_*_s3_um=0.0`
  **照常输出但无统计意义**（单样本 σ 恒 0）。
- 段内散布是差分量：相机 k/dir/swap 与反算链认知 rot_mrad、运动链
  姿态误差的恒定分量在差分后相消，残余是走位重复性 + guide 居中
  残余 + 识别噪声。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 蓝膜在位且有 die（`POST /api/workpiece/film` 上膜；start 校验
   `runtime/calibration.py:526-528`，作业内再复核
   `extra_routines.py:264-266`）。**起始兼容**：flip 有余片可直开
   （沿用，跳过取片）；head 单残留可直开（回收沿用）；flip+head
   双残留 → 请先在工艺流程页清片（`extra_routines.py:360-368`）。
2. 视觉链路可用 cv2（REAL 模式必需；start 统一拦
   `runtime/calibration.py:289-291`）。
3. 两模板已注册：coarse 认翻转吸盘上 die 背面特征
   （默认 `cv_chipback`）、up 认键合头上 die 角标（默认
   `tpl_die_head`）；back 段模板 `back_tpl` 可选（**缺省=coarse_tpl**
   的值）——三模板存在性均**在 start 校验**（迭代 34 上移，缺省
   取机器常数 `vision_marks` 后查注册表，不存在 400 列可用名，
   `calibration.py:538-554`），作业不自建不删（原 back 段就地自建
   临时模板路径已删）。
4. 建议无工艺流程在跑（本 routine 的 start 校验**不做**流程忙硬拦截，
   与 `camera_microrot` 不同——作业本身会跑交接工艺流，与业务流并发
   会互相动轴）。

三次 wait；`_run_flow` 单段超时 300s。repeat=10、wait_ms=20 实测
分钟级（`elapsed_s` 在结果里回显）。

## 4. 计算示例（真实数据手算复核）

数据来自本后端 2026-09-10 回归实测
`runtime/metrology_data/die_transfer_repeat_0910_10_55_36.csv`
（repeat=10，蓝膜满阵列、REAL 链路、默认机器常数与默认模板）。该文件
flip 段仅第 0 行有值——与现行语义一致（迭代 43 的"结束留片"只改
finally 物料去向，不改三段采集/统计口径）。

### 4.1 段内统计手算（head 段 world_x，前 3 循环）

head_world_x_mm 前 3 行 = [−46.295355, −46.295469, −46.295391]：

```
mean = (−46.295355 − 46.295469 − 46.295391)/3 = −46.295405 mm
偏差 = [+0.000050, −0.000064, +0.000014] mm
σ    = sqrt((5.0e−5² + 6.4e−5² + 1.4e−5²)/3) = 4.758e−5 mm
3σ   = 1.427e−4 mm = 0.143 µm
```

全 10 循环（程序复核同一公式）：mean=−46.295399，
`world_x_s3_um=0.2033`、`world_y_s3_um=0.1786`、`col_s3_px=0.4255`。
head 段量级：上相机 k=0.6µm/px，0.43px×0.6 ≈ 0.26µm，与世界口径
3σ≈0.2µm 一致——head 段散布 ≈ 识别噪声档（guide 居中后相机光轴
落点几乎不动）。

### 4.2 back 段统计与 k 复核

back 段全 10 循环（程序复核）：`col_s3_px=2.9496`、
`world_x_s3_um=26.9381`、`world_y_s3_um=15.4831`。
粗相机像素当量 `k = pixel_um/mag = 2.74/0.3 = 9.133 µm/px`
（`runtime/vision_model.py:505-508`）：

```
world_x 3σ / col 3σ = 26.9381 µm / 2.9496 px = 9.133 µm/px  ✓
```

二者严格同出一源：世界坐标 = 光轴落点 + 像素偏差×k，guide 居中后
残余像素散布直接按 k 放大进世界散布。back 段比 head 差 ~130×的
主因不是相机而是**落座**：die 每循环回翻后重新承靠，横向/旋转移位
~10µm 级，guide 只能把它居中到残余量级。

### 4.3 段间均值差（交接链偏差叠加）

该次实测各段世界坐标均值（mm）：

| 段 | mean world_x | mean world_y |
|---|---|---|
| flip（单样本） | 1199.723881 | 9.015317 |
| head | −46.295399 | 10.784365 |
| back | 1199.841460 | 8.988144 |

flip 与 back 同为粗相机 frame、观测位接近（FA_X=−5 附近），可直接
相减：

```
回翻落座偏移 = back − flip = (+0.1176, −0.0272) mm ≈ (+118, −27) µm
```

即这颗 die 经「pick → 交接到键合头 → 回翻」一个往返后，背面标记相对
取片时刻的位置偏移 ~118µm——这就是"交接链偏差叠加"的物理读数
（含回翻转角导致的标记杠杆位移）。head 均值在另一台相机/观测位反算，
与 coarse frame 的差是真实搬运位移 + 两相机链恒定标定差之和，只作
量级参考、不作验收。

## 5. 误差来源与注意事项

1. **识别噪声按 k 放大**：REAL 链质心噪声（recipe
   `sim_sensors.fast_noise_px`，默认 0.15px 档）经像素当量进世界
   散布——粗相机 9.133µm/px 比上/下相机 0.6µm/px 放大 15×，
   故 back 段 col 3σ 的 px 值看着小、µm 值并不小。
2. **back 段落座重复性主导段差**：head（真空持片 + guide 居中）实测
   世界 3σ ~0.2µm；back（承靠面重新落座）实测 ~27/15µm。想分离
   「落座」与「识别噪声」，可对同一噪声档跑两 repeat 对比。
3. **段间均值差含相机链恒定标定差**：k/dir/swap/位姿常数与反算链
   认知 rot_mrad 的误差进世界坐标绝对值，跨相机相减时与真实搬运
   位移混在一起；段内 3σ 是差分量不受其影响。验收重复性用段内
   3σ，别用段间差。
4. **flip 段恒为单样本**：3σ 输出 0.0 是公式结果不是故障；历史 CSV
   （迭代 29c 之前，如 `die_transfer_repeat_0909_16_53_07.csv`）flip
   每行有值——旧语义是每循环 pick+place_back，勿与现行数据混读。
5. **物料红线（迭代 43 口径）**：正常路径作业期间蓝膜 die 数恒
   N−1、全程不回升，结束保持 N−1、die 留 flip（留片待下次沿用）；
   回收沿用路径蓝膜数全程不变（回收不改 film 数、沿用不取新）。
   若看到循环内放回/再取（计数振荡）或结束被归位即为回归。
   finally 留片日志被吞掉不掩盖原始异常
   （`extra_routines.py:401-415`）；双残留开局直接 CalibError 请先
   清片（`extra_routines.py:363-367`）。
6. **cancel 语义**：`cancel` 只置标志，下一循环首 `_check_cancel`
   抛 `CalibCanceled`（`metrology/repeatability.py:169-177`），终态
   canceled 无结果；finally **不归位**（die 留在当时 carrier，
   如实打留片日志）+ 7 轴/灯/模式恢复照跑。
7. **head 段观测位是参考 test_metrology prep_up 后段定出的机器常数式
   走位**（AS_Y=6 / AS_Z=0 / BS_Arm_Z=-118.33，`extra_routines.py:317-331`
   注释——**合成值，待真机标定**）：键合头吸盘中心对上相机 + die 底面
   进焦面。改机型/换镜头需重确认这三个数。
8. **back 段合焦前提（迭代 34）**：`_pose_after_head_back` 先走
   FA_Z 回 `flip_pick.fa_z_view_mm` 粗对准调焦位再拍（head_to_flip
   结束停在 Z 安全位 20mm，离焦糊成均匀亮雾会使固定 back_tpl 识别
   失败）；若 back 段反复"视野内未找到标记"，先查 fa_z_view_mm
   机器常数与 FA_Z 实际位。
9. **本 routine 无 apply**：纯测量程序，结果无 `measured` 字段，
  `POST /api/calibration/apply` 会 400（`runtime/calibration.py:1454-1459`）。

## 7. 需求对照

- 设计草稿「芯片交接重复性」行（蓝膜台→顶针→Flip→键合臂 分段偏差
  叠加）：三段划分、每循环 handoff→head_to_flip 一个来回、分段 3σ
  统计全部落地；分段节点取的是「取片后 / 交接后头下 / 回翻后」三个
  可观测位。
- 物料口径（迭代 29c 起"循环内不放回蓝膜"；迭代 43 起"结束留片
  拾取头、不再归位"，用户明确要求）：回归用 `/api/viz` 蓝膜 die
  计数「运行期仅降 1、全程不回升、结束保持 N−1」+ flip 恰 1 die +
  日志恰 1 条"留在拾取头"断言（`tests/test_metrology.py:1955-2036`）；
  中断路径「reclaim 回收→沿用→cancel 后留片、film 全程不变」断言
  （`:2039-2096`）。
- 验收参考：repeat ≥10（回归默认 10；正式摸底建议 ≥30）；主指标
  head/back 段世界 3σ(µm)，flip 段不参判。
