# 热压键合与温控压控 V1（2026-08-28 迭代 8；2026-08-31 迭代 9 修订）

热压键合（TCB）流程 + TwinCAT 系列型位置式 PID 三回路（键合压力 ×1、
温度 ×2）的设计文档。代码：`runtime/process_flows.py`（build_bond_flow）、
`runtime/pid.py`（PID 核）、`runtime/engine.py`（三回路挂 tick、命令面、
`effective_bond_contact_mm` 厚度换算）、`runtime/flow_engine.py`
（heater/force/force_search/bond_mark op）、`runtime/tuning.py`
（下位机调参存储）、`panel/index.html`（"温控压控"调试页）。

## 1. 流程时序（process/bond）

`POST /api/process/bond {site?}` → `build_bond_flow(engine, site)` 动态生成
流程"热压键合（process/bond TCB）"：

1. **守卫**（不满足 → 400）：晶圆在位 + WT_WaferVac 真空开、head 有 die、
   EGA 完成、本 site fine_align judge=pass（读 `eng.fine_align_result`）、
   本 site 未键合（workpieces 查 die.site 占用）。
2. **硅片台保温确认**：recipe `bond.wafer_preheat=true` 时
   `heater Heat_Dw 设定 wafer_temp_C + 等到温`（硅片台加热慢、平时常开
   保温，流程里只做幂等"等到温"确认，不频繁降温）。迭代 9 起另有
   `bond.wafer_keep_warm=true`（默认开）：**处方 apply / 启动加载即设
   Heat_Dw 目标 wafer_temp_C 并常开 PID**，bond 流程外也保温——本步
   发现已在带内则秒过；keep_warm=false 时维持旧行为（流程内才升温）。
3. **脉冲加热器升温**：`heater PulseHeat_Up → bond.head_temp_C`，
   ±2℃ 进带。
4. **两段速下压 + 慢速寻力**（迭代 9，替代旧"一步 2mm/s 长行程下压"
   ——旧方案慢速长行程曾致"等待 BS_Arm_Z 到位超时(30s)"）：
   - **快速段**：`move BS_Arm_Z → 有效寻力起始位`（机械常数
     `bond.head_z_search_mm` 裸值 + 片厚换算），速度
     `bond.fast_speed_mm_s`（默认 20mm/s）；
   - **慢速寻力段**：`force_search op` 以 `bond.search_speed_mm_s`
     （默认 0.2mm/s）下行，每 10ms 读力读数 oActualForce（含噪声，
     与面板同源），≥ `bond.touch_force_N`（默认 2N）即原地停轴并把
     实际接触位记到 `engine.bond_touch_pos`；行程超过 有效接触位 −
     `bond.search_overtravel_mm`（默认 1.0mm）仍未触力 → FAIL
     "寻力未接触"。寻力停点即下一步力闭环起点。
   - **接触确认**（2026-09-04 迭代 13；2026-09-06 迭代 17 改双源判定）：
     源一（轴链）核对 |实际接触位 − 期望有效接触位| ≤ 机械常数
     `bond.contact_verify_tol_um`（默认 50µm），超差 → FAIL"接触位异常
     （轴链：厚度/机械常数不符）"。源二（几何真值，迭代 17 新增）：
     轴链两端同源（actual=停轴位、eff=同一份常数+处方算出），结构性
     测不出常数错误/面高变化——故触力停轴瞬间另用 confocal 真值面高
     `die_surface_z`/`wafer_surface_z` 在键合 site 处核算
     `geom_gap_um`（die 底面 − 晶圆面，含 wafer z/rx/ry 与 die rx/ry
     坡度项；负值=弹簧压入=接触上，正常 ≈ −touch/k 几 µm），
     |geom_gap_um| 超同一容差 → FAIL"接触面间隙异常（几何真值）"。
     无晶圆/die 不在 head/裸引擎时几何分支跳过只留轴链判定。
     actual_contact_z / eff_contact / 偏差 µm / geom_gap_um / 触力 N
     写流程日志，并存 `eng.bond_contact_evidence`
     → bond_results `chain.bond` 段 `contact_verify` 留证（结果分析页
     键合参数卡可见，geom_gap_um 单列"几何间隙"行）。
5. **加压闭环**：`force op` 目标 `bond.force_N`——PID 调 BS_Arm_Z 压入量，
   力到带（±`force_tol_N`）。
6. **保压保温**：`delay bond.dwell_s`（力/温双保持）。
7. **释放交接**：force→0 → 键合头三吸盘 OpenPositive→OpenAir（沿用交接
   吹离序列）→ `wait_die` carrier=wafer（迭代 76 起由正压指令沿触发
   `head_positive_to_wafer`，先按实际几何垂直落片）→ **bond_mark 落位修正**：
   die.site 统一覆盖为当前键合位设计坐标，并写入本 site 真值残差
   （`bond_commit`/旧流程回退口径不变）。
8. **收尾**：BS_Arm_Z 抬 head_z_safe → 脉冲加热器按 recipe
   `head_cool_after` 决定关/保温 → 完成日志（已键合 die 走既有
   wafer_dies 层显示）。

**正压/通大气落片不等于键合成功（迭代 76/78）**：非流程状态手动给任一
键合头真空回路 `OpenPositive` 或 `OpenAir`，只要晶圆在位且头片完整投影在
片内，也会沿当前 XY 垂直落到晶圆，不再受 BS_Arm_Z 接触窗口或晶圆负压限制；
这种手动落片不生成 `bond_results`。完整键合仍须经过上述寻力、加压、保压和
`bond_mark`。无晶圆/投影在片外不伪造落片；有效翻转承接条件满足时仍优先
`head_to_flip`，通大气后等头负压实际解除再完成承接。

chain 六阶段（迭代 8 起）：…→ fine_align → **bond**；本 site 已键合 →
跳过 bond；head 无 die → bond 阶段报错中止。

### 1.1 独立 IO 搜力（迭代 78）

`SystemMachine.SS_Bonding.M_BS.ForceSearch` 是 PLC 风格组合动作，不经过上述
bond 流程：从当前 BS_Arm_Z 以默认 0.2mm/s 向下搜索，发布力达到默认 2N 立即
停轴，以 50ms 滑动平均力确认稳定 0.5s 后锁存 `oForceSearchDone`。最大默认
行程 5mm，超时 120s；`oForceSearchBusy/Done/Fail/Pos` 给出状态和停止位。
停止后不启动力 PID，也不搬动芯片或写键合结果。可选参数与失败语义见
《接口规范_V1.md》§6；它与本节的流程寻力、接触确认和后续加压是相互独立的接口。

### 1.2 接触位厚度换算（迭代 9）

机械常数 `bond.head_z_contact_mm` 重新定义为**裸接触位**（无晶圆无芯片、
键合头吸盘表面贴硅片台陶瓷面，默认 **−168.93** = 陶瓷面顶 884.9 − 头吸盘底
零位 1053.83；2026-09-06 迭代 17 修 round 误差：旧值 −168.9 比几何真值高
30µm，键合时 die 底面悬空 ~26µm「没接触上」，实测取证见
`Temp/_iter17_contact_report_prefix.txt`；更早的 −167.9 是含片厚 1.0 的
示教位）。
**有效接触位 = 裸接触位 + 晶圆厚（recipe wafer.thickness_mm）+ 芯片厚
（recipe film.dies.thickness_mm）**，由 `engine.effective_bond_contact_mm`
统一换算（flow 生成与 engine 真值力模型共用同一函数，防逻辑漂移）。
符号约定：BS_Arm_Z 下行=pos 减小，真值力 F=k·(contact−pos)；片变厚 →
压头更早接触 → 有效接触位上移（pos 增大方向）。数值例：裸 −168.93 +
晶圆 1.0 + 芯片 0.5 = **−167.43**。

## 2. TwinCAT 系列型 PID 公式与离散化（runtime/pid.py）

连续形式（TwinCAT PID 标准功能块，系列型/串行结构）：

```
G(s) = Kp · (1 + 1/(Tn·s) + Tv·s/(1 + Td·s))
```

离散**位置式**实现（周期 cycle_s，默认 4ms 对齐 PLC 扫描；engine tick
内按周期调用、ZOH 保持）：

- **积分**：位式累加 `I += e·T/Tn`；`Tn=0` 关闭积分通道（纯 PD）。
- **抗饱和**：条件积分法——先试算 `u=Kp·(e+I_new+D)`，输出触限且误差仍
  把输出往限外推时**冻结积分**（不重算 I），防 windup 超调尾巴。
- **微分滤波**：`Tv·s/(1+Td·s)` 一阶滤波的差分实现
  `D_k = Td/(Td+T)·D_{k-1} + Tv/(Td+T)·(e_k − e_{k-1})`；
  `Td=0` 退化为硬差分仍有限。首拍初始化不产微分冲击（激活无冲击）。
- **位置式输出**：u 是绝对执行量（温度回路=功率 0~100%，力回路=压入量
  mm），不是增量；输出限幅 `out_min/out_max` 每回路配置。
- **无扰切换**：`reset(out0)` 积分预置 `out0/Kp`；热改参数
  （`set_params`）不复位积分。
- 数值安全：参数热改成 NaN/Inf 时输出回中位、清积分/微分，不炸 1kHz
  tick。

## 3. 三回路对象模型与整定

| 回路 | 被控对象 | 输出 | 量程/限速 | 整定（tuning.json pid 组） |
|---|---|---|---|---|
| 键合压力 force | 弹簧接触：有效接触位以下 F=k·压入量（k=`bond_hw.force_spring_k_n_per_mm`=500 N/mm） | BS_Arm_Z 压入量 mm | — | kp=0.0008 / tn=0.1s / tv=0 / td=0.01s |
| 脉冲加热 head_temp | 一阶热对象 dT/dt=(P·gain−loss·(T−Tamb))/C | 功率 0~100% | 速率限 200℃/s，上限 450℃ | kp=3 / tn=1s / tv=0 / td=0.1s |
| 硅片台 wafer_temp | 同款一阶热对象 | 功率 0~100% | 速率限 0.733℃/s（511.4℃/11.6min 实测），上限 511.4℃ | kp=20 / tn=10s / tv=0 / td=1s |

读数噪声：力 ±1N、温度 ±0.5℃（recipe `sim_sensors.force_noise_N`/
`temp_noise_C`，迭代 9 起自机械常数 bond 段迁入测校页"传感器仿真"卡；
engine 读数路径 recipe 优先、旧机械常数键兜底）。

整定依据：

- **力回路**：弹簧对象是**静态增益**（无惯性），与 4ms 采样构成代数环，
  P 通路稳定条件 `kp < 1/k = 0.002`；取 kp=0.0008（环增益 0.4，裕量
  2.5×）。纯 P 有静差（弹簧对象比例增益有限），小积分 Tn=0.1s 消静差。
  实测（默认整定、50N 阶跃）：**到带（±1N）约 1.24s、零超调**，稳态
  误差 ≤±1N（=读数噪声量级，即力控精度规格）。
- **温度回路**：一阶热对象+热损 → 纯 P 有静差，小 I 消除；kp 按速率限
  内尽快爬升整定（PulseHeat kp=3、Heat_Dw kp=20——后者对象慢、允许更大
  增益）。实测：PulseHeat 25→300℃ 与 Heat_Dw 140→150℃ 稳态误差
  ≤±0.5℃（=温度读数噪声，即温控精度规格）。
- 微分默认全关（tv=0），Td 仅作预留；温度/力对象均低阶低噪，PI 已足。

## 5. 与参考项目对比

| 项 | 参考项目（d2w_sim_semiconductor_refactor） | 本实现 |
|---|---|---|
| PID 结构 | 增量式/简易 PI | TwinCAT 系列型**位置式**（对齐真机 PLC 功能块） |
| 抗饱和 | 无/输出钳位 | 条件积分（限幅联动积分冻结） |
| 微分 | 硬差分 | Tv·s/(1+Td·s) 一阶滤波差分 |
| 力对象 | 一阶趋近（speed→tau 映射） | 弹簧接触 F=k·压入量（物理接触模型），PID 调压入量 |
| 热对象 | 固定速率线性爬升 | 一阶热对象（功率→温升−热损）+速率限 |
| 参数面 | 配置文件 | tuning.json（/api/tuning）热改 + 面板"温控压控"页在线整定 |

## 6. 命令面兼容

- `BondingByForceManual {Force, Speed}`：Force=力回路 setpoint；
  **Speed 迭代 8 起弃用**（旧一阶 tau 映射废除），签名保留兼容。
- **力控模式状态机（迭代 29 起）**：BS_Arm_Z 默认归位置环（上电
  `force_mode=False`，力回路整体旁路，任意小步微调不弹回——此前力回路
  常开，<0.5mm 小步被 0.5mm re-anchor 阈值弹回，已根治）。进入力控：
  `BondingByForceManual` 任意 Force（含 0=受控卸力）或 force_target≠0；
  力控期内语义不变（PID 输出=压入量写轴、0.5mm re-anchor、moving 期
  不写轴）。自动退出：sp=0 且真值力 pv≤0（受控卸力完成）→ 回位控态，
  退出点压入量≤0 位置连续零残压；`reset_thermal_force`（一键复位）
  强制回位控态。`pid_public` force 段带 `active` 字段。
- `SetTargetTempWithPlan {Temperature, Steady_Time}` /
  `StopTargetTempWithPlan` / `StartPreHeat`：语义不变（到温
  PreHeatFinish、保温倒计时保留），底层由固定速率改为 PID+一阶热对象；
  `Heat_Dw` 停止后冷却改一阶热损（不再是固定速率线性下降）。
- `oCurTemp` 每 tick 写点位不变；state_public.pid 暴露三回路
  pv/sp/out+参数回显（面板 4Hz 轮询）。
