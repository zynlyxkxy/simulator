## 1. 测的是什么

**定义**：传感**读数链**（传感器→发布点位）的增益误差与零偏，输出为
机器常数 `sensor_calib` 组的标定补偿常数。三条读数链：

| 链 | 发布点位 | 标定常数（sensor_calib 组） |
|---|---|---|
| 键合头温度（heater=`up`） | `SystemMachine.M_Heater.PulseHeat_Up.oCurTemp` | `head_temp_gain` / `head_temp_offset_c` |
| 硅片台温度（heater=`wafer`） | `SystemMachine.M_Heater.Heat_Dw.oCurTemp` | `wafer_temp_gain` / `wafer_temp_offset_c` |
| 键合力 | `SystemMachine.SS_Bonding.M_BS.oActualForce`（`temp_force_calib.py:51`） | `force_gain` / `force_offset_n` |

（温度点位模板 `_TEMP_POINT` 与加热器↔常数名映射见
`temp_force_calib.py:52, 54-56`。）

两个互补输出口径：

- **重复性口径**：每个 setpoint 控稳后采 `samples` 点读数，给 mean
  与 **3σ**（显示重复性，含读数噪声与量化）——`measured.points[]`
  逐点 `{setpoint, mean, s3, n}`。
- **标定口径**：全部 setpoint 的读数均值对设定值做最小二乘拟合
  `mean = a·SP + b`，合成新标定常数 **gain_new = a·gain_cur、
  offset_new = b·gain_cur + offset_cur**（推导见 2.2）——指令→显示
  的增益系数与零偏，apply 直写后发布读数精确回真值。

**关键边界**：本族标定的是**显示/测量链**，不是控制链——温度/力
PID 全程消费**真值 PV**（见 2.1），校准不改变控制行为与稳定性，
只改变发布读数（操作屏显示、测校采样、上位机记录）与真值的偏差。

## 2. 传感链模型与算法推导（核心章）

### 2.1 读数链全链路：注入 → raw → 发布

```
真值 T（engine 物理状态：温度 h.cur / 力 force_value）
  │   注入侧（recipe sim_sensors 真值旋钮，仿真设备传感残差）
  ▼
raw = 真值 × (1 + gain_err) + offset_err + noise        （传感器特性）
  │   补偿侧（机器常数 sensor_calib 组，本族测校写回）
  ▼
发布读数 = (raw − offset_cal) / gain_cal                （点位发布）
```

- **注入侧**（`recipe.json:101-110`，缺省定义 `recipe.py:145-155`）：
  `temp_gain_err` / `temp_offset_C` 按加热器名分路
  `{"PulseHeat_Up": 0.002, "Heat_Dw": 0.002}` / `{…: 0.2, …: 0.2}`℃；
  `force_gain_err` / `force_offset_N` 为标量 0.003 / 0.05N。
  **默认注入值 = 标定前残差量级的合成取值（供测校演示闭环），
  待真机标定**；置 0 得理想传感链。校验域：增益误差 ±0.5、零偏
  ±50（℃/N）（`recipe.py:761-766`）。噪声同源：`temp_noise_C`
  每加热器 ±0.5℃ 均匀、`force_noise_N` ±1N 均匀（`recipe.json:86-90`）。
  engine 每秒重读并展开为按加热器字典（标量旧值兼容展开），
  缺省兜底全 0（`engine.py:1338-1357, 1360-1364`）。
- **补偿侧**：`sensor_calib` 组六键（`machine_constants.json:174-182`），
  标称 gain=1.0 / offset=0 = 标定理想（未标定默认）。校验域
  `SENSOR_CALIB_FIELDS`（`machine_constants.py:226-233`）：gain
  ("num", 0.5, 1.5)、offset ("num", −50, 50)。engine 每秒重读
  （`engine.py:1247-1276`）——gain 键带 `|v|>1e-12` 守卫（0 增益
  不载入防除零，正常路径又被常数校验域 [0.5,1.5] 拦住）、offset
  键允许 0；写回后读数链 1s 内热换档。
- **发布**：温度 `rd = (raw − o_cal)/g_cal`（`g_cal` 按加热器名取
  head/wafer 键），round 2 位落 `oCurTemp`（`engine.py:2190-2205`）；
  力同式取 force 键，round 3 位落 `oActualForce`
  （`engine.py:2249-2260`）。
- **PID 恒用真值 PV**：温度回路 `loop.update(h.target, h.cur)`
  （`engine.py:1407-1408`）、力回路 `loop.update(self.force_target,
  self.force_value)`（`engine.py:1438-1440`）——注入与补偿**只进
  发布读数链**，控制回路既不被注入带偏也不被校准改动（刻意口径：
  真机若控制器消费发布读数闭环，需另行评估，见 §7.3）。

推论：标定把"显示值"拉回真值后，**控制设定点与显示读数自洽**——
未标定时设 100℃ PID 把真值控到 100℃，但显示 100.4℃（默认注入），
操作员会误判超温；写回后显示回 100℃。

### 2.2 标定原理与合成公式推导

设注入 `(g_e, b_e)`、当前标定 `(g_c, o_c)`。setpoint = SP 时 PID 把
**真值**控到 SP（2.1），稳态读数均值（噪声零均消去）：

```
r(SP) = (SP·(1+g_e) + b_e − o_c) / g_c
```

对 N 个 setpoint 拟合 `r = a·SP + b`（`_ls_fit`，
`temp_force_calib.py:67-79`——纯 stdlib 闭式最小二乘，点数 <2 或
setpoint 全同 `sxx≤1e-18` 抛 ValueError）：

```
a = (1+g_e)/g_c          b = (b_e − o_c)/g_c
```

要求新标定 `(g_new, o_new)` 使发布读数 = 真值，即
`(1+g_e)/g_new = 1` 且 `(b_e − o_new)/g_new = 0`，解得：

```
gain_new   = 1 + g_e = a · g_c        = a · gain_cur
offset_new = b_e     = b · g_c + o_c  = b · gain_cur + offset_cur
```

即 `temp_force_calib.py:172-173`（温度）/ `:338-339`（力）的合成式。
**measured.gain 是绝对新常数口径**（含旧常数合成后的乘积值，≈1.002
而非增量 0.002），可直接 apply 直写。

**幂等性（闭环自检）**：写回后复跑，读数已回真值 → 拟合 a′≈1、
b′≈0 → gain_new = 1×gain_cur 不变、offset_new = 0×gain_cur+offset_cur
不变——常数收敛不动点。现场可用"标定→写回→复标应得 a≈1/b≈0"
做验收规程。

### 2.3 每 setpoint 时序（bond_temp_calib）

作业启动记录加热器原态（`temp_force_calib.py:100-103`：
`saved_target/saved_active`，finally 恢复用），读当前 sensor_calib
两键作 `(g_c, o_c)`（`:91-99`），然后逐 setpoint（`:113-155`）：

```
循环 si, sp in setpoints_c（每点首 _check_cancel + _progress，:114-116）：
    eng.heater_command(hname, "SetTargetTempWithPlan",
                       {"Temperature": sp})               （:117-118；
                        命令面语义 engine.py:1169-1174：active=True）
    等到温稳定（0.1s 轮询发布读数，:120-137）：
        |发布读数 − sp| ≤ settle_tol_c  连续 2s → 进采样
        超时 settle_timeout_s → CalibError（报当前温度与稳定带）
    采样 k = 1..samples（:140-146）：
        vals[k] = oCurTemp 发布读数；间隔 sample_interval_ms
        同步落 CSV 行 [sp, idx, reading]
    mean/3σ（:147-155）→ points.append({setpoint_c, mean_c, s3_c, n})
finally（:156-165）：恢复加热器原 target/active——原 active 则
    SetTargetTempWithPlan 回原 target；原 inactive 则
    StopTargetTempWithPlan（不等待降温）
拟合 r = a·SP + b → 合成 gain_new/offset_new（:170-175）
```

统计口径 `_mean_std` 总体 ddof=0（`metrology/repeatability.py:
186-191`），s3 = 3σ。发布读数量化 0.01℃（2.1），对 3σ 影响可忽略。

注意 settle 判据消费的是**发布读数**（含注入与旧补偿）：未标定时
读数系统性偏离 SP（`rd−SP ≈ SP·g_e + b_e`），默认注入下 100℃ 偏
+0.4℃、300℃ 偏 +0.8℃，仍在默认 tol=1.0℃ 带内可过；若注入残差更
大（或 setpoint 更高，如 450℃ 偏 +1.1℃）会 settle 超时——处理见
§7.1。

### 2.4 measured 双轨键与写回目标

结果组装 `temp_force_calib.py:176-201`。measured 同时携带：

- **显示别名键** `gain` / `offset_c`（panel/GUI 结果区显示与勾选
  提交用）；
- **常数名同值键** `head_temp_gain` / `head_temp_offset_c`
  （heater=up）或 `wafer_temp_gain` / `wafer_temp_offset_c`
  （heater=wafer）——按 `_HEATER_CAL_KEYS` 映射
  （`temp_force_calib.py:54-56`），与别名键**同值**，是 apply 的
  真实写回键（APPLY_GROUP_ROUTE 只认常数名，见 §6）；
- `points`：逐 setpoint `{setpoint_c, mean_c, s3_c, n}`（**只读
  不写回**）。

`current` 为 sensor_calib 组现值（常数名键）；`series` 为
`{setpoint_c: [...], samples: [[逐点读数], ...]}`；`detail` 回显
规范化参数 + `fit_forward {a, b}`（本次前向拟合系数，诊断用）。

### 2.5 CSV 列定义

`runtime/metrology_data/bond_temp_calib_<up|wafer>_MMDD_HH_MM_SS.csv`
（`_csv_write`，`extra_routines.py:92-105`；表头
`temp_force_calib.py:166-168`）：

```
setpoint_c, idx, reading_c
```

每行一个样本：所属温度点、点内序号、该次发布读数（℃）。回执带
`csv`（相对路径）/ `csv_name` 键。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 无工艺流程在跑（start 同步 `_check_flow_idle` 拦截，
   `calibration.py:1250`）。
2. 视觉链路 cv2 可用（start 统一拦截，`calibration.py:289-291`——
   本族虽不用相机，共享入口守卫不豁免）。
3. cam 恒 `"up"`（其他值 start 400，`calibration.py:181-185`）。
4. 温度项**无工件要求**；力项要求晶圆在位 + 键合头上有 die（缺任
   一 400"请先放入芯片和晶圆"，`calibration.py:1280-1282`），见 §5。
5. heater=wafer 时注意：硅片台常保温（`wafer_keep_warm`，
   `engine.py:1228-1235`）在作业期间被 setpoints 覆盖，finally 恢复
   作业启动时的 target/active——常保温流程安排上避开生产窗口。

### 3.2 参数选取

- **setpoints_c**：2~8 点，每点 (0,450]℃（up）/ (0,511.4]（wafer）；
  缺省 up=[100,200,300] / wafer=[50,80,110]（`calibration.py:
  1234-1249`）。建议 ≥3 点拉开跨度（2 点拟合无冗余，增益/零偏耦合
  全靠跨度解耦，量级式见 §7.2）。
- **samples / sample_interval_ms**：默认 20 点 / 100ms。噪声均消
  ∝1/√samples；点间隔无关拟合，只决定单点耗时。
- **settle_tol_c / settle_timeout_s**：默认 1.0℃ / 600s。wafer 升温
  ~0.7℃/s（`engine.py:88` 回退速率，tuning 可配），大跨度温点从
  常温爬升以分钟计，timeout 按温度预算给足。

（面板/GUI 录入入口见 §8.5。）

### 3.3 启动 / 中断 / 判读

```
POST /api/calibration/start
  {"routine": "bond_temp_calib", "cam": "up",
   "params": {"heater": "up", "setpoints_c": [100, 200, 300],
              "samples": 20, "sample_interval_ms": 100,
              "settle_tol_c": 1.0, "settle_timeout_s": 600}}
→ job_id；GET /api/calibration/status?job_id=N 轮询（progress 显示
  "升温到 xxx℃（i/n）"）；done 后 GET /api/calibration/result。
POST /api/calibration/cancel {"job_id": N}（协作式取消：下一采样/
  轮询边界生效 → canceled；finally 恢复加热器原态照跑，
  temp_force_calib.py:156-165、repeatability.py:169-177）
```

判读要点：

- `measured.gain` / `measured.offset_c`：合成新常数（绝对口径）。
  对照 `current`：gain 偏离 1、offset 偏离 0 即当前残差。
- `measured.points[k].s3_c`：各温度点读数重复性（逐样本 3σ；默认
  ±0.5℃ 均匀噪声下 σ=0.5/√3≈0.289℃，3σ 量级 ~0.87℃）。
- `detail.fit_forward.{a,b}`：前向拟合系数；a−1 ≈ 读数链相对增益
  残差、b ≈ 零偏残差（未标定理想回收时 a≈1+g_e、b≈b_e−o_c 合成
  值，见 2.2）。
- **闭环验证**：apply 写回后把加热器设到某一校验温度（如 100℃），
  稳态发布读数应回真值（容差带 ±0.6℃ 回归口径）；复标应得
  a≈1/b≈0（2.2 幂等性）。

## 4. 计算示例（示意数据手算复核）

**示例数据为示意**（默认注入 temp_gain_err=0.002、temp_offset_C=
0.2℃ 下的理想无噪推导值，非实测）；§4.3 为迭代 49 回归的历史实测
数字。

### 4.1 三点拟合 + 合成手算

heater=up、setpoints [100, 200, 300]℃、未标定（gain_cur=1.0、
offset_cur=0）。各点稳态读数均值（2.1 公式，噪声零均）：

| SP (℃) | mean = SP×1.002 + 0.2 (℃) |
|---|---|
| 100 | 100.4 |
| 200 | 200.6 |
| 300 | 300.8 |

最小二乘（mx=200、my=200.6）：

```
sxx = (100−200)² + 0² + (300−200)² = 20000
sxy = (−100)(100.4−200.6) + 0 + (100)(300.8−200.6) = 20040
a = 20040 / 20000 = 1.002
b = 200.6 − 1.002×200 = 0.2
合成：gain_new   = a·gain_cur            = 1.002×1.0 = 1.002
      offset_new = b·gain_cur+offset_cur = 0.2×1.0+0 = 0.2 ℃
```

写回后发布读数：`(T×1.002 + 0.2 − 0.2)/1.002 = T` ✓ 精确回真值
（噪声 ÷1.002，≈不变）。复标幂等：读数已回真值 → a′=1、b′=0 →
gain_new = 1×1.002 = 1.002、offset_new = 0×1.002+0.2 = 0.2，常数
不动 ✓。

### 4.2 未标定显示偏差（默认注入推导）

| 指令 | 显示读数 = SP×1.002 + 0.2 | 偏差 |
|---|---|---|
| 100 ℃ | 100.4 ℃ | +0.4 ℃ |
| 200 ℃ | 200.6 ℃ | +0.6 ℃ |
| 300 ℃ | 300.8 ℃ | +0.8 ℃ |

（PID 把真值控到 SP，偏差全部来自读数链注入——这正是"显示超温但
控制正常"的误判来源。450℃ 点偏差 +1.1℃ 已超默认 settle_tol_c=
1.0℃，见 §7.1。）

### 4.3 历史实测（迭代 49 回归记录）

`tests/test_metrology.py` i49 段实测（`backend/开发交接.md` 迭代
49⑤记载）：

    measured gain = 1.0032 / offset_c = 0.107（含噪声实现）

## 5. 键合力校准（bond_force_calib）

实现：`run_bond_force_calib`（`temp_force_calib.py:204-367`）。算法
与温度项同构（拟合/合成/双轨键/CSV 结构全同，2.2 公式原样适用），
差异在**激励施加方式**：温度项是控温等稳，力项是**先寻力接触、
再逐力点力控等稳**。

### 5.1 时序

```
前置守卫（start 同步）：晶圆在位 + head 有 die + 流程忙
读 sensor_calib force_gain/force_offset_n 现值（:211-217）
z_search  = bond.head_z_search_mm（默认 −166.9，:218）
BS_Arm_Z → z_search（_move_and_wait，:231）
寻力接触段（:232-271）：
    contact_est = bond.head_z_contact_mm（−168.93）+ 晶圆厚 + 芯片厚
    z_floor = contact_est − 1.0mm（再深撞吸盘面沙盒对，
                                   实测碰撞阈 ≈−171.6）
    eng.move(BS_Arm_Z, z_floor, 0.2mm/s)，20ms 轮询 oActualForce：
        读数 ≥ force_threshold_n（默认 2.0）→ 原地停轴 break（:254-257）
        到 z_floor 仍无触力 → CalibError"寻力未接触"（:258-261）
        120s 寻力超时 → CalibError（:262-263）
    停轴后 ≤10s 等 in_position（:265-271）
逐 setpoint 循环（:273-315）：
    eng.bonding_force(sp, 0)（BondingByForceManual 命令面，

        points.append({setpoint_n, mean_n, s3_n, n})

    bonding_force(0, 0) 受控卸力（≤30s 等 force_mode 自动退出，
        engine.py:1424-1432）+ BS_Arm_Z 抬回 0
拟合 mean = a·SP + b → gain_new/offset_new（:336-341，同 2.2 式）
```

### 5.2 力控稳定判据为何用滑窗均值

单点判定 `|读数−SP|<0.5N` 在默认 ±1N 读数噪声下命中率过低
（`temp_force_calib.py:279-281` 注释口径 ~38%）——永远攒不够
"连续 1s"。故取 **1s 滑窗均值在带**（窗口跨满 0.95s 且 ≥2 样本
才判定，`temp_force_calib.py:282-293`）：均值噪声 σ≈0.065N
量级（源码注释口径），工程惯例做法。温度项无此问题（±0.5℃ 噪声
vs 1.0℃ 带宽+2s 稳定，单点连判可行）。

## 7. 误差来源与注意事项

1. **settle 判据消费发布读数**：未标定时读数系统性偏离 SP
   （`rd−SP ≈ SP·g_e + b_e`，2.3）。默认注入下 300℃ 点偏 +0.8℃
   仍在 tol=1.0℃ 带内；更大残差或更高温点（450℃ → +1.1℃）会
   settle 超时。处理：先放宽 `settle_tol_c` 粗标一轮写回，再精标；
   或直接加大 tol。写回后读数回真值，settle 不再受影响。
2. **读数噪声与拟合不确定度**：均值噪声 σ_mean = σ_rd/√samples，
   增益拟合 σ_a ≈ σ_mean/√sxx（sxx 由 setpoint 跨度决定）。量级：
   温度 ±0.5℃ 均匀噪声（σ≈0.289℃）、samples=20、跨度 [100,300]
   （√sxx≈141）→ σ_a≈4.6e-4；力 ±1N（σ≈0.577N）默认噪声下两点拟合
   σ_gain≈0.026 远超容差带——回归测量期把 `force_noise_N` 降到
   0.1N 防 flake（`tests/test_metrology.py:5324-5346` 口径，
   finally 还原）。工程建议：力标定测量期降噪声档或加大 samples
   /拉宽力点跨度。
3. **PID 用真值 PV 是刻意口径**：校准只影响显示/测量链，不影响控
   制稳定性（2.1）。真机若控制器（PLC）消费发布读数闭环，注入/
   标定语义需另行评估——仿真口径不覆盖该构型。
4. **measured.gain 是绝对新常数口径**（含旧常数合成，≈1.002），
   可直接 apply 直写；与"增量倍数"口径差一个 gain_cur 因子。任务
   书 `|gain−0.998|≤0.01` 中的 0.998 = 1/1.002，为同一物理量的
   倒数口径——回归断言 `|gain−1.0|≤0.01` 两口径同带内覆盖
   （`tests/test_metrology.py:5240-5246`）。
5. **heater=wafer 打断硅台常保温**：作业期间 setpoints 覆盖
   wafer_keep_warm 目标，finally 恢复**作业启动时**的 target/
   active（`temp_force_calib.py:100-103, 156-165`）——若作业期间
   外部改过保温设定，恢复的是旧值。wafer 升降温慢（~0.7℃/s），
   作业耗时以分钟计。
6. **寻力未接触**：到 z_floor（期望有效接触位−1mm）仍无触力 →
   CalibError 提示检查晶圆/芯片/接触位常数
   （`temp_force_calib.py:258-261`）；接触位常数
   `bond.head_z_contact_mm` 与处方厚度错配是首查项。力作业结束恒
   受控卸力 + BS_Arm_Z 抬 0（`:316-332`），不留残压。
7. **cancel/恢复语义**：协作式取消下一采样/轮询边界生效，终态
   canceled；finally 恢复照跑（温度恢复加热器态；力卸力抬 0）。
8. **点数与退化**：setpoints 全同 → sxx≤1e-18 → 拟合抛
   ValueError（作业 error 终态）；2 点拟合无冗余，建议 ≥3 点且
   拉开跨度；增益/零偏解耦全靠跨度——只关心零偏时可缩小跨度，
   只关心增益时零点附近点价值低。
9. **重复标定幂等**：写回后复标应得 a≈1/b≈0、常数不动（2.2）——
   现场验收规程；若复标 a 持续偏 1，说明读数链存在非线性或温漂
   （本族模型外误差）。
10. **只读键勾选 400**：points 等只读键不在组路由表、也不是
    cameras 合法字段，panel 勾选提交会 400（§6.1）；panel 描述与
    本文档字段表均标注"只读不写回"。
