# ACS 701 接入方案 — 三条路评估与建议（W3 止损结论，2026-08-19）

> 背景：W3 原定 TCP 701 仿真路线（本机无 C 编译器，shim dll 路线已排除）。
> 第一步实证探针（`tools/acs_probe.py`，抓包记录见 `docs/acs701_抓包记录.md`）
> 发现：**ACSCL_x64.dll 的所有通讯函数都经由本机 UMD 服务（DCE/RPC + NTLM）
> 代理**，本机未装 ACS ADK，库在联网前就失败（err=0 秒回 / 197 服务器找不到），
> 抓不到任何 701 字节。按时间盒止损，本文档给出三条可行路线与成本评估。

## 路线 A：TCP 701 继续逆向（实证发现真机线格式）

- 前提（三选一）：
  1. **装了 ACS ADK 的机器**跑同一个探针——UMD 服务存在后 ACSCL 才会真正发包，
     中间人实验即可抓全 701 握手与指令字节（探针脚本已就绪，开箱即用）；
  2. ACS 官方 **Ethernet/通讯协议文档**（随 ADK 或向 ACS 索取）；
  3. **真机抓包**：上位机↔控制器之间镜像端口/交换机抓包（Windows 本机环回抓包
     需 npcap，且通讯在真机上位机与控制器之间，不在本机）。
- 之后落地：`runtime/acs_native.py` 起 TCP **9701**（避开真机 701；用户原定 91701
  超出端口上限），按抓包归纳的 framing 实现命令子集（握手 + Enable/Disable +
  MoveAbs + Halt + GetFPos/GetVel + GetMotorState + IsBufferRunning + SendRawCmd
  回显），内部翻译到 engine。
- 已知线格式线索（AcsClient.cpp 旁证）：ASCII 行命令 `\r` 结尾；应答
  [4 字节头][载荷][2 字节尾]；日志流 0xE5+3 转义、0xE6 结束。逆向工作量预计不大。
- 成本：拿介质/文档的沟通成本 + 1~2 天实现。**当前阻塞在前提。**

## 路线 B：shim dll 替身（上位机联调的最短路）

- 做法：写一个同名 `ACSCL_x64.dll`（导出 AcsClient.cpp 实际用到的 ~30 个函数：
  OpenCommEthernetTCP/CloseComm/GetLastError/GetErrorString/Transaction/
  Enable/Disable/ToPoint/Jog/Halt/GetFPosition/GetVelocity/GetMotorState/
  GetProgramState/RunBuffer/StopBuffer/Read|WriteReal|Integer/…），内部翻译到
  仿真语义层（9101 JSON 或新起轻量通道）。上位机工程替换 dll 即可直连仿真。
- **自带优势**：shim 是我们写的，不查 CodeMeter 授权、不依赖 UMD——路线 A 的
  两堵墙天然绕开。
- 注意：AcsClient 还会用裸 socket 直连 701 做 DISPCH/?COMMCH 握手与固件日志
  （`m_socket` 通道），shim 路线需配套一个 701 行通道仿真（工作量小，格式已知）。
- 成本：需要 C 编译器（VS Build Tools / MinGW，**本机当前没有**）+ 1~2 天。
- 风险：上位机若校验 dll 签名/版本则失败（未验证）；导出 ordinal 需与
  ACSCL_x64.LIB 一致（用 .def 文件按 ACSC.h 序号表导出即可）。

## 路线 C：维持现状 9101 JSON + 语义补齐（本轮已落地）

- 9101 自定义 JSON 协议继续作为 ACS 语义层入口；本轮补齐 `reset_error`
  （清 fault / 回零 fault 态，不改 enabled，与 W2 状态机对齐）。
- 成本：零。缺点：不是真机协议，上位机无法直接对接，只能用于我们自有的
  面板/测试/将来 L2/L3 进程。

## 建议

- **短期（现在）**：路线 C 已落地，回归防退化；文档与探针已备，路线 A/B 随时可续。
- **要为上位机真机联调做准备**：优先 **路线 B**——它绕开 UMD/CodeMeter 两堵墙，
  产出物（shim dll + 701 行通道仿真）直接可被上位机工程消费；前提是装 C 编译器。
- 路线 A 只在拿到 ADK 安装介质 / 官方协议文档 / 真机抓包条件后再推进；
  探针脚本 `tools/acs_probe.py` 到时装了 ADK 的机器上直接复用。
