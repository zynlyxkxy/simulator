# 工艺流程：芯片交接（flip_handoff / head_to_flip）V1

2026-08-26（第 1 版）。翻转吸盘上的 die 交给键合头（flip→head）及其逆向
吸回（head→flip）的参数化工艺流程——**机械常数（machine_constants.json
`flip_handoff` 组）驱动的动态流程生成**，接续 `flip_pick`（见
工艺流程_翻转取片_V1.md）之后，为后续上位机工艺开发打样。

- 生成器：`runtime/process_flows.py` → `build_flip_handoff_flow(engine)` /
  `build_head_to_flip_flow(engine)`，生成时刻实时读常数（PUT 改参后下一次
  运行自动跟随，天然热生效）。
- 执行：与 flip_pick 相同——`FlowEngine.run_steps`（共用状态机/pause/
  stop/step/日志），面板"工艺流程"tab 直接可见，`steps_def` 随响应返回。
- API：
  - `POST /api/process/flip_handoff {paused?}`——交接到键合头；
    flip 无 die → 400（先取片）；head 已有 die → 400（防叠片）。
  - `POST /api/process/head_to_flip {paused?}`——吸回翻转拾取头；
    head 无 die → 400；flip 已有 die → 400。

## 交接后芯片朝向

交接完成后 die 在键合头三吸盘上，**标记面朝下**（对晶圆——取片时标记面
朝下贴翻转吸盘，交接翻转一次后不变：键合头从上方吸住 die 背面）。
后续上精对准（up 相机从下方看 die 标记面）与键合（标记面对晶圆）都
依赖这个朝向。

## 工艺时序（flip_handoff，用户给定 3 步 + 安全确认/判定共 7 段）

| # | 步骤 | 轴/IO | 目标值来源 |
|---|------|-------|-----------|
| 1 | 安全确认（先到位再传送） | AS_X/AS_Y、BS_Arm_Z、FA_Z | `as_safe_xy_mm`、`head_z_safe_mm`、`fa_z_safe_mm`（flip_pick 组复用） |
| 2 | 呈现位幂等确认 | FA_Rx | `fa_rx_flip_rad`（0，吸盘面朝上） |
| 3 | 翻转模块送 die 到键合头正下方 | FA_X | **`fa_x_handoff_mm − off_x`**（粗对准补偿，见下） |
| 4 | 键合头下降接触 die 背面 | BS_Arm_Z | `head_z_touch_mm` |
| 5 | 键合头三吸盘开负压 + 逐路吸牢判定 | WT_BondingVac_1..3 `OpenNegtive` → `wait_grip` ×3（超时 `handoff_vac_timeout_s`） | 失败 → abort + 报警文本 |
| 6 | 翻转吸盘正压吹离 → 回大气 → 交接确认 | ChuckVac `OpenPositive`（600kPa 小正压推 die 背面主动脱离）→ `delay 200ms` → `OpenAir` → `wait_die carrier=head vacated=[flip]` | transfers.json `flip_to_head` 上升沿（oNegtiveState 在正压沿即落，交接在 OpenPositive 时触发；wait_die 复核双载体态） |
| 7 | 抬起 + 撤离 | BS_Arm_Z → `head_z_lift_mm`；FA_X → `fa_x_retreat_mm` | 机械常数 |

> 2026-08-28 迭代 7：破真空方式从"直接 OpenAir 通大气"改为
> **OpenPositive 正压吹离 200ms → OpenAir 回大气**。动机：键合头负压已
> 吸牢、翻转吸盘仍带真空时直接断真空，两侧真空"抢芯片"可能拉扯 die
> （真机掉片/偏移风险）；小正压主动把 die 吹向键合头侧，脱离是定向的。
> 气路模型三态（engine.py `air_command`）：OpenNegtive/OpenAir/
> OpenPositive（AIR_POS_KPA=600）；正压沿 `oNegtiveState` 即落 →
> transfers 的 vacuum_off 条件满足，交接沿=OpenPositive 时刻，时序上
> wait_die 仍能确认（复核 carrier/vacated 双态，不等沿）。

逆向 `head_to_flip` 镜像：安全确认 → FA_X 到 `fa_x_handoff_mm`（**不补偿**，
见下）→ BS_Arm_Z 降 `head_z_touch_mm`（正逆共用）→ ChuckVac 负压 + 判定
→ **键合头三吸盘 OpenPositive 吹离 200ms → OpenAir 回大气**（与正向
对称）→ `wait_die carrier=flip vacated=[head]`（transfers.json
`head_to_flip`）→ 抬起撤离。吸回后 die 标记面朝下贴翻转吸盘，与取片后
状态一致，**可再次交接（闭环可逆）**。

## 键合头正压/通大气的承接优先级（迭代 76/78）

通用 `head_positive_to_wafer` 规则：任一键合头真空回路接受
`OpenPositive`（`cmd_state=pos`）或 `OpenAir`（`cmd_state=air`）即可触发，
不等压力变化，不要求处于 bond 流程，也不受键合高度/晶圆负压限制。晶圆在位
且芯片完整投影在片内时，按释放时实际几何把世界 XY 逆算成晶圆设计坐标，
芯片垂直落片；日志分别为 `release=positive_vertical/air_vertical` + 实际 `site`。

本流程的 `head_to_flip` 仍是优先承接路径：规则带
`defer_to=head_to_flip`，只要 ChuckVac 负压已建立且 FA_X/BS_Arm_Z 在承接
窗口，就暂缓晶圆落片，等三路头负压解除后交回 flip。因此正常三路正压/通大气
吸回、测校交接循环和失败恢复不被手动落片规则抢走。若只有部分头回路释放，
来源侧尚未全部解除吸附，仍由承接侧保持芯片，不强行转移。

完整 bond 流程的 `bond_mark` 同时识别新旧两条 head→wafer 日志；旧
`head_to_wafer` 规则保留作兼容，直接 OpenAir 优先走当前 XY 垂直落片。
手动垂直落片只改变物料，不生成热压键合结果。

报警文本（上位机报警语义对照）：
- `交接失败：键合头负压未建立（WT_BondingVac 未吸牢）（N）`——wait_grip 超时；
- `交接失败：真空已建立但 die 未交接（carrier 未变 head，transfers.json
  flip_to_head 条件未触发）`——wait_die 超时；
- 吸回对应 `吸回失败：ChuckVac 负压未建立（翻转吸盘未吸牢）` /
  `吸回失败：真空已建立但 die 未交回（…head_to_flip…）`。

## 粗对准偏差补偿（符号约定，2026-08-26 与用户确认）

- 事实源（error_kinematics.json）：flip 工具点 (1199.85, 9.0)，FA_X
  dir=[1,0,0]（正向=世界 +x）；die 世界 x = 1199.85 + FA_X + site_x。
- 粗对准时 FA_X=`fa_x_pick_mm`=0、`coarse_die_center_mm`=(1199.85, 9.0)
  =工具点 xy，故 `coarse_offset` 步测得偏差 **off = die 在吸盘上的局部
  偏移 site**（取片偏移注入 pick_offset 的测量出口）。
- 键合头工具点 x=−42.5（BS_Arm_Z 只动 z）→ 对齐条件：
  1199.85 + FA_X + off_x = −42.5 → **FA_X = fa_x_handoff − off_x**。
- 例：测得 (+0.007, −0.0022)mm = die 比标定中心偏 +7µm → FA_X 目标
  = −1242.35 − 0.007 = −1242.357（"多走 −7µm"，**方向没搞反**）。
- **Y 向不补偿**（已知限制）：翻转模块无 Y 轴；off_y 仅记日志。键合头
  y=7.0 vs flip 工具点 y=9.0 固有 2mm 间隙，10mm die 不受影响。
- 偏差落存：`coarse_offset` 流程步把 {dx, dy, die, t} 写
  `eng.coarse_offset`，并随 `GET /api/flow/state` 外露（面板"芯片交接"
  组实时显示）。交接守卫按 die id 匹配，防止串用上一颗的旧测量；无匹配
  记录 → off=[0,0] 按名义位交接 + 日志警告。
- 逆向不补偿：交接后 die 在 head 上居中（transfers site=[0,0]），世界
  x=头心，FA_X 直接用名义 `fa_x_handoff_mm`。

## Z 几何（正逆向共用 head_z_touch_mm 的推导）

- Rx=0 呈现位：die 背面世界 z = 982.9 + FA_Z（FA_Z=0 时 982.9=coarse
  焦面，见 flip_pick 组 _note）。
- 交接时 FA_Z=`fa_z_safe_mm`=20 → die 背面 z=1002.9。
- 键合头吸盘底零位 z=1053.83（bond_head 工具点）→ 接触位
  **BS_Arm_Z = 1002.9 − 1053.83 = −50.93mm**（量程 −190~0 ✔）。
- **联动注意：`fa_z_safe_mm` 改了 `head_z_touch_mm` 要同步改**（差值恒
  = 982.9 + fa_z_safe − 1053.83）。
- 逆向同一接触位：吸回时翻转吸盘面贴 die 标记面，两吸盘间隙恒=die 厚，
  die 厚度在两侧相消，几何不变。

## transfers.json 对应规则

- `flip_to_head`（2026-08-26 占位改真实几何）：pose FA_X∈[−1242.35±10]
  （±10mm 容差吸收 µm 级补偿）、BS_Arm_Z∈[−50.93±3]；vacuum_on=
  WT_BondingVac_1..3、vacuum_off=ChuckVac。旧占位 −600/−185 作废（−185
  时压头底 868.8 会穿进翻转模块）。**改 `fa_x_handoff_mm`/
  `head_z_touch_mm` 超出容差窗口时须同步改本规则 pose**。
- `head_to_flip`（新增）：vacuum_on=ChuckVac、vacuum_off=
  WT_BondingVac_1..3，pose 同窗口；与 flip_to_head 真空条件镜像互斥。
- 两规则 site=[0,0]：交接后 die 居中于新载体（补偿生效时的物理真值）。
