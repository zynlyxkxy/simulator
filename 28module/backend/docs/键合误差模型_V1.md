## 1. truth 定义（迭代 20 修正）

**truth = 对准残差（align_resid）+ 键合头下降链（descent）+ 工艺项
（process_shift）**

- 迭代 20 前：truth = 精对准完成时刻的物理残差快照（phys_resid，此时
  BS_Arm_Z≈−119.83 还在测量高度）——键合头下降链物理上存在但无人
  采样，truth 不含键合动作本身的误差（物理错误，用户质疑成立）。
- 迭代 20 起：truth 在**键合接触时刻**计算（对齐参考项目 A/B 的
  commit 语义）：bond 流程 force_search 触力停轴后、加压/保压/落片前，
  `bond_truth` op 用当前 6DOF 真值位姿走精对准同一条 fit 管线
  （`_fa_truth_resid`：fit_rigid 双侧 + relative_delta，真值来源=
  kinematics 6DOF 模块位姿 + workpieces 上片/交接真值）算 die↔site
  真值残差 commit；`bond_mark` 落片时把 commit+process_shift 写进
  die["resid"]（视觉 wafer_die 真值消费，pi_measure 因此能测到 truth）。
- 力闭环/保压期间臂位置基本不动（压入量 µm 级，BS_Arm_Z 地图梯度在
  µm 跨度上可忽略），接触时刻采样即落位真值。

## 2. 分量数学形式

### 2.1 align_resid（对准残差，fa 时刻）

精对准确认环把**测量**残余驱动到处方阈值（confirm_tol_xy=0.15µm /
confirm_tol_rz=30µrad）以内后，真值残余 =

```
align_resid = 相机噪声传播 + 末次补偿轴重复性 + 计量帧标定残差
```

- 相机噪声传播：FAST 质心噪声 0.15px（处方 sim_sensors.fast_noise_px，
  默认 0.15px，测校页"传感器仿真"卡可设，热生效；2026-09-06 迭代 21
  自 vision_model.FAST_NOISE_PX 常量迁入）×
  k=0.6µm/px = 0.09µm/点/轴（1σ）；双侧各 4 标记刚体拟合 compose 后
  σ_xy≈0.064µm、σ_θ≈12µrad（标记半径 5.37mm）。
- 末次补偿轴重复性：WS_LS_X/Y 3σ=40nm、WS_Rz 3σ=2µrad（到位重采样，
  error_system.settle）；AS_X/Y 3σ=40nm 经测量帧传播为亚 10nm 级。
- 计量帧标定残差（机械常数 fine_align.frame_cal_x/y_um /
  frame_cal_rz_urad，默认 0=标定理想）：上/下相机两条测量链的帧间
  偏差经出厂标定后的常数残余，fa 解算按标定值修正测量 Δ
  （delta_used = delta_meas + frame_cal）。本机两测量侧几乎共用同一
  AS 位姿（WS 承担大行程，AS 只做微调——wafer 侧 AS=anchor+m+
  (WS−ws_ega) 中 anchor+m 与 (WS−ws_ega) 近乎相消），上/下相机安装
  零位 xy 同为 (−42.5,1.0)，故帧间差 ≈ AS 地图在毫米级跨度上的差值
  （亚 µm），标定后残差常数取 0；注入非零值直接平移到 truth（what-if
  演示标定残余）。
- **参考原点耦合假平移（迭代 20 根因修复）**：迭代 20 前真值通道
  `_fa_truth_resid` 用 `compose_rigid`（t_Δ = t_d−R_Δ·t_w）对**世界系
  点云**（质心距帧原点 |F|≈(42.5,7)mm）求复合平移——θ_Δ≠0 时含
  (I−R_Δ)·F ≈ θ_Δ×J(F) 假平移项：fa 残余 θ（噪声 σ≈12µrad）× F 的
  x 分量 42.5mm → 假 dy 散布 σ≈0.5µm（y 向放大、x 向仅 7mm——旧
  bond_results 的 dy 系统散布即此机制）；初测 θ_Δ≈−212µrad 时假平移
  达 (+1.5,+9.0)µm 量级。修复：真值/组间远场点云改用
  `relative_delta`（t_d−t_w = 两侧设计原点像之差，参考点无关）；
  测量闭环点云在头心相对近原帧（|F|~0.1mm，耦合项 ~20nm），
  compose_rigid 维持不动。
- 上游注入（上片 offset/rz、取片粗对准偏差、交接倾斜、调平残余）
  **经 EGA/交接补偿/精对准闭环消除，不进 align_resid**——若只有
  粗对准与交接误差而其他完美，fa 补偿后键合偏差→0（用户口径，对照
  实验见 §5）。

### 2.2 descent（键合头下降链）

fa 完成→键合接触之间，bond_head 链上只有 BS_Arm_Z 运动
（−119.83→−167.43，测量高度→接触位；BS_CAL_Rx/Ry 自调焦调平后冻结，
其误差两时刻相消）：

```
descent = [t_map(z_c) − t_map(z_m)]                     （地图直读差，系统项）
        + [r_map(z_c) − r_map(z_m)] × L_arm             （姿态差×杠杆，阿贝项）
        + 沿轴 repeat 重采样（仅 z 向，XY/Rz 无贡献）
```

- L_arm = 420.67mm（BS_Arm_Z 枢轴 z=1474.5 − 工具点零位 z=1053.83；
  枢轴随轴名义平移，杠杆长与臂位置无关——error_kinematics 串行链
  语义）。注意 BS_CAL 枢轴（z=1215.25）同样随臂平移，故调平补偿值
  的杠杆也不随下降变化。
- 当前合成地图（error_maps/，synthetic_engineering_representative）在
  两位姿间的差值实测：dx +1.22µm、dy +3.02µm、rx −4.9µrad、
  ry +30.2µrad、rz +18.0µrad；经 6DOF 串行链精确合成并走 fa 同一
  fit 管线后，端到端实测 descent ≈ **(−12.46, −0.66) µm / +19.29 µrad**
  （§5，与地图直读差粗估 (−11.5, +0.9)µm/+18.0µrad 一致到串行链
  交叉项量级；常数，逐 site/逐颗不变——地图只随 z 变，下降行程
  全片相同）。这就是参考项目 B「Z 行程阿贝误差」（其 6µrad×91mm
  杠杆差≈0.55µm）在本机的对应项；本机辅助轴旋转地图（10~30µrad
  量级）与杠杆更大，故系统项达 10µm 级。
- 该常数系统项的真实设备对应=出厂计量后可前馈抵消的固定偏差：
  用结果分析页「补偿量建议」（measured mean → fine_align.bond_offset_*
  一键应用）即可把全片 truth 均值压回 0 附近（参考项目 A 的
  bond_offset 前馈语义）。
- descent 的随机分量 ≈ 0：下降只动 BS_Arm_Z，其沿轴 repeat 重采样
  只影响 z；地图按名义位采样（不随 repeat 变）。

### 2.3 process_shift（工艺项，默认 0）

压合微滑移：加压/保压瞬间 die 相对 site 的不可再补偿滑移（对照参考
项目 B 的 bond_shift 150nm/1.5µrad 语义）。机械常数 bond 组
`bond_shift_xy_um` / `bond_shift_rz_urad` 为其 3σ；非零时 bond_mark
按 die 逐颗高斯采样（seed 化 RNG，run 内可复现）落进 die["resid"]
与 truth。默认 0=工艺项不建模。

## 3. 记录与展示

- `bond_results` 每条记录带 `truth_components`：
  `{align_resid, descent, process_shift, commit}`（µm/µrad 展示单位；
  truth 本体 mm/rad 全线约定不变），恒等式 commit=align+descent、
  truth=commit+process_shift。chain.bond_commit 段同步留证。
- 结果分析页「误差传递链」重构为**注入→补偿→残余**三段式：上片/
  粗对准/交接大数只作注入展示（不再与终值同阈值着色），标注补偿
  去向与「不进终值」；精对准卡残余=align_resid（进终值）；键合卡
  给下降链/压合微滑移分量；末卡 truth 分量分解表。

## 4. 量级预算表（当前配置，FAST 视觉）

| 分量 | 量 | 1σ 预算 | 备注 |
|---|---|---|---|
| align xy | 随机 | ~0.07µm（噪声传播）+ 确认阈值停早尾巴 | 3σ 实测见 §5 |

合成（无 bond_offset 补偿时）：truth 均值 = descent 常数（允许存在，
可用 bond_offset 前馈压零）；truth 3σ = align 散布。

## 5. 数值验证

- `Temp/_iter20_repeat.py`：同 site 重复键合 N=20（每颗 workpiece
  reset 全链重跑，含 EGA 重拟合）+ 对照组 B（注入 5µm 取片扰动，
  N=8）。实测（`Temp/_iter20_repeat_report.txt`，2026-09-07，
  relative_delta 修复后）：
  - truth（组 A，n=20）：dx mean=−12.497 3σ=0.206µm；dy mean=−0.758
    3σ=0.127µm；drz mean=+23.45 3σ=28.8µrad——3σ 与理论预算
    （0.20µm/36µrad）±50% 内一致；
  - 分量：align_resid mean=(−0.035,−0.102)µm/+4.1µrad；descent
    = (−12.463,−0.656)µm/+19.29µrad 且 3σ≤0.005µm（系统常数项，
    常数性验证通过）；process_shift=0（默认）；
  - 对照：注入 5µm 取片扰动后 truth 均值差 |Δmean|=(0.010,0.024)µm/
    2.4µrad——上游误差被补偿链消除，不进 truth（用户口径验证通过）；
  - 修复前对照（同脚本，compose_rigid 旧口径）：truth dy 3σ=1.388µm
    （θ 残余 × 43mm 参考原点杠杆的假平移），修复后 0.127µm。
- `Temp/_iter20_fullwafer.py --pi`：全片 149 对（145/149 ok，4 颗
  fa 确认环 warn→bond 守卫拒——既有行为，非本轮引入）实测：
  truth dx mean=−12.485 3σ=0.224µm、dy mean=−0.718 3σ=0.195µm、
  drz mean=+17.82 3σ=35.0µrad；descent 逐 site 常数

  r=+0.21/−0.06）；pi 全片复测 measured−truth mean≈0、
  3σ≤0.37µm/2.0µrad、max 0.33µm。
- REAL 模式 pi（`Temp/_iter20_pi_real.py`）：两次独立触发各 ~0.4-0.6s，
