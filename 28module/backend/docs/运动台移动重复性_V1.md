# 运动台移动重复性_V1

测校族：运动台水平向移动重复性，两个 routine 名、**同一套动态测法**
（起始位↔拍照位往复，到位拍照统计标记波动）：

| routine | 测什么 | 实现 |
|---|---|---|
| `ws_move_repeat` 硅片台（晶圆台）移动重复性 | 下相机固定看晶圆标记，WS_LS_X/Y 往复走动的标记像素波动（3σ nm）+ 各动轴到位 3σ(µm，**迭代 48 起=误差链 actual 编码器口径**) + 标记世界坐标 3σ | `extra_routines.run_ws_move_repeat`（`extra_routines.py:167-178`）→ 复用 `repeatability.run_dynamic`（`repeatability.py:352-424`，cam 恒 down，routine 名覆盖） |
| `as_move_repeat` 对准台移动重复性 | 键合臂（键合头芯片）固定，AS_X/Y 往复，上相机统计芯片 Mark 波动（**迭代 34 起相机可选 up 默认 / down 须 jog_group=align**，见 §1） | `extra_routines.run_as_move_repeat`（`extra_routines.py:181-193`）→ 复用 `run_dynamic`（routine 名覆盖） |

执行链：HTTP 作业（`POST /api/calibration/start` → 轮询 status →
result；PyQt5 测校 GUI「运动台移动重复性」页按"晶圆台/对准台"下拉
选 routine，走同一 HTTP 作业契约 0.5s 轮询）。与
`docs/相机对准重复性_V1.md` 动态 routine（`align_repeat_dynamic`）
**完全同一条执行链**——本文重点是双 routine 名路由与复用关系。

---

## 1. 测的是什么

**定义**：运动台在 起始位置 ↔ 拍照位置 之间往复 `repeat` 次，每次
到拍照位后识别标记，统计

- **相机像素口径**：标记质心 col/row 的 mean/std/**3σ**（px 与
  nm 双单位）——"下相机看晶圆标记 / 上相机看芯片 Mark"的读数
  综合波动（视觉识别噪声 + 台重复定位误差经像素当量折算）；
- **运动轴口径**：各动轴每次**到位后轴 actual 读数**的 3σ（µm，
  `3σ = 3×std_pop(actual)`，`repeatability.py:260-267`）——台重复
  定位精度直接读出（actual=误差链编码器口径，含每次到位 repeat
  重采样/误差地图，`_axis_actual`，`repeatability.py:135-153`）；
- **世界坐标口径**：标记世界坐标 mark_world 的 3σ（µm）——
  像素波动经当前机位反投影的世界系等效量。

对应设计草稿水平向重复性表的"硅片台"行与"对准台移动重复性"行
（需求出处 `extra_routines.py:8-13`）：D2W 水平向重复性验收就是
分别对晶圆台（WS_LS）与对准台（AS）各跑一遍本项。

**两个 routine 的差别只在"谁动、谁看"**：

| | 动轴（jog 组） | 观测相机 | 标记载体 |
|---|---|---|---|
| `ws_move_repeat` | WS_LS_X / WS_LS_Y（JOG_AXES down 组，`calibration.py:145`） | **恒 down**——晶圆标记只有下相机视野可见（下相机挂对准台、穿过对准台看晶圆面；上相机看的是键合头侧，物理上看不到晶圆标记） | 晶圆（随 WS 动） |
| `as_move_repeat` | AS_X / AS_Y（JOG_AXES up 组，`calibration.py:146`） | **默认 up**；迭代 34 起可选 down（须 jog_group="align"——下相机看对准台动，走位轴才是 AS_X/Y，`ROUTINE_CAM`，`calibration.py:165-166`） | 键合头芯片（键合臂固定） |

即 `align_repeat_dynamic` 在 down/up 相机 + 默认 jog 组下的
**行业语义别名**：ws_move_repeat ≡ align_repeat_dynamic(cam=down,
jog_group=wafer)；as_move_repeat ≡ align_repeat_dynamic(cam=up,
jog_group=align)（cam=down 时 ≡ align_repeat_dynamic(cam=down,
jog_group=align)）。独立 routine 名是为了 GUI 下拉与验收报告里直接
出现"硅片台/对准台"的语义标签。

## 2. 算法推导（复用 run_dynamic 的薄封装）

### 2.1 双 routine 名路由（代码结构）

```
ROUTINE_CAM = {"ws_move_repeat": ("down",),
               "as_move_repeat": ("up", "down")}   （迭代 34 相机可选；
                                        calibration.py:165-166）
ROUTINES 注册（calibration.py:131）

calibration.start：
    routine ∈ (ws_move_repeat, as_move_repeat)
    → _validate_extra（calibration.py:510-524）：
        repeat/wait_ms 用本族口径 [3,1000]/[0,60000]（默认 10/10，
        :501-502——比相机重复性的 repeat [10,1000] 宽）
        其余坐标/软限位/流程忙/模板必填校验**原样复用**
        _validate_repeatability("align_repeat_dynamic", cam, fake)
        （:517-520；fake 剔除 repeat/wait_ms 防子校验重验 :517-518），
        jog_group/jog_axes 一并提取进规范化 params 透传 run_dynamic
        （:521-523）；cam 由调用方按 routine + 观测口径决定（GUI：
        晶圆台→down / 对准台→up 或 down+align，metrology_gui
        StageMoveRepeat 契约）
    → 规范化 start_xy/photo_xy（绝对坐标）或 travel_mm 兼容别名
      （子校验 :402-439）写回 params

calibration._run 分流（calibration.py:1668-1681）：
    ws_move_repeat → _metro_extra.run_ws_move_repeat(
        self, tpl, repeat, wait_ms, start_xy, photo_xy, axes_touched,
        cam=cam_id, jog_axes_override=job["params"].get("jog_axes"))
    as_move_repeat → _metro_extra.run_as_move_repeat(...)

extra_routines.py：
    run_ws_move_repeat(svc, tpl, repeat, wait_ms, start_xy, photo_xy,
                       axes_touched, job=None, cam="down",
                       jog_axes_override=None):          （:167-178）
        from repeatability import run_dynamic
        return run_dynamic(svc, cam, tpl, repeat, wait_ms, start_xy,
                           photo_xy, axes_touched, job=job,
                           routine="ws_move_repeat",
                           jog_axes_override=jog_axes_override)
    run_as_move_repeat(..., cam="up", ...):               （:181-193）
        return run_dynamic(svc, cam, ..., routine="as_move_repeat",
                           jog_axes_override=jog_axes_override)
                                             ← 只差 cam 与 routine 名
                                             （cam/override 均由
                                              calibration._run 透传）
```

`routine` 形参一路传到结果组装 `_assemble(routine or
"align_repeat_dynamic", ...)`（`repeatability.py:421-424`）——
**除 result.routine 字段名与日志抬头外，数值路径与
align_repeat_dynamic 零差异**。视觉现场管理（REAL 模式/点灯/模板/
finally 恢复）由 `_run` 统一做（`calibration.py:1625-1730`）：模板用
`params.template_name`——迭代 34 起**必填**（空 → start 400 列可用
名；给了须已注册，calibration.py:344-360），作业不自建、结束不删。

### 2.2 每循环时序（run_dynamic 行号级，`repeatability.py:391-409`）

```
作业启动：
    _check_marks（:381 → :55-78）：视野内须有 ≥1 标记，否则 CalibError
        （无标记载体/没对准——防无特征面上 NCC 误判产垃圾散布）
    axes = jog_axes(cam)（:382 → :48-52 → JOG_AXES）或
           jog_axes_override（jog_group 提取的组——align_repeat_dynamic
           的 down+align、as_move_repeat 的 down 相机档均用；
           迭代 34 起 calibration._run 对 ws/as_move_repeat 也透传）
    各动轴 (axis, 当前位) append 进 axes_touched（:383-384，
        finally 由 calibration._run 统一恢复轴位，calibration.py:1701-1706）
循环 i = 0..repeat-1：
    _check_cancel(job, i+1)                       （:392）
    _progress "第 i/n 次往复+拍照"                 （:393-394）
    for axis in axes: _move_and_wait(axis, start_xy[k])   （:395-396）
    _sleep_ms(wait_ms)                            （:397）
    for axis in axes: _move_and_wait(axis, photo_xy[k])   （:398-399）
    _sleep_ms(wait_ms)                            （:400）
    col, row, ang = _shot(svc, cam_id, tpl, cam)  （:401 → :156-161）
    ctx.append(_context(...))                     （:405 → :99-132）
    for axis in axes: axis_log[axis].append(_axis_actual(svc, axis))
                                                  （:406-407——迭代 48 起
                                                    记 actual 编码器口径）
```

`_move_and_wait` 走引擎正常 move 路径（联锁/限位/干涉全过，等到位，
`calibration.py:1752-1763`）；`start_xy`/`photo_xy` 为**绝对坐标**
（mm）：X 分量给第 1 根轴、Y 分量给第 2 根（多轴时）。

### 2.3 采集字段

每拍 `_shot`（`repeatability.py:156-161`）：

- **col/row**：`svc._centroid(res, cam.score_threshold)`——判真点云
  质心（score ≥ 相机阈值的识别实例；亚阈值幽灵峰不进质心，
  `calibration.py:1779-1791`），px；
- **angle_deg**：`_angle_deg`（`:88-96`）——判真点的 lstAngle 均值，
  无角度信息时 None（本族 CSV 该列可能全 0 或缺列）。

每拍上下文 `_context`（`:99-132`，任何子项失败置 None 不阻塞）：

- `cam_world_mm`：相机世界位姿（camera_pose）；
- `mark_world_mm`：质心反算世界坐标（`cam.solve_pixel`）；
- `axes_pos` / `axes_actual`：全轴名义位 / 误差链 actual 读数
  （errors.actual，含 actual-value 分量）——actual 与 pos 的差即
  当次误差链注入，供阿贝/重复定位判读。

每循环 `axis_log[axis]`：动轴**到位后轴 actual 读数**（`_axis_actual`，
`repeatability.py:135-153`——`errors.actual(name, pos,
base=x_actual)`，含每次到位 repeat 重采样与误差地图，编码器口径；
errors 未挂/异常回退名义 pos）。**迭代 48 口径变更**：旧记名义
pos（仿真名义链精确到位，pos≡指令目标，axis_log 每循环恒等于
photo_xy、3σ 恒 0.0000µm——无物理信息，历史报告/截图里的
"到位 3σ=0.0000"即此旧口径）；现行 actual 口径下 3σ 即配置
repeat_3σ 量级（WS/AS≈0.04µm、FA_X≈0.5µm 级）。

### 2.4 指标公式（_assemble，`repeatability.py:229-305`）

像素当量（`nm_per_px`，`:42-45`）：

```
k_nm = cam.pixel_um / cam.mag × 1000      （machine_constants cameras 组）
     = 6.0µm/10×1000 = 600 nm/px           （up/down；coarse ≈ 9133）
```

统计（`_mean_std` 总体 ddof=0，`:186-191`）：

```
row/col : mean_px, std_px, s3_px = 3σ = 3×std_pop(像素)
          s3_nm  = 3σ × k_nm                （:240-244，round 2）
angle（有值才带）: mean_deg, std_deg,
          s3_urad = 3·σ_deg·π/180·1e6       （:251-257）
axes（仅动态）:  每动轴 mean_mm, std_mm,
          s3_um = 3×std_pop(actual)×1000    （:260-267——
                    迭代 48 起 σ 作用在到位 actual 序列上）
mark_world（context 全齐才带）: x/y 分量的
          mean_mm 与 s3_um = 3σ_mm×1000      （:268-280）
series_nm = px 序列 × k_nm（round 3，前端 nm 趋势图，:294-295）
```

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 标记载体在位：ws→**晶圆已上片**（down 视野有晶圆标记）；
   as→**键合头有芯片**（up 视野有 die Mark；可先跑芯片交接或
   prep_up 类就位流程）。as_move_repeat 选 down 相机时改为：
   对准台侧有 down 视野可见的标记（该档位下相机看对准台动）。
2. 视觉链可用 cv2（REAL 模式必需，`calibration.py:289-291`）。
3. 模板：params.template_name **必填**（迭代 34 起）——空/None →
   start 400 列可用模板名；给了须已注册（存在性 400，
   `calibration.py:344-360`）。作业不自建模板、绝不删用户模板。
4. **无工艺流程在跑**（动态动轴，start 校验流程 running/paused、
   全片键合、一键串联一律 400，`calibration.py:363-376`）。
5. 起始位/拍照位：start_xy/photo_xy 成对给出（绝对坐标，
   分量 ∈ [−10000,10000]mm 且在动轴软限位内，`:402-421`）；
   或 travel_mm 兼容别名（photo=当前位、start=photo−travel，
   [0.1,20]mm，`:422-439`）。往复行程越小越偏"纯重复性"，越大越
   含回程/螺距类系统误差——按验收口径选。

### 3.2 启动 / 中断 / 判读

```
POST /api/calibration/start
  {"routine": "ws_move_repeat", "cam": "down",
   "params": {"repeat": 10, "wait_ms": 20, "travel_mm": 2.0,
              "template_name": "必填-已注册模板"}}
→ job_id；GET status 轮询；done 后 GET result。
POST /api/calibration/cancel {"job_id": N}（下一循环边界生效；
finally 恢复轴位/光源/视觉模式照跑，calibration.py:1700-1722）
```

PyQt5 GUI（`metrology_gui/StageMoveRepeat.py`）：「晶圆台/对准台」
下拉 → `build_routine`（含"晶圆台"→ws_move_repeat，否则
as_move_repeat，`:138-142`）+ `build_cam`（晶圆台恒 down 且锁下拉；
对准台可选 up/down 默认 up，`:64-72,144-146`）+ `build_params`
（start_xy/photo_xy/template_name，模板名**必填**；对准台+down 相机
附 jog_group="align"，`:148-160`）；起始位/拍照位各配"取当前位"
按钮（按运动台下拉映射轴组回填）；结果区 row/col nm 双曲线
（series_nm）+ 轴到位统计表（stats.axes，`:176-`）。

判读要点：

- `stats.row/col.s3_nm`：标记像素波动主指标（与
  `align_repeat_dynamic` 同口径可比）；
- `stats.axes.{WS_LS_X,...}.s3_um`：**到位 actual 3σ**——迭代 48 起
  **非零为正常**（= 配置 repeat_3σ 量级，WS/AS≈0.04µm、FA_X≈0.5µm
  级；回归断言带 (0.002, 2.0)µm 且回拍照位 ±1µm 内抖动，
  `tests/test_metrology.py:849-857`）。**恒 0 反而说明 actual 读取
  失败回退名义**；迭代 48 前历史报告里的"0.0000"是名义 pos 旧口径
  （无物理信息），新旧数据不可直接比较；
- `stats.mark_world.{x,y}.s3_um`：世界系等效波动（= 像素 3σ 经
  solve_pixel 反投影，同量级互相印证）；
- 3σ 显著大于静态对准重复性（`docs/相机对准重复性_V1.md`）为
  正常现象——动态含一次完整往复的重复定位。

## 4. 计算示例（真实数据手算复核）

数据来自本后端 2026-09-10 实测（晶圆上片、REAL 链、默认常数）：
`runtime/metrology_data/align_stability_dynamic_0910_21_04_28.csv`
——down 相机 WS_LS 组、20 循环，列结构与 ws_move_repeat 落盘完全
一致（index,col,row,angle_deg,WS_LS_X,WS_LS_Y,mark_world×3,
cam_world×3；文件名族 ws_move_repeat 与 align_repeat_dynamic 共用，
§2.5）。**注意该历史 CSV 的动轴两列是迭代 48 前的名义 pos 口径**
（见 §4.2）；§4.1/§4.3 的像素与世界坐标口径与现行一致。

### 4.1 像素 3σ（n=20，k_nm=600）

col 列 20 行：1498.3230, 1498.1130, 1498.2750, 1498.2980,
1498.2820, 1498.3940, 1500.2390, 1498.6340, 1498.7950, 1498.8700,
1497.9840, 1498.3390, 1499.7610, 1500.2920, 1498.9040, 1498.5350,
1498.2340, 1498.2610, 1499.4010, 1498.6080

```
Σcol = 29974.5420   mean = 1498.7271 px
Σ(col−mean)² = 8.7751
σ  = sqrt(8.7751/20) = sqrt(0.438757) = 0.662388 px
3σ = 1.9872 px = 1.9872×600 = 1192.30 nm
```

row 列同理：Σrow = 29975.0580，mean = 1498.7529 px，
Σ(row−mean)² = 8.7710，σ = 0.662231 px，3σ = 1.9867 px =
**1192.02 nm**。与结果字段 `stats.col={mean_px:1498.7271,
s3_px:1.9872, s3_nm:1192.3}` / `stats.row={mean_px:1498.7529,
s3_px:1.9867, s3_nm:1192.02}` 一致。散布比纯静态（同期静态约
50~105nm，见相机对准重复性文档 §4）大一个量级——本次实测含少量
质心跳变点（如 col=1500.2390/1497.9840），动态往复 + REAL 识别
噪声的综合口径如实体现。

### 4.2 轴到位 3σ（axis_log——新旧口径差异，务必区分）

**本历史 CSV（迭代 48 前名义口径）**：WS_LS_X 列 20 行全部 =
58.2162000、WS_LS_Y 全部 = 111.6102000（= 当次 photo_xy）：

```
mean = 58.2162000 / 111.6102000 mm
σ    = 0   →   3σ = 0.0000 µm
```

即旧口径 `stats.axes = {WS_LS_X: {mean_mm: 58.2162, s3_um: 0.0},
WS_LS_Y: {mean_mm: 111.6102, s3_um: 0.0}}`——仿真名义链精确到位
（pos ≡ 指令目标）的设计行为，**3σ 恒 0 无物理信息**（repeat/map
误差只进 actual 读数与图像，i29 回归
`tests/test_metrology.py:1246-1327` `test_i29_repeat_into_image`
同口径）。

**现行口径（迭代 48 起，actual 编码器读数）**：同一作业今天重跑，
WS_LS_X/Y 两列记每循环到位后 `errors.actual` 读数——围绕 photo_xy
±repeat 抖动，到位 3σ = 3×std_pop(actual)。迭代 48 定向实测
（`Temp/_i48_mrep_dyn.py`，同 travel 口径）：

```
WS_LS_X 到位 3σ = 0.031 µm      WS_LS_Y 到位 3σ = 0.045 µm
```

即 `stats.axes = {WS_LS_X: {mean_mm: 58.2162, std_mm: ~1.0e−5,
s3_um: 0.031}, …}`——与配置 repeat_3σ≈0.04µm 量级一致。**新旧数据
不可直接比较**：历史报告里的"到位 3σ=0.0000"不是"当年设备更好"，
是名义口径无信息；现行非零值才是台重复定位精度的真读数。

## 5. 误差来源与注意事项

1. **视觉识别噪声**：REAL 链质心噪声（recipe `sim_sensors.
   fast_noise_px`，默认 0.15px 档）是像素 3σ 的底噪；低对比模板
   下经验噪声上限把散布压在物理封顶内（迭代 28 模板响应度机制）。
2. **台重复定位误差**：每循环一次完整 起始位→拍照位 往复，动轴
   repeat/map 误差在到位时刻经 6DOF 真值链进图像（i29 注入点
   核验：`tests/test_metrology.py:1246-1327`）——动态 3σ² ≈ 静态
   3σ² + 注入 3σ²（量级式断言同段）。
3. **到位读数口径（迭代 48 起 = actual）**：axis_log/CSV 动轴列与
   stats.axes 现记误差链 actual（含到位 repeat 重采样+误差地图，
   编码器口径，`repeatability.py:135-153,406-407`）；名义 pos 恒
   等于指令目标只作参照（context.axes_pos）。actual 读取失败
   （errors 未挂/异常）回退名义 pos——此时 3σ 恒 0，判读时注意
   区分"回退"与"高精度"。GUI 链 20 列 CSV 的四轴名义/actual 列
   同口径（/api/axes 取数）。
4. **angle 列**：本族标记（cross/quad）识别带角度时才有 angle_deg
   列与 stats.angle；全 None 时 CSV 无该列、stats.angle=None——
   不是缺数据。
5. **回程/行程选择**：travel 越大，往复带入的丝杠回程、导向系统
   迟滞越显著；验收口径要对齐行程（草稿建议值见
   `测校/测校文档/设计草稿/`）。
6. **cancel/恢复语义**：协作式取消在循环边界生效（`:169-177`）；
   finally 恢复 axes_touched 轴位 + 恢复光源/模式（用户模板不删），
   status=done 的语义包含现场已恢复（`calibration.py:1723-1727`）。
