## 1. 测的是什么

**定义**：相机镜头/传感器装配绕光轴的微小转角（rad 量级）。迭代 38/39
起该物理量在建模里拆成**真值/认知两个角色**（真值/认知分离）：

| 角色 | 载体 | 进哪条链 | 说明 |
|---|---|---|---|
| **物理安装旋转角·真值** `view_rot_deg`（°） | `vision_cameras.json` 每相机域（`/api/vision/camera/config` 在线改，±5°） | **只进投影链**：`project_rel` 先施加 R(−view_rot)（相机 +θ 逆时针 → 图像内容转 −θ，`runtime/vision_model.py:514-528`）；`camera_pose` 的 yaw 同取 view_rot（`:694-708`） | 物理世界的真值旋钮；REAL 渲染/识别结果即"原始传感器系"，不再剥旋 |
| **控制器认知** `rot_mrad`（mrad） | `machine_constants.json` cameras 组（本 routine 的写回目标） | **只进反算链**：`solve_rel` 在逆 dir/swap 后施加 R(+rot)（`vision_model.py:543-561`）——所有"像素→世界"反算（`solve_pixel`，`:563-574`）按认知修正 | 认知与真值相等（θ_b=θ_t）时 solve∘project=恒等（补偿到位）；不等时世界解相差旋转 (θ_b−θ_t)——认知不准则测量带旋转误差，符合真实 |

**补偿二选一**（GUI/panel 结果区"视场旋转建议"块同口径文案）：
① **写回 rot_mrad = 带入计算修正世界坐标**（反算链生效，图像不变——
沿用本 routine 的 apply 写回）；② **物理转正 = 直接旋转视场**
（view_rot_deg 调为 `cur − measured×0.0572958°`，图像去旋，
**rot_mrad 须置 0**）。**二选一，都做 = 双重补偿。**

`rot` 标错 → 粗对准"拍照→芯片世界坐标"反投影整体带一个与半径成比例
的切向误差。标定思路（附件 4.3）：给标记一个**纯 X 世界位移杠杆**，
无微旋时像素位移应严格落在映射后的轴向（水平/垂直按 dir/swap 定号）；
像素位移向量偏角即微旋角。迭代 38/39 起**输出约定重钉**：
`measured.rot_mrad` = 物理角真值 θ_t 的估计（=建议写入 rot_mrad 的
认知值）——映射末端翻一次符号（投影链是 R(−θ_t)，旧双角色公式
（观测角−指令角）会得 −θ_t；翻号使输出=θ_t，θ_b=θ_t 时
solve∘project=恒等）。符号锚定用例=`i39.microrot_view_rot_loop`
（注入 view_rot=+0.4mrad 等效 → measured≈+0.4mrad，
`tests/test_metrology.py:4001-4085`）。

**两台相机同挂对准台**（`vision_cameras.json` mount.module=
align_stage）：`up`/`down` 由 `AS_X/AS_Y` 走位、动相机 = 等效动标记，
标记相对相机**反向**移动（`rel=−1`）；`coarse` 由 `FA_X` 走位
（`rel=+1`）。迭代 34 起 down 相机可选 `move_stage="wafer"` 改走
晶圆台 `WS_LS_X/WS_LS_Y`（`rel=+1`，动标记载体口径，见 §2.2）。
三相机 `dir/swap` 组合（迭代 35 起默认统一 dir=(+1,−1)、swap=False，
各机现值以 machine_constants 为准），同一公式经映射链各自收敛
各自的 `rot_mrad`。

## 2. 算法推导

实现：`metrology/extra_routines.py` 的 `run_camera_microrot`
（`extra_routines.py:886-1014`）。`_best_peak` 复用旧链
（`metrology/microrot.py:55-67`，单特征模板匹配取最强判真峰——滑窗
幽灵峰会拖偏质心，故不用 `_centroid` 多点平均）。

### 2.1 映射链推导：undo swap → undo dir → 指令角减观测角（末端翻号后）

设标记相对相机的世界位移 `w`（mm，焦面），相机物理安装旋转真值
θ_t。正链（`vision_model.py:514-528`）逐步施加：

```
p = S · D · R(−θ_t) · w / k        （像素位移，k = 像素当量 mm/px）
  R(−θ_t)：真值微旋（相机 +θ 逆时针 → 图像内容 −θ）
  D = diag(dir_x, dir_y)（定号，±1）
  S = swap_xy 互换（swap_xy=True 时 u,v 对调，:526-527）
```

已知实测像素位移 `p_obs=(dc,dr)` 反解 θ_t——逐步做**精确逆**
（`extra_routines.py:959-961`）：

```
① undo swap（正链最后施加，逆序最先撤）：
      (u,v) = (dr,dc) if swap_xy else (dc,dr)          (:959)
② undo dir（D 自逆，分量乘回 dir）：
      q = (u·dir_x, v·dir_y) = R(−θ_t)·w / k           （同 :959）
③ 取角分离 θ_t：R(−θ_t) 给向量减角——q 的方向角 = w 的方向角 − θ_t，
   故 rot_i = ang_cmd − atan2(q_y, q_x)                 (:960)
   （= 指令角 − 观测角；迭代 38/39 符号重钉——旧双角色约定下投影链
     施加 R(+rot)、公式为 观测角−指令角，两式在该约定下等价；
     新架构投影链改 R(−θ_t)（view_rot 真值），若沿用旧式输出为
     −θ_t，故映射末端翻号，输出=物理角真值估计）
④ wrap 到 (−π, π]：rot_i = (rot_i+π) % 2π − π          (:961)
```

`ang_cmd` 是指令运动方向角（`extra_routines.py:939-940`）：

```
dx_cmd = (photo_pos2[0] − photo_pos1[0]) × rel          # 标记相对相机的
ang_cmd = 0.0 if dx_cmd > 0 else π                      # 纯 X 杠杆 → 0/π
```

`rel` 即 `MICROROT_AXES[(cam, move_stage)]` 的标记相对相机符号
（`runtime/calibration.py:190-193`）：down+align / up → AS_X/AS_Y
rel=−1，down+wafer → WS_LS_X/WS_LS_Y rel=+1，coarse → FA_X rel=+1。
动相机时 rel=−1：相机走 +Δ 等效标记走 −Δ，`dx_cmd` 同步翻 π，像素
位移向量也翻 π，`atan2` 差值不变——各 (cam, move_stage) 档同一
公式各自收敛（符号自洽性，`extra_routines.py:902-911` docstring；
i31/i32/i34/i39 实测验证）。

`φ_raw = −atan2(dr, dc)`（:954）是**参考 SOP 原式**：像素行轴向
下生长，取负把 (dc,dr) 转成"y 向上"数学角。它不进统计，仅作诊断
（`series.phi_raw_urad` 与 CSV `phi_raw_rad`）。

### 2.2 move_stage 两档：方向逻辑推导（迭代 34 新增）

下相机有两个可走的台，物理图像完全不同：

| move_stage | 走位轴 | rel | 谁在动 | 标记相对相机运动 |
|---|---|---|---|---|
| `align`（默认） | AS_X / AS_Y | −1 | **相机**（下相机挂对准台，随 AS 平移） | 反向：相机 +Δ ⇒ 标记 −Δ（等效动标记） |
| `wafer` | WS_LS_X / WS_LS_Y | +1 | **标记载体**（晶圆随 WS 平移，相机固定） | 正向：WS +Δ ⇒ 标记 +Δ（动标记载体） |

用户口径"两种模式计算方向和逻辑不一样"的准确表述是：

- **指令方向相反**：同一"拍照位 1→2"（轴坐标 x1→x2，x2>x1）下，
  align 档标记相对相机的位移是 −Δx（相机动），wafer 档是 +Δx
  （标记动）——`dx_cmd`（ang_cmd 的符号来源）随之翻 π；
- **公式相同**：映射链 `undo swap → undo dir → 指令角减观测角 →
  wrap` 一行未动，两档共用（`extra_routines.py:959-961`）；
- **rel 符号承载差异**：两档的差别全部收进 `MICROROT_AXES` 的
  rel 符号（`calibration.py:190-193`），rel 翻 π 时**指令方向角
  （ang_cmd）与像素位移向量同步翻 π，atan2 差值不变**——所以同一
  公式各自收敛各自的 rot_mrad（`extra_routines.py:902-911`
  docstring；align 档 i31/i32/i39 实测、wafer 档 i34 回归
  `test_i34_microrot_wafer_stage` 均验证）。

取值约束（`calibration.py:1344-1360`）：down 可选 `align`（默认）/
`wafer`（其它值 400）；up 恒 `align`（传 `wafer` → 400）；coarse
恒 FA_X 不参与本选择（传入忽略）。

### 2.4 每轮时序（行号级伪代码）

作业现场（模式/灯/模板/轴位）由 `calibration._run` 通用路径管理
（`:1625-1730`：切 REAL、亮灯 `:1645-1649`；用户模板在 start 已校验
必填、不自建 `:1635-1639`；finally 恢复轴位/灯与模式 `:1700-1722`）。
worker 本体：

```
jog = MICROROT_AXES[cam_id]["align" if coarse else move_stage]
                                            # ((axis, rel), ...)（:919-920）
axes = [AS_X, AS_Y]（down/up）或 [WS_LS_X, WS_LS_Y]（down+wafer）
                                            或 [FA_X]（coarse）（:921）
_check_marks(svc, cam_id, cam)             # 视野须有标记（:922；
                                           #  repeatability.py:55-78）
axes_touched += 各轴当前位                 # finally 恢复用（:923-924）
dx_cmd = (pos2[0]−pos1[0]) × rel           # 标记相对相机指令位移（:939）
ang_cmd = 0 if dx_cmd>0 else π             # 指令方向角（:940）

for i = 1..repeat（:944）：
    _check_cancel(job, i)（:945，协作式取消：本轮边界生效）
    _go(photo_pos1)（:947，逐轴 move_and_wait 到绝对位 :930-932）
    wait（:948）
    c1, r1 = _snap()（:949，_best_peak 取最强判真峰，:934-936）
    _go(photo_pos2)（:950）
    wait（:951）
    c2, r2 = _snap()（:952）
    dc, dr = c2−c1, r2−r1                  # 像素位移向量（:953）
    phi_raw = −atan2(dr, dc)               # 参考原式（诊断，:954）
    u, v = (dr,dc) if swap_xy else (dc,dr) # ① undo swap（:959）
    rot_i = ang_cmd − atan2(v·dir_y, u·dir_x)  # ②③ undo dir + 指令角减
                                               #    观测角（:960）
    rot_i = wrap(rot_i, ±π)                # ④（:961）
    追加 phis/raws/pts/rows；记 cycle 日志（:962-973）
```

采集字段（每轮 `pts[i]`，`:964-966`）：`i, col1, row1, col2, row2,
phi_urad`（= rot_i×1e6，注意命名是历史兼容——它是映射后的 rot，
不是 φ_raw）。

### 2.5 统计口径与 CSV

`_mean_std` 总体口径 ddof=0（`metrology/repeatability.py:186-191`）：

```
mean = (1/n)·Σ rot_i        → measured.rot_mrad = mean×1000（mrad，:983）
std  = sqrt((1/n)·Σ(rot_i−mean)²)
stats.rot = {mean_mrad, mean_urad, std_urad, s3_urad=3σ}   （:990-993）
```

CSV（`camera_microrot_MMDD_HH_MM_SS.csv`，表头 `:974-977`）：

```
index, col1, row1, col2, row2, d_col_px, d_row_px, phi_raw_rad, rot_urad
```

每行一轮：`d_col_px/d_row_px` 是位移向量（= col2−col1 / row2−row1），
`phi_raw_rad` 诊断量，`rot_urad` = rot_i×1e6（统计对象）。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. cv2 可用（start 统一拦，`runtime/calibration.py:289-291`）。
2. 相机视野内有标记（作业首 `_check_marks` 硬拦；无标记载体/没对准
   报清晰错误，`metrology/repeatability.py:55-78`）。
3. 无工艺流程在跑（本 routine **有** busy 硬守卫，
   `calibration.py:1329-1343`）。
4. **模板已注册**：迭代 34 起无自建临时模板路径（原 601px 特征
   ROI 自建已删），template_name 必填且须已在视觉页注册。
5. **拍照位须显式示教**（photo_pos1/2 必填，无缺省路径）：两点位
   须纯 X 方向（y 容差 0.01mm）且在走位轴软限位内。杠杆大小
   （X 间距）由用户自定——start 不再限上下限、不再做模板可达
   窗口预估；间距过大出视场由作业期识别失败自曝
   （`i34.microrot_tight_span_ok`，0.2mm 小间距旧口径会 400"过小"、
   现通过校验，`tests/test_metrology.py:3415-3448`）。
6. coarse：蓝膜上有 die，FA_X 把 die 移到粗对准视野中心附近
   （两拍照位之间）。
7. down 相机选 `move_stage="wafer"` 时：晶圆已上片、down 视野有
   晶圆标记，拍照位给 WS_LS_X/WS_LS_Y 轴位（rel=+1 动标记载体
   口径，§2.2）。

### 3.2 拍照位选取

- coarse：`[0,0] → [-10,0]`（FA_X 行程 [−1250,0]，负向是自然方向，
  `dx_cmd<0 → ang_cmd=π`，见 §4.4）；间距 ≥10mm 是 SOP 建议口径
  （角度解算精度需要）——**迭代 34 起非后端硬校验**，更大/更小
  由模板匹配可达范围决定。
- up/down（move_stage=align）：居中后 `x0±0.5~0.7mm` 横跨
  （上/下相机 k=0.6µm/px，1.2mm 杠杆 ≈ 2000px 位移向量，短杠杆
  换角度灵敏度靠低噪声补，见 §5.1）。
- down + move_stage=wafer：给 WS_LS_X/Y 轴位的纯 X 横跨位
  （下相机固定看晶圆标记动，回归用 ±0.5mm，`tests/test_metrology.
  py:3386-3395`）。
- **无缺省拍照位**（迭代 34 删"当前位±delta 越限自动反向"路径），
  必须显式给（GUI「取当前位」按钮按 相机+运动台 映射的运动组
  回填当前位，`CameraMicrorotCalib.py:107-139`）。

### 3.3 启动 / 中断 / 写回 / 判读

```
POST /api/calibration/start
  {"routine": "camera_microrot", "cam": "down",
   "params": {"template_name": "必填-已注册模板",
              "photo_pos1": [x0-0.6, y0], "photo_pos2": [x0+0.6, y0],
              "move_stage": "align",     # 仅 down 相机可选；缺省 align
              "repeat": 10, "wait_ms": 20}}
→ job_id；GET status 轮询；done 后 GET result。
POST /api/calibration/cancel {"job_id": N}（协作式取消：本轮边界生效
  → canceled；轴位/灯/模式恢复照跑，calibration.py:1700-1722）
POST /api/calibration/apply {"job_id": N, "fields": ["rot_mrad"]}
  → measured.rot_mrad 写回 cameras.{cam}.rot_mrad（原子落盘+热生效；
  响应带 derived.k_um_px 派生值，calibration.py:1448-1507）
```

判读要点：

- `measured.rot_mrad`（物理角真值估计）vs `current.rot_mrad`（控制器
  认知现值）：偏差量级 = 运动台直线度/误差链与匹配亚像素系统差的

## 4. 计算示例（手算复核）

**示例数据为示意**（数值自洽，口径为现行迭代 35 dir 默认 (+1,−1) +
迭代 38/39 符号约定；与任何历史 CSV 无一一对应关系）。相机常数
（`runtime/machine_constants.json` cameras 组 + `vision_cameras.json`
view_rot_deg；rot_mrad 是控制器认知可被写回改动，表中"认知现值"为
迭代 38 迁移口径参照）：

| cam | dir_x | dir_y | swap_xy | view_rot_deg（物理真值） | rot_mrad（认知现值） | k µm/px |
|---|---|---|---|---|---|---|
| coarse | +1 | −1 | False | 0.0458366°（=+0.8mrad） | 0.8 | 2.74/0.3 = 9.133 |
| up | +1 | −1 | False | −0.0286479°（=−0.5mrad） | −0.5 | 6.0/10 = 0.6 |
| down | +1 | −1 | False | 0.0177044°（=+0.309mrad） | 0.309 | 6.0/10 = 0.6 |

### 4.1 down 相机：逐式手算（第 0 轮）

AS_X 居中横跨 ±0.6mm 级显式拍照位（`pos2>pos1 → dx_cmd>0 →
ang_cmd=0`；位移向量 dc≈2000px×0.6µm/px ≈ 1.2mm）。设物理真值
θ_t=+300µrad（=view_rot 0.0171887°）：第 0 行 col1=500.0000,
row1=1500.0000, col2=2499.9999, row2=1500.6000。

```
dc = 2499.9999 − 500.0000  = 1999.9999 px
dr = 1500.6000 − 1500.0000 =    +0.6000 px
φ_raw = −atan2(dr, dc) = −atan2(0.6000, 1999.9999) = −3.00000e−4 rad
      → CSV phi_raw_rad = −0.000300 ✓
① swap_xy=False → (u,v) = (dc, dr) = (1999.9999, +0.6000)
② q = (u·dir_x, v·dir_y) = (1999.9999×1, 0.6000×(−1)) = (1999.9999, −0.6000)
③ rot_0 = ang_cmd − atan2(q_y, q_x) = 0 − atan2(−0.6000, 1999.9999)
        = +3.00000e−4 rad = +300.000 µrad
④ wrap 不动作
      → CSV rot_urad = 300.000000 ✓（=注入真值 θ_t，符号约定锚定）
```

几何读法：θ_t>0 时图像内容反向旋转，纯 +X 杠杆的像素位移向量向
**下**偏（dr>0）；`q` 的方向角 = 指令角 − θ_t，故 `指令角 − 观测角`
还回 θ_t。（对照：dir_y=−1 使 ② 的取负与 φ_raw 的取负相消，本相机
特例 `rot_i ≡ −φ_raw`——勿据此推广到别的相机/别的指令方向。）

### 4.2 down 相机：前 3 轮统计手算

rot_urad 前 3 = [300.000, 302.412, 297.155]：

```
mean = (300.000 + 302.412 + 297.155)/3 = 299.856 µrad
σ    = sqrt( (0.144² + 2.556² + (−2.701)²)/3 ) = 2.148 µrad
3σ   = 6.445 µrad
```

即 `stats.rot = {mean_urad: 299.856, std_urad: 2.148, s3_urad: 6.445}`、
`measured.rot_mrad = 0.300`（mean×1000 round 3）。低噪声档
（fnp=0.05）下逐轮散布 µrad 级；默认噪声档（0.15px）散布放大
~3×（量级式见 §5.1）。

### 4.3 结果对照

```
measured.rot_mrad = 0.300
current.rot_mrad  = 0.309（认知现值）→ 差值 = −0.009 mrad
```

写回 rot_mrad=0.300 后认知逼近真值（θ_b→θ_t），solve_pixel 链世界解
旋转误差 → 0（闭环断言口径见 `i39.microrot_view_rot_loop`：注入
view_rot=+0.4mrad → measured≈+0.4（dev<0.25）→ 写回认知后
solve∘project 对 0.72mm 半径点世界误差 <0.25µm，
`tests/test_metrology.py:4001-4085`）。或走物理转正：view_rot_deg
调为 `0.0171887° − 0.300×0.0572958° ≈ 0°`（图像去旋，rot_mrad 须置
0）——二选一。

### 4.4 coarse / up 相机：映射链分支复核（第 0 轮逐式）

**coarse**（dir=(+1,−1)，rel=+1；FA_X 行程 [−1250,0]，显式给负向位
`pos2<pos1 → dx_cmd<0 → ang_cmd=π`；设 θ_t=+800µrad，10mm 杠杆
→ 1094.9px）：col1=2048.0000, row1=952.0000, col2=953.1095,
row2=951.1241。

```
dc = −1094.8905, dr = −0.8759
φ_raw = −atan2(−0.8759, −1094.8905) = +3.1407927 rad（≈π 近旁，诊断量）
① (u,v) = (−1094.8905, −0.8759)
② q = (−1094.8905×1, −0.8759×(−1)) = (−1094.8905, +0.8759)
③ rot_0 = π − atan2(0.8759, −1094.8905) = 3.1415927 − 3.1407927
        = +8.00000e−4 rad = +800.000 µrad
④ wrap 不动作      → CSV rot_urad = 800.000000 ✓
```

**up**（dir=(+1,−1)，rel=−1 动相机；`pos2>pos1` 但 dx_cmd=(x2−x1)
×(−1)<0 → ang_cmd=π；设 θ_t=−500µrad，1.2mm 杠杆 → 2000px）：
col1=2500.0000, row1=1500.0000, col2=500.0000, row2=1501.0000。

```
dc = −2000.0000, dr = +1.0000
φ_raw = −atan2(1.0000, −2000.0000) = −3.1410927 rad
① (u,v) = (−2000.0000, +1.0000)
② q = (−2000.0000, −1.0000)
③ rot_0 = π − atan2(−1.0000, −2000.0000) = 3.1415927 − (−3.1410927)
        = 6.2826853 rad
④ wrap：6.2826853 − 2π = −5.00000e−4 rad = −500.000 µrad
      → CSV rot_urad = −500.000000 ✓
```

三行数据把 swap/dir/ang_cmd 三个分支各走了一遍，公式每一步均可
独立复算；φ_raw 逐轮在 π 近旁的摆动是负 X 位移向量的表象，看 rot
（wrap 后）才是物理角。

## 5. 误差来源与注意事项

1. **角度噪声量级式**（`metrology/microrot.py:81-82`）：
   `σ_φ ≈ √2·σ_pt / (L·√R)`——σ_pt 单点质心噪声(px)、L 杠杆(mm
   折 px)、R 轮数。up/down 杠杆可用性由**用户模板匹配可达范围**
   决定（迭代 34 起 start 不限间距上下限：FOV 1.8mm 下
   1.4mm≈2300px 仍作物理参考，间距过大出视场由作业期识别失败
   自曝）；要压亚 mrad 偏差须降噪声档/加轮次（回归 run 段统一
   `fast_noise_px=0.05` 低噪声档）；coarse 10mm 杠杆
   （~1095px）信噪比天然好一个量级。φ_raw 逐轮在 π 近旁的 ±几千
   µrad 摆动是负 X 位移向量的表象，看 rot（wrap 后）才是物理角。
2. **mean 是集总量**：运动台直线度/误差链分量与模板匹配亚像素系统
   差都集总进 `measured.rot_mrad`——仿真里它与真值（view_rot 等效
   值）比对（阈值 250µrad），真机同样只能拿到这个集总值。
3. **模板策略敏感**：① 模板须已注册且在两拍照位均可匹配（迭代 34
   起无自建 601px 特征 ROI 路径，也无 start 可达窗口预估——选
   模板/定间距是用户职责）；② 远距滑窗的纹理/边缘幽灵峰（score
   贴阈）会把多点质心拖离真峰~870px（`_best_peak` 注释，
   `metrology/microrot.py:55-67`）——故取最强判真峰而非质心。
4. **rel 符号自洽（两档同式）**：动相机（down+align / up，rel=−1）
   与动标记载体（down+wafer / coarse，rel=+1）的差别全部收进
   MICROROT_AXES 的 rel 符号——rel 翻 π 时 ang_cmd（被减数）与
   像素位移向量同步翻 π，atan2 差值不变，公式一行未动
   （`extra_routines.py:902-911`）；若误用动标记载体口径
   （JOG_AXES down→WS_LS）会双重取反——MICROROT_AXES 与 JOG_AXES
   已分离（`calibration.py:145-147, 190-193`）。
5. **cancel/恢复语义**：取消本轮边界生效；轴位（axes_touched）/
   灯/模式由 `calibration._run` 通用 finally 恢复
   （`:1700-1722`），用户模板绝不删。
6. **写回语义（补偿①）**：apply 把 `rot_mrad` 写回 `cameras[cam]`
   组（APPLY_GROUP_ROUTE 无该键 → 缺省相机组，
   `calibration.py:1487-1501`），`constants.update` 全量校验失败 →
   400，成功则原子落盘 + `apply_constants` 热生效（`:1502-1503`；
   `vision_model.solve_rel/solve_pixel` 立即按新认知反算）；响应
   `derived.k_um_px` 供 GUI 展示。GUI 写回按钮在作业 done 后启用，
   写后建议人工核一眼再保留（`CameraMicrorotCalib.py:317-349`）。
7. **物理转正语义（补偿②）**：`POST /api/vision/camera/config
   {cam, view_rot_deg}`（±5° 钳位）把物理真值调小 measured 等效量
   ——图像内容去旋；此后 **rot_mrad 必须置 0**（真值已正，认知再
   补偿=双重补偿）。二选一口径的 GUI/panel 文案与视觉页
   "真值 vs 认知换算差值"提示同出迭代 38/39。
