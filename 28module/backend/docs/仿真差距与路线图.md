## 2. 差距清单（按优先级）

### P3.5 — 伺服环本体【结论：不做】
真机三环对上位机联调/流程验证/测校语义无可观测差异；到位整定模型已落地
（一阶滞后+settle 窗口）。若将来需要频响/过冲形态，最多升级二阶阻尼解析
响应，不实现三环 PID。

收集器）。未做：报警系统（点位表报警阈值未实现）、仿真状态快照/回放。

## 3. 质量把控原则（后续开发遵守）

1. 每次迭代必须跑 `tests/test_client.py` 全量回归，性能三项（tick 1000Hz /
   推送 500Hz / 延迟 p50<1ms）不许退化；
2. 新功能必须带用例；误差、物理参数进配置不进代码；
3. 前端可感知的行为变化必须更新 `开发交接.md` 和相关 docs；
4. 任何"看起来差不多"的简化都要在文档里写明与真机的差异（见 仿真实现原理.md §2）；
5. **接口/参数契约是已冻结的代码事实，文档与代码同迭代更新**（迭代 50 起；
   验收数值章节标"待真机实测"不阻塞契约先行）。
