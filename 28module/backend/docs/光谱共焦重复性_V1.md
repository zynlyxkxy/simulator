# 光谱共焦重复性_V1

测校族：光谱共焦（上/下探头）静态连读重复性，单个测校 routine，
探头即"相机"参数（cam=down/up 实为探头选择）：

| routine | 测什么 | 实现 |
|---|---|---|
| `confocal_repeat` 光谱共焦重复性（下探头） | 下探头对晶圆面固定机位连读的读数散布（mean/std/**3σ**，µm） | `metrology/extra_routines.py:113-158`（`run_confocal_repeat`，cam=`down`） |
| `confocal_repeat` 光谱共焦重复性（上探头） | 上探头对键合头吸盘面（或芯片交接后 die 面）连读的读数散布 | 同上，cam=`up` |

执行链：HTTP 作业（`POST /api/calibration/start` → 轮询 status → result；
PyQt5 测校 GUI 光谱共焦页走同一 HTTP 作业契约，0.5s 轮询）。纯静态
连读——全程不动任何轴、不点光源、不过视觉链。共焦读数的物理模型
（量程、中点共面约定、近大远小、噪声源）见
`docs/调焦调平与高度链_V1.md` §1（`runtime/confocal.py:11-21`），
本文不重复抄。

---

## 1. 测的是什么

**定义**：机位完全静止（不动轴、不换被测面）的条件下，对同一被测面
连续读 `repeat` 次共焦位移计读数，统计读数序列的

- `mean_um`：读数均值——近大远小模型下读数 ≈ 量程中点 ± 面高偏差，
  均值偏移提示机位/被测面设置类系统差（如下探头读数偏离中点 350µm
  很多 = 相机离焦，对应调焦链失准）；
- `std_um` / `s3_um`（**3σ，主指标**）：读数重复性——共焦传感器自身
  噪声 + 被测面/机位微扰的综合读数稳定性（对应设计草稿 D-07「测量
  系统重复性验证」）。

与相机对准重复性（`docs/相机对准重复性_V1.md`）的区别：本项**完全
不拍照**，读数来自 `engine.confocal.read(probe)` 的物理读数模型
（`runtime/confocal.py:177-235`），不含视觉识别噪声；采集字段里
`z_surface_mm`/`z_focus_mm` 给出当次读数背后的真值面高与焦面，供
判读"读的是哪个面"。

**两个探头的被测面**（`runtime/confocal.py` 真值面高函数）：

| 探头 | 朝向 | 被测面 | 量程外常见原因 |
|---|---|---|---|
| `down` 下探头 | 朝下 | 晶圆面（陶瓷面 884.9mm + t_w） | 晶圆不在位 |
| `up` 上探头 | 朝上 | 键合头吸盘面（1053.83+BS_Arm_Z mm；有 die 时 die 底面） | BS_Arm_Z 未调到观测位（无 die 时约 −118.8mm 读吸盘面）；或先做芯片交接再上测 |

## 2. 算法推导

实现：`metrology/extra_routines.py` 的 `run_confocal_repeat`
（`extra_routines.py:113-158`）。输入已由 `calibration.start` 校验
规范化：probe（=cam 参数，down/up）、`repeat`（默认 10，[3,1000]，
`runtime/calibration.py:354-355`）、`wait_ms`（默认 10，[0,60000]；
探头域/共焦挂载校验 `calibration.py:356-362`）。

### 2.1 每循环时序（行号级）

```
作业启动（calibration._run 分流 → _run_simple 壳，calibration.py:950-954）：
    confocal not attached → 抛错（start 已拦 400，运行期再守卫，
    extra_routines.py:118-119）
循环 i = 0..repeat-1（extra_routines.py:123-140）：
    _check_cancel(job, i+1)                       （:124，协作式取消边界）
    _progress(job, i+1, repeat, "第 i/n 次读数")    （:125）
    _sleep_ms(wait_ms)                            （:126，简单 time.sleep）
    r = engine.confocal.read(probe)               （:127，同步物理读数）
    r["ok"] 假 → 抛 RuntimeError("共焦读数失败")    （:128-129）
    reading_um is None 或 valid=False
        → 抛 RuntimeError("共焦读数无效（量程外…）") （:130-134，见 2.3）
    reads.append(float(reading_um))               （:135）
    valids/zs/zfs 同 append                        （:136-138）
    _log "read: %.3f um" / "cycle time"           （:139-140）
```

无基线、无 warm-up、无现场管理（`_run_simple` 壳不做视觉/轴/光源
恢复，`calibration.py:1088-1099`）——共焦读数不动任何执行器。

### 2.2 单次读数的采集字段（`confocal.py:177-235`）

`read(probe)` 返回 `{ok, probe, reading_um, valid, z_surface, z_focus}`：

| 字段 | 含义 | 物理模型 |
|---|---|---|
| `ok` | 读数通道本身正常（probe 合法、常数/引擎就绪） | ok=False 只在基础设施异常时出现 |
| `reading_um` | 本次读数（µm，4 位小数） | 下探头 `mid_down + (z_surface − z_focus)×1000 + noise`；上探头反向（`confocal.py:15-18`） |
| `valid` | 读数是否有效 | raw+noise 落在量程 `[0, confocal_range_um]`（默认 0~700µm）内才 True（`confocal.py:226-231`） |
| `z_surface` | 被测面世界 z（mm，6 位小数） | 真值面高函数（晶圆面/吸盘面/die 面分支） |
| `z_focus` | 共焦焦面世界 z（mm） | 相机焦面公式（中点共面约定：`confocal_mid_*_um` ↔ 相机最佳焦面） |

噪声 `noise ~ N(0, σ)`，σ=recipe `sim_sensors.confocal_sigma_um`
（按探头 up/down 逐实例，`confocal.py:19-21`；默认 0.05µm 档）——
**读数散布的仿真真值主项就是这个 σ**（加噪后越出量程即 valid=False）。

### 2.3 统计口径

`_mean_std`（`metrology/repeatability.py:165-170`），**总体 ddof=0**：
`mean = (1/n)·Σx_i`，`σ = sqrt( (1/n)·Σ(x_i − mean)² )`，`n = repeat`，
`3σ = 3σ`。结果组装（`extra_routines.py:147-154`）：

```
series.reading_um = [round(v, 4) for v in reads]
stats.reading = {mean_um: round(mean,4), std_um: round(σ,4),
                 s3_um: round(3σ,4)}
```

### 2.4 为什么"读数无效 = 测校失败"而不是静默剔除

设计决策（docstring 明示，`extra_routines.py:114-116`）：

1. **量程外是机位/被测面异常信号，不是噪声**。真实测校中读数掉到
   量程外意味着：晶圆没上片（down）、BS_Arm_Z 没到位（up）、或被测
   面出了共焦量程（机位系统差）——继续测出来的"3σ"不含这些样本，
   指标被系统性美化。
2. **静默剔除会破坏样本完整性**。repeat 是事先定的采样数，剔除后
   n<repeat 的统计不再对应"连读 repeat 次"的验收口径，也无法与
   CSV 逐行对账。
3. **失败即 error 态 + 明确提示**。`:130-134` 的错误信息直接给出
   处置建议（"down 需晶圆在位；up 把 BS_Arm_Z 调到约 −118.8mm
   （无 die 读吸盘面）或用芯片交接后再测"），引导工程师修机位后
   重测，而不是拿残缺的 3σ 交差。

同一口径贯穿所有测校 routine：拍照类找不到标记也是抛错进 error 态
（`repeatability.py:135-140`），绝不以 0 值/缺行混入统计。

### 2.5 CSV 列定义

`runtime/metrology_data/confocal_repeat_{down|up}_MMDD_HH_MM_SS.csv`
（命名/防撞名 `_csv_write`，`extra_routines.py:89-102`；列常量
`CONF_COLS`，`extra_routines.py:86`；逐行写出 `:141-145`）：

```
index,reading_um,valid,z_surface_mm,z_focus_mm
```

每行一次读数：序号、读数（µm，4 位小数）、有效标志（0/1）、真值面高
（mm）、焦面（mm）。作业日志同步落 "read: %.3f um" 与 "cycle time"
行（`:139-140`）。

## 3. 详细测试步骤（SOP 级）

### 3.1 前提条件

1. 后端已启动、共焦传感器已挂载（start 校验
   `calibration.py:356-358`，未挂载 → 400 "confocal not attached"）。
2. 被测面在位：**down 须先上片**（`POST /api/workpiece/wafer`）；
   **up 须先把 BS_Arm_Z 调到观测位**（无 die 时约 −118.8mm 使吸盘面
   进上探头量程中点附近；或先做一遍芯片交接作业让 die 位于键合头）。
3. 无需 cv2/视觉链（本 routine 不拍照；start 的全局 cv2 拦
   `calibration.py:181-183` 对全部 routine 生效，REAL 环境需装）。
4. 无并发测校作业（作业互斥 409，`calibration.py:198-200`）。

### 3.2 启动 / 中断 / 判读

```
POST /api/calibration/start
  {"routine": "confocal_repeat", "cam": "down",
   "params": {"repeat": 10, "wait_ms": 20}}
→ job_id；GET /api/calibration/status?job_id= 轮询（GUI 0.5s，
  metrology_gui/job_base.py:74,155-178）；done 后 GET result。
POST /api/calibration/cancel {"job_id": N}（协作式：下一循环边界生效，
  repeatability.py:148-156）
```

PyQt5 GUI（`metrology_gui/ConfocalRepeat.py`）：探头下拉「下/上」→
`build_cam`（下→down / 上→up，`ConfocalRepeat.py:57-58`）、参数区
repeat/wait → `build_params`（`:60-62`），ROUTINE 固定
`confocal_repeat`（`:24`），走 job_base 的 HTTP 作业轮询；结果区
逐次读数趋势曲线（标题 3σ µm）+ N/mean/std/3σ 统计表
（`:64-86`）。

判读要点：

- `stats.reading.s3_um`：读数重复性（主指标）。
- `stats.reading.mean_um` vs 中点 `confocal_mid_*_um`（默认 350）：
  偏差大 = 相机离焦/机位系统差（转调焦链处理，见
  `docs/调焦调平与高度链_V1.md`）。
- 作业 error 且信息含"量程外"：按 2.4 的处置建议修机位重测，
  不要把 error 当噪声大。

## 4. 计算示例（真实数据手算复核）

数据来自本后端 2026-09-10 实测（晶圆在位、默认机器常数
`confocal_mid_down_um=350`、量程 700µm、噪声默认档）：
`runtime/metrology_data/confocal_repeat_down_0910_21_04_58.csv`
（down 探头，repeat=5，wait_ms=20）。

### 4.1 down 探头（n=5）逐步

CSV 5 行读数（µm）：349.0000、349.0620、349.0559、348.9727、349.0484。

```
Σx   = 349.0000+349.0620+349.0559+348.9727+349.0484 = 1745.1390
mean = 1745.1390 / 5 = 349.0278 µm
偏差  = [−0.0278, +0.0342, +0.0281, −0.0551, +0.0206]
Σ(x−mean)² = 0.00077284+0.00116964+0.00078961+0.00303601+0.00042436
           = 0.00619246
σ    = sqrt(0.00619246/5) = sqrt(0.00123849) = 0.0352 µm
3σ   = 0.1056 µm
```

与结果字段一致（组装时 round 4 位）：`stats.reading =
{mean_um: 349.0278, std_um: 0.0352, s3_um: 0.1056}`。CSV 同时记录
`valid=1`、`z_surface_mm=885.900000`（晶圆面）、
`z_focus_mm=885.900960`（焦面）——每行都成立，无一进 2.4 的失效
分支。均值核验读数模型（下探头
`reading = mid_down + (z_surface − z_focus)×1000 + noise`，
`confocal.py:15-16`）：350 + (885.900000 − 885.900960)×1000 =
349.04µm——与实测均值 349.0278µm 差 0.012µm，正是噪声均值偏移
量级；即"近焦但非严格中点"的正常机位。

### 4.2 up 探头对照（同批次，
`confocal_repeat_up_0910_21_05_12.csv`，n=3）

读数：350.0688、350.0181、350.0261。

```
Σx = 1050.1130   mean = 350.0377 µm
偏差 = [+0.0311, −0.0196, −0.0116]
Σ(x−mean)² = 0.00096928+0.00038285+0.00013379 = 0.00148592
σ  = sqrt(0.00148592/3) = 0.0223 µm
3σ = 0.0668 µm
```

与 `stats.reading={mean_um: 350.0377, std_um: 0.0223, s3_um: 0.0668}`
一致。`z_surface_mm=935.000000` = 键合头吸盘面（1053.83 + BS_Arm_Z
→ BS_Arm_Z ≈ −118.83 观测位），`z_focus_mm=935.000036`；按上探头
模型（`reading = mid_up + (z_focus − z_surface)×1000 + noise`，
`confocal.py:17-18`）：350 + 0.036 = 350.036µm ≈ 实测均值
350.0377µm——上探头已对在吸盘面焦面附近，机位正常。

## 5. 误差来源与注意事项

1. **读数噪声主项 = recipe `sim_sensors.confocal_sigma_um`**（默认
   0.05µm/探头，可热改）：3σ 的理论底 ≈ 3σ_noise（n 大时样本 3σ
   向其收敛）；本例 down n=5 得 0.106µm ≈ 3×0.035，量级吻合。
2. **中点共面约定的读数解释**：mean 偏离 `confocal_mid_*_um` 是
   面高/机位系统差（调焦链的事），不散布进 3σ；两者要分开判读。
3. **量程边界效应**：加噪后落回量程内的截断（`confocal.py:227-231`）
   使靠量程边缘的读数分布不对称——机位应让均值工作在量程中段。
4. **valid=False = 失败非剔除**（见 2.4）：验收时若拿到 error 态，
   统计口径上"这次测校没有产出指标"，不允许手工删行重算 3σ。
5. **不动轴 ≠ 无被测面变化**：若作业期间有别的东西动 BS_Arm_Z/
   晶圆（或工艺流程并发），读数会真实反映——本 routine 的 start
   校验不做工艺忙拦截（共焦不动轴，设计上不冲突），但测量期间应
   保持设备无其他操作。
6. **CSV 与作业日志双落账**：CSV 5 列 + 日志 "read:"/"cycle time"
   行一一对应，回归核对用（`extra.confocal_csv` 断言表头，
   `tests/test_metrology.py:1362-1372`）。
