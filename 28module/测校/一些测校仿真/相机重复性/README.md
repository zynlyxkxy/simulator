# D2W 测校离线仿真框架 (simcore 重构版)

每个测校项 = **参数Schema + 误差源组合的声明**。引擎、解析RSS、蒙特卡洛、
误差特征诊断、验收区间推导、报告、GUI 全部复用。

## 文件结构

```
simcore.py                   核心库: 误差源构件/通用引擎/诊断/报告 (仅依赖numpy)
simgui.py                    通用GUI框架 (Schema驱动, 条件可见性, 5个标准标签页)
camera_repeatability_sim.py  相机对准重复性 静态/动态合并版 (FR1/FR2/FR5/FR6)
```

运行: `python camera_repeatability_sim.py` (需 numpy + matplotlib + tkinter)

## 验收判据: 模型推导的验收区间 (不设固定Spec)

运行后状态栏与[验收参考]页给出 **建议验收区间 [MC P2.5, MC P97.5]**,
并与解析RSS交叉校验 (两条独立路径吻合度<1%)。判读:
- 实测3σ 落于区间内 → 设备状态正常
- 高于上限 (建议验收上限取P97.5, 工程裕量可上浮10~20%) → 按诊断页排查
- 低于下限 → 核查测量有效性 (传感器/算法是否真实工作)

n=30~50 时 3σ点估计自身相对波动约10~13% (1σ), 区间判读比点值判读更可靠。

## 静态/动态合并

模式切换 (静态FR1/FR2 / 动态FR5/FR6) 时无关参数自动折叠:
- 静态: 相机+标记+照明+环境 误差源, 帧周期为时间基 (ms级);
- 动态: 在静态全部误差源之上叠加 台到位重复性 / 导轨直线度交叉耦合(按行程缩放) /
  反向间隙(双向到位↔定向逼近可切换) / 稳定残余振荡, 循环周期为时间基 (s级)。
- 漂移类参数以时间计 (nm/min, nm/√min): 同一漂移系数下动态贡献自动放大
  (循环周期≫帧周期), 这是动态验收区间天然宽于静态的物理原因。
- "到位方式"开关可量化定向逼近策略收益 (3σ收窄, 代价为常值偏置→准确度项)。

## 误差源构件 (simcore)

| 构件 | 用途 | 解析σ |
|---|---|---|
| GaussianNoise | 相机离线重复性、台到位重复性 | σ |
| UniformQuantization | 亚像素量化 | h/√3 |
| RandomWalkDrift | 热漂移 (nm/√min) | step·√((n+1)/6) |
| LinearDrift | 预热漂移 (nm/min) | slope·√((n²−1)/12) |
| Vibration | 随机RMS+正弦分量 | √(rms²+A²/2) |
| Backlash | 反向间隙 双向/定向逼近 | h/2 或 仅抖动+偏置 |
| RailStraightness | 导轨直线度交叉耦合 (X行程→Y误差) | 按行程缩放 |
| SettlingResidual | 稳定时间不足残余振荡 | A₀·e^(−t/τ) |
| ConstantBias | 系统偏置 (微旋残差×r、畸变)→准确度项 | 0 (入bias) |

每个构件同时实现 sample() 与 sigma(), 保证 MC 与 RSS 殊途同归。

## 诊断 (为现实排查提供指导)

仿真序列与 **导入的实测CSV** (`idx,x_nm,y_nm` 或 `x_nm,y_nm`) 跑同一套识别:
线性漂移t检验 / lag-1自相关(慢变特征) / FFT周期定位(报出Hz, 周期≈2帧提示间隙交替) /
去趋势奇偶分裂(间隙特征) / 离群点; 每条发现附整改建议;
方差贡献排名给出超区间时的排查优先级; 实测3σ同时报告其在MC分布中的分位。
